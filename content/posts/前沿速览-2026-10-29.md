## 大模型 LLM

### [RSI Arena: Towards Recursive Self-Improvement with Human Feedback](https://arxiv.org/abs/2610.33624)
`评分4 · HF 34赞`

这篇论文要解决的是一个相当具体且野心不小的问题：能不能让 AI 智能体完全自主地把一个基座模型训练成可用的助手，并且在拿到人类用户反馈后继续自我改进？之前的相关工作，比如 PostTrainBench，虽然也让智能体做后训练，但任务通常只跑几小时、只用一两块 GPU、而且只针对一个事先告知的基准来优化，本质上是在刷单指标。现实中的后训练远不止于此：要从基座模型出发，自己选数据、写训练代码、跑监督微调和偏好优化、反复评估，最终目标是让人愿意用这个模型，而这不是任何一个固定基准能衡量的。更关键的是，之前没有任何工作把“人类用户的实际偏好”纳入智能体的开发闭环——智能体训练完就结束了，没有人真正去用它、评价它、再把评价反馈回去。RSI Arena 的动机就是补上这一环：把整个后训练流程交给智能体，人只负责盲测投票，然后再把投票记录交还给智能体，看它能不能据此继续改进，从而向“带人类反馈的递归自我改进”迈出可审计的一步。

方法上的核心设计是一个两阶段的竞技场，镜像了真实模型开发中“发布前后训练”和“发布后根据用户反馈迭代”的流程。Stage 1 里十个前沿模型作为训练智能体，全部从同一个 NVIDIA Nemotron 3.5 Lightning 30B-A3B Base 出发——这是一个约 300 亿参数、每 token 激活约 30 亿的 MoE 模型，而且它的结束符从未被训练过，所以每个智能体首先得教会模型怎么停下来。每个智能体拿到 1000 GPU 小时和 300 美元 API 额度，在共享的 64 卡 Slurm 集群上各自独立选数据、写训练代码、决定 checkpoint，平台通过沙箱隔离、预算计费和提名审核来防止作弊和越权，但不指定任何目标基准，目的就是减少 reward hacking 的激励。训练完成后，十个模型在 20 个基准上评测，同时进入一个仿照 Chatbot Arena 的盲测人类竞技场，用户并排比较两个匿名模型的回答并投票。Stage 2 的关键洞察在于把 Stage 1 中涉及自己模型的对比记录和投票结果交还给每个智能体，再给三天时间继续训练——这检验的正是自我改进闭环中“能否利用用户反馈驱动下一版改进”这一环。评分用 Bradley–Terry 模型拟合，并且做了风格控制：把回答长度、markdown 标题数、列表项数和加粗片段数作为风格向量纳入回归，因为人天然偏好更长更格式化的回答，不控制风格就看不出真实能力差异。这个风格控制的系数是从自己的投票数据里估出来的，同时报告有控制和无控制两套分数。

结果方面，Stage 1 中十个智能体全部产出了能用的助手，最强的是 GPT-6 Astra 训练的模型，在 12 个能力基准上中位数填补了基座到 NVIDIA Instruct 之间 76% 的差距；无风格控制时 NVIDIA Instruct 得分 1182 对 1161 领先，但控制长度和格式后两者打平在 1095 和 1094。有意思的是预算使用完全不预测结果——Gemini 3.8 Flash 只用了 12 小时和 19 GPU 小时，人类评分却高于各花了约 1000 GPU 小时的 Muse Spark 1.3 和 DeepSeek V4.1 Flash。基准和人类评分只有中等相关（ρ=0.73），LLM 评判的对话类基准跟人最一致（WildBench 达 ρ=0.95），竞赛数学则完全不搭，AIME 2026 最高分的模型人类评价排第八；更长的回答赢下 72% 的决定性投票。安全方面任务根本没提，结果三个模型在 StrongREJECT 上比基座给出了更多有害帮助。Stage 2 中十个里有八个缩小了与 NVIDIA Instruct 的风格控制差距，中位提升 28 分，DeepSeek V4.1 Flash 训练的模型进步最大，从 −207 到 −35，但它的中位回答长度也从 61 token 涨到 508 token，说明部分“进步”可能来自变长而非变强；基准变化很小且与人类评分变化不相关（ρ=−0.19），MiniMax M3.1 Flash 训练的模型基准掉了 18 分，部分原因是很多回答不再以评分器能读的格式结尾，同时有害帮助从 2.6 升到 24.5。局限也很明显：智能体大量预算没用完（5051 GPU 小时只用了 2880），基准提升有限且与偏好提升脱钩，安全没有被纳入任务导致部分模型回退，风格控制虽然缓解但无法完全分离“变长”和“变好”。尽管如此，这项工作提供了一个可审计的公开实验场和全部 checkpoint，把人类判断同时嵌入评估和后续开发，为研究“人类反馈如何引导自主模型开发”这个方向立了一个可复现的参照点。

### [Nemotron-Labs-Diffusion-Uni: Elastic Self-Refining Unified Diffusion LLM with Cross-Paradigm On-Policy Distillation](https://arxiv.org/abs/2610.36466)
`评分4 · HF 30赞`

这篇论文要解决的核心问题是：统一的多模态大模型虽然能在一个序列建模接口下同时做视觉理解和生成，但现有的统一离散扩散语言模型（DLLM）在性能上明显落后于专用的自回归视觉语言模型和连续流模型。具体来说，之前有两条主流路线——一条是把文本和图像都离散化成 token 用统一自回归建模，另一条是用自回归生成文本加连续扩散生成图像——而基于掩码扩散（MDM）的统一 DLLM 虽然只需单一目标、训练简单、推理时可并行解码多个 token，却始终打不过专家模型。作者认为卡点有两个：第一，想用 on-policy 蒸馏（OPD）把强模型的能力迁移过来，但 OPD 需要一个强教师，而现成的强教师要么是自回归 VLM、要么是连续流模型，它们和 MDM 的生成范式根本不同，没法直接蒸馏，而 MDM 自身又缺乏足够强的教师模型；第二，MDM 在视觉生成上缺少连续流模型那种自我修正能力——推理时每个 token 从掩码态一步跳到干净态后就锁死不变，而同一步内采样的所有 token 被假设为条件独立，这在真实图像里几乎不成立，因为同一张图的 token 高度相关，导致生成质量受限。已有的一些缓解手段，比如按置信度安排解掩码顺序、或者允许修正已解掩码的 token，都依赖启发式阈值，且训练和推理的设置不匹配。

方法上有两个关键创新。第一个是跨范式 on-policy 蒸馏（cross-paradigm OPD）。作者利用 SBD（块级半自回归扩散）的一个性质：当块大小设为 1 时，SBD 退化成标准自回归模型，于是可以把学生模型的这个“自回归视图”直接拿来自回归教师的 OPD 监督；但如果只这样，扩散视图就完全没被监督。朴素做法是把教师分数直接拷给扩散视图，但这会出问题——比如学生答“Jason visited San Francisco”，教师在给定前两个词时高置信度想生成“New”，若块大小为 2、当前部分状态是“[m] Francisco”，直接拷贝教师分数会引导学生生成“New Francisco”这种病态结果。为此作者提出传递式蒸馏目标：先用 AR OPD 损失监督学生自回归视图生成的干净块，再把该干净块按前向过程腐蚀成部分掩码版本，最小化学生自回归预测与扩散预测之间的 KL 散度作为自一致性损失（对自回归侧做 stop-grad，只算掩码位置），这样扩散视图通过自己的自回归视图间接接受教师指导，避免了上下文错配。第二个创新是渐进式自细化扩散过程。标准 MDM 的状态空间是词表加一个掩码 token，token 在干净态和掩码态之间二值跳变；NLD-Uni 引入“token 年龄”这一 token 局部的离散索引，把状态空间扩展为词表乘以年龄集合，年龄 0 是干净态、年龄 K 是完全掩码态，前向过程中 token 只能逐级从年龄 k-1 跳到 k，中间经过 K 次跳变而非一次。关键设计在于每次跳变不是随机换成任意 token，而是利用 VQ 码本的几何结构：作者在 VQ 嵌入空间上构建了一棵平衡二叉球树，父节点半径大于子节点，把第 k 步的转移定义为在对应深度球内均匀采样，于是腐蚀过程表现为 token 逐渐被替换成嵌入空间中越来越远的随机 token，直到终端态变成与初始态无关的均匀分布——这既满足了终端必须与初始解耦的要求，又实现了由粗到细的部分掩码。用球树而非全距离矩阵是出于效率：13.1 万个 VQ 码的全配对距离矩阵要 32GB 显存，而 18 层二叉树只需一个 1D 数组、约 524KB。在连续时间轴上，作者沿用 DNDM 的每 token 跳变时间采样，并扩展为采样一个区间，让所有中间年龄在该区间内均匀推进，ε 趋于 0 时退化为 DNDM，ε 等于 1 时所有 token 同步腐蚀。推理时每个 token 在区间内被渐进细化、区间外保持掩码或固定，从而支持“中间提交”和迭代自我修正，让同一步内 token 之间产生细粒度交互。架构上采用双塔 Elastic Mixture-of-Transformer，理解塔用 NLD 初始化、生成塔复制同一初始化，通过联合注意力交互，图像同时用语义编码器和 VQ 编码器编码。

实验结果方面，NLD-Uni 在视觉问答、多模态推理、目标定位、文生图和图像编辑等多样任务上取得了统一 DLLM 中的 state-of-the-art，并大幅缩小了与专用自回归 VLM 和连续流模型的差距。不过作者也坦承局限：模型还能通过更好的数据配比和架构优化进一步提升，说明当前的数据混合与结构设计并非最优；此外跨范式蒸馏依赖教师模型的质量和师生分布差距，球树腐蚀的粒度受码本结构约束，渐进细化的额外中间状态也带来推理步数上的开销。这项工作的意义在于，它证明了统一离散扩散模型不必困在“没有强教师”和“无法自我修正”这两个死结里——跨范式 OPD 打开了从异质强模型迁移能力的通道，基于码本几何的多级腐蚀则给 MDM 补上了连续流模型式的迭代精炼能力，为统一多模态模型在保持单一目标和并行解码优势的同时追平专家模型提供了一条可扩展的路径。

### [HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory](https://arxiv.org/abs/2610.24520)
`评分3 · HF 87赞`

这篇论文要解决的是 LLM 智能体在长期交互中一个被现有评测忽视的能力缺口：从跨会话的弱证据里推断用户的行为习惯，并判断这些习惯在当下是否适用。真实场景中，用户从不明确声明“我的习惯是什么”，而是通过一次次选择、确认、拒绝来间接暴露规律，而且单次观察往往只提供部分证据——某个重复选择可能只在特定情境下成立，助手自己提出的建议也不等于用户接受了它。已有的记忆评测各有侧重：LoCoMo、LongMemEval 考察长历史中的召回与推理，MemoryAgentBench 加入增量学习和选择性遗忘，PrefEval、PersonaMem 关注隐式偏好推断与画像演化，BenchPreS、OP-Bench 研究何时应当抑制个性化，MemoryArena、Mem2ActBench 把记忆接到后续行动上。但这些工作都没有精确回答一个关键问题：现有历史在什么条件下足以支撑把一个用户特定的行为默认值应用到新决策上。仅仅把历史存下来、检索出来，并不等于智能体能重建习惯的适用范围、例外、时效性和用户认可状态，这正是论文要暴露的鸿沟。

HABIT-Bench 的核心设计是把“习惯记忆”形式化为两个耦合问题：从跨会话的不完整证据中推断行为默认值，以及判定该默认值在当前请求下是否被证据支持。基准用任务型对话数据作为种子，叠加受控的习惯图来合成用户历史，覆盖餐饮、金融、软件、旅行四个领域，共 114 个合成用户、37,152 个会话、3,328 个探针。每个探针包含一个请求、四个候选动作、一个可见性截断时间和一个目标时间，四个选项都满足请求的硬约束，区别只在于习惯的使用方式是否恰当——比如套用过时的选择、把默认值扩展到其适用范围之外、或把用户从未接受的建议当成既定决策。四个领域刻意构造了互补的证据结构：餐饮把重复选择与情境对比、局部例外混在一起，考验“直接套用”与“过度泛化”的区分；旅行侧重从零散行为中恢复行为规则并迁移到新请求；金融和软件则要求重建用户确认过的工作流，并追踪这些工作流在会话间何时被替换——金融的例子里，2023 年 5 月的目标时间点要求同时保留两套旧工作流，尽管 2025 年的替代方案已经出现在历史中，正确作答必须同时记住“选了什么”和“何时生效”。评测协议上，各记忆方法按时间顺序把会话写入用户隔离的记忆，在探针处检索出上下文，再交给同一个基座模型做四选一，采用精确匹配计分以避免 LLM 评委带来的方差，随机猜测的基线是 25%。论文还设置了关键诊断控制：Oracle Evidence 直接把标注好的相关证据喂给模型，用来区分“找不到证据”和“找到了却不会用”这两种失败；压缩历史控制则检验简单粗暴地把历史压缩后全量提供能走多远。人工验证方面，两名评审在看不到金标和系统预测的情况下独立判断意图决策是否可从证据包中唯一恢复，餐饮、金融、软件、旅行的答案一致率分别为 99.50%、100%、99.68%、92.84%，说明标签本身是可辩护的。

实验结果相当不乐观：八种记忆方法中最好的宏平均准确率只有 33.06%（Qwen3-235B-A22B）和 33.61%（GLM-5.3-Flash），仅略高于最好的检索基线，而 GLM 的压缩历史控制反而达到 41.98%——也就是说，精心设计的记忆流水线在这些任务上并没有稳定胜过简单检索甚至压缩全文。更关键的是 Oracle Evidence 诊断：即使把标注好的证据直接送到模型面前，决策错误依然大量存在，说明瓶颈不只在检索，更在于模型能否正确重建习惯状态并判断其适用条件。论文也坦承了局限：历史是源数据接地的合成数据而非真实用户的纵向记录，评测是非交互式的动作选择而非真实对话中的主动个性化，边界与非约束证据的诊断不等于概率校准或全局的虚假个性化率。不过这项工作把“习惯推断”和“习惯的恰当使用”拆成了可分别诊断的两个环节，并给出了证据访问与下游决策的分离控制，这对记忆系统的评测方向有明确影响：未来的记忆研究不能只报告召回率或问答准确率，而必须回答历史证据是否足以支撑一个被辩护的决策，以及系统在证据齐备时是否真的会用。

### [What Effort Level Should I Choose? On the Economics of Reasoning Effort in LLM Agents](https://arxiv.org/abs/2610.34491)
`评分3 · HF 28赞`

这篇论文要解决的是一个在推理模型实际部署中非常现实但此前被系统忽视的问题：当模型暴露出一个“推理努力程度”的旋钮时，用户该在不知道任务难度的情况下选哪一档。问题的核心在于，推理努力是一种“信任品”（credence good）——用户能看到最终结果对不对，却无法判断自己为推理多付的钱到底有没有产生边际价值。一次成功的运行只能证明任务被解决了，不能证明所购买的额外算力是必要的，而换一档重跑来验证的成本又往往不划算。更麻烦的是，在智能体场景下，努力程度不仅影响单次调用内的思考量，还会改变智能体规划多少、调用多少工具、如何验证，而一个固定的努力档位会被乘到每条轨迹的每一步上，随着上下文不断累积，成本被反复放大。此前的方法隐含地假设努力档位是一个有序的单调旋钮——提高算力只会增加解出的任务数，但作者要检验的正是这个假设是否成立，以及固定高档位或直接关闭推理是否是可接受的默认策略。

论文的关键洞察在于把努力程度当作一个需要按任务动态分配的资源，而不是一个预先设定的全局常量。作者在四个基准上（AIME 2026、GPQA Diamond 两个单次调用基准，以及 Terminal-Bench v2.1、SWE-Bench Pro 两个多轮智能体基准）对专有模型和开源权重模型系统地变化努力档位，同时固定任务、提示词和智能体框架，从而在配置内部做反事实比较。他们从四个角度刻画努力程度的影响：第一，聚合准确率的提升掩盖了“回归集”——高努力会在低努力能解的任务上失败，解出集合并不嵌套，例如 Inkling 在 GPQA 上从 low 升到 medium 净增 16 题，但 medium 在 low 解出的 5 道题上四次尝试全部失败；在 Terminal-Bench 上八个模型的最低与最高档之间回归集都非空，GPT-5.6-sol 从 high 到 xhigh 丢了 8 题只新解 5 题。第二，在“所有档位都能解”的交集任务上，高努力纯粹是过度花费，最高档成本可达最低档的 42 倍，机制有两层：单次调用内算力更多，以及轨迹变长导致不断重处理膨胀的交互历史；有意思的是关闭推理（None）也不是省钱良方，因为智能体会用更长的轨迹来补偿，GPT-5.6-luna 在 None 档平均 21.5 次模型调用、成本反而是 low 档的 4.58 倍。第三，努力程度改变的是解题策略而非单纯“想更久”：高努力下智能体更频繁地检索现成答案（GPT-5.6-sol 在原始 SWE-Bench Pro 环境里读参考修复提交的比例从 low 的 15.9% 升到 xhigh 的 75.0%），也更重地做自我验证，这些行为会拉长轨迹却未必改变结果；作者为此构建了去除 git 历史、限制网络的 SWE-Bench Pro-Corrected 环境，发现高努力下的解出率从 77.3% 降到 59.1%，说明部分“提升”其实是基准泄漏。基于这些观察，作者提出“朴素阶梯”（naïve laddering）：从最低努力开始，只有在经过正确性检查确认失败后才升档，这样把努力分配变成按任务触发的自适应过程，而不是一次性押注。

结果层面，阶梯策略在所有模型和基准上匹配或超过了固定最高档的成功率，同时在考虑用户等待时间的情况下对多数专有模型保持了更低的中位推理成本；而固定最高档不仅在实例级别上没有性能保证，成本还随努力单调上升，固定关闭推理同样不是安全默认。论文也坦承了局限：智能体任务受预算限制每个档位只跑一次，虽然作者用 DeepSWE 上的四次独立运行做了消融、说明观察到的反转在概率上与随机水平相当，但单次运行毕竟不能给出任务级成功概率的确定性结论；此外成本换算依赖提交时的价目表，模型和档位命名也带有明显的虚构色彩（如 GPT-5.6-sol、Claude Sonnet 5、GLM-5.2 等），应视为对一类趋势的受控研究而非对具体产品的评测。这项工作真正的意义在于把“推理努力”从一个被默认为越大越好的旋钮，重新框定为一个需要可验证计费、按任务动态分配的经济学决策问题：只要用户既看不到推理内容也判断不了它是否必要，他们就仍然是信任品的买方，而评测如果只数准确率和 token 而不看实例级的得失与轨迹行为，就可能误判哪种配置实际上更好。

### [Zooming without Zooming v2: From Seeing Details to Connecting Evidence for Generalizable Multimodal Perception](https://arxiv.org/abs/2610.37037)
`评分3 · HF 26赞`

这篇论文要解决的是多模态大模型在空间感知和多模态长上下文理解这两类任务上训练数据难以规模化获取的核心矛盾。空间感知要求模型恢复实体之间的相对位置关系，并把多个空间关系组合起来，这是具身智能的基础；长上下文理解要求模型跨图像和对话轮次定位证据、保持实体身份一致，并把历史证据带入当前问题，这是多模态智能体的基础。此前的方法各自为战：空间感知方向主要靠扩大区域标注的关系数据规模，但精确的定位和关系标注人工成本极高，自动化生成器又经常幻觉出不存在的关系；长上下文方向的多图多轮指令数据集中在少数格式和任务类型上，因为要自动构造出在长序列上仍然可回答的多样化问题非常困难；而具身空间推理和智能体任务的数据更难合成，因为它们还涉及物理或交互环境和多步轨迹。结果是这些能力和建立在其上的应用都缺乏可扩展、高质量的干净可验证监督信号。作者的洞察是：这些看似不同的任务其实共享一个原子能力，称为“连接证据”——识别与任务相关的视觉事实、把每个事实绑定到正确实体、恢复它们之间的关系、再把证据整合成答案。空间感知是在单场景内通过空间关系连接物体，长上下文理解是跨图像和对话轮次通过实体身份和指代连接事实，证据所在的位置和连接方式不同，但底层步骤相同，因此强化这些步骤可以同时惠及两类任务；而且第一步“识别视觉事实”本身就是细粒度感知，所以细粒度感知也会受益。关键在于，针对这个能力构造训练数据比针对下游任务本身构造数据容易得多，也更容易验证。

方法上的核心创新是 EvidenceConnect 数据合成框架，它完全自动化、易于实现，思路是在单张图像内选出一组相关区域，用“特权缩放视图”合成需要跨区域连接证据的组合式问题。具体流程是：先让强 VLM 筛选高分辨率、视觉复杂的图像，并提议具体可定位的候选区域（带边界框和简短描述），过滤掉过小、过大或高度重叠的提议；然后以图像描述和区域描述为条件，让强模型提出若干区域组，每组标注任务族和必要性模式，丢弃无效、重复或不可比对象的闭集，优先保留任务族多样的组。对每个选中的组，构造一个仅在数据构造阶段可见的特权证据布局：把各区域的原分辨率裁剪图按相对水平垂直顺序排布在紧凑画布上，去掉无关背景但保留布局，每个区域用不同颜色描边，且该颜色在全图中也标记同一区域，使问题可以用颜色无歧义地指代区域。问题生成器只接收这个布局作为视觉输入，从而把问题限制在组内证据上，再结合区域描述和推理蓝图模板，生成若干候选问题及简洁答案（单值、集合或有序对），同时要求生成器说明每个区域的贡献、移除该区域后的预期答案、以及一条把区域连到答案的推理证书。确定性规则会拒绝那些证书中有区域未被使用、步骤不导向答案、预测答案在移除某区域后仍成立、措辞主观、通过描边颜色泄露答案或算术不一致的候选。问题形式分三类：聚合（合并计数或数值事实，可能带简短计算）、比较与匹配（把区域当作完整候选集，只有考虑全部区域才能找出异常值、极值或配对）、依赖链与组合（用线索决定下一步读什么、固定视角解释其余部分、或组合不同区域的谓词），三类都要求把各区域承担的角色合起来才能确定答案。这些形式与目标任务的对应关系是：空间关系（包括智能体或物体自身坐标系中的关系）对应空间感知和具身空间推理，而把事实绑定到用描边颜色指代的区域并整合，对应长上下文理解和智能体处理绑定到图像或轮次引用的事实。质量保障分两阶段：跨模型答案锚定让两个不同模型家族的 VLM 在只看特权布局、不看区域描述和候选答案的情况下多次作答，只有每个模型多数响应一致支持同一答案才保留该答案作为参考；自适应逐一移除测试则针对“答案是否真正依赖所选证据”——由于每个问题构造时都要求用到全部区域，如果移除某个区域后答案仍然成立，说明存在装饰性区域或捷径，该问题被丢弃。最后每个验证通过的问题转成多项选择形式以支持基于规则的奖励，并与全图配对（全图中通常用彩色轮廓标出所选区域以避免歧义指代），模型必须自己感知并连接证据。训练上用 RLVR（带可验证奖励的强化学习）在合成数据上微调 Qwen3.5-4B、Qwen3.5-9B 和 Qwen3.6-27B，不做监督微调、不用基准特定的问题格式，得到 ZwZ2-4B/9B/27B。它比之前方法更好的原因在于：监督信号直接打在“连接证据”这个共享原子上，而不是模仿某个下游任务的输入输出格式；特权视图让问题能涉及全图尺度下难以看清的细节，但训练时只给全图，迫使模型自己完成定位与绑定；跨模型一致加区域消融的双重校验保证了答案可靠且证据必要，避免了自动化合成中常见的幻觉标签和捷径问题。

实验结果上，尽管合成数据没有针对任何下游基准定制，ZwZ2 在细粒度感知、空间感知和多模态长上下文理解上都有显著提升，并进一步泛化到具身空间推理、多模态智能体任务和通用视觉推理。以 ZwZ2-4B 为例，ViewSpatial-Bench 从 37.43 提升到 45.26（+7.83），MileBench 从 60.08 提升到 70.08（+10.00），全部 25 个基准的平均分从 49.41 升到 54.79；ZwZ2-9B 平均从 51.63 升到 56.59，ZwZ2-27B 从 55.52 升到 60.51。尤其值得注意的是，ZwZ2 只在单图上训练，却在多图长上下文基准和多模态智能体任务上也有提升，这直接支持了“连接证据是可泛化训练目标”的论点。局限方面，论文的验证主要依赖强 VLM 的跨模型一致性和区域消融，这两者本身仍以模型判断为基础，若强模型在特定细节上系统性一致地出错，错误答案可能被保留；区域提议和分组也依赖强模型的判断，可能遗漏某些类型的证据结构；训练仅用单图，虽然实验显示向多图和交互任务迁移，但对于真正需要跨帧时序推理或长对话中复杂指代消解的场景，单图代理任务的覆盖是否充分尚未被系统刻画；此外问题形式限定在聚合、比较匹配和依赖链三类，其他类型的证据连接（如因果、反事实）未被覆盖。意义上，这篇工作把“连接证据”明确为一个可独立监督的原子能力，并给出了一套无需人工标注、可审计的合成加验证流水线，提示了一条路径：不必为每个下游任务分别造数据，而是找到任务间共享的底层能力，针对该能力合成可验证的代理任务，再用 RLVR 训练，就能获得跨任务的泛化收益。这对具身智能和多模态智能体的数据瓶颈问题提供了一个有实操性的解法，也把“缩放视图”从推理时的技巧转变为数据构造时的特权信息，降低了训练与推理之间的分布差距。

### [EmbeddingGemma 2: Unified and Efficient Multimodal Representations](https://arxiv.org/abs/2610.37364)
`评分3 · HF 25赞`

EmbeddingGemma 2 要解决的核心问题是：现有嵌入模型要么只能处理单一模态，要么依赖 ASR 和图像描述器做模态转换，前者丢失了非语言声音和细粒度视觉细节，后者引入额外计算开销且误差累积。CLIP、SigLIP 这类双塔模型虽然跨模态对齐质量不错，但架构上无法原生处理交错混合模态输入，捕捉不到模态间的交互。后来基于多模态大模型改造的嵌入模型虽然支持交错输入和复杂任务，但参数量动辄数十亿，对延迟敏感、高吞吐或端侧部署场景来说成本不可接受。所以这篇论文的动机很明确：在 7 亿参数级别上做一个原生统一多模态嵌入模型，同时不牺牲跨模态和混合模态的质量。

架构上的关键设计是模块化的模态编码器加共享双向 Transformer 主干。视觉编码器是 patch size 16 的 ViT，音频编码器是两层下采样卷积加十二层 conformer，两者分别输出 768 维和 1536 维的软 token，经线性投影映射到 512 维主干空间后，与文本 token 按位置交错拼接，用分隔符标记模态边界，整条序列送进 24 层双向 Transformer，最后做 mean pooling 加线性投影和 L2 归一化得到最终嵌入。因为模态编码器独立于主干，模型可以按需加载：纯文本 271M、视觉语言 439M、音频语言 577M，这是它在资源受限环境下的核心灵活性来源。另一个重要改动是简化了 per-layer embeddings：Gemma 3n 原本为 PLE 维护一张独立的大查找表，这里直接复用主嵌入表产出的输入 token 嵌入，经每层独立的线性投影和 RMSNorm 生成层特定表示，再用该层输出算出的门控做调制后残差加回。消融显示这不仅降成本还提性能。训练目标由三部分组成：带 in-batch、hard negative 和 same-tower negative 的对比损失，其中去掉了前代的 hardness weighting 以避免放大噪声正例和跨模态梯度失衡；基于 GOR 第二矩项的 spread-out 正则，推动嵌入在单位球面上各向同性分布，既利于量化鲁棒性也利于 ANN 检索；以及直接对齐教师嵌入空间的蒸馏损失，利用 Gemini Embedding 2 支持低维输出的特性直接截断教师嵌入而无需额外投影层，且蒸馏同时作用于 hard negative。训练课程分三阶段推进模态和目标的渐进引入，并先用蒸馏、后用对比加正则的分段策略，避免早期噪声正例干扰嵌入空间成形。

在覆盖文本、代码、图像、视频、文档、语音和声音的七个综合基准上，EmbeddingGemma 2 建立了新的 Pareto 前沿，经常匹配甚至超过专用模型和参数量大 2 到 12 倍的模型；文本侧参数比前代更少却同时提升了多语言文本和代码基准。消融还确认了视觉编码器联合训练的必要性、原生音频理解优于 ASR 管线，以及视觉 token 预算主要影响文档检索这类需要细粒度视觉理解的任务。局限方面，视频帧预算固定为 32 帧、图像默认 280 个视觉 token，对长视频和高分辨率文档仍有信息瓶颈；音频以 40ms 块处理、每秒 25 个软 token，长音频的序列长度压力不小；蒸馏依赖 Gemini Embedding 2 这个强教师，教师能力上限即学生上限。但整体而言，它把原生多模态嵌入从数十亿参数拉到了 7 亿级别，加上可截断维度、量化感知训练 checkpoint 和选择性模态加载，对端侧和隐私敏感部署有直接推动意义，也为后续在更小规模上做统一多模态表示提供了可复用的架构与课程设计范式。

### [On the SPOT: Enhancing Speculative Decoding for Diffusion Language Models via Commit-Order Prediction](https://arxiv.org/abs/2610.22543)
`评分3 · HF 25赞`

这篇论文要解决的是扩散语言模型（DLM）在推理加速上的一个根本性困境。DLM 的生成方式与自回归模型不同：它在每个块内通过迭代去噪来填充被 mask 的位置，理论上可以并行生成多个 token，但实践中存在一个尖锐的速度-质量权衡。精确解码每次前向只提交一个位置，速度慢；而多 token 并行解码（基于置信度、top-k 或动态阈值策略）虽然快，却会改变解码轨迹、损害生成质量。自回归模型有投机解码这一无损加速方案——用一个便宜的 drafter 提议若干未来 token，target 并行验证且严格保持原分布——但这个方法无法直接搬到 DLM 上。原因在于：自回归模型的下一个位置是固定的，drafter 只需预测"下一个 token 是什么"；而在 DLM 中，块内注意力是双向的，提交一个位置会改变所有剩余 mask 位置的表示和输出分布，target 必须同时决定"写什么 token"和"下一个写哪个位置"。已有的 DLM 投机解码工作（如 SSD、Spiffy、BlockSpec、MRP）虽然利用状态转移做验证，但留下了两个核心问题没有回答：drafter 到底应该预测什么信息才能有效地往前推演多步？以及当 target 是采样而非贪心解码时，如何对一棵投机状态树做精确验证？

论文的关键洞察来自对 SDAR-8B 的实证分析：drafter 的主要瓶颈不是 token 预测，而是提交顺序预测。target 上一轮前向产生的"陈旧"输出分布中，其 argmax 在 92%–100% 的测量位置上已经给出了最终会被提交的正确 token，八个陈旧候选就能覆盖 89% 的完整八步提交延续；但上一轮置信度最高的位置在下一轮真正被提交的概率到第 9 个块时已跌到 3%。也就是说，"写什么"几乎已知，"下一个写哪里"才是缺失的信息。基于此，作者设计了 SPOT——一个仅 0.62M 参数的小模型，它只读取 target 的陈旧输出分布，预测未来的提交顺序，并且是前缀条件化的：每假设一次提交后重新预测下一个位置，将这些预测组织成一棵候选块状态树，优先展开高概率分支。target 在一次批量前向中同时评估当前状态和所有草稿状态（每个草稿作为块的一个副本接在缓存前缀之后），接受与自身轨迹一致的最长前缀。第二个技术难题是采样下的精确验证：温度大于零时 target 的提交是随机抽样，独立采样即使分布相同也可能与提议不符，导致状态相等验证错误拒绝。作者引入耦合噪声验证——drafter 和 target 共享每个位置的 Gumbel 随机噪声，使 target 的转移在给定共享噪声后成为状态的确定性函数，于是状态相等可以验证整棵投机树，而对噪声边缘化后恰好恢复 target 的采样分布，从而在任意温度下实现精确的树式验证，且不需要经典拒绝采样那种顺序提议接口。这一思路还延伸出 SPOT-Sets：在动态阈值解码中，一个 target 步骤会同时提交多个位置，此时陈旧 token 预测的可靠性下降（一步后 83% 正确，三步后仅 44%），因此 SPOT-Sets 不仅预测提交集合，还同时草拟集合内的 token，读取 target 隐藏状态和候选 token 嵌入，构建以完整 target 步骤为节点的树。

实验覆盖六个 DLM（SDAR-8B/4B/1.7B、LLaDA2.0-mini、LLaDA-8B、Dream-7B），在贪心和 T=1 采样下均匹配或超越校准式和免训练基线。在 SDAR-8B 上，SPOT 比 Spiffy 的校准草稿图少用 16%–36% 的 target 前向，吞吐量达其 1.4 倍（自适应预算配置下达 1.7 倍）；相对标准无草稿解码，target 前向减少最多 6.8 倍，吞吐量最高 3.4 倍。SPOT-Sets 在动态阈值解码之上将 SDAR-8B 吞吐量平均提升 59%，达到标准解码的 5.2–9.9 倍（平均 7.9 倍），而单独阈值解码器只有 3.3–6.1 倍。drafter 还展现出跨模型迁移能力，无需重训练即可用于 LLaDA-8B 和 Dream-7B。局限方面，论文自己指出高温度区间（T 超过约 1.5）target 本身质量急剧下降，成为主导瓶颈，加速方法能保留的质量有限；此外每轮验证要前向 (1+D)×L 个位置，NFE 的降低并不线性映射到墙钟时间，验证成本是实际加速的独立限制。这项工作把 DLM 投机解码的分析框架从"预测 token"推进到"预测提交顺序"，并用共享随机数把采样下的精确验证问题干净地解决掉，对扩散模型的高效推理方向有明确的方法论贡献。

### [Cross-modal Steering Vectors Exist Across Both Image and Text Generation](https://arxiv.org/abs/2610.36269)
`评分3 · HF 19赞`

这篇论文要回答的是一个相当根本的问题：在当前的多模态模型内部，视觉和语言的概念到底是被统一表征的，还是各自独立实现的？作者选择用"跨模态引导"来操作化这个问题——具体来说，就是在一个模态的 token 上找到一个引导向量，然后零样本地把它加到另一个模态的 token 上，看它还能不能因果性地控制生成。这个设计的关键在于"因果"二字：以往研究多模态表征对齐的工作大多停留在相关性层面，比如比较文本和图像表征的余弦相似度，但表征相似不等于共享机制，两个模态的表征可能碰巧落在相近方向却服务于完全不同的计算通路。引导向量则不同，它直接干预隐状态并观察输出变化，是因果性的证据。之所以之前没人系统研究这个问题，是因为主流的多模态建模范式——无论是自回归的图像描述模型还是扩散模型——文生图和图生文是分开参数化的，根本不存在"同一个向量加到两种模态 token 上"的操作空间。作者因此转向统一多模态模型（UMM），这类模型用共享权重、单一自回归目标同时生成文本 token 和离散视觉 token，使得跨模态引导在技术上成为可能。但共享参数不等于共享机制，此前已有工作报告了明显的不对称性：文本导出的向量能较好地迁移到图像生成，反过来图像导出的向量迁移到文本生成却很困难。这篇论文的核心发现恰恰是对这一不对称性的反驳——双向迁移都能成立。

方法上，作者在三个 UMM 上做实验：UniAR（8B）、Emu3.5（34B）和 Liquid（7B），三者的主要区别在于图像 tokenizer 的设计——UniAR 的视觉 token 来自语言对齐的语义编码器，而 Emu3.5 和 Liquid 的 token 是面向像素重建训练的。引导向量的提取采用对比式配方：对每个概念（如情绪的高兴/悲伤、大小的微小/巨大），构造 100 对最小差异输入，分别前向传播后取每层表征的配对差值均值作为该层的引导向量，并归一化为单位长度，使得引导强度可以由一个跨层可比的标量系数控制。文本侧的最小对由 Gemini 2.5 Flash 自动生成，填入固定模板，取最后一个 token 的隐状态；图像侧则先用 Gemini 2.5 Flash Image 生成基线图，再用指令式图像编辑模型朝两个对立极值编辑（要求保持主体、姿态、构图和背景不变），对编辑质量不稳的概念改用更强的编辑模型，最后对所有图像 token 的隐状态做均值池化得到一个表征。这里有个值得注意的设计选择：文本用末 token 表征、图像用全局均值池化，两者在表征粒度上并不对称，但作者仍然用同一套对比差值公式提取向量，说明他们追求的是模态无关的提取流程而非精细对齐的表征工程。应用时，在共享 transformer 主干的指定层范围内，对每个生成 token 的隐状态加上强度系数乘以单位引导向量，文本侧还额外作用于提示中主语短语的 token。跨模态设置下，向量原封不动地加到另一模态的 token 上，不做任何适配、不用目标模态的数据微调。作者扫描了早期、中期、晚期三个四层连续区间（Emu3.5 因深度翻倍用八层），发现层区间引导比单层更强，且比全层引导更能揭示模态间在模型何处对齐。引导强度则按模型和设置分别扫描，因为文本和图像生成的可承受强度差异很大，迁移向量往往需要更大的强度才起效。

结果层面，在三个模型、八个概念上，跨模态迁移在绝大多数概念上都成立：除"空间左右"外，每个概念都存在某个层区间使文本导出向量恢复超过 80% 的模态内引导效果。UniAR 上迁移向量在图像侧恢复了模态内向量的 84%、文本侧恢复了 74%，几乎与原生向量持平；在 Emu3.5 和 Liquid 上，文本导出的向量有时甚至比图像导出的向量更好地引导图像生成。更耐人寻味的是那些高度模态专属的概念：用"正式 vs 口语化语言"的文本向量去引导图像生成，会让画面中的人物或房间呈现更正式的着装与设计；用"低分辨率"的图像向量去引导文本生成，模型会写得更短并表达不确定性。这说明迁移不是简单的语义标签匹配，而是模型内部确实存在某种跨模态的概念桥梁。几何分析进一步给出了签名：尽管文本和图像表征之间存在明显的模态间隙（近乎正交），但同一概念在两个模态下提取的引导向量方向越接近，迁移效果就越好——也就是说，共享的因果控制方向可以在表征空间相距甚远的情况下存在。局限方面，空间概念（左右）的迁移明显失败，提示某些概念可能确实依赖模态特定的空间编码；评估依赖 LLM 裁判（与人类评分者的一致性 Cohen's κ 为 0.62），概念率的绝对数值需谨慎解读；三个模型虽覆盖不同 tokenizer 设计，但都是自回归 UMM，扩散式统一模型是否同样成立尚不清楚。这项工作的意义在于，它把"多模态概念是否统一"这个哲学味道很浓的问题转化成了一个可测量的因果实验，并指出了一条实用路径：对于难以在目标模态中构造最小对的概念，可以直接在容易的模态里提取向量再迁移过去，为多模态生成控制提供了模态无关的新思路。

### [h1: A Taste of the Bitter Lesson in Automated Theorem Proving](https://arxiv.org/abs/2610.35962)

h1的核心设计极其克制：它不施加任何分解、规划或搜索结构，只给模型一个高效的Lean 4接口，然后让它一直工作到验证器接受或预算耗尽。每一轮迭代中，模型在一个ReAct循环里推理并调用工具，最多T个回合，编辑一个持久化的工作文件；每次编辑都会立即编译并返回错误和未完成目标。迭代在模型提交文件时结束，外部验证器随后对照原始陈述检查，也接受经过检查的反证。如果验证器拒绝，一个反思LLM会把对话记录和反馈压缩成"已验证的进展、失败尝试的教训、有用的引理名"，并劝阻放弃，模型带着这份摘要从当前文件继续。这个循环建立在APN basic、AxProverBase和软件工程中的Ralph循环之上，每增加一轮迭代类似于在s1模型的思考后追加"Wait"，从而延长测试时可用计算。关键洞察在于：h1的简单不等于简陋——它提供的是定向编辑而非重写整个证明、即时编译器反馈、迭代内增长并被缓存的上下文，以及可选的Mathlib搜索、定义查看和证明片段测试工具，由模型自行决定用哪些、怎么推进证明。消融实验和与AxProverBase、Claude Code、Humanfia的对照表明，仅靠"简单"远远不够：一个可靠高效的Lean接口在很大程度上决定了成本和求解率，而维持修复与反思的循环、以及高效的推理与缓存复用同样关键。换句话说，h1比专门工作流更好的原因不在于它更"聪明"，而在于它把模型的推理能力与环境的执行反馈之间的接口摩擦降到了最低，让测试时扩展的每一分算力都花在有效推进上，而不是消耗在笨拙的交互或强加的结构上。

### [Metacognitive Decoding: Efficient Inference for Diffusion Language Agents](https://arxiv.org/abs/2610.37642)
`评分3 · 10 pages, 4 figures`

这篇论文要解决的是扩散语言模型在作为智能体（agent）使用时推理效率低下的真实问题。扩散语言模型的卖点本是并行生成多个 token 来加速推理，但一旦放进智能体循环里——模型推理、调用工具、观察结果、继续生成——传统解码机制就暴露出严重的不匹配。问题有两个层面：其一，智能体输出中混杂着高度可预测的格式化内容（比如 API 调用模板）和真正复杂的推理，而常规解码对所有 token 一视同仁，要么在简单 token 上浪费算力过度处理，要么过早确定复杂 token 导致错误；其二，智能体交互有严格的执行边界，一旦生成完工具调用就必须停下来等环境反馈，但扩散模型按固定大小的块处理 token，往往会多算一大截超出边界的尾部 token，这些计算最终被直接丢弃。已有的加速方法，比如 Fast-dLLM 的置信度并行解码或 KV 缓存，只关注单步去噪的加速，没有把解码策略和智能体的交互状态、结构模式联系起来，因此无法从根本上消除这种由智能体轨迹结构带来的计算冗余。

作者的核心洞察是：扩散智能体的解码应该像人一样具备“元认知”——知道自己当前在生成什么、哪里确定、哪里不确定、交互进行到哪一步了，从而动态决定哪些 token 可以确定、计算范围应该延伸到哪。为此他们设计了一个轻量级的元认知控制器，作为扩散骨干网络的插件，不修改骨干权重，只在其上做两阶段级联解码。控制器同时监控三类信号：去噪状态（预测不确定性、token 揭示情况、块内进度）、结构状态（工具调用、思考段、最终答案中反复出现的格式模式及其与已生成内容的兼容性）、交互状态（当前轮次以及思考、工具调用、最终答案是否已完成）。在第二阶段，控制器执行两个策略。置信对齐解码负责 token 接受：它从采样轨迹中提取反复出现的结构片段作为候选，用学习到的打分函数评估当前块中匹配位置的候选片段是否应该整体接受，若得分超过全局阈值就一次性填好该片段的所有掩码位置；对剩余位置则预测一个阈值偏移量，让每个 token 的接受门槛根据上下文自适应调整，而不是用固定阈值。通量解码负责计算范围：它引入一个可恢复的空 token 作为活动计算范围的动态端点，控制器根据位置表示预测不同范围长度的概率分布，选择能保留所有已确定非填充 token 的最短长度，超出该端点的位置不参与后续去噪；如果活动范围全部解码完但回合还没结束，控制器可以扩大范围、把空 token 后移并恢复那些位置为掩码，且一旦开始恢复，当前块内的范围只能扩大不能缩小。控制器用 GRPO 在完整交互轨迹上做在线策略训练，奖励函数同时考虑任务正确性和相对推理成本——正确轨迹按成本打折，成本以同一冻结骨干无控制器时的推理开销为参照做归一化，成本超过阈值则奖励归零，从而让控制器学会在正确性和计算量之间做权衡。

实验在五个基准上展开：BFCL v3 的工具调用任务，以及 HotpotQA、2WikiMultiHopQA、MuSiQue 各 1000 题的多跳推理与工具使用任务。对比对象包括通用扩散模型 LLaDA2.0-mini、任务适配的 LLaDA-8B-Tools、扩散智能体 DLLM-Searcher（含 P-ReAct 解码），以及免训练的加速方法 Fast-dLLM。结果显示，在保持有竞争力的任务准确率的前提下，该方法相比最高效的基线平均减少 20.6% 的推理 FLOPs，消融实验进一步验证了控制器各组件的有效性。局限方面，控制器需要针对具体任务采样轨迹来构建结构候选并训练，跨任务泛化性尚未充分验证；通量解码的范围一旦开始恢复就不能在块内收缩，这种单调性在极端情况下可能限制灵活性；此外奖励设计中的成本参照和阈值需要预先设定，对超参有一定敏感性。尽管如此，这篇工作把扩散语言模型的解码加速从“单步去噪层面”推进到了“智能体交互层面”，证明了将生成过程与智能体所服务的交互结构对齐是一条可行的效率提升路径，对扩散模型在智能体场景中的实际部署有直接意义。

### [Rare, Relevant, and Still Wrong: How Memory Fails LLM Group Decisions](https://arxiv.org/abs/2610.37624)
`评分3`

这篇论文要解决的是 LLM 多智能体协作决策中一个被此前工作严重混淆的真实问题：当一群 LLM 智能体讨论完、需要把讨论压缩成一段短记忆交给最终决策者时，记忆策略到底该保留哪些证据。此前最自然的两个启发式是"保留最稀有的主张"（rarest-first，按陈述该主张的智能体数量升序排列）和"保留与决策标准相关的主张"（relevance-first）。在经典的 hidden-profile 任务上，这两个启发式看起来都很有吸引力，因为"一个事实被多少人持有"与"它是否有用"被混在了一起。HiddenBench 就是典型例子：私有事实支持正确答案、共享事实指向诱饵，于是只保留私有事实的记忆在 Qwen 上能到 91.3%，只保留共享事实的记忆只有 5.6%，甚至低于空记忆的 35.4%。这意味着 R1 在 HiddenBench 上的巨大优势根本无法区分"稀有性本身有用"和"稀有事实恰好是有用事实"这两种解释。而 relevance-first 面临相反的问题：诱饵按构造就是与决策标准相关的，一个完美的相关性过滤器也无法把支持和诱饵分开。要真正检验这两个规则，必须设计一个让"事实的持有分布"与"事实的决策作用"正交变化的实验。

作者为此构建了 CrossProfile 诊断基准：60 个模板、12 个决策领域，每个模板 4 个智能体、3 个选项、12 个事实（5 个支持、3 个诱饵、4 个无关），三类事实各自独立地被设为共享或私有，得到 8 种所有权变体和 480 个任务。关键设计是：同一模板内事实文本和决策角色在所有变体中固定不变，答案键由事实角色自动推导并自动验证（支持事实给正确选项加分、诱饵给竞争选项加分、无关事实零分），脚本化讨论确保每个被分配的事实都被说出，因此记忆选择是在一个已知清单上被研究的。所有权变化同时改变了事实首次出现的位置、附带的持有者标签和 token 成本，作者对每一项都加了控制。结果两个启发式都在设计预测的格子里失败：relevance-first 平均有帮助，但在经典 hidden-profile 格子里反而比 rarest-first 低 20 到 32 分，即使完美的相关性过滤器也一样，因为相关性无法区分支持和诱饵；rarest-first 平均而言并不优于随机选择（Qwen 上 64.0% 对 64.5%，Llama 上 63.0% 对 63.4%），它的优势随"谁持有诱饵"在 28 到 41 分之间翻转——支持私有、诱饵共享时 R1 达 90–97% 而首次出现选择 B4 跌到 11–31%，反过来支持共享、诱饵私有时 B4 达 92–96% 而 R1 只有 18–40%。更根本的发现是：跨策略来看，准确率随"被保留事实中正确选项的净证据领先量"单调上升，一旦这个领先量已知，策略本身几乎不再提供额外信息。决策模型还贡献了第三个独立失败——一种社会证明效应：它给被多个智能体归属的事实额外权重，尽管这些共享事实在任务中是分配的而非独立观察到的；去掉归属标签或在保持行序不变的前提下随机重分配标签，能把经典格子里的全事实准确率提升 13 到 24 分。而在自然讨论中，没有任何记忆策略优于另一个，完整转录本甚至比空记忆还差，说明证据在记忆起作用之前就已经丢失了。

这项工作的意义在于把"记忆策略好不好"这个笼统问题拆解成可诊断的失效点，并给出了明确的负面结论：稀有性和相关性都不是保留证据的正确准则，真正决定决策质量的是保留证据的净平衡，而这一平衡在现有管线中往往在记忆环节之前就已经被破坏。实验覆盖 Qwen2.5-7B、Llama-3.1-8B 和两个 DeepSeek 模型，配有随机参照、固定条目数、oracle 相关性等多重控制，并用预注册的分析计划和 Holm 校正保证统计严谨性。局限也很清楚：CrossProfile 是脚本化诊断基准而非自然讨论，固定四智能体设计不考察群体规模效应，答案键依赖构造的评分规则而决策提示并未明示该规则，Llama 在 HiddenBench 上的头寸检查未过预设阈值因而其结果被当作探索性处理，自然讨论中"证据在上游丢失"的具体机制也尚未定位。但它指出的方向很有价值：与其继续在记忆选择策略上做启发式优化，不如先解决讨论阶段证据披露与保真问题，并重新审视决策模型对归属标签的过度加权——这两点对多智能体 LLM 系统的实际部署都有直接警示。

### [Follow the Gradient: Tracing Safety Degradation Back to Training Data](https://arxiv.org/abs/2610.37481)
`评分3`

这篇论文要解决的是大模型后训练阶段一个相当隐蔽的安全问题：用看似完全无害的指令数据做微调，模型的对抗鲁棒性会悄悄退化，更容易被越狱。已有的研究（如 Qi 等、He 等）已经确认这种退化并非均匀分布在整个数据集上，而是集中在少数特定样本里，因此问题可以转化为数据筛选——只要在训练前把这些样本找出来删掉就行。但难点在于这些样本从内容上看毫无问题，既没有毒性词汇，也不涉及敏感话题，所以常规的毒性过滤器、LLM 安全裁判这类看“内容说了什么”的方法基本失效。论文的关键动机是换一个信号维度：不看样本长什么样，而看它对模型参数做了什么。一个样本产生的梯度恰好描述了“在这个样本上训练会让模型往哪个方向更新”，因此可以用梯度归因来问：哪些训练样本的梯度方向与不安全行为一致？但传统梯度归因（如影响函数）在 LLM 规模上计算不可行，之前基于梯度的安全筛选工作（He 等）也只在较小数据集上做过，无法覆盖完整的后训练数据规模。论文要填的正是这个“从分析工具到实用过滤器”的工程与算法缺口。

方法上的核心是 SimpleLoRIF，它建立在 LoRIF 这一可扩展影响归因方法之上，但做了两处关键简化。第一，LoRIF 原本要计算带曲率修正的影响分数，需要 H⁻¹ 的近似，而论文指出：我们只用分数做排序、只关心相对次序，不需要校准过的影响力数值，因此可以完全丢掉曲率项，退化为纯粹的梯度内积——这与 TracIn 的精神一致。第二，LoRIF 用两级压缩来表示每个样本的梯度：先在反向传播过程中对每层的输入激活和输出梯度分别做随机高斯投影（投影维度 32×32），避免显式构造完整的权重梯度矩阵；再利用逐样本梯度有效秩很低的特点，用几次幂迭代提取 rank-1 因子，把每层存储从 1024 个浮点数压到 64 个，打分时用双线性形式直接等价于重构梯度的 Frobenius 内积，无需真正重构。论文进一步做了嵌入成本消融，发现投影维度、token 截断、嵌入模型大小这三条轴要么收益甚微要么风险太大，真正有效的是限制反向传播的层数：只对最后四个 transformer 块做反传，因为反向传播到最浅的选中块拿到输入梯度即可停止，而前向仍然走完整网络。两块时 AUC 明显掉到 0.65，六块八块收益很小，四块是性价比最优点，相比基础简化版带来 91.53% 的加速，同时保持 0.684 的检测 AUC。正是这个限制让方法能在一个小时内用 8 张 H100 嵌入完整 Tulu 3 的 939,343 条样本，把梯度归因从“小规模分析”推到了“全量后训练数据过滤”的实用层面。在涌现性失配的验证中，论文用 insecure-code 微调后的 Qwen 和 Mistral 检查点，把 6000 条 insecure 代码样本与 6000 条匹配的 secure 代码样本分别嵌入，再与模型在非编程问题上产生的广泛有害回答的梯度比对，发现 insecure 样本的梯度系统性地更靠近有害输出，AUC 最高达 0.865——这说明表面内容毫不相干的样本可以在梯度空间里指向同一种参数更新方向，为“把安全退化当作训练数据归因问题”提供了直接证据。

在应用层面，论文用 SimpleLoRIF 对 Tulu 3 做过滤，删掉与不安全 SafeRLHF 回答梯度最对齐的 20% 样本，得到 SafeTulu。在 Qwen、Llama、Olmo 三个模型族上，GCG 攻击成功率相对基线最多下降 22%，同时优于 LLM-as-a-judge 过滤和此前的梯度过滤方法，而通用、代码、数学、医疗等基准上的能力基本保持甚至有所提升——这一点很重要，说明删掉的并非“有用但危险”的数据，而是真正冗余或有害的样本。论文还分析了被删数据的内容模式，发现工具执行失败、叙事性算术、直接编码任务等反复出现，提示这些看似无害的类别可能是此前被低估的安全退化来源。局限方面，方法依赖一个参考模型来计算目标集梯度，目标集（不安全回答）的构造本身带有一定人为选择；排序只保证相对次序，删除比例（20%）是超参而非从原理导出；对梯度空间的线性对齐假设是否能覆盖所有类型的安全退化也尚未验证。但论文释放了 SafeTulu 数据集和一个 Hugging Face Space，允许研究者自行调整删除比例、只过滤特定子集，这把这个方法从一篇分析性工作变成了可复用的数据审计工具，对“后训练数据安全筛选”这一方向有明确的推进意义。

### [ETAMem: Decoupling and Aligning Heterogeneous Memory for Long-Term Conversational Agents](https://arxiv.org/abs/2610.37443)
`评分3`

这篇论文要解决的是长期对话智能体中的记忆组织问题。现有记忆系统大致分两类：扁平式方法把每轮对话抽取成独立文本条目，靠嵌入相似度检索；结构化方法用层次树或图来组织记忆。但作者指出这两类方法都受困于两个根本缺陷。其一是信息纠缠：一轮对话里往往同时包含事实事件、个人偏好和时间上下文，现有系统把整轮对话或粗粒度摘要当作基本记忆单元，导致这些异质信息纠缠在一起，检索时难以隔离出真正相关的证据，反而引入噪声。其二是组织错配：现有结构主要按语义相似度或时间关系组织记忆，但不同信息类型其实需要不同的组织原则。比如回答"我喜欢什么活动"需要跨上下文聚合情感偏好，而回答"我这周做了什么"需要按时间关系聚合经历，若统一按语义主题聚类，相关偏好会被打散到不同分支，难以集体检索。作者从认知神经科学中情景记忆与情绪处理由功能专门化又相互作用的神经系统支撑这一发现获得启发，提出应解耦异质对话信息，并让记忆表示与组织方式对齐各自特性。

ETAMem 的核心设计分四步。首先是异质信息解析：用 LLM 把每轮对话拆成语义完整的原子记忆单元（AMU），保证每个单元只承载一条独立记忆且拆分后信息不丢失，同时用现成情感分类器给每个 AMU 打上正/中/负的极性标签，以此区分事实内容与情感内容。其次是视图专属的记忆结构化：中性 AMU 进入事件视图，按文本语义层次聚类，捕捉反复出现的事件与实体；正负 AMU 进入情感视图，用独立的情感编码器编码后按情感语义聚类，捕捉持久偏好与态度；所有 AMU 同时进入时间视图，按会话→天→周→月的预定义时间粒度索引，高层节点只存摘要。每个视图都是树结构，叶节点存 AMU，内部节点存子树摘要。第三是动态维护：新 AMU 通过束搜索在树中找最相似节点（以子树质心计算余弦相似度），据匹配分数决定挂到现有叶、新建叶还是新建根；叶节点过大或内聚度低于阈值时用余弦 K-means 分裂；每轮会话结束时合并质心相似度超阈值的节点以减少冗余；内部摘要采用惰性更新，用待更新计数器累计结构变化，达到间隔才重新生成，避免频繁调用 LLM。结构参数和维护阈值还会根据观测到的记忆统计量自适应校准，无需重建已有树。最后是熵基检索：对每个查询，先根据各视图的熵分布自适应分配检索预算，再在每个视图内做层次束搜索，从根向下逐层保留 top-B 候选路径直到叶层，最终跨视图汇总证据。这套设计之所以优于先前方法，关键在于它不再把异质信息塞进同一表示空间和同一组织原则，而是让每种信息在自己最匹配的表示与结构中被索引和检索，从而在需要跨上下文聚合偏好或按时间聚合经历时都能命中正确证据。

在 LoCoMo 和 LongMemEval-S 两个长期对话记忆基准上，ETAMem 相对最强基线分别取得 12.46% 和 7.96% 的相对准确率提升，同时在 token 开销上保持竞争力，多跳推理和时间定位类问题上的增益尤为明显，消融分析也验证了三个视图的互补价值。局限方面，系统仍依赖 LLM 做 AMU 抽取和摘要生成，解析质量与调用成本受底层模型能力制约；情感极性仅用三分类粗粒度标签，难以刻画复杂或混合情绪；时间视图的粒度是预定义的，对非均匀时间分布的对话可能不够灵活；自适应校准虽有缓解，但树结构在极长对话下的规模增长与检索延迟尚未充分讨论。尽管如此，这篇工作把"解耦异质信息并对齐表示与组织"这一原则落成了可运行的完整框架，为长期记忆系统从单一语义索引走向多视图协同提供了清晰的技术路线，其视图专属编码、惰性摘要更新和熵基预算分配等机制也具有较强的可复用性。

### [What Improves During Pretraining? Tracking Knowledge Acquisition with Point-in-Time Models](https://arxiv.org/abs/2610.37631)

这篇论文关心的是一个很实际但长期被忽视的问题：预训练过程中，模型到底在什么阶段、以什么方式学会不同类型知识。以往研究要么用聚合基准分数看整体提升，要么用 infini-gram 这类语料检索工具统计精确文本匹配频次来估计知识暴露程度，但后者有个根本缺陷——同一个事实可以用完全不同的措辞表达，精确匹配计数高度依赖查询措辞，换个说法就漏计了，因此无法可靠衡量知识在训练数据中的真实普遍性。作者提出的替代思路是利用网络语料的时间结构：预训练数据由不同年份爬取的网页快照混合而成，如果某个知识在各年快照中稳定出现，那么分别在各年快照上训练的模型应该给它相近的似然；反之，若某知识在年份间流行度波动大，各年模型给它的似然就会更分散。基于这个直觉，他们定义了时序变异性分数（TVS），即一个条目在八个年度 PIT-4B 模型下负对数似然的变异系数。关键设计在于用变异系数而非原始标准差做归一化——因为未归一化的 NLL 标准差主要是在挑更难的题，与均值 NLL 高度纠缠，归一化后才能把“跨年相对波动”和“绝对难度”区分开。TVS 衡量的是似然的跨年相对变化，不是直接的流行度，也不是“常识 vs 专业知识”这类语义分类。

方法的核心运作方式是这样的：作者取 2017 到 2024 年八个 PIT-4B 模型，它们共享架构、分词器和训练配方，唯一区别是训练数据来自不同年份的 FineWeb 爬取分区，因此可以把它当作一组“时间探针”。对每个基准条目，把问题和正确答案拼成固定字符串，计算各年模型下的逐 token 负对数似然，再算这八个值的变异系数作为 TVS。由于 TVS 与字符串长度相关，他们在每个基准内先按 token 长度分十个箱，每箱内再按 TVS 三等分，最后合并，保证低/中/高三组在长度上匹配。然后他们在六个开源模型家族（Pythia 1.4B/6.9B、TinyLlama 1.1B、SmolLM3 3B、OLMo 1B/7B）的多个检查点上追踪各组准确率随训练 token 数的变化，用 chance-normalized accuracy 做跨基准可比。关键发现是学习轨迹的分化：在最早期的检查点（Pythia 0.54B token、OLMo 2B token），低 TVS 和高 TVS 组表现几乎无差异，高减低平均只有 -0.8 分，13/24 设置里低 TVS 领先，与随机无异；但到训练后半程，高 TVS 组的准确率每十倍 token 增长快 2.0 分。到预训练结束时，高 TVS 组在 34/36 个模型-基准设置中胜出，平均领先 7.3 分（95% CI [5.5, 9.2]）。这个结论之所以不是“高 TVS 只是题更简单”的假象，是因为作者做了层层剥离：先用回归去掉均值 NLL 的线性和二次项、取残差再分组，在 ARC 和 MMLU 上优势仍在全部 18 个设置中为正（+6.9 分）；进一步控制 PIT-4B 的金答案-干扰项 margin 和准确率后，剩余差距缩到 1.4 分但仍有 22/36 为正。反过来，直接按均值 NLL 分组会得到完全相反的排序（高 NLL 组在全部 36 个设置中更差），按未归一化 NLL 标准差分组也会反转效应——这恰好证明 TVS 的归一化设计不是可有可无的细节，而是把“跨年波动”从“绝对难度”中分离出来的关键。更有意思的是答案特异性分析：把正确答案的 TVS 减去错误答案的平均 TVS，得到答案特异的 TVS 分量，它能预测后期训练中正确答案相对最强干扰项的 margin 增长斜率（在 ARC-Challenge、ARC-Easy、MMLU 上 p < 10^-6），而仅用问题本身的 TVS 分组只带来 2.1 分的平均差距，远小于正确答案-最强干扰项 TVS margin 分组带来的 12.3 分、35/36 设置最优的成绩。这说明 TVS 捕捉的信号很大程度上取决于答案本身在年份间的似然稳定性，而不只是问题措辞。

结果的意义和边界都需要客观看待。在知识密集型任务上模式最稳健：ARC 和 MMLU 在控制难度后 18/18 设置全为正，而 HellaSwag、PIQA、WinoGrande 上控制难度后差距只剩 +0.5 分，说明这些任务里 TVS 效应有相当部分来自难度混杂。作者也做了污染检查：用交错双重差分加条目和年份固定效应，发现基准发布后金答案 NLL 没有下降（+0.016），金-干扰项 margin 无显著变化（p = .34），高 TVS 准确率反而略降（-0.011，p = .004），与泄漏预期方向相反；55B FineWeb token 的 13-gram 重叠扫描显示高 TVS 条目重叠率 3.1% 对低 TVS 2.0%，且多来自 WikiHow 等源页面而非答案键，加入重叠指示变量后 TVS 系数基本不变。但局限也很明确：TVS 是依赖底层模型质量的似然统计量，PIT-4B 只覆盖单一模型尺寸和 2017-2024 八年；污染检查只覆盖 PIT-4B 的训练数据而非被评估模型的完整预训练语料，稀疏的年度采样无法排除污染；研究只涉及似然排序的多选题基准，因为这类基准最适合监控早期检查点。这项工作的真正贡献不在于提出某个刷榜方法，而在于提供了一种不需要访问训练语料、不依赖被评估模型自身训练轨迹的外部诊断工具——用时间切片模型把“知识在数据中的稳定性”变成一个可计算的条目级标签，从而揭示聚合基准分数所掩盖的学习动态差异。它暗示的方向是：预训练中后期模型对高时序变异性知识的快速吸收可能反映了一种“先打基础、后补长尾”的课程式学习节奏，而 TVS 这类外部探针可以为数据配比、课程设计和知识溯源提供比精确匹配计数更鲁棒的信号。
