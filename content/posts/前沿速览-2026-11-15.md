## 大模型 LLM

### [ArchSpace: Recording, Reviewing, and Referencing LLM Architecture Research](https://arxiv.org/abs/2611.17332)
`评分3`

这篇论文要解决的是一个在LLM架构研究中长期存在但很少被正面处理的信息不对称问题。工业界（DeepSeek、Qwen、Kimi等团队）在发布新模型时 routinely 引入架构创新，但公开报告几乎从不记录哪些设计成功了、哪些被放弃了、以及背后的权衡是什么——这些实验和决策过程对社区完全不可见。学术界虽然贡献了大约三分之一的架构相关论文，但根据作者的调查，这些工作获得的引用不到总量的10%。造成这种局面的核心原因有两个：一是学术界算力有限，通常只能在较小规模上做单点对比，无法验证一个改进在更大算力预算下是否仍然成立、是否能转化为更广泛的影响；二是缺乏统一、可复现的基线，不同论文的实验设置各异，导致结果难以横向比较。换句话说，社区缺少的不是新想法，而是一个能系统性地记录、审查和引用架构验证过程的公共基础设施——让一个想法从提出到验证的完整推理链条（包括失败的尝试）都能被后来者追溯和复用。

ArchSpace的核心设计围绕“记录—审查—引用”三个环节展开，但真正让它区别于普通论文仓库的是其两阶段验证框架。第一阶段用缩放定律在五个算力预算（从1e18到1e20 FLOPs）上拟合每个架构的compute-optimal loss曲线，判断其是否落在Pareto前沿上——这意味着不是看单点胜负，而是看整个算力-损失趋势是否系统性优于基线。具体操作上，框架提供了三档设置：最省算力的设置一直接复用基线的最优超参（模型规模、token数、学习率、batch size），只训练五个点来拟合幂律；设置二在固定算力下对模型规模和训练token数做IsoFLOP扫描，但沿用基线的学习率和batch size；设置三则在此基础上额外扫描学习率和batch size，拟合一个更完整的缩放定律，其中loss被分解为两部分——基础曲面（模型规模与token数的耦合幂律，带有一个交互指数来刻画两者的非独立效应）和LR-BS偏离项（用两个cosh函数在log空间建模，分别捕捉学习率偏离最优值和batch size偏离最优值带来的损失增量）。这个分解的关键洞察在于：它允许从任意batch size反推出最优学习率（两者在log空间呈幂律关系），从而在有限实验预算下获得更多信息。第二阶段则用1B参数模型在150B token上预训练（8K上下文）再加10B token长上下文中间训练（64K），检验缩放阶梯上观察到的增益是否在更长训练和下游任务上持续存在。整个框架用OLMo 3的tokenizer和Dolma 3数据池固定数据侧变量，确保架构差异是唯一变量。

在结果层面，论文提供了Qwen3.5（Gated DeltaNet与全注意力3:1交错）和OLMo3（滑动窗口注意力与全注意力3:1交错）两套基线阶梯的完整缩放定律拟合，包括耦合形式与加性形式的消融对比，以及外推验证——即在更大算力预算上测试拟合定律的预测能力。这些基线本身构成了平台的首批“参考坐标”，后续提交的架构提案可以直接与之对比。论文的局限也很明显：目前只覆盖了混合注意力这一主流架构方向的两条基线，1B规模的Phase II验证虽然比单点小规模实验更有说服力，但距离工业级大模型仍有数量级差距；社区审查机制的有效性依赖于参与者的规模和专业度，冷启动阶段可能面临提交量不足的问题；此外，缩放定律拟合本身对超参搜索范围和数据分布敏感，不同架构的最优超参曲面形状可能差异很大，设置一和设置二的“复用基线超参”策略在架构改动较大时可能引入偏差。尽管如此，ArchSpace的方向性意义在于它试图把“架构验证”从一次性论文贡献转变为可持续积累的公共知识——每个经过审查的PR成为新基线，后续工作可以链接到前序提案，形成可追溯的架构演化图谱。如果这个社区能运转起来，它可能改变学术界在算力劣势下参与架构创新的方式：不是比拼单次训练规模，而是通过标准化验证和累积性引用获得可见度。

### [CoReMem: Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation](https://arxiv.org/abs/2611.17316)
`评分3`

这篇论文要解决的是“连续编码任务”场景下的记忆设计问题：在一个持续演化的代码仓库上，任务一个接一个到来，每个任务继承前一个任务留下的仓库状态，但未来任务的内容在写记忆时是未知的。现有记忆方法在这个设定下并不可靠——任务内方法（如上下文压缩）优化的是已知当前任务的目标，跨任务方法大多在独立任务和独立仓库之间迁移通用经验，而MemOp虽然在同仓库上累积记忆，却在任务间重置仓库状态，因此它衡量记忆价值时用的是“产生记忆的那个任务”上的收益，而不是“继承已改动仓库的未知未来任务”上的收益。作者在ChainSWE上实测了完整历史、Mem0的事实、MemOp的指南和ReasoningBank的策略，发现没有任何一种现有形式能同时降低下一步任务的步数和总token数：有的用更多token换来解决率，有的记忆模块开销比它省下的还多。于是两个核心挑战浮现：第一，在不知道未来任务的情况下，凭什么判断哪些信息值得跨任务边界携带；第二，即使写对了记忆，actor模型本身并不会天然地去读它、用它，因为模型是按“从零解题”训练的，可能忽略有用的记忆，也可能盲从不适用的记忆，而记忆是否适用只有在任务展开过程中才逐渐明朗。

方法上的关键洞察是把“记忆的价值”定义为它在下一个未见任务上造成的可测量差异，并让这个测量同时决定记忆长什么样、以及模型怎么学会用它。作者提出“前瞻性分段估值”：把当前任务的完整轨迹按角色切成七类片段（推理文本、命令、环境观察、测试输出、diff、结果等），然后在下一个任务的边界上做配对实验——用整条轨迹当记忆跑一遍，再逐段移除某一段跑一遍，比较步数和token的中位数变化，并用置换检验校正，保留那些“移除后会让下一步任务多花步数”的片段，丢掉只增加token而不省步数的片段。测量结果很有指向性：命令和仓库内容（读哪些文件）移除后步数上升，而推理叙述和diff正文移除后步数不变却省token；测试命令加退出码比完整测试输出更省步数，diff的文件列表也接近完整diff的效果。由此他们归纳出记忆应以“锚点”为核心——锚点是对仓库具体位置（文件路径加行号、代码符号名）或可执行检查（运行/测试命令、测试标识符）的引用，未来任务可以直接据此行动。最终的记忆模板把命令和仓库内容作为主字段，测试输出、diff和结果做压缩，丢掉推理文本和临时文件，用约6%的字节保住了整条轨迹带来的步数节省中位数。这个设计之所以比之前的方法更靠谱，是因为它不是在猜“什么信息有用”，而是用下一步任务的真实配对rollout去测量每一段的边际贡献，并且测量对象是继承改动后仓库的未知任务，而不是产生记忆的那个任务。

在让actor学会用记忆这一侧，作者设计了“成本内化”的on-policy训练：在每个训练边界上，用当前策略从同一仓库状态出发，成组地rollout三类会话——不带记忆的、带本边界记忆的、以及带一个“形式正确但内容来自别的仓库”的错位记忆的。奖励函数把解决率放在最高优先级，任何解决了的会话都排在未解决会话之上，步数惩罚只在成功内部生效，这样既不会为了省步数而放弃解题，也让记忆为它增加的步数付费、为它省下的步数和赢得的解决付费。组内相对优势以无记忆会话为基准计算，带记忆会话的总信用被拆成两部分：一部分是普通的结局信用，按GRPO方式发给每一步，训练模型用更少步数解题；另一部分是记忆价值信用，等于带记忆组与无记忆组的平均奖励差，它估计的正是前瞻价值在当前策略下的on-policy版本，且每次访问都免费测得。关键的一步是“来源门控”：只有那些被判定为“所操作的内容来自记忆锚点”的步骤才额外获得这份价值信用，其余步骤只保留结局信用。作者还给出分析，说明如果把同样的价值平均发给所有步骤，这份推动就会消失，因此门控是必要的。这样一来，记忆的使用不是靠提示词鼓励，而是靠测量出的价值直接反传到真正用到记忆的那几步上，同时错位记忆的会话会因为结局差而被惩罚，迫使模型学会判断记忆是否适用，而不是盲从或无视。

实验结果上，在连续任务基准ChainSWE上，CoReMem把27B actor的解决率从21.0%提升到25.7%，同时步数减少17%、含记忆模块调用在内的总cache-aware token减少11%，对比对象是不带记忆的未训练actor模型；跨三个不同actor模型平均，每token解决率相对无记忆提升41%。这些数字的意义在于它同时压低了步数和总token，而现有方法没有一个能落入这个象限。局限方面，论文的估值流程依赖在下一个任务上做配对rollout，虽然训练时这些rollout本来就要跑、边际成本可控，但在纯推理部署阶段若要在线估值仍有开销；分段划分和锚点抽取目前是针对编码任务手工定义的七类和两类锚点，迁移到其他领域需要重新设计；错位记忆只取了一个样本，对“记忆适用性判断”的覆盖可能有限；此外实验集中在27B量级和ChainSWE这一个连续任务基准上，更大规模模型、更长任务链以及记忆跨多个任务累积时的衰减行为还没有充分验证。尽管如此，这篇工作的方向性影响比较清晰：它把记忆从“存什么、检索什么”的启发式设计，推进到“用未来任务的实测价值来反向定义记忆形式和训练信号”的闭环，锚点作为可追溯的中间表示也让记忆的使用变得可归因，这为后续在持续演化环境中的agent记忆研究提供了一个可测量、可优化的框架。

### [Sketching Language Models for Context Attribution](https://arxiv.org/abs/2611.17313)
`评分3`

这篇论文要解决的是上下文归因（context attribution）中的核心问题：给定一个由 n 个 token 组成的提示，如何量化每个 token 对模型输出的贡献。最直接的定义是留一法（leave-one-out, LOO）——把第 i 个 token 从提示中去掉后，测量函数 φ（比如模型生成目标回答的对数概率）会变化多少。精确计算全部 n 个 LOO 值显然需要 n 次模型前向评估，对长上下文来说代价不可接受。已有的实用方法——稀疏代理模型拟合、梯度显著性、KV 缓存加速的启发式估计——虽然跑得快，但都没有形式化的精度保证，而且在上下文片段之间存在非线性交互、或者局部线性化低估删除效应时可能失效。论文的目标是在一个可证明的结构性假设下，用远少于 n 次的评估调用把所有 LOO 值同时估计到误差 ε 以内。

核心洞察在于把问题转化为对算术电路（模型计算图）的泰勒系数进行草图（sketching）。论文假设测量函数 φ 满足“稳定性”：其在原点附近的各阶泰勒系数张量的 Frobenius 范数随阶数 r 以 α(B)/B^r 的速度衰减，B>2 时截断到 O(log(1/ε)) 阶只引入 ε 级误差。直接对 φ 做前向微分草图（沿随机高斯方向 g 计算各阶方向导数 T^(r)[g^⊗r]）可以同时得到所有阶的投影，但方差较大，需要 Õ(log n/ε²) 次评估。论文的关键改进是：不对 φ 本身做前向草图，而是先通过反向传播构造梯度电路 ∇φ，再对这个梯度电路做前向微分。由于反向传播只带来常数倍电路膨胀，对 ∇φ 做草图的单次开销与对 φ 做草图同阶，但此时草图对应的是张量的“切片” T^(r)[e_i, ·] 而非整个张量——也就是说，随机性只作用在除第一个指标以外的维度上，第一个指标被固定为具体的 token 坐标。这大幅降低了估计量的方差：总误差按张量范数缩放而非按最大分量缩放。配合对每个 (i, r) 组合使用截尾均值（trimmed mean）来应对重尾分布，算法只需 O(√(log(1/ε))/ε) 次评估调用就能以常数概率把所有 LOO 值估到 ε 误差，且草图数量与 token 数 n 无关。论文还证明了匹配的下界：在 oracle 模型下，任何达到 ε 误差的算法至少需要 Ω(√(log(1/ε))/ε) 次调用，说明该上界在阶数意义下是最优的。剩余的高误差查询（至多 O(1/ε) 个）再逐一精确评估，总时间仍可控。

实验部分在 Llama-3.2-1B 上验证了两件事：一是稳定性假设在现代语言模型上确实成立——泰勒系数的衰减行为与理论预测一致；二是在一个小规模检索任务上，草图算法能准确估计 LOO 值。与直接改编 Gunn 的前向草图方案（需 Õ(log n/ε²) 次调用）相比，本方法把调用数从对数依赖 n 降到与 n 无关，提升因子为 log(n)/ε。局限也很明显：稳定性是一个较强的假设，并非所有 downweight 实现都满足——论文用注意力分数的连续掩码来实现 downweight 并观察到与 Transformer 兼容，但这只是经验性的；此外理论保证是常数概率下的逐点误差界，并非对所有查询同时成立的最坏情况保证，高误差查询靠额外精确评估兜底，最坏情况下仍需 O(1/ε) 次精确前向。尽管如此，这篇工作把上下文归因从纯启发式推进到了有查询复杂度上下界保证的算法层面，并且展示了“对反向传播电路做前向草图”这一技巧可以同时降低方差和调用复杂度，对训练数据归因等相关方向也有直接的借鉴意义。

### [Classical Energies Learn to Reason 1,000x Faster than Looped Models](https://arxiv.org/abs/2611.17309)
`评分3`

这篇论文瞄准的是"用循环模型做推理"这一范式的根本性低效问题。以HRM、TRM为代表的循环推理模型在Sudoku-Extreme、Maze-Unique这类约束谜题上确实能刷出很高的准确率，但它们代价惊人：训练要靠截断的BPTT把梯度穿过整条推理轨迹，既慢又不稳定，而且参数量和推理FLOPs都远超任务本身所需。更尴尬的是，这些模型为什么能成功，社区其实说不清楚。作者指出了一个被忽视的对照：能量最小化本来就是循环的" principled 版本"——每一次循环不过是能量函数上的一步梯度下降，天然保证稳定性、天然有早停判据、天然不需要BPTT。而现有的循环推理器其实是在一件件地把能量网络的好处"打补丁"式地加回来：有的训练更新收敛到不动点，有的外挂一个halting网络学停止，但每一样都要额外的头、额外的损失、额外的模块，而且仍然靠对反复应用做反向传播来训练。既然这些理想性质都是能量本来就有的，作者反问：为什么不直接学一个能量？Hopfield和Tank在80年代就手工设计过能解约束问题的能量，但"能否从数据中学出显式能量来解一大类推理问题"一直没被认真回答。

CRAM的核心是把Hopfield-Tank能量做成可训练版本，并配上推理时下降它的循环动力学。具体来说，它把每个格子i的信念建模为对C个候选值的softmax分布，能量由三部分组成：格子对之间的可学习代价矩阵（刻画两个格子取某对值的相容成本）、每个格子的偏置向量（刻画单个格子取某值的成本），以及一个熵项；当信念是one-hot时熵为零，能量就退化为所选值对的代价之和，这本质上是mean-field自由能，是连续Hopfield网络向C状态神经元的推广。推理时把谜题给定的线索固定，对其余格子的无约束神经元状态做梯度下降，由于softmax单调，对信念求梯度再更新logits仍保证收敛到同一不动点；取步长为1时，每次迭代恰好就是循环模型里的一层递归。连续时间下能量单调不增，但纯确定性下降会卡在局部极小，所以实验中改用focused Gibbs search，按格子的局部能量优先更新，用随机性跳出局部解。早停也很自然：要么棋盘能量低于从训练解拟合出的阈值，要么任何单格改动都无法再降低能量。训练则完全绕开对relaxation求导——这是相对BPTT最大的成本优势——主用pseudolikelihood目标，压低观测解的能量、抬高模型自己偏好的负样本能量，权重从零初始化，用带动量的SGD加余弦调度训练，谜题的结构先验以共享权重或数字重标记的方式注入，全程不告诉能量任何谜题规则。

结果相当有冲击力：在Sudoku-Extreme上CRAM解出99.996%的测试题，Maze-Unique上100%，而最强的循环基线TRMP分别是99.87%和99.23%；训练时间在单张GPU上分别只要42毫秒和132毫秒，比循环模型快至少1000倍。推理侧，在10000道Sudoku-Extreme上扫描各方法的推理预算后，CRAM达到EBR最高准确率（99.86%）只需每題约1.9×10⁹ FLOPs，而EBR要5.4×10¹¹，少了282倍；对EqR更是少了约128000倍。它还是数据高效的，用少一个数量级的训练谜题就能学出可解释的权重——这些权重可以直接读成谜题的约束规则；甚至手工设定、最多只有三个不同权重的CRAM能量就能精确解出所有基准的全部测试题。局限也很坦率：作者明确警告，Sudoku和Maze这类"轻易可解"的基准上的高准确率并不能预示在更难任务上的表现，CRAM这种简单能量单独面对ARC-AGI这类复杂推理会吃力，论文只在附录里展示了一个简单的隐变量扩展能近乎完美地解Maze-Hard。真正的意义在于两点：能量路线在从数据训练推理这件事上极有前景，以及社区不该再用这些trivially solvable的基准去检验循环推理技术的可扩展性。

### [LiveGeo: Benchmarking Geographic Agents in Continuously Evolving Worlds](https://arxiv.org/abs/2611.17267)
`评分3`

这篇论文要解决的是地理智能体评测中一个被长期忽视的真实问题：现有基准几乎都在"冻结的世界"里考察智能体。无论是早期的地理知识问答、空间推理，还是后来的城市模拟、行程规划基准，任务相关的地理状态在执行过程中基本保持不变——即便有些工作引入了动态性，也往往是围绕某个特定城市过程或预先设定好、直接暴露给智能体的扰动（比如"前方道路封闭"这种明示事件）。但真实世界的地理环境是持续、独立于智能体自行演化的：路况会变、店铺会关门、区域性事件会发生，而且只有一部分变化与当前任务相关。这就带来一个更本质的可靠性要求——智能体不仅要基于当下信息做决策，还要主动获取任务相关证据、验证先前决策所依赖的证据是否仍然有效，并在失效时修正计划。更麻烦的是，现有基准大多只测"端到端任务能否完成"，而不测智能体究竟依赖了哪些地理约束和决策依赖关系，导致失败难以归因：到底是地理理解不行、可行性评估不行，还是无法随时间维持决策有效性？论文正是围绕"智能体能否在持续演化的地理环境中保持决策与有效证据的一致性"这一核心问题展开。

方法上的关键创新可以拆成两层。第一层是环境平台 GeoWorld：它把世界状态建模为"稳定地理结构加动态条件"的组合——前者包括地点、道路、区域及其空间关系，后者包括交通、天气、地点营业状态、区域事件，并且所有状态都绑定到同一套地理实体和空间参照上，而不是各自为政的独立数据源。平台用一个全局虚拟时钟驱动异构状态更新，每个变化都有生效时间和可选的持续时间，且这些变化对智能体行为是外生的，世界按预设轨迹自行演化，从而既保证可复现、可回放，又让智能体在执行中真实遭遇变化。对外，GeoWorld 提供统一工具接口（地点搜索、路径与交通、天气、营业状态、区域事件），所有工具返回都按当前虚拟时刻的世界状态解析，保证跨服务观察在时空上一致，并完整记录查询、观察、动作及其时间戳和状态引用，为事后重建执行过程、评估行为提供依据。第二层是基准 LiveGeo：它按"地理能力×时间设定"组织任务，能力维度上分三个原子任务（Grounding 定位实体、Discovery 按空间/语义/情境约束选点、Mobility Planning 在交通约束下构造可行路线）和四个组合任务（多实体协同、长程依赖、安全感知、区域感知），时间维度上为部分任务构造"匹配的静态—动态对"：两者共享同一初始世界状态、约束和用户请求，唯一区别是动态版本引入了时间性状态变化，因此可以干净地隔离出"世界演化"这一变量对决策的影响。构建流程也很讲究：先在世界状态中找可行参考解、从地理事实导出约束集，用程序化检查和约束求解器验证参考解满足约束、约束有世界状态依据、且解题所需信息能通过工具获取，再让 LLM 转写成自然语言请求并人工审核；动态版本则额外指定更新后的参考解，由 LLM 提出带时间戳的事件序列，并验证事件时序一致性、各参考解在其对应世界状态下的有效性、以及任务相关变化对智能体可观察。这样它测的就不是"能否响应某个预设扰动"，而是"能否在持续演化中维持证据与决策的一致性"。

结果层面，论文在统一 ReAct 式智能体脚手架和工具访问协议下系统评测了 9 个代表性闭源与开源模型，结论相当不乐观：即便是被广泛研究的原子任务，最强智能体在地点定位和地点发现上 pass@1 也只有 38.0%，组合任务进一步下滑，说明难点不在调用单个工具，而在同时满足多个相互依赖的地理约束；世界动态带来一致且显著的性能代价，在匹配的动态设定下，相对对应静态设定，Task-Only Dynamics 下降 70.3%、Shared Dynamics 下降 79.3%，且这一现象跨模型、跨任务类别稳定出现。进一步分析把瓶颈定位为两类失败模式：静态设定下的"证据幻觉"（智能体做出缺乏地理依据的断言）和动态设定下的"变化监控失败"（世界已发生必要变化后，智能体未能获取更新信息）。换句话说，当前智能体具备一定的一次性决策能力，但维持决策随世界演化而持续有效的能力很弱。局限也很明显：平台目前只覆盖六座城市、1376 个 POI，动态事件由 LLM 提议加人工审核构造，规模与真实世界的复杂度仍有距离，评测也局限于 ReAct 脚手架下的工具调用范式。但它的意义在于把"证据有效性随时间衰减"这一可靠性维度显式纳入评测，并提供了可扩展的基础设施，为研究下一代能在演化地理世界中可靠行动的智能体划出了一条可度量的问题边界。

### [Ballad: Bandit-Based LLM Routing for Automated Heuristic Discovery](https://arxiv.org/abs/2611.17241)
`评分3`

这篇论文要解决的是自动化启发式发现（AHD）中一个被普遍忽视却代价高昂的实际问题：在FunSearch、EoH、AlphaEvolve这类用大模型迭代变异代码启发式的流程里，每次运行需要成千上万次LLM调用，模型选择因此成为一等成本因素。人们通常默认更强更贵的模型会稳定产出更好的启发式，但作者在五个NP-hard组合优化基准上直接推翻了这一假设——更大更贵的模型并没有一致优势，某些情况下小模型或免费开源模型反而胜出。这就引出一个更深的问题：面对一个混合了前沿闭源模型和免费开源模型的池子，应该如何自适应地在搜索的每一步选择调用哪个模型。这个问题的难点在于它并不等价于传统的LLM路由：传统路由假设可以在离线标注数据上训练、且每次查询独立路由，但AHD里既没有离线监督信号（唯一的反馈是启发式被评测后得到的分数），每次选择又会通过共享的启发式种群影响后续所有调用的上下文。作者进一步把AHD中路由的独特性拆成三条性质：目标是整个运行过程中找到单个最高分启发式而非平均每次调用最优（P1，极值目标）；一个模型的输出会成为其他模型后续提示的上下文，导致奖励信号在模型间纠缠、归因困难（P2，跨臂耦合）；随着种群演化，各模型的相对效用会漂移，最优策略是非平稳的（P3）。这三条同时成立，使经典bandit算法的独立同分布假设和累积奖励目标都不再适用。

Ballad的核心做法是把自适应模型选择建模为在线bandit问题，每个LLM是一个臂，评测分数是奖励，但为每个臂设计了一个由三项加和构成的标量分数，每轮重新计算并拉取分数最高的臂。第一项针对P1，用极值而非均值来刻画模型价值：直接取高分位数在小样本下方差大，直接取历史最大值又容易被单次离群值主导，于是作者用bootstrap对分数缓冲区重采样、取每次重采样的最大值、再取这些最大值的分位数，得到一个在小样本和重尾下都稳定的上尾估计，并与实际观测到的最大值做凸组合，用一个系数在低方差尾部估计和记录值估计之间插值。第二项针对P2，利用变异家谱DAG做信用传播：每个启发式是节点，若生成某启发式时其父代被放进上下文则连边，当某个高分启发式出现时，沿祖先链回溯，把信用按某种衰减分配给那些输出曾作为父代出现在提示中的模型——即便那个改进是几轮之后由另一个模型产出的，弱模型产出的启发式在强模型上下文中触发突破时也能获得部分功劳，这正是单纯按调用者归因会漏掉的组合效应。第三项是带权重的探索 bonus，防止分数过早集中到单一臂上，保证每个模型积累足够观测。针对P3，作者对历史观测做滑动窗口归一化（折扣陈旧观测），使分数反映模型当前的“生育力”而非整个运行历史上的平均表现。整个方法是即插即用的，替换任何FunSearch/AlphaEvolve式流水线中的固定LLM生成器即可，不需要离线监督，也不需要改动提示构造或评测。

在五个NP-hard组合优化问题和四个能力、成本各异的模型（含开源与闭源）上，Ballad不仅匹配最佳单个LLM，在若干问题上还超过了所有单个模型——作者强调这一结果无法仅用“选对了模型”解释，说明Ballad学到了一种模型间的协作动态，是任何单模型无法复现的；同时相对始终使用最强模型，API成本最多降低65.6%。局限方面，论文的方法依赖若干超参数（尾部水平、bootstrap分位数、混合系数、信用衰减、窗口长度、探索权重），虽然做了消融但最优配置可能随问题漂移；DAG信用传播在数千个启发式、仅几个模型的规模下需要谨慎设计以避免信用被稀释到近乎均匀，论文对此只给出了部分处理；此外评测集中在组合优化基准上，向其他AHD场景（如程序合成、调度）的泛化性尚未验证。意义上，这项工作把“模型选择”从AHD里一个被当作工程细节的固定超参提升为需要在线学习的决策问题，并用极值目标、家谱信用和非平稳折扣三个机制说明为什么经典bandit和传统LLM路由都不够用，为后续把异构模型池编排成超越任何单模型的搜索系统提供了一个可复用的算法骨架。

### [Expanding the Decision Space of Pretrained Models through Structured Re-Decoding](https://arxiv.org/abs/2611.15109)
`评分3 · 29 pages, 2 figures`

这篇论文要解决的核心问题是：预训练模型在生成完整输出后，下游任务往往需要满足新的结构约束（比如分子要满足特定组成、RNA 要避免互斥碱基配对），而传统做法是在模型已经生成的一批完整样本里做筛选（best-of-N），这就把可交付的对象死死限制在模型已经产出的那些完整输出上。问题在于，局部预测分数或采样状态里其实暗含了更多满足新约束的组合方式，但这些组合从未作为完整输出出现过——比如某个分子的原子类型和键级在终端预测里各自合法，但拼装起来才满足目标组成；又比如 RNA 配对边在局部打分上可行，但全局需要协调避免冲突。现有结构化推断方法（如 IPknot、KnotFold 用整数规划协调 RNA 配对，Fusion Moves 从提案解中选兼容标签，QSQS 用二次重叠代价选检测框）已经展示了耦合选择的价值，但它们要么在模型内部约束扩散过程（如 PRODIGY），要么只在完整提案层面操作，没有系统性地利用冻结模型输出的局部候选来扩展决策空间。作者的关键洞察是：干预应该发生在模型输出层面而非模型内部，通过重组对齐的采样状态或利用局部预测分数构造候选，可以在不改变预训练参数的前提下，把决策空间从“已生成的完整样本池”扩展到“局部候选的笛卡尔积与约束的交集”。

SRD 的具体设计分三层。第一层是候选构造：给定输入上下文，适配器定义可编辑单元、受保护上下文、每个单元的局部候选集以及一个确定性重建映射，把联合状态拼回完整输出。候选来源有两类——分数派生候选保留冻结预测器允许的替代状态（FLOWR 从终端预测暴露原子、电荷、键的选择，KnotFold 提供带分数的配对边），这些候选可以包含任何完整样本中都不存在的状态；样本派生候选则对齐多个完整输出的决策单元并保留观测到的状态（如 ProteinMPNN 的精确枚举分析）。外部任务规范还可以提供候选状态或重建规则，比如非天然氨基酸库或肽环化语法。第二层是联合优化：把选择问题写成二次无约束二值优化（QUBO），一元代价编码模型偏好或局部几何，二元代价协调相互作用的决策，加性等式约束（如组成要求）和 one-hot 约束通过平方惩罚融入目标，作者给出了惩罚权重的下界保证——当惩罚权重超过所有非恒定软系数绝对值之和时，每个精确最小值点都可行。第三层是重建、验证与回退：选中的联合状态经确定性映射重建为完整输出，验证器区分编码可行性、域有效性和下游效用，任务特定策略对接受的候选排序，若全部被拒则回退到原始输出并标记。论文还给出了一个精确的理论刻画：在样本派生接口下，从固定采样流中取前 K 个可行样本去重得到池子，重组支持集是各位置观测状态笛卡尔积与可行集的交集，它必然包含原池子；在固定 KL 散度预算下，重组支持集的最优奖励前沿不低于原池子的前沿，因为条件参考分布达到了最小可达散度，而扩展支持集回收了被原池子丢弃的概率质量——ProteinMPNN 实验里 K=64 时支持集从平均 57.67 个状态扩展到 8041.79 个，保留参考质量从 14.7% 跳到 77.5%，在 0.5 nat 预算下 24 个重组支持集全部可行而原池子无一可行，这就是“凭什么更好”的机制层面解释。

实验结果覆盖四个任务。FLOWR 分子生成上，单目标（N+O=4）的组成加质量验证成功率从 best-of-4 的 419/1800 提升到全域重解码的 1309/1800，提升 49.4 个百分点；双目标（再加一个卤素）从 119 提升到 615，提升 27.6 个百分点；归档记录显示至少 868 个单目标交付既成功又不在原始四样本池中。ProteinMPNN 四站点枚举精确量化了支持扩展带来的可达奖励提升，4 nat 预算下 23 条流严格改善最优双目标奖励，等 backbone 平均增益 0.389。KnotFold RNA 配对预测上，全域堆叠在六个文件上宏观 F1 均优于独立正分配对，相对 native flow 在 ArchiveII、TS0、bpnew 上序列簇区间高于零，但相对规范匹配参考在 TS0 和 bpnew 上反而下降，说明求解到数值最优不一定带来最高参考 F1，且局部堆叠在部分文件上点估计更高。DiffAb 抗体设计上，带成对项和硬配对回退的策略在 3600 个嵌套案例上把归一化重叠从 0.327 降到 0.262 Å²/原子，每千个 CDR 重原子碰撞从 320.7 降到 282.9，固定身份对照实验确认成对选择单独就能降低重叠 0.067 Å²/原子。局限也很明显：FLOWR 的全域重解码在质量检查通过率上（94.4%）仍低于 best-of-4 筛选（99.8%），说明扩展决策空间和保持原始输出质量之间存在张力；KnotFold 的结果显示目标函数最优与参考指标最优并不总一致，tie-breaking 可以改变预测而不改变匹配目标；RNA 训练与开发集重叠、抗体代理相关性等数据泄漏风险作者自己标注了但未完全排除；物理相干伊辛机上的实验只是初步可行性演示，离实际加速还有距离。意义在于，SRD 提供了一个训练无关的通用推理时框架，把“筛选已生成样本”转变为“在局部候选上做约束优化再重建验证”，并且用 QUBO 形式天然对接量子退火和量子启发求解器，为科学领域里结构化推断和组合优化打开了一条不碰模型参数就能扩展决策空间的路径。

## 强化学习 RL

### [Towards a Theory of Learnability via Debate](https://arxiv.org/abs/2611.17303)
`评分3`

这篇论文要解决的是“辩论式训练协议”中长期被忽视的学习问题。此前关于可扩展监督的辩论研究，基本都把人类裁判视为已知且固定的验证器，只分析两个辩论者在给定裁判下博弈的均衡性质：只要提议者存在获胜策略，就等价于它给出了正确标签，于是人们乐观地认为，人类借助辩论就能监督解决 PSPACE 级别的问题。但这种分析跳过了最关键的一步——模型到底怎么把背后的真实函数学出来。存在获胜策略不等于能找到获胜策略，辩论者面对的是未知的裁判和未知的真实假设，每轮只能看到一个针对新输入的二值判决反馈，却从来看不到真实标签。更麻烦的是，已有工作沿用“提议者最小化自己输掉辩论的次数、回应者最小化对方赢的次数”这种对抗式损失，而论文指出这个目标在学习场景下并不合适，因为辩论者可能通过操纵裁判判决来“赢”，而不是真正逼近真实函数。作者因此把辩论形式化为在线学习问题：每轮环境给出输入，提议者先预测标签，双方交替提交论据，裁判给出判决，学习者的目标是让预测标签与真实假设不一致的次数最少，并区分可实现情形与裁判偶尔判错的 k-非可实现情形。

核心创新在于重新定义学习目标和辩论者之间的关系。作者首先论证对抗式博弈的损失函数不能保证学习效果，转而采用后悔式的错误计数目标，并给出一个关键反例：存在某些辩论问题实例，两个辩论者若彼此对抗，学习根本无法完成，但如果合作则只需常数次错误就能学会。这促使他们定义“合作式辩论”——回应者不再以驳倒提议者为目的，而是真心提供反论据，帮助裁判得出正确结论，两个辩论者合起来被视为一个学习器。为了刻画哪些验证器类可以被有限错误地学习，作者构造了一棵辩论树：边对应学习器所有可能的行动（提议的标签和双方论据），节点对应环境的最坏选择，并据此定义了一个新的组合维度“辩论学习维度”，用它给出可实现情形下确定性合作辩论者最优错误上界的精确刻画。这里最微妙的地方在于，标准在线学习里学习器每轮都能看到真实标签，而辩论学习里学习器永远看不到真实标签，只能通过裁判对辩论记录的判决间接推断，因此传统的 Littlestone 维度分析不能直接套用。论文还进一步分析了裁判可能出错的情形：即使只有少量轮次判决被任意污染，学习所需的错误数也会被显著放大，说明该协议对裁判的不可靠性远比普通在线学习敏感。

在结果层面，论文最重要的定量结论是关于不可靠裁判的：对任意常数 d>1，都存在这样的问题实例——可实现情形下最优确定性错误上界是 d，而一旦有 k 轮判决被污染，任何学习器的错误数都至少是 Ω(dk)。这与标准在线学习形成鲜明对比：后者只要假设类具有有限 Littlestone 维度 L，在 k-非可实现设定下就有错误上界约为 k 加上根号下 kL 再加 L 的无后悔算法，预测错误率会收敛到污染率；而辩论学习即使污染率很小，错误率也可能永远无法接近污染率。局限方面，论文目前主要给出的是确定性合作辩论者在可实现情形下的错误界刻画，对随机化策略、更一般的验证器类以及非可实现情形下的最优上界还没有完整结论，裁判出错模型也采用的是任意污染而非统计噪声。尽管如此，这篇工作的意义在于把辩论从“已知裁判下的博弈分析”推进到“未知裁判下的学习理论”，明确指出对抗式辩论未必是学习的最优方式，并首次给出辩论学习可学习性的组合刻画，同时用下界警示：把人类裁判当作永远正确的验证器是一个很强的假设，少量判决错误就可能导致监督信号严重失真，这对可扩展监督的实际部署是一个需要认真对待的理论提醒。

## AI + 生物

### [Reproducible quantum clustering for single-cell transcriptome atlases](https://arxiv.org/abs/2611.11745)
`评分3 · 28 pages; 5 figures and 1 table in the main text; 5 Extended`

单细胞图谱的聚类是整个下游生物学发现的地基——细胞类型、标记基因、通路乃至药物靶点都从聚类结果里读出。但现有流程存在两个根本性缺陷。第一，scanpy 和 Seurat 这类标准工具在聚类之前就丢弃了绝大部分转录组信息，只保留约两千个高变基因（HVG），再做 PCA 降维并在最近邻图上划分。HVG 的选择偏好的是在大量细胞间方差高的基因，这恰恰系统性地剔除了稀有细胞类型（占比不到百分之一）的标记基因——而现代图谱的细胞数往往是基因数的十五到二百五十一倍，在这个数据丰度下全转录组本可以被可靠估计，丢基因就是丢生物学。第二，基于学习的嵌入（如 scVI 的变分自编码器、scGPT 的基础模型）在训练中存在随机性：随机梯度下降在不同种子下收敛到不同的局部最优，scGPT 推理时每细胞采样一千二百个基因，GPU 浮点累加本身也非确定性的。结果是换一个随机种子重训 scVI，就有百分之十四的细胞被重新分配，稀有类型的标记和药物靶点随之改变，实验室之间无法复现同一套生物学结论。图工作流在固定种子下虽然确定，却会把均质的大类群沿技术轴（比如线粒体读数比例）劈成几块。所以核心问题是：能否在百万级细胞上、用全部实测基因做聚类，并且同一份数据永远给出同一套簇和同一套生物学？

KQE-2 的答案是把每个细胞的完整转录组编码成一个无纠缠的量子态，从而让所有量子特征都有精确的闭式表达。具体流程分四步，全部确定性。第一步，对全转录组的对数计数做逆文档频率（IDF）加权，在少数细胞中才被检测到的基因获得更高权重——这正是标记基因的信号特征。第二步，用固定起始向量做确定性 SVD，取一百三十二个方向；同时用一个把每个基因在细胞间置换的零模型把信号方向与噪声分开，再用这些方向归一化奇异值的香农熵（即数据熵）估计数据里含有多少个独立的表达程序，各图谱算出来是五到七，因此每块用六个量子比特。第三步，把一百三十二个白化后的得分分别通过三层重上传（re-uploading）旋转各自的量子比特，层与层之间不施加任何纠缠门；每个细胞由此得到七百二十六个量子特征，包括每个比特的 Bloch 向量（三个期望值完全描述单比特态）以及块内的成对关联。第四步，在量子态构成的图上做量子精度收缩聚类（Q-PSC）：每个细胞连到它精确找到并经过定理认证的十五个最近量子态，边权为态保真度，Leiden 先分出约一点五倍 k 个簇，再反复合并总保真度相对规模最大的两个簇直到剩下 k 个。关键洞察在于纠缠门会让量子特征的精确求值变成 #P-难问题，而硬件估计又受散粒噪声和漂移影响；去掉纠缠后，两个细胞的态保真度（态重叠的平方）退化为逐比特乘积，线性时间可精确计算，且定理证明去除纠缠是单比特特征方差局部有界的充要条件——这就是它既能精确又可扩展的理论根基。此外，一个基于数据熵的无标签基因集规则在聚类前决定输入：只有当图谱包含的表达程序远多于请求的簇数时才退回五千个 HVG，否则保留全转录组。与以往依赖采样纠缠映射的量子核方法（此前仅能处理约一千个细胞）和需要二值化或稀疏贝叶斯模型的经典无 HVG 方法相比，KQE-2 是第一个在完整百万级图谱上做可复现聚类的量子框架。

在十个完整图谱（六十一万到二百八十六万细胞）的基准上，KQE-2 在八个图谱上取得最高精度，另外两个落在最优方法多次运行的波动范围内；即便完全沿用其他方法的下游协议（在特征图上按 k 做 Leiden），它也在六个图谱上领先、另外三个与最优差距不超过零点零零四，说明增益并非来自最后的聚类步骤。相对最强对比方法的领先幅度从鼠标小脑的零点零三二到发育皮层（六十九万三千细胞）的零点一六九；在发育皮层上仅加入量子编码就把标准 HVG 管线的 AMI 从零点六零五提到零点七八八，在 Siletti 非神经元脑图谱上把少突胶质前体细胞（OPC）的 F1 从 scanpy 的零点四五提到零点九六。稀有类型上的优势经分层 Wilcoxon 检验显著（对 scanpy、Seurat、scVI 的 P 值分别低至十的负二十六次方量级），在十一个百万核的完整小鼠胚胎图谱上，脊索、浦肯野细胞、心内膜等稀有群体形成独立的态岛，F1 达零点八五到零点九零。可扩展性方面，单块 GPU 上把一百一十二万斑马鱼细胞全部三万两千个基因嵌入只需九百七十三秒、峰值内存十三点二 GB，而四个专用聚类方法在三小时、一百五十 GB 内都没能处理十四万六千细胞；最大的运行是一千一百四十四万核的小鼠胚胎全图谱，全转录组确定性分解十一小时三十六分、认证最近态图三小时六分、Q-PSC 十二分钟，在单台五百零二 GB 内存的服务器上 scVI 直接内存溢出、scanpy 未能返回嵌入、scGPT 不适用于小鼠数据，KQE-2 是唯一给出聚类的方。可复现性上，所有完整图谱重跑后分解、量子特征和簇完全逐位一致，跨服务器对六十一万核小脑图谱也给出一致结果；在 IBM 量子处理器上，三百八十个细胞的实测特征与精确值相关系数为零点九七八，验证了编码的硬件可核查性。局限也很明确：方法依赖标注类型数 k 作为输入，基因集规则虽无标签但阈值是人为设定的；在表达程序数与请求簇数接近的图谱上必须退回 HVG，此时全转录组的优势收窄；量子硬件目前仅用于校验而非加速，实际计算仍在经典 GPU 上完成。但它的意义在于证明了无纠缠的精确量子表示可以在千万级完整图谱上同时做到领先精度和逐位可复现，把「换种子就换生物学」这个长期困扰单细胞领域的隐患从流程中移除。

### [Synaptic Dendritic Neuron Model (scDNM) for Cell Type Classification in Single-Cell RNA Sequencing Data](https://arxiv.org/abs/2611.10207)
`评分3`

这篇论文要解决的是单细胞RNA测序数据里的细胞类型分类问题。scRNA-seq数据的特点是维度极高（动辄上千个基因）、极度稀疏（大量基因在单个细胞里表达为零）、噪声大，而且很多细胞类型在转录组层面高度相似，仅靠表达谱很难区分。更麻烦的是，标注数据往往有限、类别不平衡严重，训练集和目标数据之间还存在批次效应等分布差异。之前的方法大致分几类：SVM类（包括线性核和RBF核）在多项基准比较中表现最稳，scPred把PCA降维和SVM概率输出结合，SciBet用多项式模型做判别基因选择和概率分类，CHETAH、scClassify、scAnnotatR走层次分类路线处理不确定细胞，SingleR用相关性打分做参考相似度匹配，Garnett用用户定义的marker规则训练弹性网多项回归并保留"Unknown"输出，还有Random Forest系的SingleCellNet、自编码器系的scIAE、图方法gCAnno和scPriorGraph、以及Transformer系的scTrans和scTab等深度模型。但作者指出的核心问题是：这些方法要么依赖核函数或树分裂来隐式地学基因层面的决策边界，要么需要大量标注或复杂预训练，而树模型之所以在scRNA-seq上表现好，一个关键原因就是它能直接在基因层面学阈值——某个基因在某种细胞类型里是"开"还是"关"往往就很有判别力。经典树突神经元模型（DNM）恰好天然具备这种结构：每个突触对输入做sigmoid阈值化，模拟兴奋/抑制连接，树突整合突触输出，胞体做最终决策。但经典DNM的树突输出是突触输出的乘积，在几百个基因的维度下乘积会数值坍缩到零，没法直接用；而且之前没人把DNM系统地适配到scRNA-seq分类上，也没有在严格无泄漏的评估框架下和主流分类器做过公平比较。另外作者特别强调评估设计本身的问题：很多比较里特征选择、缩放、超参调优没有完全独立于外层测试折，导致乐观偏差，所以这篇论文把"无泄漏评估"也作为贡献之一。

scDNM的核心设计可以拆成几个关键模块来理解。首先是突触层：每个基因到每个树突的连接被建模成一个可学习的软阈值，形式是对标准化后的基因表达做sigmoid变换，其中权重符号决定这个连接是兴奋性还是抑制性，阈值参数控制"开/关"的切换位置，斜率参数控制切换的陡峭程度。关键洞察在于阈值的初始化——作者把每个突触的阈值初始化在"不表达水平"和"表达细胞平均表达量"之间的中点，这样每个突触在训练开始时就是一个基因"开/关"检测器，正好对应树模型擅长学基因阈值这件事，但这里是可微的、可以端到端训练的。然后是树突层：每个树突从基因池里随机抽取一个子集（随机子空间），对这些基因的突触输出做加权求和再过sigmoid。这里作者做了一个重要的工程决策——经典DNM用乘积整合树突，但在高维稀疏数据上乘积会坍缩，所以改成加法整合，保证了数值稳定性。基因池本身是有监督构建的：只用内层训练数据计算每个基因的标准化类均值差，取绝对值排名前P个基因组成候选池，每个树突从池里随机选m个基因，这样不同树突处理部分重叠的基因群，形成类似集成学习的多样性。膜层和胞体层把各树突输出加权求和，同时加了一条全局线性通路直接连到输出，最终过sigmoid得到概率。训练分两阶段：第一阶段只训树突相关参数（突触、树突、膜权重、胞体偏置），第二阶段冻结树突部分，让全局线性通路去学树突logit没解释掉的残差信息——这个"残差全局通路"的设计相当于给树突模型加了一个线性校正项，弥补树突随机子空间可能漏掉的信息。最后用5个不同随机种子、不同基因子集、不同内部分划的网络做概率平均集成。整个流程里，HVG选择、缩放、基因池构建、超参调优全部在外层训练折内部用内层三折交叉验证完成，外层测试折完全不参与任何决策，这是它评估可信度的关键保障。消融实验也验证了树突和突触层确实是性能来源：去掉树突或去掉突触层都会掉准确率。

在结果方面，作者从Paul15、PBMC3k、Nestorowa三个数据集构造了六个二分类任务，覆盖生物学上相似（如14Mo vs 13Baso、CD4 T vs CD8 T）和差异明显（如3Ery vs 16Neu、CD4 T vs CD14+单核）的细胞类型对。六个任务里scDNM在三个任务上排名第一（其中一个和SVM并列），Nestorowa上排第二，平均准确率排名2.00，优于XGBoost的2.75、Random Forest和逻辑回归的3.33、SVM的3.58；AUC和F1的平均排名也是第一。在PBMC3k的六分类实验里，scDNM达到95.997%准确率和0.944宏F1，对比官方SingleR实现的94.243%和0.914，有明确提升；Garnett在测试环境里只返回"Unknown"，作者把它当作零覆盖的技术性结果处理而没有强行排名，这个处理是诚实的。消融分析确认树突和突触层都有贡献。但作者也客观报告了局限：在14Mo–13Baso这个特别难的任务上scDNM比树模型低约七个百分点，六个二分类任务的平均准确率95.32%也低于XGBoost的96.20%，说明树模型在困难任务上仍有优势；而且只有六个任务，跨任务排名差异在统计上不显著，不能宣称普遍优越性，需要更广泛的数据集来验证。整体来看，这篇论文的意义在于把树突神经元模型这个有神经科学启发的结构成功地适配到了高维稀疏的scRNA-seq分类场景，用可学习的基因级软阈值加随机子空间树突加残差全局通路的设计，在严格无泄漏的评估框架下证明它能和强基线竞争，同时坦诚地划定了性能边界——它不是全面碾压树模型，而是在多数任务上排名靠前、在部分任务上有明确优势，为后续在更大规模、更多细胞类型层次上的验证提供了一个有原则的起点。

### [Using an energy pixels approach to estimate the size a 2nd Generation DEL must be to train a high-resolution binding model](https://arxiv.org/abs/2611.17121)
`评分3 · 11 pages, 4 figures`

这篇论文瞄准的是DNA编码化合物库（DEL）在药物发现中角色转变后的一个真实瓶颈：找到苗头化合物已经不再是难点，难的是拿到足够好的训练数据去构建一个能指导后续药物化学优化的高分辨率结合预测模型——这个模型必须能分辨化学家改动单个原子时亲和力的细微变化。要训练出这样的模型，数据得同时满足两个条件：在苗头化合物周围的化学空间里有密集采样，且这个局部区域内要有足够多真正高亲和力的结合物。而一个多样化的朴素DEL恰恰两头都不占：它覆盖的化学空间极其庞大，导致任何一个局部邻域内的样本都稀薄得可怜，同时高亲和力结合物本身又极为罕见。用这种数据训练出来的模型，本质上被迫外推到比训练集中任何样本都更强的结合物上去，而这正是模型最容易失效的地方。围绕苗头化合物构建的第二代DEL理论上能同时提供这两种属性，但关键问题是：这个库到底需要多复杂？此前没有方法能在不做结构解析、不实际合成的情况下回答这个问题，导致第二代库的设计基本靠猜，要么规模不够导致采样仍然稀疏，要么盲目做大造成巨大浪费。

论文的核心洞察是把结合自由能拆解为靶标上的“像素”和配体上的“反像素”之间一系列小而独立的相互作用的加和，从而把亲和力分布转化为可计算的组合问题。在这个框架下，作者仅利用朴素DEL中测得的亲和力分布的展宽信息——不需要任何蛋白结构、不需要合成任何化合物——就能反推出第二代DEL需要多大的复杂度才能同时满足密集采样和足够多高亲和力结合物这两个要求。具体来说，方法做了两件实用的事：第一，它把“模型需要多少个紧结合物”这个训练需求，翻译成“库需要包含多少个化合物”这个合成层面的可操作数字，打通了机器学习需求与库设计之间的定量桥梁；第二，它能估计一个随机设计的第二代DEL的预期产出率，这就意味着用机器学习或主动学习来设计库所带来的增益，可以和一个明确的基线做对比，而不必花费与实验本身同等规模的代价去合成一个对照库。相比之前的方法，这套思路的优势在于它完全绕开了结构信息和先验合成，把不可直接测量的库复杂度问题转化为从已有朴素库数据中可估计的统计量，使得第二代DEL的设计从经验猜测变成了有定量依据的工程决策。

在结果层面，论文通过该方法给出了第二代DEL所需复杂度的具体估计，并展示了随机设计的第二代库的预期紧结合物产出率，为主动学习设计相对于随机基线提供了可量化的比较框架。关键数字体现在它将模型所需的紧结合物数量直接映射为库的化合物数量级，使得库设计有了明确的目标规模而非盲目扩张。不过，该方法建立在结合能可加性假设之上，即把结合拆解为独立像素贡献的近似在存在协同效应或构象熵大幅变化时可能偏离真实情况；此外，从朴素库亲和力分布展宽反推像素参数本身带有统计不确定性，估计的库复杂度是一个期望意义上的指导值而非严格保证。尽管如此，这篇工作为DEL领域提供了一个重要的方法论转向：把机器学习对训练数据的需求前置到库的设计阶段，用定量框架替代经验试错，这对降低第二代DEL的开发成本和推动高分辨率结合模型的实用化具有直接的方向性影响。

### [Silscore: modelling siRNA potency with positional thermodynamics and data-selected nucleotide-identity terms](https://arxiv.org/abs/2611.15812)
`评分3 · 25 pages, 10 figures, 2 tables; includes supplementary mater`

这篇论文要解决的是siRNA效力预测的真实难题：针对同一转录本的不同siRNA候选分子，其沉默效力可能相差悬殊，而现有预测方法陷入两难。一类是可解释的经验规则（如Reynolds、Ui-Tei规则），它们基于序列特征和热力学稳定性给出定性判据，但精度有限，且规则本身是人为规定的而非从数据中学到的。另一类是近年兴起的深度学习模型（如OligoFormer），它们把热力学描述符与序列嵌入、靶标上下文特征拼接起来，参数量动辄上百万，预测能力虽强，却容易在数据集或靶标变化时性能骤降——因为高容量模型可能学到实验设计的人为偏差，而训练集与测试集之间的序列重叠又会虚高评估结果。更关键的是，此前研究已经暗示热力学信息确实有用（比如双链整体稳定性存在中间最优区间、末端不对称性影响链选择），但单纯用最近邻堆叠能拟合的位置分辨谱不如序列表示准确，说明有些序列效应根本无法用碱基配对能量表达——最典型的例子是guide第5'端第一个核苷酸，Argonaute蛋白是通过直接接触识别它的，任何堆叠能量的重新排列都解释不了这种效应。这就构成了Silscore的动机：需要一个既紧凑又可解释、能把热力学骨架与少量序列身份修正结合起来的模型，并且必须在真正的跨数据集迁移场景下验证其稳健性。

Silscore的核心设计可以拆成三块，全部只从guide序列出发（不依赖靶标上下文或可及性），主模型仅26个参数。第一块是整体双链稳定性的二次偏好项：模型用Tinoco最近邻模型加Xia参数算出guide与互补链配对的全程自由能，然后不是简单地认为越稳定越好，而是拟合出一个最优自由能ΔG*和一个惩罚强度κ，对偏离最优值的稳定性施以二次惩罚——这直接把文献中“双链太稳定或太不稳定都不好”的定性经验变成了从数据估计的两个连续量。第二块是位置分辨的堆叠能谱：为19个核苷酸位置各配一个权重w_i，刻画局部稳定性在guide不同位置上的贡献差异，关键约束是这些权重之和为零，从而让局部谱只描述位置间的相对偏好，不会把整体稳定性项的一部分偷偷吸收进来。第三块是稀疏的核苷酸身份修正项：先只用热力学部分拟合，得到残差，然后在训练数据上以多重比较校正后的阈值筛选出那些残差显著偏离零的“位置-碱基”组合，只保留少数几个非零系数（主模型中选了U1、C1、C2、G14、G18、A19共六个），这些项捕捉的正是堆叠能无法表达的效应，比如5'端核苷酸与Argonaute蛋白的直接接触。整个模型通过闭式最小化求解，不需要随机初始化或验证集，因此每次拟合是确定性的。它之所以比之前的方法更有希望，一是参数极少（26个，不到任何可训练对比方法的一半，比OligoFormer少四个数量级），过拟合风险低；二是热力学骨架提供了物理归纳偏置，身份项只做稀疏修正，二者分工明确；三是身份项是在Huesken上单独选出的，却能在外部数据集上带来迁移增益，说明它抓到的是可泛化的序列效应而非数据集特异噪声。

在结果上，作者用Huesken的官方划分（2182训练、249测试）拟合，在三个迁移评估中Silscore都取得了观测到的最高Pearson相关：在Katoh–Suzuki单靶标EGFP数据集上，它比那里可用的最佳DSIR表示高出+0.023（95% bootstrap区间[+0.0002,+0.045]），数据支持它优于所有适用对比方法；在Mixset和“未见靶标”评估中它相关最高，但数据不足以确立它对最接近对比方法的优势；在Huesken留出集上它并非最高，但数据同样不能证明可训练对比方法优于它——作者也提醒这个同数据集比较偏乐观，因为实验上下文未变且未控制训练-测试序列相似度。消融实验显示，相比纯热力学模型，加入身份项在四个评估中分别提升+0.064、+0.064、+0.032、+0.068，且bootstrap支持每次都有改善；其中U1偏好贡献了Huesken留出集上的大部分增益（其余五项仅再加+0.004），但这些额外项在Mixset和Katoh–Suzuki上分别带来+0.037和+0.026的迁移提升，支持其可迁移性。在降低训练-测试靶标相似度的压力测试中（同一批1453条人类insert guide，训练集换成489条啮齿类insert guide，后者与评估集的局部序列重叠从39%降到0.07%），Silscore在相似度更低的训练集上仍保持最高观测相关，数据未确立其性能下降。局限也很清楚：模型完全不含靶标可及性和转录本上下文，对依赖靶标位点开放性的场景可能失效；身份项的选择依赖训练集残差，换数据集后保留的项会变（如啮齿类训练集只留U1和G18），说明这部分选择有一定数据依赖性；此外外部验证中Mixset和未见靶标上的优势尚未被统计确立。尽管如此，这项工作的意义在于把此前散落的定性设计规则——末端不对称、seed区偏弱、中央配对偏强、整体稳定性中间最优——统一成一个从数据估计参数的紧凑模型，在参数少两个数量级的前提下实现了有竞争力的预测和更好的迁移稳健性，为siRNA设计提供了一个可解释、可复现的基线。

### [Protein B-factor modeling with local magnitude](https://arxiv.org/abs/2611.08832)
`评分3`

这篇论文要解决的是蛋白质B因子（晶体结构中原子位移参数，反映柔性）的建模问题。B因子本质上刻画了蛋白质局部柔性，而柔性对分子识别、催化、构象适应都至关重要，因此从已知结构预测B因子既是一个实用建模任务，也是检验结构表示好坏的试金石。此前已有大量方法：分子动力学、简正模式分析、高斯网络模型、各向异性网络模型、图论刚性分析、柔性-刚性指数（FRI）、持续同调、多尺度高斯环绕积分、Jones多项式描述子、多尺度微分几何学习等。其中与本文最直接相关的是基于拓扑magnitude的工作：magnitude用距离结构度量有限度量空间的“有效大小”，此前已被用于从结构建模蛋白质柔性——具体做法是对Cα原子构建相似度矩阵，用其逆矩阵的行和定义每个残基的权重，再对所有核参数求和得到标量magnitude。但问题在于，全局magnitude加权需要求解稠密线性系统，计算代价随蛋白质规模呈三次方增长（N³，N为Cα原子数），对大蛋白不可行；而且全局求解意味着结构中任何一处的变化都会影响所有残基的权重，局部堆积信息被全局耦合掩盖。作者想保留magnitude的几何洞察，同时把计算限制在局部、把残基级信息保留下来，于是提出局部magnitude表示。

核心创新在于把全局加权“局部化”并“向量化”。对每个中心残基i，取其自身加上最近的k-1个邻居（实验中k固定为50，也可用半径R定义邻域），在这个小邻域上构建核矩阵K，核函数采用高斯型（p=2）或拉普拉斯型（p=1），参数α控制长度尺度（α越大交互长度越短）。求解K w = 1得到邻域权重向量，其中两个量被区分开：邻域magnitude是权重之和（标量），而中心加权分量f_i是中心点对应的那一个权重分量——后者被称为局部magnitude柔性指数（LMFI），是真正被用作特征的量。论文证明了在欧氏点集上该核矩阵严格正定，因此局部加权唯一存在且邻域magnitude为正；构造对平移、旋转、反射不变，坐标统一缩放可通过调整α补偿，具有良定义性和几何不变性。关键洞察是：局部加权一般不等于全局加权的对应分量，弱远距离相似性不足以让局部近似全局，因为条件数和邻域外的权重也会影响误差（附录给出了固定邻域下的扰动界）。但局部化带来两个好处：每个分解只涉及k×k小矩阵，复杂度降为O(Nk³)，与N呈线性；且局部堆积不受结构其他部分变化影响。特征提取上，作者用一组固定的12个参数对（6个p=1、6个p=2，α递增），对每个中心只保留中心分量，形成N×12的特征矩阵，目标标签只在最后回归阶段进入，因此该几何特征可缓存复用于不同折和不同回归模型。盲预测时还拼接了37个辅助描述子，与全局magnitude基线使用完全相同的辅助特征、模型和评估协议，以保证比较公平。作者还特别澄清了几个概念：f_i是几何预测子而非力学响应定律，不保证对每个残基都随实验B因子增大；常用的刚性倒数1/f_i只在f_i>0时有正刚度含义，接近零不稳定、为负时不是正刚度，且与FRI的核密度刚性得分（邻域核值之和的倒数）一般不同；邻域大小k和核长度尺度α是两个独立控制——固定k不意味着固定物理半径（1ABA例子中50邻居半径约18Å，而p=1的e折长度仅1.67到10Å），增大k扩展参与求解的点集，增大α则改变距离被赋予的相似度。

结果方面，在364个蛋白的蛋白内拟合任务中，局部magnitude的平均蛋白内拟合Pearson相关系数从全局的0.725提升到0.728；在345个蛋白的盲预测任务中，局部特征与全局特征配同样的辅助描述子和回归模型（随机森林与梯度提升），在三种验证协议下共六组模型-协议比较中，局部特征全部提升了主PCC，最大绝对提升为0.008（蛋白级十折梯度提升）。计算上，固定特征库时局部分解为O(Nk³)对全局的O(N³)，在五个具名蛋白上的计时显示大结构上局部magnitude具有计算优势。作者也坦率说明了局限：提升幅度很小（0.003到0.008），并非所有情况下局部化都改善性能；实验只用了单种子配置，且全局与局部使用不同的尺度库；绑定截断处的行索引打破平局规则只是可复现性约定而非内在几何选择；局部加权不保证一致逼近全局加权，也不恢复magnitude homology；几何表示只用保留的Cα坐标，不加氢、侧链、水、配体，不插补缺失残基，因此能描述的内容有限；B因子本身还受静态无序、晶体堆积、占有率和精修影响，只是代理目标而非溶液态动力学的完整描述。总体而言，这篇工作的意义在于把magnitude这一几何工具从“全局稠密求解”改造成“局部紧致表示”，在保持有用B因子信息的同时把特征提取代价降到对大蛋白可承受的水平，为基于拓扑/几何描述子的柔性建模提供了一个透明、可复现、与基线严格对齐的比较范式，并明确了局部化在何时有益、何时无益的边界。

### [EvoSurv: Evolution-Aware Multimodal Survival Modeling Reveals Complementary Prognostic Signals](https://arxiv.org/abs/2611.13190)
`评分3 · 11 pages, 3 figures`

这篇论文要解决的是癌症生存预测中肿瘤异质性带来的精度瓶颈。现有的大多数多模态生存模型虽然整合了临床变量和分子数据（比如RNA表达），但它们普遍忽略了一个关键维度：肿瘤演化信息。肿瘤的发生发展本质上是体细胞持续演化、突变累积和克隆选择的过程，由此产生的克隆与亚克隆群体构成了瘤内异质性，而相同临床分期的患者生存结局可能截然不同，这背后的分子基础很可能就藏在演化历史里。问题在于，全外显子测序通常只捕获单时间点的基因组快照，无法直接观测演化轨迹；不过，通过突变层面的癌症细胞分数可以推断克隆结构——克隆突变存在于所有采样癌细胞中、对应祖先谱系，亚克隆突变只存在于部分细胞中、反映后续的克隆多样化，这就使得从单次测序样本中刻画不同克隆状态的突变特征成为可能。此前基于深度学习的生存模型如DeepSurv、Cox-nnet，以及较新的AGGSurv、FGCNSurv、CoFormerSurv，要么只做单模态，要么在多模态整合时没有把克隆/亚克隆演化模式纳入表示，导致这部分预后信号被系统性遗漏。

作者的核心做法分两层。第一层是构造eTime——一个38维的演化感知特征表示，分八组特征：克隆负荷（克隆与亚克隆突变数的对数、亚克隆比例、亚克隆PyClone簇数、Shannon多样性）、克隆与亚克隆各自的六类嘧啶参照替换谱（C>A、C>G、C>T、T>A、T>C、T>G，按克隆状态分别算比例，共12维）、功能后果（错义、无义、剪接相关、其他非沉默四类，按克隆状态各一套，共8维）、SIFT有害性（每个克隆状态下有害SNV比例和平均SIFT分数，共4维）、拷贝数变异负荷（CN≠2、扩增、缺失的基因比例及平均绝对拷贝数偏差，共4维），以及失巢凋亡相关基因的基因组改变（5维，包括失巢凋亡基因中非沉默SNV占比、其亚克隆比例、是否有失巢凋亡SNV的二值指示、失巢凋亡基因扩增与缺失比例）。克隆划分依赖PyClone从突变reads、肿瘤纯度和拷贝数推断的癌症细胞分数。第二层是EvoSurv模型：RNA分支先用重构目标预训练一个2000–512–256–64的对称自编码器，eTime分支用两层MLP，两者都带LayerNorm、GELU和dropout，各自接线性风险头输出风险分；临床风险则用只含年龄和分期的Cox模型拟合，系数在分子模型训练时固定不动，作为固定偏移量。最终风险是临床、RNA、eTime三路风险分的加性融合，训练用联合硬监督——主损失优化融合预测的Cox偏似然，两个辅助损失分别约束RNA和eTime分支在临床偏移条件下仍保留预后判别力，再加风险正则（惩罚过大的分子风险分）和L2-SP正则（把微调后的RNA编码器拉向预训练参数），从而在保住预训练表示的同时让演化特征贡献可解释的增量信号。这个设计的关键洞察在于：把临床作为固定基线、让分子分支在基线之上竞争性学习，才能干净地评估eTime是否提供了临床和转录组之外的额外预后信息，而不是被临床变量掩盖。

在六个TCGA队列共2782例患者上，EvoSurv在全部六个癌种中都取得了最高平均C-index，总体均值0.663，相对CoFormerSurv、FGCNSurv、AGGSurv分别提升5.6%、7.8%、8.2%，其中UCEC达0.716、BRCA达0.699，BLCA、LIHC、OV相对最佳基线也有约4.8%–5.8%的增益。更关键的是增量预后价值的检验：在调整临床变量和RNA风险分后，eTime风险分在头颈鳞癌（HNSC）和肝细胞癌（LIHC）中仍与生存显著相关；特征组分析还揭示了癌种特异的模式，比如HNSC中T>G替换在临床和分子调整后仍与死亡风险升高相关，且在HPV阴性患者中依然成立，并得到独立CPTAC-HNSCC队列（102例、39例死亡）的支持。局限方面，eTime的克隆推断依赖PyClone和ABSOLUTE的估计质量，38维表示是人工设计的、可能未覆盖全部演化维度，独立验证目前只做了HNSC一个癌种，其他癌种的演化信号尚缺外部队列确认，且C-index的绝对提升幅度有限。但这项工作的重要意义在于证明了肿瘤演化特征携带临床和转录组之外的互补预后信息，为多模态生存建模引入了一个此前被忽视的生物学维度。
