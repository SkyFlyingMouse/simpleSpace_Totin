## 大模型 LLM

### [Factored One-sided Adam-Moment for Practical and Scalable SOAP](https://arxiv.org/abs/2611.16905)
`评分3 · HF 14赞 · 有代码`

这篇论文要解决的是二阶优化器在LLM预训练中“性能好但用不起”的真实困境。AdamW长期是默认选择，而Shampoo/SOAP这类Kronecker分解的二阶方法虽然在大batch下能比AdamW快35–40%（wall-clock和步数），代价却极其高昂：SOAP需要维护两个Kronecker因子L=GGᵀ（m²）和R=GᵀG（n²）、一个在特征基旋转空间里的稠密二阶矩v_rot（m×n），以及一阶矩，优化器状态约为AdamW的4.5倍；同时每pf步要对L和R各做一次特征分解，单步时间显著慢于AdamW。所以实践者往往退回AdamW或Muon。论文的核心动机就是：SOAP的性能优势是否能在接近AdamW的开销下保留？作者指出，SOAP原文其实做过one-sided和factored的消融，Frans等人也发现input-only旋转加factored方差各自能保留大部分质量，但都只是“降本消融”，没有回答“该保留哪一侧、什么时候分解是合理的、为什么两者组合有效”这三个关键问题——这正是本文的贡献所在。

方法上有两个结构性简化，且每个都有明确的理论依据。第一是input-only预条件：丢掉输出侧因子L，只保留输入侧R=β₂R+(1−β₂)GᵀG及其特征基Q_R，梯度只沿输入轴旋转为G_rot=GQ_R。依据来自仿射层交叉熵的Hessian精确分解——输出侧因子diag(p)−ppᵀ的非对角元p_i p_k比对角元p_i(1−p_i)小一个p_k/(1−p_i)的因子，在大词表下绝大多数类别的这个比值很小，因此输出侧曲率被对角主导；而输入侧xxᵀ在所有输出行间共享，非对角结构都在输入侧，所以保留输入侧是自然选择（注意这与SOAP原文“保留维度较小一侧”的规则不同，在MLP down-projection上两者会选相反侧）。第二是factored Adam-moment：把稠密的v_rot替换为行、列统计量r∈ℝᵐ和c∈ℝⁿ的外积v̂_rot=τ·r̂·ĉᵀ，τ是trace-matching标量，使重构二阶矩的元素和等于tr(R)，从而固定整体尺度；缓冲从mn降到m+n。关键洞察是Lemma 1：在K-FAC假设𝔼[ggᵀ]=R⊗L下，用Q_R旋转后协方差变为Λ_R⊗L，取对角并reshape成m×n恰好是秩一矩阵diag(L)·λ_Rᵀ，所以存r̂和ĉ能保留每个坐标自身的方差、相对稠密缓冲无损；而在“输出侧曲率对角”的K-FAC Fisher假设下，这个估计器精确恢复SOAP的稠密二阶矩，实测K-FAC违背只有15–20%且对更新影响可忽略。合起来，FOAM的隐式Fisher是R⊗diag(r̂)，优化器状态从2mn+2m²+2n²降到mn+2n²+m+n，摊销特征分解从两次减为一次（并沿用Purifying Shampoo的自适应容差来跳过不必要的刷新）。

实验在124M到760M参数的LLM预训练上，学习率从μP锚点出发在每个规模重新调参。结果：FOAM在验证loss上匹配强SOAP和Muon基线，优化器状态只有SOAP的一半，实测峰值训练内存仅比AdamW高7.4%，wall-clock达到Muon级别；在760M规模下SOAP需要两倍以上时间才能达到AdamW最终loss，而FOAM只需AdamW自身wall-clock的7%左右，且在3倍学习率范围内保持与AdamW相当的鲁棒性。局限也需客观看待：input-only的合理性主要建立在输出侧曲率近对角的论证上，输出层的softmax机制有严格解释，但隐藏层只援引了“MLP近块对角”的既有观察和本文的Gauss-Newton对齐测量作为间接证据，并非普遍证明；K-FAC违背虽小但非零，秩一重构在输出侧曲率显著非对角的情形（如某些注意力结构或极端分布）可能退化；实验规模止于760M，更大模型和下游任务上的表现尚未验证。意义在于，它把“SOAP级质量是否必须付SOAP级代价”这个问题给出了否定答案，并提供了可复用的判据——保留输入侧、在旋转后分解、用trace归一化——这对二阶优化器能否真正替代AdamW成为默认选择，是一个务实的推进。

### [Maximizing Capacity Utilization of LoRA Adapters for Mitigating the Learning-Forgetting Trade-off](https://arxiv.org/abs/2611.17191)
`评分3 · 有代码`

这篇论文针对的是LoRA在实际部署中一个被广泛忽视却影响深远的问题：标准LoRA训练出来的适配器，其实际利用的容量远低于配置的秩所允许的上限。作者在GSM8K、Hausa指令跟随以及混合域持续学习代理任务上做了秩扫描实验，发现有效秩与配置秩的比值随秩增大而持续下降，而且这种下降在深层网络中比浅层更严重。这意味着单纯调大r并不能可靠地带来“更多适配器容量”——配置秩只是可用方向的数量，而有效秩（基于奇异值谱的归一化熵定义的Roy-Vetterli有效秩）衡量的才是更新能量在这些方向上分布得有多均匀。之前的方法，无论是PiSSA、LoRA-XS这类谱初始化方案，还是VeRA、TinyLoRA、SVF这类刻意压缩适配器的方法，本质上都是在学习-遗忘权衡上做重新分配而非真正改善：拟合得好的方法遗忘严重，限制遗忘的方法又欠拟合新数据。作者的关键洞察在于，学习-遗忘权衡不只取决于更新的大小，更取决于更新能量在权重正交方向上的分布方式，因此真正相关的变量是实现的有效秩而非名义秩。

方法上，作者将问题形式化为在标准语言建模损失上叠加一个容量正则项，目标是最大化适配器更新的有效秩。直接对Roy-Vetterli有效秩求梯度有两个麻烦：归一化奇异值趋近于零时导数奇异，且需要做SVD分解带来额外开销。为此他们采用了一个无SVD的替代量——Rényi-2有效秩，它基于能量分布（各奇异值平方占全部奇异值平方和的比例）的Rényi-2熵的指数，理论上构成Roy-Vetterli有效秩的下界，且仅依赖奇异值而不依赖奇异向量，因此梯度中不会出现奇异值间隙做分母的不稳定项。具体实现有两条路线：第一条是范数约束路线，利用定理证明在算子范数上限约束下最大化Frobenius范数可以提升Rényi-2熵，配合NB-LoRA的Stiefel-Cayley重参数化来强制算子范数不超过阈值，但作者坦承这种重参数化在实践中导致训练不稳定；第二条也是主方法，即Rényi-2惩罚项，直接以低秩因子A和B计算能量分布而无需显式构造ΔW，不改变适配器参数化形式，可即插即用地加到标准LoRA以及PiSSA、LoRA-XS等变体上，实验中还采用了对数变体来按有效秩大小自适应缩放梯度。这个惩罚项是酉不变的、光滑可微的、实现简单且优化稳定，本质上是把“让奇异值谱尽量均匀”这一目标变成了一个可训练的正则项。

实验结果覆盖Qwen2.5-0.5B、Qwen2.5-3B-Instruct和Llama-3.2-3B-Instruct三个模型，在混合域持续学习代理设置（GSM8K 45%、WMT19 cs-en 10%、Aya Hausa 45%的混合SFT）下，λ=0.01的惩罚项在所有至少为16的测试秩上都降低了平均Wiki困惑度，训练困惑度在绝大多数模型-秩组合中持平或改善（仅Qwen2.5-3B-Instruct在r=16时有较大上升）。在Qwen2.5-0.5B最大秩上，λ=0.01和0.1同时改善了混合域拟合和保留能力。值得注意的是，PiSSA和LoRA-XS虽然报告了更低的StarCoder和GSM8K困惑度，但Wiki困惑度最高，说明它们主要靠欠拟合来限制遗忘；而将Rényi-2惩罚应用到PiSSA和LoRA-XS上可以同时改善任务拟合和保留。单任务GSM8K上配合晚启动调度也能在提升目标任务拟合的同时减少参考探针上的遗忘。奇异方向分析揭示了一个反直觉的发现：惩罚后和标准LoRA在无预训练对应方向的奇异值质量占比几乎相同（0.97对0.96），但惩罚后的适配器遗忘远少，说明关键不在于是否存在“入侵维度”，而在于更新的主导部分是否以均衡、承载信息的方式使用了分配的秩预算。局限方面，NB-LoRA路线训练不稳定，惩罚权重的选择仍需针对模型和秩做一定调参，且实验主要围绕MLP的down_proj层和有限模型规模展开，更大规模模型和更多模块类型的泛化性有待验证。但这项工作把有效秩从一种事后诊断指标提升为可训练的训练目标，为LoRA类参数高效微调提供了一个与现有改进正交的新优化轴，对理解和改善持续学习中的灾难性遗忘具有方法论层面的启示。

### [AgentSSL: Can MLE Agents Leverage Unlabeled Data?](https://arxiv.org/abs/2611.17323)
`评分3 · NeurIPS 2026. Project Website: https://codiscovery.ai/AgentS`

这篇论文瞄准的是一个在真实部署中非常常见、但此前被 MLE agent 研究系统性回避的场景：标注数据稀缺、无标注数据充足。现有 MLE agent（如 MLE-Bench 上那些把 Kaggle 竞赛百分位从 45.2% 推到 83.1% 的系统）几乎全部在全监督设定下评测，训练集动辄成千上万条标注样本，因此 agent 被隐式地优化成"在标注充足时搜程序"的搜索器，它默认可以用一个规模可观的标注验证集来给候选程序打分。可现实中的科学发现、医学诊断、生态监测恰恰相反：标注昂贵、无标注数据海量。把问题放进半监督学习（SSL）框架后，新的困难浮现出来——SSL 方法本身对数据分布与算法假设（聚类结构、增广一致性等）的匹配程度极其敏感，同一套方法换个数据集就要重新调参，这种脆弱性意味着"用 SSL"本质上是一个在巨大设计空间（图标签传播、伪标签、一致性正则等）里的搜索问题。于是论文把 AgentSSL 形式化为两个子问题：程序发现（在弱反馈下让 agent 搜出有效的 SSL 程序）和程序选择（在没有大规模标注验证集的情况下从候选池里挑出唯一一个用于部署），并明确指出后者才是真正的瓶颈。

方法上的关键洞察是把 SSL 程序的构造定义成一个比"训练某个固定参数化模型"更一般的映射：程序接收标注集与无标注集、返回一个预测器，从而把深度 SSL、经典直推式方法、图方法都纳入同一搜索空间。Agent 的搜索被建模为在一张程序有向无环图上的增长过程，贪心、MCTS、进化交叉分别对应扩展单节点、树搜索和双亲合并，每轮 agent 选节点、施加 Draft/Debug/Improve/Analyze 四类算子生成新程序、用适应度函数打分后入图。适应度函数是设计的核心变量，论文对比了两类反馈：一是从少量标注里划出的"噪声验证"信号，直接但有高方差；二是无监督指标，用无标注验证集上由预测或表征算出的无标签统计量给程序打分。搜索策略（贪心/进化/MCTS）和 LLM 骨干则分别控制探索-利用权衡与算子实例化。值得注意的是，论文发现即使无监督反馈与最终准确率弱相关甚至负相关，agent 依然能搜出有竞争力的程序——这说明 agent 的探索能力部分独立于反馈质量，它会跨越数十年的 SSL 研究史去组合多样思路，最强的 agent 程序能同时利用无标注数据和领域特定结构。但发现强程序不等于能挑出强程序：当按 agent 自己的反馈指标做选择时，性能最多掉 47%，这正是论文强调的"程序选择瓶颈"，为此作者构建了 ProgramSelectBench，包含 16,977 个 agent 生成与人工设计的 SSL 程序、累计超过 10,000 GPU 小时，用来系统评测无监督选择与主动选择两条路线。主动选择的思路是：当无监督指标失效时，把有限的标注预算花在"选程序"上而非"训程序"上反而更划算。

结果层面，在 12 个设定中 agent 有 8 个超过了最强的人工 SSL 基线，最高提升 +21.8%，这是在反馈信号很弱、算力对齐的条件下取得的，说明 agent 确实能自主发现领域适配的 SSL 策略。论文还把 AgentSSL 放到真实生态学动物检测任务上验证，既展示了降低标注成本的潜力，也暴露了把 agent 发现的策略迁移到受控分类基准之外时的不稳定性。局限也很清楚：程序选择仍未解决，无监督指标依赖的假设一旦不成立就会失效，噪声验证的方差与评估成本的权衡目前还是按数据集手工调、没有自动化；主动选择方法此前只在"同一微调流程下不同骨干/超参"这种同质候选集上评测过，而 AgentSSL 的候选程序在架构、训练流程、超参上差异巨大，现有选择方法能否 scale 仍是开放问题。总体而言，这篇工作的意义在于把 MLE agent 的评测从"标注充足"推到"标注稀缺"，并用 ProgramSelectBench 把"选程序"这一被长期忽视的环节变成可量化研究的问题——它提醒我们，agent 能搜到什么和最终能部署什么，是两件需要分别解决的事。

### [Detection of local recombination and mutation hotspots in bacterial genomes using neural posterior estimation](https://arxiv.org/abs/2611.13763)
`评分3 · 有代码`

这篇论文要解决的是细菌基因组上局部重组率和突变率推断的问题。在细菌中，重组表现为供体基因组的短片段被整合进受体基因组，效果更接近真核生物中的基因转换而非交叉互换，因此 ancestral recombination graph（ARG）加上基因转换才是描述这一过程的正确框架。但精确推断 ARG 中发生过哪些具体事件极其困难，而且遗传数据对具体事件的信息量本身就很弱，即使能精确推断，结果的不确定性也很大，所以作者把目标降级为推断速率本身。真正的难点有三层：第一，重组和突变在序列数据中留下的信号是重叠的，高重组会带来同质性（homoplasy），而高突变也会产生类似模式，两者容易混淆；第二，克隆关系是一个强混杂因素，细菌的克隆结构会让亲缘关系近的基因组天然共享更多相同位点，如果不把这个因素控制住，就会把克隆关系误读成低重组或低突变；第三，全基因组测序已成常规，推断必须能扩展到整个基因组、逐基因给出速率，而此前 Ansari 和 Didelot 的方法基于近似贝叶斯计算（ABC），需要选距离函数和接受容差，且每换一个观测就要重新跑一遍模拟，计算上无法支撑对成百上千个基因分别做推断；同时已有方法通常假设突变率恒定，或者只依赖少量摘要统计量，无法同时处理突变率沿基因组变化这一事实。作者的做法是把问题建模在 ClonalOrigin 模型下——这是对带基因转换的 ARG 的一个近似，条件化在固定的克隆系统树上，非克隆谱系只能与克隆树合并、彼此之间不合并也不再重组，这一限制既符合非克隆谱系携带的祖先材料很少这一事实，又让过程沿基因组保持马尔可夫性，从而使模拟变得廉价。

方法上的核心是三步。第一步是把基因组切成若干区段（文中统称"基因"，不一定是生物学意义上的基因单元），每个区段有自己的重组率、突变率和长度，然后用 ClonalOrigin 前向模拟生成大量"参数—观测"对：沿克隆树按枝长比例抽取重组事件的出发点和到达点，用几何分布刻画重组片段长度并利用其无记忆性逐位点更新活跃事件集合，再在每位点的局部系统树上按突变率抽突变，最终得到模拟比对。第二步是用神经后验估计（NPE）替代 ABC 的拒绝采样：训练一个条件密度估计器直接逼近后验，损失函数是最小化生成参数在估计后验下的负对数密度，等价于最小化估计后验与真实后验之间的 KL 散度，作者用的是 NPE-C（自动后验变换）变体，因为所有训练模拟都直接从先验单轮抽取，不需要提案修正。密度估计器采用条件神经样条流（NSF），把简单基分布变换成依赖观测的灵活密度。关键工程细节是压缩网络：输入是全部摘要统计量加上基因长度，先过一个 MLP 压成 m 维非线性特征，但作者把原始基因长度原样拼回输出向量末尾，形成"保长度"的嵌入，再喂给 NSF。这样设计的原因是基因长度既作为参数又作为观测输入，让网络在训练中学会长度如何影响其他统计量的信息量，从而训练一次就能适用于各种长度的基因；推断时对每个基因只需一次前向采样即可得到后验样本，无需逐基因跑 MCMC，这正是摊销推断带来的可扩展性。第三步是热点检测：作者没有简单挑后验速率最高的基因，而是提出循环后验传播的高斯差分检测器（ppDoG）。它把染色体上各基因的后验对数速率视为一个不规则采样的空间信号，用窄带宽高斯平滑器代表局部速率、宽带宽平滑器代表区域背景，两者之差即为 ppDoG 得分，取指数后就是局部相对背景的富集倍数；平滑时使用循环基因组距离，使染色体首尾基因互为邻居，并且每个基因的贡献按其后验精度加权。更重要的是，这个得分是在每一条后验抽样上分别计算的，再对 M 条抽样统计富集超过阈值 F_min 的比例，得到后验热点概率，从而把 NPE 的后验不确定性完整传播到热点判定中；后验热点概率不低于 0.9 的基因被列为候选。这个设计识别的是相对空间富集而非绝对速率高低：一个高速率区域如果周围背景同样高，响应反而弱；一个中等速率若形成孤立的局部峰，响应则强。

结果方面，作者先在已知真值的模拟数据上验证：方法能恢复真实的重组率和突变率，可信区间随基因长度增加而收窄，并用经验覆盖率、欧氏误差、模拟校准（SBC）和 TARP 做了校准检验，覆盖率低于或高于 95% 分别指示过度自信或不够自信，同时因为基因长度被直接输入并保留在压缩嵌入中，推断出的长度与真值的一致性也作为流程信息保真的额外检查。在方法比较上，作者报告在所考察的配置下 NPE 在统计性能和计算效率的组合上优于神经似然估计（NLE）和神经比率估计（NRE），后两者的细节和实证对比放在补充材料中。真实数据应用覆盖了蜡样芽孢杆菌、金黄色葡萄球菌和大肠杆菌三个已有数据集，展示了方法在不同情境下的可用性。局限也需要客观看待：整个推断建立在 ClonalOrigin 这一 ARG 近似之上，非克隆谱系不与彼此合并、不再重组的假设在重组频繁或非克隆材料较多的场景下可能偏离真实过程；克隆系统树被视为固定且已知，树本身的不确定性没有进入后验；热点检测的带宽和富集阈值仍需按应用设定，虽然作者在补充材料中给出了解释，但并非完全免调参；此外方法推断的是相对速率沿基因组的分布，绝对速率的解释仍依赖模型假设。尽管如此，这项工作把摊销式神经后验估计引入细菌群体基因组学的局部速率推断，用一次训练换取全基因组逐基因的快速后验采样，并把后验不确定性显式传播到热点判定，为在全基因组尺度上系统扫描重组和突变热点提供了一个可复用的框架。

### [Deep learning-guided discovery reveals the diversity and mutational potential of environmental beta-lactamases](https://arxiv.org/abs/2611.14568)
`评分3`

这篇论文要解决的是环境微生物组中β-内酰胺酶功能多样性认知严重不足的问题。β-内酰胺酶是细菌对抗β-内酰胺类抗生素的主要机制，根据Ambler分类系统分为A、B、C、D四类，其中A、C、D为丝氨酸酶（依赖保守的Ser-X-X-Lys基序催化），B类为金属酶（依赖锌离子水解）。尽管临床来源的β-内酰胺酶已被大量表征，但自然环境（土壤、水体、废水、宿主微生物组等）中存在的同源序列的功能特性和突变潜力仍不清楚。之前的方法卡在两个地方：一是传统的序列同源性搜索（如BLAST或HMM扫描）难以有效识别与已知酶序列差异较大的远缘同源物，因为这些序列虽然保留保守结构域，但整体相似度可能低至30%左右，基于比对的方法灵敏度不够；二是即便找到了候选序列，也缺乏系统性的功能验证和突变潜力评估手段，无法判断这些环境酶是否具有实际的抗生素水解活性、以及它们通过序列变异获得新抗性的可能性有多大。这就导致了一个关键缺口：环境微生物组作为一个巨大的β-内酰胺酶基因库，其真实多样性、生态分布规律和进化潜力都未被系统揭示。

作者的核心思路是用蛋白质语言模型（PLM）提取序列的深层表征，再结合集成学习做分类识别，从而突破传统同源搜索的灵敏度瓶颈。具体来说，他们选用了ESM2-t33-650M作为特征提取骨干，对每条蛋白序列的每个氨基酸残基生成1280维嵌入向量，去掉序列首尾的特殊token后保留残基级表征。然后设计了五个互补的分类器——三个深度学习模型（MLP捕获全局特征、CNN通过多尺度卷积和最大池化识别保守基序和局部结构签名、BiLSTM双向处理捕获长程上下文依赖）加两个传统机器学习模型（SVM和随机森林，在小样本条件下泛化更稳健），采用软投票策略将各分类器的类别概率加权平均后取最高者作为最终预测。五个基分类器用五折交叉验证训练评估，分层采样保证每折类别分布与原始数据一致。关键洞察在于：PLM的嵌入空间能够编码与蛋白功能和进化相关的特征，使得远缘同源序列在嵌入空间中仍然靠近，从而让分类器在序列相似度很低的情况下也能做出准确判断。集成模型在所有折上都正确分类了每个验证样本且置信度高，而单个基分类器在不同折之间表现有波动。用这个框架对MGnify蛋白数据库（2024_04版）进行挖掘，先用各类的HMM profile做初筛、按200-400氨基酸长度过滤，再用集成模型精筛降低假阳性，最终在四个Ambler类中鉴定出超过46000条候选β-内酰胺酶序列。值得注意的是，候选序列的类别组成与已知参考序列的分布明显不同——已知序列中A类占主导，而环境候选里B类和C类多样性和丰度更高，说明临床上对A类的偏重可能扭曲了我们对β-内酰胺酶真实多样性的认知。在突变潜力预测方面，作者进一步结合了蛋白质逆折叠模型与PLM来识别可能改变抗性谱的高适应度突变位点，并通过实验验证了一些替换能提高对碳青霉烯类药物的抗性。逆折叠模型的思路是：给定一个蛋白骨架结构，预测在每个位置哪些氨基酸替换在结构上是可兼容的，结合PLM对突变后序列的功能合理性评分，筛选出既有结构可行性又有功能增益潜力的突变。实验验证方面，作者从每个Ambler类中挑选了与已知酶序列相似度仅约30%的候选进行功能测试，选取了两个来自不同抗生素压力环境、与已知β-内酰胺酶同源性低的C类候选（Prot22和Prot94），以已知C类酶AmpC为阳性对照，用pET26b载体在E. coli中异源表达（去除天然信号肽、统一使用载体编码的pelB信号肽引导周质定位），测定了一系列β-内酰胺抗生素的最低抑菌浓度。结果这些远缘候选确实赋予了宿主对多种β-内酰胺类药物的抗性，证实了计算预测的功能有效性。

在结果层面，这项工作将环境β-内酰胺酶的已知数量从数据库中的1778条实验表征序列大幅扩展至超过46000条高置信度候选，且这些候选广泛分布于全球各类栖息地，具有明显的栖息地相关类别组成差异——B类在几乎所有环境中都占主导（34.0%-44.5%），支持环境微生物组是B类金属酶重要储库的推断；废水和活性污泥中B类和C类共富集，可能与该环境持续接收来自生活、临床和工业的微生物和化学物质、以及高细胞密度促进水平基因转移有关；而粪便样本中A类占48.38%、D类占11.9%，反映了宿主肠道环境的选择性富集。实验验证的候选与已知酶仅约30%序列相似度仍具有广谱抗性活性，突变预测还发现了能增强碳青霉烯抗性的替换，且预测的高适应度位点总体上呈现更大的自然序列变异性，废水来源的酶比海洋来源的变异更高，暗示不同环境的选择压力差异可能塑造了酶的突变空间。局限方面，实验验证的候选数量仍然有限（每类仅选了两个代表），计算预测的突变潜力尚未在大量酶上系统验证，MD模拟虽然提供了结构机制线索但毕竟是模拟而非直接结构解析；此外MGnify数据库本身的采样地理偏倚（北美、亚洲、欧洲占绝大多数，非洲、南美、大洋洲数据稀疏）意味着全球分布分析可能反映的是测序投入的偏差而非真实的生态分布格局。但无论如何，这项工作建立了一个可推广的“PLM+集成学习”挖掘框架，证明了环境微生物组中存在着大量功能活跃且序列远缘的β-内酰胺酶，其突变空间比预想的更宽广，为评估环境抗性基因库的潜在风险提供了系统性基础。

### [When gene summaries reveal the answers: Gene Ontology circularity in gene embedding benchmarks](https://arxiv.org/abs/2611.11118)

这篇论文要解决的是基因功能预测基准测试中一个长期被忽视却足以扭曲结论的评测污染问题：NCBI Gene页面上展示的基因摘要，有相当一部分并非由人类策展人撰写，而是由Alliance of Genome Resources用模板从GO注释自动生成的句子。也就是说，当GenePT这类方法把这些摘要编码成文本嵌入、再在GO注释预测任务上评测时，模型输入里已经包含了部分评测标签的“散文版答案”，分数虚高在所难免。作者统计发现，在19,256个人类蛋白编码基因中有6,172个（32.1%）携带这种自动生成摘要，而且分布极不均衡——没有关联文献的基因中占56%，1到10篇文献的基因中占58%，而101到1000篇文献的基因中仅占6%。恰恰是文献稀少、最需要被基准测试关注的“被研究不足”基因，最可能拿到这种自带答案的摘要。此前并非无人意识到注释循环性的风险：SPINDOCTOR讨论过从生成描述中反推GO注释的可能性，DEGEmbedR区分了自动描述与其他来源，Zhong等人也把评测限制在实验证据注释上；但实验证据同样会被Alliance优先写进生成句子，而且旧摘要仍能提供基因此前的注释画像，所以这些过滤手段都没有真正切断输入文本与评测标签之间的同源关系。

论文的核心方法不是提出一个新模型，而是设计了一套“保持评测基因与交叉验证折不变、只改动输入语料”的受控对照实验，把摘要来源的贡献从其他因素中剥离出来。作者用Qwen3-Embedding-8B编码GenePT的文本，构造两个版本：一个保留全部摘要，另一个把5,851个基因的生成摘要删掉、只留“Gene Symbol X”，然后各自拟合线性探针和多层感知机，在同一批留出基因上比较。结果在线性探针下，1到10篇文献组的单基因GO AUROC从0.883降到0.849，降幅0.078（95%自助区间0.072–0.084），MLP下也有0.033的下降。更关键的是他们做了几组精巧的替换对照来区分“删掉任何描述都会掉分”和“删掉直接由标签生成的文本才掉分”：把生成摘要换成RefSeq摘要，降幅只有0.054，比删生成摘要少0.087；换成Qwen2.5-7B写的描述，得分甚至比只留基因符号还低0.007，说明损失并非来自信息量减少，而是来自与标签同源的措辞。但UniProt功能描述给出了一个耐人寻味的结果——它与生成摘要长度相当，逐字重合率仅3.0%（生成摘要是29.5%），却几乎完全补回了性能，与生成摘要只差0.004。作者进一步分析发现，UniProt策展人贡献了GOA中24%的人工GO注释和29%的实验注释，也就是说UniProt文本与评测标签共享的是“策展来源”而非字面文本，这种隐性同源同样能抬分。此外，TF-IDF这种无预训练编码器也能从生成摘要中获益0.043，说明问题出在输入文本本身而非编码器容量；在实验证据过滤下降幅反而更大（线性探针0.098，生物过程单项达0.118），因为Alliance恰恰优先把实验支持的术语写进句子。作者据此提出GeneProv基准，用固定文本轨道衡量换语料的影响、用开放轨道在记录输入来源的前提下比较表示，并引入GO恢复、非GO终点和共必需性等不同证据来源的任务来检验表示排名是否稳健。

结果层面，除了上述AUROC降幅，论文还给出了几组有分量的数字：在Zhong等人38个嵌入的基准协议中，保留生成摘要使56个GO术语的平均留出AUROC提高0.016（Wilcoxon p=0.0001）；在IBM基因基准的MPNet编码器下，28个生物过程任务平均提高0.010（25/28为正），22个表达特异性任务提高0.012（全部为正），HPA生物过程注释增益最大达0.032；而在基因–基因相互作用任务上仅变化0.005，说明效应集中在功能注释类终点。时间维度上，用2026年文本评测“基准词表内首次获得注释”的基因，生成摘要使AUROC从0.800升到0.861，但换成GenePT的2023年旧文本则几乎无差异（0.789对0.798），清晰展示了“未来文本泄露未来注释”的机制；在Zhong的时间切分任务中，即便2023年摘要没有逐字提到留出术语，删除摘要仍使AUROC降0.024，且降幅主要来自负样本选择——对有生成摘要的负基因，AUROC从0.744骤降到0.660。局限也很明显：历史GO评分器对并列处理有误且原始预测不可得，无法精确重算修正后的效应量；替换对照中LLM描述的长度、准确度和细节混杂，难以完全归因；已发布嵌入的观察性比较无法排除同一暴露层内基因本身的其他差异；UniProt与标签的共享策展来源只能做探索性量化，尚未形成可完全分离的因果设计。但这项工作的方法论意义很直接：它把“文本嵌入在基因功能预测中常常排名靠前”这一结论的解释权交还给了文本来源审计，提示任何用自然语言描述做基因表示的学习方法都必须报告描述的生产者与生产依据，否则基准排名可能只是在测量谁更擅长复述答案。

### [AI for Biologists: The Knowledge Boundaries of Foundation Models in the Age of Agentic Systems](https://arxiv.org/abs/2611.17015)
`评分3 · To be published on Annual Review Biomedical Data Science`

这篇论文要解决的是生物医学研究中一个日益紧迫的实际问题：当生物基础模型和建立在大型语言模型之上的智能体系统越来越多地被用于预测蛋白质结构、突变效应、细胞对基因扰动的响应等任务时，研究者往往无法判断这些模型的输出在什么范围内可信。问题的根源在于，当前基础模型的构建过程——从数据选择、架构设计到训练策略——缺乏对“知识边界”的显式刻画。以往的方法要么只报告模型在特定基准上的平均性能，要么依赖事后经验来判断可靠性，但这两者都无法告诉使用者：面对一个具体的输入，模型是否处于其能力范围之内。更麻烦的是，当智能体自动调用基础模型作为工具执行多步分析时，错误会沿着流程传播放大，而使用者可能根本没有意识到某个中间步骤已经越界。因此，论文将“知识边界”定义为模型输出可靠的输入、任务和条件的范围，并试图系统性地解释这个边界是如何被构建过程所决定的。

论文的核心洞察在于，基础模型的知识边界并非事后才能观测到的模糊属性，而是由五个设计要素共同塑造的：数据、架构、训练方案、评估方案和后分析处理。具体来说，训练数据的覆盖范围和偏差直接决定了模型在哪些输入分布上具有内插能力、在哪些区域只能外推；架构的归纳偏置（比如对序列局部性或对称性的假设）限制了模型能表达的函数空间；训练方案中的目标函数和正则化策略影响了模型在稀疏数据区域的泛化行为；评估方案如果只覆盖常见任务和基准分布，就会系统性地高估模型在边缘条件下的可靠性；而后分析环节——包括不确定性量化和输出校准——则决定了模型能否在推理时“知道自己不知道”。论文主张，通过对这五个要素进行标准化描述，可以事先刻画出一个模型的知识边界轮廓，而不是等到部署后再被动发现失败模式。这一思路比之前的方法更进一步的地方在于，它把可靠性问题从“跑分”转向了“边界刻画”：不是问模型在平均意义上有多好，而是问它在什么条件下可靠、什么条件下不可靠，并且这种刻画可以传递给下游的智能体系统，使智能体在调用基础模型时能够根据输入条件判断是否应该信任输出、是否需要引入额外验证或回退策略。

在结果与意义方面，论文通过梳理现有证据展示了当前生物基础模型在哪些任务上表现稳健、在哪些条件下出现系统性失败，并给出了模型局限的标准化描述模板，使研究者和智能体能够据此做出更可靠的调用决策。虽然摘要中没有给出具体的性能提升数字，但论文的贡献不在于刷新某个基准的分数，而在于提供了一套可操作的框架来界定模型的能力范围。其局限也很明显：五个设计要素与知识边界之间的映射关系目前更多是定性或半定量的，如何为每个要素定义可计算的边界指标、如何在不同模型之间进行边界比较、以及如何在智能体系统中实时执行边界检查，都还是开放问题。此外，标准化描述本身依赖于模型开发者主动披露训练数据构成和评估覆盖范围，这在当前开源生态中并不总是可行。尽管如此，这篇论文的方向性意义在于，它把基础模型在生物学中的可靠性问题从“信任与否”的二值判断，推进到了“在什么条件下可信”的结构化刻画，这对于构建负责任的智能体科研助手来说是绕不开的一步。

### [Protein Language Models Fail To Capture Contact Predictions Under Invariant Relabeling](https://arxiv.org/abs/2611.16881)
`评分3 · Accepted to the ICBINB - Failure Modes of AI in Biology Work`

这篇论文针对的是蛋白质语言模型在接触图预测上被广泛信任的一个核心假设：模型之所以能从单序列输入中预测出高精度接触图，是因为它们隐式学到了与经典共进化方法（如 Potts 模型）等价的、对氨基酸字母表置换不变的共进化统计信号。作者要检验的正是这个假设是否成立。他们设计了一个诊断性扰动——对氨基酸字母表做全局双射重标记，也就是把 20 种残基的字母身份做一个任意置换，但保持序列比对层面的所有信息不变：列熵不变、成对编辑距离不变、共进化结构不变。关键洞察在于，经典 Potts 伪似然模型和逆协方差估计器在这种重标记下是可证明不变的，因为它们的参数化只依赖于残基之间的等价关系而非残基的具体标签；如果 pLM 真的学到了纯粹的共进化统计，它也应该对这种重标记保持不变。然而实验表明 pLM 并不具备这一不变性，这直接动摇了“pLM 隐式学到了共进化统计”这一流行叙事，说明之前的方法评估只看了预测精度，却没有检验模型是否以正确的方式利用了正确的信号。

为了定位失效的根源，作者在多个架构（ESM-2、MSA Transformer、AMPLIFY）和从 8M 到 3B 参数的多个规模上系统性地施加随机重标记，并配合两类控制实验来隔离混杂因素。第一类是 Hamming 距离控制，用来排除重标记后序列间距离分布变化带来的影响；第二类是生化分组干预，即按照氨基酸的生化性质（如疏水、极性、带电）重新分组标签，观察模型对生化类别的敏感度。结果显示，在任意重标记下 pLM 的接触图质量全面崩溃，而 Potts 类模型纹丝不动。进一步的干预表明，模型实际上依赖的是显式的、规范化的残基身份——作者称之为“字母表锚定”（alphabet anchoring），也就是说模型在训练中把特定的字母符号与其在自然蛋白质中出现的统计角色绑定了起来，而不是纯粹从共进化模式中提取接触信息。一个有意思的细节是，增大模型规模会让模型对生化类别更加敏感，说明大模型确实学到了更丰富的残基层面表征，但即便如此，重标记下的性能退化依然存在，意味着规模并不能修复这种锚定偏差。换句话说，pLM 的接触预测能力部分来自于对训练分布中字母身份的记忆性关联，而非对置换不变的共进化信号的提取，这与经典方法在计算机制上有本质区别。

在结果层面，论文的核心数字是：在标准接触预测基准上，pLM 原本能给出相当高的精度，但在施加随机字母表重标记后接触图质量大幅下降，而同等条件下 Potts 模型的预测完全不变，两者形成了鲜明对比；这一模式在从 8M 到 3B 参数的整个规模范围内一致出现，排除了“规模不够所以没学到不变性”的解释。论文的意义在于两方面：一是对蛋白质语言模型的可解释性和可靠性提出了严肃警告——高精度接触图不等于学到了正确的物理/进化信号，在分布外或标签体系变化时可能不可靠，这对下游结构建模的信任度有直接影响；二是方法论上的贡献，即展示了“对经典模型可证明不变、对神经网络却能暴露隐藏偏差”的诊断性扰动，是一种比单纯看精度更深刻的评估范式，可以推广到其他生物建模场景中，防止对神经黑箱的过度依赖。局限方面，论文主要聚焦于接触图这一任务和氨基酸字母表重标记这一种扰动，尚未证明字母表锚定是否也影响其他下游任务（如突变效应预测、结构生成），也没有提出修复这一偏差的具体训练方案；此外，重标记在自然界中并不对应真实的生物学变换，其生态效度需要进一步讨论。但作为诊断性工作，它清晰地划出了 pLM 与经典共进化模型之间的机制鸿沟，对后续设计更具不变性的蛋白质表示学习方法是直接的推动。

### [PDO Drug Screening Data for Evaluating and Training AI Drug Response Prediction Models](https://arxiv.org/abs/2611.15769)
`评分3`

这篇论文要解决的是抗癌药物反应预测（DRP）模型在临床转化中面临的一个根本性错位：绝大多数DRP模型是用永生化癌细胞系（CCL）的大规模药筛数据训练出来的，但模型最终要预测的是患者肿瘤的反应，而CCL经过长期二维培养后，在基因组和分子层面已经与患者肿瘤产生了实质性偏离——细胞异质性丢失、三维组织结构消失、肿瘤微环境缺失。患者来源类器官（PDO）作为三维培养体系，能更忠实地保留原发肿瘤的基因组、分子和表型特征，是连接细胞系与患者肿瘤之间更合理的桥梁。但问题在于，PDO的药筛数据规模远小于CCL，此前几乎没有专门为DRP模型开发与评估而系统生成的PDO药筛数据集，这就构成了一个数据瓶颈：想验证模型在更接近患者的体系上是否有效，却没有足够的数据可用。作者还特别指出，他们选择结直肠癌和头颈癌作为重点，是因为此前分析显示这两类癌症的DRP预测精度相对较低，积累数据有助于改善。

作者开展了四项PDO药筛研究（三项属于IMPROVE项目，一项为Pilot 1），覆盖结直肠癌、头颈癌和肉瘤，生成了配套的多组学图谱、药物特征数据和活性测量值。关键设计在于三项IMPROVE研究之间刻意设置了重叠的PDO系和化合物，使得不同实验室、不同检测技术（3D高内涵成像 vs. CellTiter-Glo 3D ATP释放法）和不同实验流程产生的活力数据可以跨平台直接比对，从而评估药筛测量的可重复性——这是此前PDO数据中很少被系统检验的维度。在模型评估层面，作者选取了六个公开DRP模型（涵盖图神经网络、Transformer、梯度提升树等不同架构），设计了三种学习策略：仅用CCL训练后直接迁移到PDO、CCL与部分PDO联合训练、CCL预训练后以PDO微调，并配合两种交叉验证方案——随机划分和癌症盲划分（训练/验证/测试集中的癌症病例互不重叠）。癌症盲划分是这里的关键洞察：随机划分会因同一癌症病例的数据泄漏而高估泛化能力，只有癌症盲划分才能真正检验模型对未见过的癌症病例的预测能力，也就是知识从CCL向PDO迁移的真实程度。通过这套设计，作者得以回答一个此前缺乏系统证据的问题：大规模CCL数据学到的知识到底有多少能迁移到PDO域，以及有限的PDO数据能否通过联合训练或微调带来实质性的性能增益。

结果部分的核心发现是：在PDO上评估时，仅用CCL训练的模型直接迁移表现有限，而引入PDO数据进行联合训练或微调后预测性能有可测量的提升，但提升幅度受限于PDO数据量——这正好印证了该数据集的价值所在，即为后续方法开发提供一个更贴近临床的评估基准。跨平台一致性分析则揭示了不同实验室和检测技术产生的活力数据之间存在可量化的差异，提示PDO药筛的标准化仍是未完全解决的问题。局限性也很明显：PDO系数量仍然有限（四项研究合计约数十个PDO系），癌症类型集中在结直肠癌、头颈癌和肉瘤，化合物覆盖虽尽量涵盖主要作用机制但远不及CCL筛选的规模，且PDO本身仍非患者肿瘤的完美替身——它缺乏免疫细胞和完整的微环境。不过这项工作真正的意义在于把DRP评估的“靶子”从细胞系向患者方向推进了一步：它提供的不仅是一个数据集，更是一套评估范式——跨平台可重复性检验加上癌症盲划分下的迁移学习评估——这对未来DRP模型是否真的具备临床相关性，给出了比单纯在CCL测试集上刷点更有说服力的检验手段。
