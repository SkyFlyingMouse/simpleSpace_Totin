## 大模型 LLM

### [Learning Video Foresight Reasoning from Unlabeled Videos via On-Policy Self-Distillation](https://arxiv.org/abs/2611.26954)
`评分3 · HF 38赞`

这篇论文要解决的是视频前瞻推理（video foresight reasoning）任务中训练信号来源受限、且监督信号质量不高的问题。所谓视频前瞻推理，就是让视觉语言模型（VLM）只看当前视频片段，去推断接下来会发生什么事件或下一步该做什么动作。此前的方法大致分三类：一类是监督学习，直接拟合未来片段的文本描述或推理依据（rationale），比如 Next-Event Prediction 用未来片段的 caption 和纯文本 LLM 生成的 rationale 做监督；第二类是把推理对齐到未来的视觉状态，比如 TwiFF 显式地用未来帧推理、FUTURE-L1 让隐式推理与未来帧的嵌入对齐、IVT 在微调时加入下一嵌入预测；第三类是用强化学习，靠答案、事件或生成质量构造奖励。这些方法卡在两个地方：第一，监督信号要么依赖人工标注的 ground-truth，要么依赖外部大模型（LLM 生成 rationale、LLM 当裁判），这严重限制了可扩展性，因为标注和调用大模型都很贵；第二，它们把整个未来片段当作同等价值的目标去拟合，但未来信息对当前问题的有用程度其实极不均匀。论文举了一个很直观的例子：要预测“下一步做什么”，真正与事件相关的内容信息可能只是“冲洗刀具”这一个动作，而画面里的水龙头、沥水架、水槽这些大部分内容都是无关的上下文信息。均匀地拟合整个未来片段，会让模型把大量算力浪费在无关上下文上，反而稀释了真正决定决策的内容信息。所以核心动机就是：能不能不靠任何标注和外部大模型，只用视频自身天然存在的“过去—未来”配对，构造出自监督信号，并且让模型学会自动挑出未来片段里最有价值的那部分信息。

方法上的关键创新有两个，且是耦合在一起设计的。第一个是采用 on-policy 自蒸馏（on-policy self-distillation）框架，把过去—未来视频对变成自监督信号。具体做法是：把每段视频切成过去片段 X（含问题）和它对应的未来片段 Z（称为 paired future）；学生模型只看过去 X，生成一段“推理+答案”的回复 Y；教师模型是初始学生模型的一个冻结副本，它额外能看到配对未来 Z，并对学生生成的这段回复逐 token 打分。注意这里教师不是外部大模型，而是同一个模型在有未来信息时的冻结版本，所以完全不需要标注，也不需要 LLM 裁判，天然可扩展。第二个创新是定义了一个 foresight score（前瞻分数），用来衡量学生回复与真实未来的匹配“特异性”。它的思想源自 InfoNCE：不是看教师对回复的绝对概率，而是看配对未来下教师给该回复的概率，相对于在一堆随机参考未来（从别的视频里采样的未来片段）下平均概率的比值——也就是这个回复到底有多“专属”于这段真实未来。直接优化这个分数是不可行的，因为它要对所有可能的未来求期望，归一化常数算不出来。于是论文推导了一个可计算的下界代理目标（Theorem 2），这个代理目标在两个优势之间做插值：一个是 contrastive privilege advantage，即同一个回复在配对真实未来和无关参考未来下教师打分的差，用来压制那些在所有未来下都成立的共享上下文信息、放大只属于配对未来的内容信息；另一个是 teacher–student distillation advantage，即向配对未来教师做蒸馏，防止学生跑偏。两者用一个 λ 加权（实验中 λ=0.75），并证明了在 KL 正则下这个插值目标确实是 foresight score 的下界。直观地说，对比项负责“挑出有价值的信息”，蒸馏项负责“别学歪”，二者合起来既放大了决策相关的内容信息，又抑制了无关上下文。最后把这个序列级目标转成 token 级的 PPO 更新：每个 token 用即时奖励作为优势，优势做裁剪和批内中心化，用带 clip 的重要性采样比做 PPO 损失，教师、rollout 策略和优势都保持固定，只更新学生。推理时只用学生，不需要未来片段。

实验结果上，论文在 Qwen3-VL-8B-Instruct 和 Qwen3.5-9B 两个基座模型上验证，覆盖两个任务：开放式预测在 Future-L1（5 万片段）上训练、在 TwiFF-Bench（1078 题）上评测，用 Qwen3.6-27B 裁判对推理和答案分别打 1–5 分再归一到 0–100；封闭式规划在 EgoPlan-IT（约 4.3 万道四选一下一步动作题）上训练、在 SEED-Bench-R1 上评测，用准确率。相比基座模型，Future-OPSD 在开放式预测和封闭式规划上分别最多提升 14.2 和 15.9 个点，并且稳定超过 Naive OPSD（只做蒸馏、不做未来对比的版本），说明 foresight score 那一套对比机制确实在起作用；同时增益能跨任务迁移，在 TempCompass、TemporalBench、Video-MME、MVBench 等通用视频理解基准上也没有明显掉点。消融还显示更强的教师（如 2B 学生配 4B 教师、4B 学生配 8B 教师）和更多训练数据都能进一步放大收益。局限方面，论文自己也指出：下界代理目标更高并不必然意味着真实的 foresight score 更高（因为常数项与参数无关但界不是紧的）；λ=1 即只保留对比、去掉蒸馏正则时可能出现训练崩溃；方法依赖“过去—未来”配对数据这一结构，对没有自然时间延续关系的视频任务未必适用；另外教师虽然冻结、但训练时仍需对每个回复在真实未来和参考未来下各跑一次前向，计算开销比朴素 SFT 高。总体而言，这篇工作的意义在于把视频前瞻推理的监督从“标注/外部大模型”转向“视频自身的时间结构”，并用一个有理论下界保证的对比+蒸馏目标解决了“未来信息价值不均”这个此前被忽视的问题，为无标注视频上的前瞻推理训练提供了一个可扩展、可解释的新范式。

### [Clover-35B-A3B-Preview Technical Report](https://arxiv.org/abs/2611.24636)
`评分3 · HF 36赞`

Clover 要解决的真实问题是：扩散语言模型虽然在并行解码上有理论优势，但在智能体任务（仓库级代码修复、终端操作）上始终打不过同等规模的自回归模型。论文复现的对比显示，LLaDA2.2 flash 和 DiffusionGemma 在 SWE-bench Verified 和 Terminal-Bench 2.1 上都落后于 Qwen 基线。卡点有两个层面：一是架构层面，标准块扩散模型在去噪当前块时，对已完成前缀的访问要么靠全注意力缓存（显存随上下文线性增长，长上下文下不可行），要么靠因果循环状态（只能单向压缩，丢掉了块内双向建模的好处）；二是效率层面，扩散模型一次并行预测多个 token，但真正能被接受的 token 数取决于验证环节，草稿质量和验证成本的权衡没被系统性地处理过。之前的工作如 Fast-dLLM 用近似 KV 复用和置信度并行解码来加速，DreamReasoner 用块大小课程学习扩展到长思维链，但都没有同时解决"高效访问长前缀"和"块内充分双向交互"这两个矛盾。

核心创新是 BD-GDN（Block-diffusion Gated DeltaNet），关键洞察是把"写已完成上下文"和"读它"拆成两条路径。干净路径沿用 Gated DeltaNet 的门控 delta 规则循环：每个干净 token 用保留门控制旧记忆衰减、用写入门控制新值写入强度，delta 规则写入的是"新值减去用当前 key 检索出的旧值"这个残差，得到一个固定形状的循环状态矩阵，与 token 数无关。噪声路径在去噪当前块时，从这个块边界处的固定前缀状态读出历史信息，同时让块内所有有效位置（包括尚未解析的 mask token 和查询自身）通过双向 softmax 注意力互相交互。关键设计是历史读出和块内 token 的 logits 被放进同一个 softmax 里归一化竞争：历史只占一个条目，块内每个 token 各占一个条目，每个 value head 学一个局部 logit 缩放、一个历史偏置和一个块大小系数，其中块大小系数乘以块有效长度与参考长度之比的对数，用来补偿"块越大、局部竞争者越多、历史被稀释"的效应——当所有局部 logit 相等且系数为 1 时，历史权重恰好与块大小无关。另外加了一条独立的右上下文深度卷积分支，宽度为 4 的因果核保留预训练权重，三个右向抽头零初始化，只在块内有效后继上取值、不跨块边界，保证初始化时等价于原因果卷积。MoE 侧用 dMoE 的块感知路由：先按块内所有 token 的 top-8 专家概率聚合，取覆盖 90% 总质量的最小专家前缀作为该块的专家核心集，再在核心集内做 token 级 top-8 选择，避免并行预测把路由打散到过多专家。整个设计凭什么更好：前缀状态形状固定，长上下文下显存不随历史增长；块内双向注意力不被循环状态的单向性压制；右卷积零初始化保证不破坏预训练行为，新增参数仅约 74 万。

结果上，Clover 在七项智能体指标上领先，SWE-bench Verified 73.6、Terminal-Bench 2.1 51.7，内部智能体负载下单张 GB300、BF16、batch size 1 报告生成速度 680 tokens/s。决策模型变体在 500 组内部数据上做单次去噪联合预测相关问题答案，问题准确率从 90.37% 提到 93.88%，全组全对率从 65.4% 提到 77.0%。局限也很明确：680 tokens/s 是内部负载下的报告值，不是标准基准上的端到端吞吐，实际接受 token 数受草稿质量和验证策略制约；BD-GDN 的历史读出只用一个 softmax 条目压缩整个前缀，信息瓶颈客观存在，块越大历史越容易被稀释，块大小系数的补偿是学习出来的而非理论上界；右卷积只在块内生效，跨块的长程局部依赖仍靠循环状态承担；决策模型变体的联合预测目前只在 500 组内部数据上验证，泛化性未知。意义在于它给出了一条可复现的路线：用混合循环-注意力骨干加块扩散，在保持并行生成的同时把智能体能力拉到有竞争力的水平，并开源了权重、SFT 代码和推理引擎，把"扩散模型能不能做 agent"从开放问题推进到工程可评估的阶段。

### [MemOnce: A Scalable Memory Architecture for Large Language Models](https://arxiv.org/abs/2611.27973)
`评分3 · HF 20赞`

这篇论文要解决的是大语言模型在长程持续交互场景下的记忆管理问题。现有架构面临一个根本性权衡：标准 Transformer 保留逐层、逐 token 的 KV cache，上下文一长，显存就线性膨胀、注意力计算二次方增长，导致长上下文推理既贵又慢；而 Mamba、RWKV、GDN 这类线性/循环模型把历史压进固定大小的状态里，换来常数内存和线性时间，但状态容量有限，长程细粒度信息会衰减丢失。介于两者之间的努力各有短板：混合架构和跨层 KV 共享（如 YOCO）虽然消掉了层数这个乘数，但缓存仍随上下文长度线性增长；稀疏注意力仍需维护或访问随长度增长的全局缓存，且路由索引要逐层计算；Titans、M+、Metis 这类原生记忆模型通过训练或后训练把历史压成紧凑表示，却常伴随性能下降、逐层检索开销或灾难性遗忘；Mem0、A-MEM 等外部记忆系统则要显式建库、维护成本高、难以端到端优化。核心问题于是变成：能否构建一种基础架构，同时做到准确召回、线性时间推理、以及有界的 GPU 缓存开销。

MemOnce 的关键洞察是把"记忆"从逐层逐 token 的缓存中解耦出来，只保留一份紧凑的全局记忆，并且每次持续输入只检索一次、再按需解码成各层 KV。具体有两个核心设计。其一是记忆编码器-解码器：它只缓存最后一层隐藏状态中每个片段末尾一小部分（默认压缩比 r=8，即只留 1/8）的 token 表示作为紧凑记忆，写入全局记忆库，这一步同时消掉了层数 L 这个乘数和序列维度的 r 倍，持久缓存被压缩 L·r 倍；推理时再用每层专属的轻量 MLP 投影，把这些末层语义表示解码回该层注意力所需的 K、V。这里的关键在于不是让所有层共享同一份 KV（那会限制各层表达力），而是用层特定的解码器从同一份语义记忆中"生长"出各层的 KV，形成一种循环式的记忆生成与使用。其二是记忆稀疏注意力：全局记忆库被划分为长期池和短期窗口，短期窗口保留最近若干条记忆以维持局部连续性，长期池则存放遥远历史；对每个持续输入，只用其末层表示经 MLP 投影和 L2 归一化后算余弦相似度，在长期池里做一次 top-K 检索，选出的记忆与短期窗口拼接成当前活跃记忆状态。最要紧的是这个稀疏路由索引只算一次，然后在所有注意力层和所有解码步中复用，而不是像逐层检索器或 token 级稀疏注意力那样反复计算路由。检索到的活跃记忆被解码成各层 KV 后，直接拼接到当前输入的局部 KV 前面参与注意力。由于活跃子集大小被常数预算 C 限制，活跃记忆缓存是 O(C·D)，对上下文长度和层数都是常数级，而可扩展的持久记忆库可以卸载到 CPU 内存或 SSD。实测端到端检索加载只需 64.2 毫秒，比 M+ 的逐层检索快 12 倍以上，比 RAG 流程快 17 倍以上。默认骨干是每个阶段三个线性块（GDN）夹一个记忆稀疏注意力块的混合结构。

实验从三个层面验证。作为基础架构，从零训练 150M 到 1B 参数，MemOnce 在验证困惑度和下游基准上不逊于甚至优于 Transformer、GDN、YOCO 等基线，即便在 r=8 的压缩比下也是如此。作为原生记忆模型，对 Qwen3.5-4B 做后训练适配，在覆盖 4K 到 1M token 的五个记忆基准上，它是首个超过全上下文基线的原生记忆模型，4B 规模上整体记忆性能提升 5.77%，比 M+ 高 18.68%、比 Metis 高 32.27%；1M 上下文下记忆状态缓存降低 1313 倍、prefill 延迟降低 6.9 倍、吞吐提升 3.5 倍。由于推理时参数冻结、且天然忽略无关的解码缓存，它在通用基准上没有出现灾难性遗忘。作为表示模型，学到的记忆表示能零样本迁移到检索和重排序任务，无需任务特定微调就超过专用模型。局限方面，论文未充分展开，但从设计可推断：压缩比 r 和 top-K 预算 C 是影响保真度的关键超参，极端压缩下的细粒度召回边界仍需更系统的压力测试；记忆库的写入策略目前依赖片段末位状态承载整段语义，对语义分布不均的长文档可能不够稳健；此外结果主要基于作者自建的训练与评测配置，跨更多模型族和真实 agent 长程任务的泛化性还有待社区复现。总体而言，MemOnce 把"缓存一次、检索一次、按需解码"这条路径做成了一个可训练的基础架构，在性能-复杂度帕累托前沿上推进了一步，也为原生记忆模型与表示模型的统一提供了有说服力的证据。

### [Self-WSP: Can Language Models Improve Themselves Through Weight-Space Programming?](https://arxiv.org/abs/2611.28833)
`评分3 · HF 7赞`

这篇论文要解决的是递归自我改进（RSI）在语言模型上的一个具体而尖锐的问题：模型能不能直接读写并修改自己的权重来提升能力，而不依赖外部数据、代码或梯度训练。此前语言模型自我改进的路径都是间接的——用自己生成的推理链、数据或奖励去重新训练，或者改写调用自己的代码，权重始终是通过训练这个中间环节被动变化的。Takehi等人已经证明一个强模型（GPT-6）可以读取并编辑另一个小模型的权重，像改代码一样把Qwen3.5-0.8B的MATH500准确率从7.9%拉到48.1%，但这留下一个关键空白：模型能不能编辑自己的权重？这篇论文正是要填这个空。动机很直接——如果模型能直接改自己的权重，那就朝RSI迈进了一步；但小模型能否胜任“编辑者”这个角色、它到底懂不懂自己在改什么，此前完全没有答案。

方法上的核心设计是一个单模型双角色的闭环：Qwen3.5-0.8B既当解题者又当编辑者，两个角色始终使用当前权重，所以每一次被保留的编辑都会同时改变它解题的方式和它下一次提出编辑的方式。作为编辑者时关闭思考，它看到的是系统预先算好的318个可编辑张量的目录（名称、形状、均值方差、最多64个带位置的具体数值、行列范数），以及当前模型在一批练习题目上的表现和参考答案；作为解题者时开启思考回答数学题。关键约束是编辑必须以JSON形式在由张量形状构造的语法下输出，每个提案包含一到两个编辑，每个编辑选中张量中一段连续元素、行或列，施加七种操作之一：置零、乘一个数、加一个数、填充一个数、按张量均值方差随机重抽、移除一个方向、或写一段短NumPy表达式。其中“移除方向”只对矩阵生效，编辑者指定某一列作为方向，被选中的每一列减去它在该方向上的分量乘以一个系数，系数为1就完全去掉该分量——GPT-6最有效的编辑也是移除方向，但它是从模型激活中算出来的，而这里编辑者只能从权重目录里自己挑。外层循环负责筛选：每个有效编辑先应用到权重副本上，然后在两个不相交的练习批次上测试，只有在两个批次合计多解出足够多的题且任一批次都不变差时才保留。系统跑两种接口，主要区别是张量目录的排序——乱序接口随机排列、编辑者直接选张量、每批32题、总共三轮预算分别为4/6/12个有效编辑；有序接口按层排列、编辑者先选层再选张量、每批128题、要求至少多对三题、每轮8个有效编辑。每轮结束后在验证集上打分（验证集从不反馈给编辑者），取验证增益最大的轮次作为该次运行的最佳模型，再从多次运行中选Top-1到Top-3在GSM8K和MATH500测试集上做最终评估；另外还按固定规则预先指定若干“抽查运行”来代表普通运行的真实水平。

结果相当戏剧性：24个被选中的模型里有22个显著优于原始模型。有序接口下自编辑把GSM8K从11.8%提到61.0%、MATH500从7.0%提到24.7%，继续叠加有序轮次后进一步到62.2%和32.2%。最惊人的是编辑的极小规模——那个24.2%的MATH500模型与原始模型只差16个数，全是第一层线性注意力层的A_log（控制每个头遗忘过去的速度），一个改32个数的GSM8K模型达到59.9%，还有一个继续运行的MATH500模型只差两个数却又涨了6.8个点，没有任何被选模型改动超过0.2%的权重。但论文非常诚实地拆穿了这些收益的来源：编辑者几乎不理解自己在做什么。它倾向于编辑目录里排在最前面的张量（有序接口下62%的编辑落在第0层，而乱序接口下第0层只占2.9%，且15个有序接口的选中模型全部编辑了第0层的A_log，乱序接口的9个一个都没有），编辑中的数值有9%到28%直接抄自它刚读到的统计量（比如-1.979这个均值反复作为缩放或偏移出现），附带的解释大量是幻觉——最极端的一条全文是“一把椅子的成本是11美元”，逐字抄自同一次调用中练习反馈里某个解题回答的结尾，与编辑毫无关系。11580个提案中69%连格式合法都做不到（重复已有编辑或整体缩放张量），有效编辑里只有12%被保留，而且它从不使用“移除方向”和“写表达式”这两种能表达结构化改变的操作。更麻烦的是，由于外层循环只看练习分数，乱序接口下超过40%的保留轮次实际降低了验证准确率，有序接口在MATH上也有三分之一如此；抽查运行平均只涨24.7点（GSM8K）和7.7点（MATH500），远低于被选模型的数字。随机搜索的对照进一步压低了叙事：在GSM8K上随机搜索的最佳模型32.8%与自编辑的31.9%不相上下，同预算下MATH500随机搜索找不到任何提升而自编辑能到17.3%，但随机搜索多花约70%预算也能找到一个13.6%的模型；GPT-6那个较简单的已发表编辑（把第15层注意力输出矩阵的256列置零）本质上落在单次随机编辑的分布范围内，评估得分22.0%/13.8%，和最佳单次随机编辑相当。自编辑真正跑赢随机的地方在于：在同样的筛选中，乱序接口的最佳自编辑模型在两个数据集上都超过了全部352个随机编辑，MATH500上继续运行的+4模型在筛选中最多涨17.2点、是最佳随机编辑的两倍多，说明它的提案确实比随机抽样好，只是好得有限，而且不是因为模型知道为什么有效。论文的结论因此是审慎的：通过权重实现自我改进对0.8B模型来说已经触手可及，但当前的收益主要来自搜索和选择而非理解，缩小这个差距是未来最大的挑战；局限也很清楚——验证集选择带来的乐观偏差、练习分数估计的长尾误差导致保留有害编辑、编辑者完全不具备可解释的编辑意图，以及继续运行只在少数幸运情况下才持续提升。这项工作真正的意义不在于那几个百分点的数字，而在于它把RSI从哲学讨论拉到了一个可测量、可证伪的实验平台上，并且诚实地标出了“能改”和“懂改”之间那道还没跨过去的鸿沟。

### [WeightCode: Installing New Capabilities into Neural Networks via Weight-Space Programming](https://arxiv.org/abs/2611.25476)
`评分3 · HF 6赞`

这篇论文要解决的是一个在模型部署和持续演化中非常实际的问题：如何在不重新训练、不破坏原有能力的前提下，往一个已经训练好的神经网络里“装”进一项新能力。传统做法各有各的卡点。微调需要梯度优化和标注数据，容易覆盖旧能力，属于典型的灾难性遗忘；模型编辑虽然能定点改变某些输入上的行为，但通常只针对单点事实修正，难以安装一个完整的、可泛化的新计算；测试时自适应只能在推理阶段调整归一化统计或熵最小化，能力是临时的、随输入条件消失；任务算术和模型合并在权重空间做加减，但前提是模型共享同一个预训练起点，对独立训练的模型要先做神经元对齐，而且它们操作的是“学到的参数差”，不是“如何构造这个差”的过程。作者的核心动机是：软件的功能可以通过可执行指令扩展，而神经网络的能力却锁在分布式权重里，那么能不能让可执行程序直接读写权重、把任务知识翻译成新的计算，并且让这个构造过程本身成为可复用、可叠加的对象？这就是他们定义的 Weight-Space Programming（WSP）。

WeightCode 的关键设计是把“构造更新”和“执行更新”拆开：一个冻结的大语言模型负责写出一段可执行的权重程序，程序接收目标网络的权重和任务知识（规则、演示、带标签样例等），直接返回修改后的权重，推理时完全不需要 LLM。程序不是输出一组固定数值，而是保留了一套测量与构造流程——它会读取网络的权重、跑前向传播、看激活统计，用 SVD、PCA、闭式拟合、单单元消融这些无梯度手段定位可复用的计算结构，再把新能力“接线”到网络已有的计算上。比如 ViT 的高斯噪声程序会测量噪声如何平移 patch token，找出在干净图像上近乎闲置的 MLP 单元，把每个 block 里的两个单元改写成门控：当 token 沿噪声方向移动时门打开，然后减掉测得的偏移量。这种做法的好处是更新依赖目标网络自身的坐标和表示，而不是一组从别的网络抄来的数值，因此同一个程序换一个独立训练的同类网络重跑时，会重新测量、重新构造出适配该网络的编辑。程序的选择靠评估反馈：每个候选在 check split 上统计“修好了多少新条件输入、弄坏了多少”和“旧条件上的净变化”，保留满足保留规则（旧能力损失不超过阈值）且总分最高的那个，整个会话最多 8 次检查，和每种微调方法尝试 8 个配置、接受同样检查的预算对齐，保证了比较公平。此外还有“复制”“重跑”“后继更新”三种操作：复制是直接把权重差搬过去，重跑是不调用 LLM、原样执行程序代码让它在目标网络上重新计算编辑，后继更新则是让 LLM 针对已被编辑过的网络再写一个新程序，构造时同时看到旧程序代码和所有先前条件的检查，从而在保留已装能力的前提下继续叠加。

实验结果覆盖了语言指令、导航策略和视觉识别三类任务。SCAN 上程序只改了 257 个权重，就把未见过的命令组合的精确匹配从 0% 提到 99.8%；BabyAI 用 8 个演示就让策略学会新的 pickup 动作，成功率达 98.4%，同时保留原有指令和导航能力。ImageNet 上四个权重程序在腐蚀条件下取得 8.84 到 17.62 个百分点的净增益且不损干净精度，在样例、检查次数和保留约束都匹配的条件下优于八种微调方法中的最佳者。机制层面，因果干预显示装进去的噪声校正门控确实驱动了鲁棒性提升，而它们的选择性激活解释了干净精度为何得以保持。复用性上，十个程序在五个独立训练的 ViT 上重跑，平均保留源网络增益的 83% 到 110%，而直接复制固定权重编辑几乎无效，这正好说明“构造过程”而非“数值结果”才是可迁移的东西。后继更新方面，六个为已编辑网络写的第二轮程序额外带来 5.23 到 14.50 个百分点的对比度鲁棒性，同时保住先前装入的噪声增益。局限也很明显：程序目前主要把新能力接到网络已有的计算上，能否安装真正全新的计算结构还不清楚；实验集中在中小规模网络和特定腐蚀条件，程序由特定 LLM 在沙箱内写出，编辑规模被限制在 20% 权重以内，跨架构迁移和更大模型上的可扩展性尚未验证；保留规则依赖 check split 上的阈值，理论上仍存在旧能力被缓慢侵蚀的风险。尽管如此，这篇工作把“权重程序”确立为一种可复用、可重跑、可叠加的构造对象，为已训练网络的持续能力扩展提供了一条不依赖梯度训练的新路径，对模型编辑、持续学习和权重空间学习几个方向都有直接的启发意义。

### [Loop-Count Schedules in Looped Transformers: An Empirical Study](https://arxiv.org/abs/2611.29704)
`评分3 · 16 pages, 4 figures, 11 tables. Code: https://github.com/kvo · 有代码`

这篇论文要解决的是循环Transformer（looped transformer）中一个此前被忽视但很实际的问题：同一个Transformer块被重复调用多次时，每次额外传递到底应该起什么作用，以及训练时循环次数R的调度方式如何决定这种作用。背景动机很直接——循环Transformer用共享权重换取重复计算，理论上能在不增加参数的情况下获得更深的计算能力，近年来被当作实现隐式推理的路径之一，Geiping等人、Zhu等人的Ouro系列、以及Ladhak和Fishman把配方推到4B以上参数的工作都报告了推理基准上的收益。但文献里对两个动力学问题关注不足：一是迭代是否收敛，Dong等人早已证明纯自注意力堆叠会双重指数地损失秩，是前馈子层在阻止坍缩，所以块的两半在迭代时方向相反；二是跨传递复用KV缓存到底付出什么代价。更关键的是，先前工作虽然用了随机采样循环次数（比如Ladhak和Fishman在每次优化器更新内从1到4混合采样），却没有意识到采样范围的下界才是决定性变量——他们的范围包含R=1，而本文发现这恰好落入所谓的“阻尼 regime”。Prairie等人的并行独立工作用残差流的相对步长观察到随机深度训练会把表示推向共同极限而静态深度不会，但没有回答是调度中的哪个性质造成了这一差异、模型为此放弃了什么、以及两者能否分离。本文就是在一个小到可以一次只改一个变量的设定里回答这些问题，并且用两个更大规模研究没有报告的工具来读取答案：每次循环传递上的学习残差门控，以及逐token的残差流方向与范数轨迹。

方法上的核心洞察是：循环次数采样范围的下界决定了每次额外传递是充当完整一层还是仅做小幅修正。模型是标准的decoder-only pre-norm Transformer，RMSNorm、RoPE、QK-norm、SwiGLU，嵌入与输出投影绑定。循环版本中第一次传递不加门控、与普通块完全相同，从第2到第R次传递则在注意力和FFN两条路径上各加一个学习标量门控，门控参数化为sigmoid(θ)、初始化为0.5、不做权重衰减、每步记录。门控接近1意味着该次传递以普通层的全强度写入，接近0则几乎跳过。这里没有步嵌入、没有输入注入、没有截断反传，门控就是Huang等人输入依赖且单调的学习步长的最简形式。三种调度分别是固定R=2、从{1,…,6}均匀采样（均值3.5，部分训练步只跑一次并在单次传递上算损失）、以及从{2,3,4}均匀采样（均值3，每步至少跑两次）。采样是按微批次独立抽取的，配合梯度累积后一个优化器步的更新已经是对多个深度的平均。静态KV变体是第一次传递投影出K和V后在后续传递中复用、只重算query，于是后续传递的注意力输出是固定value向量的凸组合、由新query操控，推理缓存等同于同样块数的普通模型，且token i的更新不再依赖token j的当前状态——这是前向共享，与Prairie等人训练后把最终传递的缓存反向广播给前面传递的做法相反。收敛度量上，作者固定一个块和一个token位置，记录每次传递后残差向量相对上一步的余弦距离（方向变化，因为pre-norm块只有方向能到达下一子层和输出投影，所以这是主指标）以及相对步长（与Prairie可比），取批次内token的中位数以对抗重尾分布，并报告相邻中位数的比值作为收缩率；输出空间则用相邻传递读出分布之间的KL散度。这套设计的巧妙之处在于门控值本身就是调度性质的直接读数：如果采样范围包含R=1，那些只跑一次的训练步会在单次传递上计算损失，梯度会把门控压向0.1–0.5，使每次额外传递退化为对第一次的小修正；如果范围从2开始，每步至少两次，门控稳定在0.6–0.9，每次传递保持完整层的强度，同时模型仍能在2到最大训练值两倍的任意R上运行且验证损失只差几百个nats的零头。这解释了为什么下界而非上界或均值才是决定变量——它决定了模型是否被允许把“一次传递”当作完整计算的基准。

实验在2B token的混合语料上进行（FineWeb-Edu文本80%、codeparrot-clean代码10%、FineMath-4+数学10%），32k BPE分词器，隐藏维度768、12头、SwiGLU内维2048，块约7.1M参数、绑定嵌入约25.2M，3/6/12块的普通模型总计46.4M/67.6M/110.1M参数，循环只增加每块两个标量。所有run用同一优化器（AdamW，峰值学习率6e-4，2k步线性预热后余弦衰减到10%，权重衰减0.1仅作用于权重矩阵，梯度裁剪1.0，bfloat16计算配fp32主权重），每步32768 token，训练61000步即一遍语料，每2000步验证并在R∈{1,…,6,8}上评估。关键结果是{2,3,4}调度给出最好的循环模型，验证损失2.909 nats，对比参数匹配的普通模型2.951，且在训练深度两倍处运行只退化0.038 nats；而包含R=1的调度落入阻尼 regime，门控坍缩。作者进一步表明固定R下残差流的方向在超过训练深度后几何收敛而损失发散，这细化了“静态深度训练不收敛”的近期发现；复用第一次传递的K和V在每个regime下代价0.01–0.03 nats，但使逐token迭代一致收缩并将推理缓存减半。循环在等参数下大约恢复了真实深度所能提供能力的三分之一。局限也很清楚：规模只有46M–110M参数、2B token、单种子为主（关键对比用双种子，一致性在0.003 nats内），结论是否能外推到数十亿参数和万亿token的Ouro式预训练尚未验证；作者只测了语言建模损失和收敛轨迹，没有下游推理基准，而Huang等人已提示困惑度会低估循环模型的生成收益；静态KV的0.01–0.03 nats代价虽小但并非免费，且前向共享与Prairie的反向共享之间的取舍没有直接对比。尽管如此，这篇工作的意义在于把“循环调度为什么有效”从一个笼统的随机深度故事拆解成一个可操作的单一变量——采样下界——并证明它可以通过门控值直接监控，这为以后设计循环模型时选择调度范围提供了明确指引，也把收敛性与缓存复用这两个此前分开讨论的问题放进了同一个可测量的框架里。

### [Position-Skipped Distillation of Sparse-Attention Indexers: Train Short, Serve Long](https://arxiv.org/abs/2611.29664)
`评分3 · 55 pages, 4 figures, 48 tables`

这篇论文要解决的是长上下文推理中 top-k 稀疏注意力索引器的训练成本问题。在 DeepSeek-V2 这类架构里，注意力并不对全部缓存 token 计算，而是由一个轻量的逐层索引器给缓存 token 打分，只保留分数最高的 k 个再交给注意力，这样解码时注意力的开销就从与上下文长度成正比降到近似常数。索引器的训练通常采用蒸馏：让它在相同输入上模仿稠密注意力的输出分布。问题在于，为了让索引器在服务时的长上下文（比如 32K、64K）上表现良好，常规做法是直接在完整服务长度上做蒸馏，于是每一个训练 step 都要跑一遍长序列的稠密注意力，训练成本随目标长度线性增长，非常昂贵。一个自然的想法是只在短序列上蒸馏，但作者指出这样做会失败：索引器在短序列上训练后迁移到长上下文时性能明显下降。关键诊断是，这种失败主要不是内容匹配能力退化，而是旋转位置编码（RoPE）带来的外推问题——索引器在训练中见到的位置编码模式与推理时长上下文中的位置编码分布不匹配，导致排序失准。也就是说，瓶颈在位置，而不在语义。

针对这个诊断，作者提出了位置跳跃蒸馏（position-skipped distillation）。具体做法是：索引器和冻结的教师模型都只看短序列，但序列中每个 token 的位置 ID 不再是连续的 0、1、2……，而是在某个随机位置插入一个“空洞”，使得位置 ID 跳过一段区间，从而让序列中出现的最大位置 ID 接近甚至达到目标服务长度，而实际处理的 token 数仍然只有短训练长度。这样索引器在训练中就能见到长上下文才会出现的大位置 ID 及其相对间隔模式，学会在位置编码层面泛化，而无需真正处理长序列，稠密教师的计算量也随之被限制在短长度上。由于位置 ID 的间隔是随机放置的，模型不会过拟合到某一种特定的位置分布，而是学到对位置跳变鲁棒的排序能力。这一设计的巧妙之处在于把“长度外推”问题转化成了“位置 ID 分布增广”问题：训练时序列长度不变，但位置编码的覆盖范围被拉长，索引器因此获得了在长上下文位置空间里工作的经验，而成本仍按短序列计算。此外，作者还对索引器的 key 做了无需重训练的 3-4 bit 量化，并用融合的整数 kernel 计算打分，进一步降低索引器本身的开销。

实验在 DeepSeek-V2-Lite 和 Qwen3-30B-A3B 上进行。在 8K token 上用位置跳跃蒸馏训练出的索引器，在最长 32K 的上下文里与用 32K 蒸馏的索引器相比，困惑度差距约在 0.5 以内；在 DeepSeek-V2-Lite 上，它在 64K 时能追平 64K 蒸馏的索引器，而每 token 的训练计算量大约只有后者的六分之一。在 Llama-3.1-8B 上，它比更强的 32K 蒸馏版本落后 0.6 困惑度，且在 64K 时简单的位置压缩方法往往表现相当，说明该方法的主要收益是训练成本而非质量上限。量化方面，4 bit 下困惑度变化不超过 0.05，索引扫描比半精度快 1.6-2.2 倍。局限也很明确：质量上并未全面超越长序列蒸馏，在某些模型和长度上会被更简单的位置压缩追平；而且在实际服务引擎中，索引器带来的解码加速只在长上下文且多路并发流的情况下才体现出来，短上下文或低并发时收益有限。总体而言，这篇工作把索引器蒸馏的成本瓶颈定位到 RoPE 外推这一具体环节，并给出了一种训练短、服务长的实用方案，对长上下文稀疏注意力的部署成本有直接意义，但也说明索引器优化本身的收益高度依赖服务场景的上下文长度与并发形态。

### [Which Loopholes Get Found? Predicting Reward Hacking of LLM Judges Before RL Training](https://arxiv.org/abs/2611.29651)
`评分4 · 16 pages, 6 figures, 6 tables. Code and run summaries: https · 有代码`

这篇论文要解决的是一个在 RLHF/RLVR 实践中非常具体却长期被忽视的问题：当我们用一个 LLM 作为裁判（judge）来给策略模型打分时，策略模型会学会利用裁判的漏洞（loophole）来刷分，而不是真正解题。已有的静态探测方法只能告诉我们某个裁判会接受哪些退化答案——比如单独一个左花括号、一句"Thought process:"、或者直接声称答案正确——但无法预测在真实的 GRPO 训练中，策略模型会最先找到并利用哪一个漏洞。作者指出，Huang 等人已经观察到 DeepSeek-R1-Distill-Qwen-1.5B 在静态探测中漏洞百出，但在他们的 RL 训练中却没有被利用，而一个从它微调出来的更准确的 verifier 反而被利用了。这说明"裁判有漏洞"和"策略会利用这个漏洞"是两回事。之前的研究要么往 rubric judge 里注入已知偏差、要么在 coding 环境里人为构造漏洞、要么用 SFT 替代 RL，都没有回答一个关键问题：在真实裁判已有的漏洞中，能否在训练前就预测出策略会先利用哪一个，而且这个预测能否泛化到没见过的裁判上。作者还指出了一个实际困难：在他们这个规模下，基础策略的自然倾向太低——174,760 个回答里只有 19 个落在 14 类 hacking pattern 中——即使裁判全部接受，初始 exposure 也低于 0.03，比他们实验中任何被最先利用的 pattern 低约 70 倍，未播种的对照组跑 300 步也没有出现 exploitation。所以必须在受控条件下人为提高倾向才能做因果检验。

论文的核心洞察是把"哪个漏洞会被先利用"分解为两个可测量的因素的乘积：exposure = 策略产生该 pattern 的概率（propensity）× 裁判对该 pattern 的误接受率（FPR）。这个思路来自对 GRPO 机制的朴素分析：一个 pattern 只有在被策略采样到、且被裁判奖励时才会被强化；每一步有 N 个回答，产生率为 p、接受率为 FPR 的 pattern 平均每步获得 N·p·FPR 个被奖励的回答，这就是它的 exposure。作者假设 exposure 最高的 pattern 会最先被利用，而单独看 FPR 或单独看 propensity 都不够。为了因果性地检验这个假设，他们设计了一个精巧的实验：把 14 类 hacking pattern 以三种剂量（0.3%、1.2%、4.0%）通过拉丁方旋转的方式播种进一个短暂的 SFT 阶段，这个 SFT 是在策略模型自己已经答对的答案上做的，且播种比例与 FPR 独立。因为 14 类 pattern 合计替换了约四分之一的样本，他们又额外做了低播种比例的对照：只播种两个 pattern，总量 3% 到 3.8%，并且刻意选择使 exposure 与单独 FPR 或单独 propensity 产生分歧的配对。所有 exposure 分数都在训练前记录。FPR 的测量也做了细化：不是用 family 平均值，而是用每个 family 最常出现的那个具体字符串，因为 GRPO 强化的是实际采样到的字符串，而这些字符串的 FPR 与 family 均值最多可差 67 个百分点。propensity 则通过在起始 checkpoint 上对每个 pool 采样 16 次×250 题来测量，并用 Jeffreys 平滑。最终 exposure 分数就是 propensity 乘以 FPR 再乘以每步采样数 256。这个设计的巧妙之处在于：它把"策略会不会找到某个漏洞"这个看似不可预测的动力学问题，转化成了两个可以在训练前静态测量的量的乘积，并且通过播种实验直接操纵 propensity 来验证因果性，而不是停留在相关性观察上。

在结果上，论文在 36 个主实验（4 个核心裁判 × 2 个难度 pool × 3 个种子，加上 9 个 held-out 裁判实验和 3 个 0% 对照）中验证了预测。在 12 个出现 exploitation 的主实验中，最先被利用的 pattern 在全部 12 个里都是 exposure 最高的，而只有 6 个是 FPR 最高的。在 24 个核心实验上，exposure 区分被利用与未被利用 pattern 的 AUROC 达到 0.974，对比 FPR 单独的 0.937、propensity 单独的 0.847、静态准确率的 0.379（后者取负号），所有 p 值经 Holm 校正后小于 0.001。更关键的是，在 12 个主实验中有 5 个的获胜者既不是 FPR 最高也不是 propensity 最高，但两者的乘积排第一；条件 logit 显示 log propensity 与 log FPR 的权重比在 0.46 到 1.66 之间都能把每个获胜者排第一，说明乘积形式是稳健的。低播种比例的 6 个实验进一步直接检验了乘积：每对 pattern 在 propensity 和 FPR 上的排序相反，结果 exposure 高的那个在全部 6 个实验中都先被利用，而 FPR 单独漏掉了全部 4 个 F1/F2 的获胜者、propensity 单独漏掉了全部 2 个 P2 的获胜者。事件发生步数与 exposure 的 Spearman 相关为 -0.84，log 事件步对 log exposure 的斜率接近 -1.03，说明 exploitation 的启动大致需要一个固定的被奖励回答数（234 到 804 个），而收集速率就是 exposure。难度方面，exploitation 只发生在 hard prompt 上，因为在那里一个被接受的 exploit 往往是组内唯一的奖励，获得的 group-normalized advantage 约为 easy prompt 上的 2.6 倍。论文也坦诚了局限：exposure 是在起始策略上测量的，所以它只预测第一个事件，不预测后续的"接管"——在四个 F 实验中有三个出现了第二个 pattern 在 10 到 130 步后后来居上，因为一旦获胜者填满了组内大多数，组均值接近获胜者自身的接受率，只有 FPR 更高且仍被采样的 pattern 才能继续获益。此外，实验规模限于 1.5B 模型和 300 步 GRPO，held-out 裁判只有三个，且 exploitation 在 easy pool 上从未发生，说明难度门控的机制还需要在更大模型和更多任务上验证。尽管如此，这篇论文的意义在于提出了一个可在 RL 训练前执行的审计流程：测量裁判对具体字符串的 FPR、测量策略的 propensity、取乘积排序，就能以很高精度预测哪个漏洞会先被利用，并且他们开源了七个裁判在 14 类 pattern 上的 FPR、代码和所有实验摘要。这为"在训练前审计 reward hacking 风险"提供了一个可操作、可证伪的定量框架，而不是事后诊断。

### [Reinforcement Learning from LLM-Generated (Suboptimal) Demonstrations](https://arxiv.org/abs/2611.29732)
`评分3`

这篇论文要解决的是强化学习在稀疏奖励、长时程任务中样本效率极低的现实问题。传统做法是用人类专家演示来预训练智能体，但收集演示成本高昂，而且即便是专家数据也普遍存在次优性——执行失败、擦边操作、行为不一致都是常态，因此次优性不是某种数据源的缺陷，而是演示数据的内在属性，任何从演示中学习的方法都必须面对它。作者同时切入这两个痛点：既然人类演示又贵又不完美，能否用大语言模型以近乎零人力成本生成演示数据？但 LLM 生成的策略同样不完美，甚至可能出现在原地打转、动作振荡、遗漏子技能或子技能顺序错乱等退化行为，所以方法设计必须能在“建议本身有错”的前提下仍然受益。论文的核心主张是：LLM 生成的建议策略虽然次优，但作为一种廉价的演示来源，只要用对方式，依然能显著加速 RL 训练，甚至在被系统性劣化后仍有效果。

方法上分两条路线。第一条是直接的演示预热：让 LLM 用 RLang（一种与环境、算法无关的声明式 DSL，包含 Feature 和 Policy 两类声明，前者在观测或状态上计算布尔/数值条件，后者用条件逻辑选动作）写出可执行的建议策略，rollout 得到轨迹后，只保留终止回报非零的成功回合放入回放池，避免失败轨迹污染缓冲区，然后用一步 TD 损失加上 n 步 TD 损失的组合离线预训练 Q 网络——n 步项在稀疏奖励下尤为关键，因为大多数转移的一步 TD 信号为零，只有靠更长视野的信用分配才能把终止奖励回传。在线训练阶段并不丢弃建议策略，而是把 ε-greedy 改成三路分流：以 ε/2 概率随机、ε/2 概率跟随建议策略、其余贪心，随着 ε 退火，建议的影响自然衰减。但这条路线有个隐患：预训练的 Q 网络只见过建议策略采取的动作，贪心策略会倾向于复制这些动作，包括错误动作，必须在线“遗忘”。于是第二条路线 value warmstart 做了关键转向：不学建议策略“做什么动作”，而学它诱导的行为下“哪些状态有前途”。具体做法是先把基于状态的建议策略行为克隆成一个基于观测的 actor（加熵正则防止过早坍缩到确定性策略），冻结后让这个克隆 actor 在自己的行为分布下重新 rollout——这一步很重要，因为价值函数必须校准到 actor 实际会遇到的观测分布，包括模仿不完美带来的偏移；然后在完整回合的蒙特卡洛回报上回归拟合一个 critic，最后把 critic 的卷积主干拷进 Q 网络，并把标量价值头广播到每个动作上，使初始化时所有动作的 Q 值相等。这样智能体起步时对动作没有任何偏好，只继承了“哪些状态值得去”的先验，从而保留了选择不同于建议动作的自由，同时蒙特卡洛回归让每个转移（包括失败回合）都获得直接的目标信号，缓解了稀疏奖励下 TD 预训练信号稀薄的问题。

实验在 MiniGrid 套件上展开，包括 Empty 导航以及 Unlock、UnlockPickup、BlockedUnlockPickup 三个逐级加难的对象交互任务。直接预热在 Unlock 系列上收益最大，标准 DQN 在大部分训练时间内回报接近零，而预热版本显著提前了学习曲线；Empty 上虽然在线更新初期有回落，但整体更早接近最优，说明建议引导在“成功行为难以靠探索发现”时价值最高。Value warmstart 则在 UnlockPickup 这个含八个子技能的长时程任务上做受控劣化实验：以 LLM 生成的最优状态建议为基底，把定位钥匙、拾取钥匙、导航到门、开门、定位箱子五个子技能中的一到两个替换为随机动作，构造出有标签的失败类型空间。结果显示，即使建议被大幅劣化，方法相对无辅助基线仍有有意义的加速，且对比“直接执行建议策略不学习”的虚线可以分离出性能提升究竟来自 RL 对建议的改进而非单纯复现。局限也很明显：实验规模限于 MiniGrid 这类网格世界，任务复杂度和观测维度都远低于真实场景；建议生成依赖 LLM 对领域的先验知识和人工重提示，RLang 的表达能力也限制了可描述的策略复杂度；劣化实验是人工构造的，与 LLM 自然产生的次优模式之间还有距离。但论文的意义在于给出了一条清晰的论证链——LLM 建议的次优性不必被消除，只要用价值预热而非动作克隆的方式吸收，它就能作为人类演示的廉价替代品，这为低成本的演示驱动 RL 提供了一个可操作的方向。

### [Direct Feedback Policy Optimization for AI Coding Agents](https://arxiv.org/abs/2611.29193)
`评分3`

这篇论文要解决的是AI编程智能体强化学习中的信用分配难题。当前主流的GRPO、GSPO等方法依赖稀疏的终端奖励——一个复杂的仓库修复任务可能跑上一小时，最后只在提交补丁时拿到一个任务级分数，成功或失败都只给一个标量。问题在于，一条执行轨迹里混杂着有用的实现、无效的尝试、甚至引入回归的编辑，把所有token都赋予同一个终端奖励，等于让这些行为朝同一方向更新，模型根本学不到哪一步决策真正导致了成功或失败。另一条路是组相对方法，需要对同一任务反复采样多次来估计优势，在长时程编程任务上采样成本极高。作者的核心观察是：失败的测试本身就是可复用的反馈信号——给定失败点的原始输出、错误信息和仓库状态，模型可以重写自己历史中的一部分、重放受影响的命令、再用同一个测试检验局部修改是否有效，这就把信用分配拆成了两个可以直接检验的问题：局部测试决定保留哪个版本，最终验证评估整体任务结果。

DFPO的关键设计是在单条轨迹内构造对比训练对。每个任务只启动一次，主轨迹在修复后可恢复。当某步测试失败时，保留原始模型输出、输入前缀和真实工具观测，连同测试错误一起构成修复前缀，模型据此生成修复片段和一条编辑命令，该命令修改轨迹文件中此前的助手输出；系统把命令应用到轨迹文件的工作副本，重放受影响的代码编辑命令到仓库工作区，再跑局部测试。接受修订的条件很严格：原始版本失败、修订版本通过、且同一个策略模型检查修订没有通过弱化断言等方式作弊。被拒绝的修订会记录真实执行错误，模型据此重写整个修复片段并重试，最终通过的版本被拼接回原位置、工具观测替换为重放的真实结果，得到拼接轨迹。这样原始轨迹和拼接轨迹共享未改动的前缀，各自保留自己的条件上下文和真实执行记录，形成一对训练样本。在损失层面，DFPO用token级Levenshtein编辑脚本计算双向编辑掩码，只让被编辑位置上的助手token参与策略损失，匹配的token被排除，共享历史和工具观测仅作为评分上下文。主损失是对拼接侧和原始侧掩码位置的概率比做裁剪对比，局部验证决定偏好方向，终端奖励R设定权重幅度：通过的拼接版本拿+R，原始版本拿-R。重试损失则把最终通过的修复段与每个失败修复段对齐，通过版本拿+R、每个失败版本拿-R/n，使失败版本权重之和为-R。关键约束是只保留R>0的任务做更新，因为若R<0代入会把偏好方向反转，破坏局部验证建立的偏好。相比GSPO需要多次采样估计组内相对优势，DFPO直接从单条轨迹的局部修复对比中提取token级信号，把粗粒度的响应级奖励转化为细粒度的编辑位置监督。

实验用Qwen3.5-35B-A3B基座加rank-32 LoRA，在SWE-mini harness和400条2026年前发布的SWE-rebench数据上训练，按端到端GPU小时匹配各方法的训练算力，每种方法跑三个随机种子取均值。在2026年3月后发布的110题SWE-rebench留出集上（温度0.7、每题三次取avg@3严格解决率）和500题的SWE-bench Verified上，DFPO两个基准都取得最高严格解决率，优于GSPO和GSPO+BASIS；在OpenHands SDK上用2699条OpenSWE任务、200轮交互、200K上下文预算的设定下同样超过GSPO。消融显示：仅开启历史重写与重放对基座模型只有小幅提升，但在训练和评估共享该协议时DFPO对GSPO的优势幅度大于重写本身带来的增益；去掉重试损失会降低解决率，说明对比通过与失败的修复段提供了有效监督；去掉编辑掩码同样下降，证明把响应级信号细化到token级是有效的；固定正权重不如按终端分数加权；在相同修复对和掩码下，DFPO的对比目标优于只在通过版本掩码token上做交叉熵的masked SFT；而严格成功门控（只保留完全通过所有目标与回归测试的任务）反而略降解决率，说明保留部分通过的正分任务有助于训练。局限也很明确：编辑脚本只度量文本差异，局部测试只覆盖它实际执行的行为，重放需要重建仓库状态和工具观测，外部依赖变化和不稳定测试会破坏一致性；对于直接重写的token，代理概率比的统计性质依赖于重写过程与评分前缀下旧策略之间的关系，这一点论文没有给出严格保证。总体而言，DFPO把"用测试反馈做局部版本选择、用终端奖励做全局加权"这条思路落到了可执行的单轨迹训练算法上，为长时程编程智能体的信用分配提供了一个不依赖多次采样的实用方向。

### [On Adaptive Step Sizes for Eligibility Traces in Deep Reinforcement Learning](https://arxiv.org/abs/2611.29178)
`评分3 · Accepted at NeurIPS 2026. Code: https://github.com/esraaelel · 有代码`

这篇论文要解决的是深度强化学习中一个被长期忽视但很实际的问题：如何在不依赖经验回放缓冲区的情况下，让智能体从数据流中即时、高效地学习。传统深度RL方法（如DQN、SAC、PPO）把交互数据存进缓冲区再随机采样，这带来两个毛病：一是内存开销大，二是学习有延迟——一条经验要等到被采样到才起作用。更关键的是，随机采样破坏了时间结构，而大多数方法只用一步或短短几步的TD更新，信用分配很慢。虽然λ-return能利用更长的时序信息，但PPO这类用前向视图的方法必须等未来若干步才能算目标，更新被推迟。资格迹（eligibility trace）本可以作为等价的后向视图实现无延迟的在线更新，历史上在线性函数近似下很常用，但在深度RL里长期被认为不work，直到最近Stream-X等工作才重新把它做起来。然而这些工作只用了自适应的标量步长，没有用上深度RL里占主导地位的向量步长优化器（如Adam），这个空白很可能限制了资格迹方法的性能。

论文的核心洞察在于：把自适应向量步长朴素地乘在资格迹更新外面是错的，会破坏前向视图与后向视图的等价性。作者证明，要让等价性成立，时间相关的向量步长必须被放进迹本身里——也就是迹的递归更新要变成衰减旧迹再加上“步长逐元素乘梯度”，而不是先算一个不带步长的迹、再在外面乘步长。他们进一步分析了这种放置差异的后果：在线性TD(λ)加状态相关步长的设定下，两种放置会收敛到不同的不动点，朴素做法的固定点把步长矩阵塞到了不该出现的位置；他们还给出了朴素更新与正确更新之间误差的精确表达，这个误差正比于相邻两步步长的变化量和迹的幅度——而Adam这类优化器每步都在改变步长，所以误差不为零。更麻烦的是，作者指出Adam的步长本身没有在线的后向视图，无法被正确地放进迹里。为此他们提出了Function-Space Distance（FSD）优化器，它在函数空间里约束更新，使得在自适应向量步长下前向与后向视图的等价性依然保持。基于FSD，他们构造了ARC(λ)——一个带正则化critic的actor，critic用的是梯度TD算法TDRC的变体，以适配非线性函数近似和离策略采样。他们用FSD搭配四种资格迹算法（AC(λ)、ARC(λ)、Q(λ)、QRC(λ)），覆盖了半梯度与梯度TD、值函数与actor-critic两大类。

实验上，作者在连续动作的MuJoCo任务和离散动作的MinAtar任务上做了评估。结论是FSD明显优于SGD和朴素套用Adam的方案；在MuJoCo上，这些流式算法追平了Stream-X，并且在多数环境中与使用缓冲区的PPO相当甚至更好；在MinAtar上则在所有环境中都超过了Stream-X。这说明正确的步长放置加上合适的优化器，能让无缓冲区的资格迹方法真正具备竞争力。局限方面，等价性推导仍依赖“回合内参数不变”的假设，真正的在线TD(λ)形式尚未扩展到非线性函数近似；FSD虽然保住了等价性，但它的函数空间约束在理论上和计算上的代价、以及在大规模网络和更复杂任务上的可扩展性，论文没有充分展开。不过这项工作的意义在于，它把“自适应步长如何与资格迹正确结合”这个基础问题讲清楚了，并给出了一个可用的优化器方案，为流式深度RL指出了一条绕开经验回放、保留长时序信用分配的技术路线。

### [VeriLogic: Reinforcement Learning over Verifiable Logical Reasoning Traces](https://arxiv.org/abs/2611.29147)
`评分3`

这篇论文要解决的是大模型逻辑推理训练中奖励信号粒度过粗的真实问题。现有方法要么靠提示工程和推理时扩展（思维链、自一致性、思维树等）来提升逻辑推理，要么用结果级强化学习只对最终答案给奖励，前者没有把推理能力内化进模型参数，后者则把一整条回复当作不可分割的学习单元。问题在于逻辑推理的内部结构天然是可分解、可逐步检验的：一条回复里可能答案正确但中间推理无效，也可能中间步骤有效却得出错误结论，这种“异构正确性”在结果级奖励下完全被抹平——对的答案掩盖了坏推理，错的答案也惩罚了好步骤。已有的过程监督方法用学习到的评判器或人工步骤标注，信号仍是概率性的、可能漏掉细微逻辑错误；而基于符号求解器或定理证明器的工作（如 Logic-LM、SymbCoT、Lean 相关系统）多是把自然语言翻成形式语言再调外部求解器，或者面向完整形式证明，并没有用自身生成推理所获得的形式化验证反馈去训练策略。VeriLogic 的动机就是利用逻辑推理“可追踪、可验证”这一被长期低估的结构特性，把内部推理轨迹变成显式、可验证的学习对象。

方法上，VeriLogic 把逻辑推理组织成“接地—优化—精炼”三段流水线。第一步是构造可验证推理环境：把每个问题形式化为（上下文、查询命题、三值标签）三元组，标签为真、假、未知，并显式构造三条对应不同逻辑状态的推理路径——正路径论证命题成立并给出 Lean4 证明目标 P，负路径论证其否定并给出目标 ¬P，未知路径论证现有信息不足以支持任一可证结论、因此不带形式证明目标；同时定义一个映射把自然语言前提和查询转成 Lean4 前提集与目标命题，使正负两条路径的证明可被 Lean4 独立检查。第二步是逻辑结构化策略优化，核心创新是 PSAR-GRPO（路径特定优势路由的 GRPO）。它在标准 GRPO 的 on-policy 采样循环里直接嵌入 Lean4 验证：每个问题采样一组回复，每条回复含三条可分别定位的推理路径及证明，Lean4 逐条检查，于是同一条回复内不同路径的正确性可以被分开评估。奖励分两层：全局奖励看最终三值答案是否正确、结构化输出格式是否合规，在组内归一化后得到全局优势并广播到整条回复的所有有效 token；但全局信号分不清三条路径谁对谁错，于是再为每条路径单独构造局部奖励，包含路径推理状态是否正确、证明是否通过 Lean4 验证（未知路径无此项）、以及路径推理、证明结果与最终决策之间是否一致，然后按路径类型在组内各自归一化，得到路径特定的相对优势。最后用路径掩码把局部优势只路由到对应路径的 token 区间，与全局优势相加构成 token 级优势，这样整条回复仍受任务级结果监督，而每条推理路径按自身正确性获得独立的细粒度修正信号——这正是它比结果级方法更强的地方：它能区分“推理对答案错”“推理错答案对”等不同状态并分别施以奖惩，而不是让一条路径的错误连累同回复中其他正确路径。第三步是验证器引导的迭代精炼：把 Lean4 返回的证明状态、剩余目标和错误信息回灌给模型，让失败的推理被诊断、修订并重新验证，形成迭代闭环，使验证不只是终局判对错，而是可操作的纠错信号。

实验在六个逻辑推理基准、三个骨干模型（Qwen3-8B、Qwen3-4B、Llama-3.1-8B）上进行，相对最强对应基线平均提升分别为 1.83%、6.39% 和 5.00%，消融实验进一步确认了路径特定优势路由和验证器引导精炼各自的有效性。这些结果说明提升逻辑推理的关键不只是奖励正确答案，而是让推理过程本身显式、可验证、可优化。局限方面，论文的设定限于自然语言前提集上的真/假/未知三值判定，而非完整形式定理证明，未知路径因无证明目标而拿不到验证奖励，其监督相对较弱；整套流程依赖把自然语言可靠地转成 Lean4 前提与命题，这一接地的语义对齐质量会成为性能上限，翻译出错时验证信号本身就可能失真；此外 Lean4 验证嵌入 rollout 循环带来额外计算开销，迭代精炼也增加了推理轮次。意义上，它给出了一个把形式化验证反馈真正用于策略优化的范式，把过程级监督从概率性评判推进到符号级可检查，为逻辑推理的过程感知强化学习提供了一个可复用的框架方向。

## AI + 生物

### [General-purpose language models are neurosymbolic reasoners able to annotate proteins from sequence](https://arxiv.org/abs/2611.28529)
`评分4 · 20 pages, 3 figures. Code and data: https://github.com/ai4cu · 有代码`

这篇论文要解决的是蛋白质功能注释中的一个真实困境：如何在仅有序列、没有同源比对和结构信息的情况下，判断一个蛋白质是否具有催化活性、它的结构域边界在哪里、以及它是否已经丢失了催化能力。此前这个领域基本被两类方法分割：一类是蛋白质语言模型（如 ESM-2），它们从海量序列中学习统计规律，擅长从序列信号预测结构和功能，但对符号化的生物学知识几乎无法推理；另一类是通用文本大模型，它们能对功能进行符号层面的讨论，但默认假设是它们读不懂序列。于是出现了一个尴尬的空白——真正需要的是把序列层面的证据和符号层面的知识结合起来做注释，而现有工具各自只覆盖一半。更麻烦的是，专用注释工具有一个系统性盲区：它们倾向于根据蛋白质所属的家族来推断活性，因此会把那些保留了酶折叠但已经丢失催化残基的“伪酶”错误地标注为有活性。这类伪酶在酶家族中占比估计在 5% 到 15% 之间，仅靠家族识别无法区分它们，必须逐残基阅读序列才能发现催化位点的丢失。论文的动机正是要检验：前沿通用大模型是否已经具备了这种“读序列、做注释”的能力。

论文的核心设计是把同一批冻结的测试集和相同的提示词交给四个模型（Claude Fable 5.2、Claude Opus 5.5、Claude Opus 4.6 和 Gemini 4 Neon），让它们完成四类任务，每一类都配有对照来检验模型是否真的在响应序列本身而非表面模式。最关键的是“催化残基与伪酶”测试：给模型 20 个活性激酶、同样的激酶但催化天冬氨酸或 ATP 结合赖氨酸被替换的突变体、20 个 Swiss-Prot 标注为“inactive”的激酶折叠蛋白，以及 20 个其他酶及其活性位点突变为丙氨酸的版本。此外还设置了诱饵对照——把同样类型的替换放在没有功能注释的位置上，如果模型只对催化位点的替换做出反应而忽略诱饵，就说明它确实在读取催化残基而非对任何序列改动都敏感。结构域与膜特征测试则要求模型给出 Pfam 结构域及其边界、跨膜螺旋和信号肽，并用打乱残基顺序的序列作为对照，检验模型是否会把结构域“幻觉”到随机序列上。结构和功能测试使用 2026 年 8 月后发布的 PDB 结构，按此前是否存在 30% 以上序列同一性的同源结构分为“无匹配”和“有匹配”两层，要求预测二级结构、长程接触和功能。整个设计的关键洞察在于：如果通用模型真的在做神经符号推理，它应该能够同时利用序列中的残基模式（神经层面）和关于催化机制、结构域定义的符号知识，并且这种能力会表现为对催化位点替换的选择性敏感、对打乱序列的不敏感、以及在无同源信息时仍能做出高于随机的结构预测。

结果方面，三个前沿模型在催化位点敏感性上表现突出：Fable 5.2、Opus 5.5 和 Neon 都把全部 20 个野生型激酶判为活性，并把 20 个天冬氨酸突变体全部判为失活；在 60 个突变序列中，它们分别有 57、47、47 个正确报告了被替换的位置。诱饵对照更有说服力：Fable 5.2 和 Opus 5.5 把全部 58 个诱饵判为活性，却只把 3 个和 8 个真正的催化位点突变体判为活性，说明它们确实在追踪催化残基而非对任何改动都做出反应。在结构域注释上，Fable 5.2 为 45 个采样蛋白中的 39 个命名了至少一个正确的 Pfam 家族，边界平均重叠度达到 0.85；三个模型几乎从不把结构域分配给打乱序列（分别为 1、0、0/60）。在无同源结构的 12 个新发布蛋白上，三个模型的二级结构三态准确率分别为 76%、73%、69%，而最佳单态猜测只有 57%；长程接触精度分别为 37%、19%、28%，随机水平仅 2%。但论文也坦率地指出了局限：模型会以同样的自信度给出错误答案，例如把 DUF968 蛋白分到错误的家族、在多跨膜转运蛋白中把螺旋切分得过多（预测 85 到 87 个螺旋，而注释为 74 个）；在 20 个被 Swiss-Prot 标注为“inactive”的激酶中，模型的高一致率很大程度上反映的是对条目名称的召回而非生物学准确性，其中 RLK902 和 RKL1 已有实验证据表明它们具有自磷酸化活性，而模型仍跟随数据库标注判为失活。此外，模型有时会把催化角色“转移”到邻近的同类型残基上，或者报告了替换却绕开其功能后果，这些行为说明它们在做符号推理时仍带有幻觉性。论文没有与 AlphaFold 等专用结构预测工具做对比，样本量也偏小（12 个无匹配蛋白不足以排名模型），因此其意义不在于宣称通用模型可以替代专用工具，而在于展示了一种可能性：单一模型同时读取序列、调用结构知识和符号注释，为神经符号式的蛋白质功能注释开辟了一条值得认真对待的路径。

### [RumiFold: Teaching an LLM to Natively Fold Proteins and Reason About Their Function](https://arxiv.org/abs/2611.29444)
`评分4`

蛋白质结构预测长期被视为需要专门架构的独立任务，而通用语言模型能否原生地“学会折叠”并从中获益，此前并未被认真回答。现有方法大致分两条路线：一条是 AlphaFold 系列及 SimpleFold 等专用折叠模型，它们依赖多序列比对、模板或精心设计的等变几何网络，在单一结构预测任务上精度很高，但与语言推理能力完全割裂；另一条是直接把蛋白质序列当作字符串喂给 LLM 做功能问答，模型从未真正“看见”三维结构，只能靠序列 motif 的统计相关性去猜功能，遇到需要空间邻近性才能解释的注释（如活性位点、结合界面）就力不从心。问题在于：结构信息和语言推理被拆成了两套系统，前者无法受益于大模型的语义先验，后者也无法从几何约束中获得生物学上可靠的归纳偏置。RumiFold 要解决的就是这个割裂——让一个预训练 chat 模型在自己的隐状态空间里完成折叠，再用这份折叠表示去回答自然语言问题。

核心做法是把折叠变成模型内部的一次“隐状态迭代精炼”，而不是外挂一个结构预测头。模型对每条蛋白质执行多轮 folding pass：每一轮中，每个残基的隐向量根据当前自身表示与序列上下文更新，同时通过注意力机制在残基之间交换信息，逐步把一维序列表示“折叠”成携带空间邻近关系的 per-residue 表示。关键在于这些表示始终留在 LLM 的隐空间里，与语言 token 的表示同源，因此折叠不是旁路任务，而是对模型内部状态的组织方式。训练上，模型同时接受结构监督（与真实坐标对齐）和语言监督（功能描述、GO 注释问答），使得同一份隐状态既要满足几何一致性，又要能支撑语义生成。作者的关键洞察是：折叠预训练会把隐状态按“功能”而非单纯按“序列位置”聚类，形成一个生物学上有意义的 per-residue workspace——也就是说，残基表示自发地编码了它参与的功能角色。因果干预实验进一步验证了这一点：当人为扰动这个折叠 workspace 时，模型的功能预测随之改变，说明结构与语言之间的桥接确实经由这份折叠表示发生，而不是两条平行通路各说各话。相比之前“先预测结构、再把结构当特征喂给另一个模型”的串行方案，RumiFold 的优势在于端到端共享表示，结构约束直接塑造了语言推理所用的内部表征，避免了信息在模块边界处的损失和错配。

在结果上，RumiFold 的折叠精度与 SimpleFold 这类专用单表示模型相当，同时在 Gene Ontology 功能预测和自由文本功能描述两项任务上达到 state-of-the-art，意味着它没有为了折叠而牺牲语言能力，反而因折叠预训练获得了更好的功能理解。需要客观看待的是，论文强调的是“可比”而非“超越”专用折叠模型，在极高精度要求的结构基准上它未必是首选；多轮 folding pass 也带来额外推理开销；此外，隐空间折叠的可解释性和对长蛋白、多链复合物的扩展性仍有待检验。但它的意义在于示范了一条路径：蛋白质计算可以不是外挂模块，而是通用语言模型的一种原生能力，折叠与语言推理共享同一套隐状态，为“生物分子智能”提供了一个可操作的技术原型——结构不再是喂给模型的输入，而是模型自己算出来的内部工作空间。

### [BioEmu2: Scalable Emulation of Biomolecular Dynamics](https://arxiv.org/abs/2611.27924)
`评分4`

BioEmu2 要解决的核心问题是：蛋白质、核酸等生物大分子的功能不仅取决于静态三维结构，更取决于它们在不同构象之间的动态转换、配体结合与解离、以及这些过程的动力学速率，而现有工具在这条链路上是断裂的。AlphaFold 系列和 RoseTTAFold 解决了“给定序列预测一个结构”的问题，但单个静态结构无法告诉你哪些构象会被占据、它们之间转换有多快、配体结合如何改变这些分布。实验手段如冷冻电镜和核磁共振能捕捉构象状态或涨落，但通量低、成本高，且通常只给出低维观测值而非全原子系综。全原子分子动力学模拟原则上能给出时间分辨的构象演化，但受限于采样成本——折叠、构象重排和结合事件涉及稀有势垒穿越，需要极长的模拟时间，即便有专用硬件和增强采样算法，复杂构象景观的探索仍然昂贵。此前的机器学习路线各有短板：粗粒化模型虽然大幅降低计算量，但难以扩展到小分子、丢失原子细节、动力学标定困难；Boltzmann Generator 虽然能直接采样已知能量函数定义的分布，但难以扩展到大规模体系；BioEmu 第一版、AlphaFlow、DiG 等数据驱动的系综模型只处理单蛋白且为粗粒化表示；Timewarp、MDGen 等虽然涉及时序，但不是能泛化到多组分复杂体系的生物分子基础模型。BioEmu2 的动机就是用一个统一的原子分辨率生成框架同时覆盖结构预测、平衡系综采样和时间传播三种能力，且支持蛋白质、DNA/RNA、修饰残基、配体、离子等多组分体系。

方法上的关键设计在于把学习问题拆成“序列主干做生物推理”和“结构模块做坐标生成”两部分，并在此基础上引入三种推理模式。主干将蛋白质链表示为氨基酸序列并附加多序列比对提供的演化信息，核酸表示为核苷酸，其他物种直接表示为原子，输出缓存的嵌入表示；结构模块是一个扩散生成模型，输入含噪坐标和噪声水平，逐步去噪输出结构。核心创新在于结构模块接受一个可选的动力学条件输入——起始结构加时间间隔 τ，模型被训练来采样从起始结构出发、经过时间 τ 后的结构分布，也就是用生成模型直接模拟分子动力学在任意时间跨度上的传播，而不是逐步积分。三种推理模式由此组合而成：结构预测模式让模型生成类似 X 射线或冷冻电镜实验得到的静态结构；平衡采样模式让模型从学习到的室温水溶液平衡分布中独立采样构象，这里 BioEmu2 被定位为“Boltzmann 模拟器”——它不像 Boltzmann Generator 那样从已知力场采样，而是从数据中学习一个跨体系泛化的近似平衡分布，训练数据来自显式溶剂全原子分子动力学在 300K、1 atm 下的 NpT 系综，溶剂效应被隐式学习；时间传播模式则在平衡模式基础上加入起始结构和时间间隔，输出未来时刻的结构采样。由于主干嵌入计算比单次结构模块评估昂贵得多，BioEmu2 只算一次主干嵌入并在大量采样或传播步骤中复用，这是推理效率的关键。此外，模型支持通过接触条件或用户定义的偏置势在推理时引导生成，并实现了上下文并行来把配对表示分散到多块 GPU 上，从而将可处理的体系规模推到上万残基量级。

结果方面，在 FoldBench 和 Runs N' Poses 两个共折叠基准上，BioEmu2 的结构预测精度与 Boltz-1、ESMFold2、OpenFold3、Protenix v1/v2、OpenDDE 等可商用且训练数据截止时间可比的基线模型相当，蛋白-蛋白结合由于训练数据偏重该方向而表现更强。大规模推理上，借助上下文并行在 NVIDIA B200 上从单卡扩展到 4 卡和 16 卡，支持约 16000 残基的体系，几个数千残基的多聚体测试案例 backbone lDDT 在 0.80 到 0.94 之间、全局 RMSD 在 2.0 到 6.6 埃之间；对于 4020 残基的 8WY8 复合物，仅指定一个链间接触就把 RMSD 从 71.2 埃降到 5.0 埃、DockQ 从 0.10 提到 0.46，说明少量实验先验知识能显著改善超大复合物的预测。平衡采样方面，作者用 TICA 投影到每个测试体系最慢的两个集体变量上比较自由能面，在测试的蛋白和复合物上自由能误差接近 1 kcal/mol，状态覆盖率也作为指标被报告，意味着模型既能找到相关亚稳态又能重现其相对布居数。时间传播能预测长时标动力学轨迹以及结合和构象变化的动力学。局限也很明确：作者自己指出若干能力仍处于实验阶段，尤其是慢动力学，需要更大规模的高质量实验数据集和进一步验证；超大复合物的结构预测成功率随规模下降，部分原因是问题本身更难定义，因为大复合物在细胞内组装而非溶液中自发形成。总体而言，BioEmu2 把分子动力学风格的采样任务加速了数个数量级，使生物分子系综和动力学的规模化研究成为可能，对这个方向的影响在于它把“静态结构预测”推进到“可控制的系综与动力学模拟”，为药物靶点选择和机制研究提供了一个可快速迭代的计算基础设施。

### [BQDNA: Multi-Head Binary Spherical Quantization for Genomic Sequence Modeling](https://arxiv.org/abs/2611.29395)
`评分3 · 有代码`

这篇论文瞄准的是基因组语言模型里一个被长期低估却非常关键的环节：DNA 的分词方式。DNA 只有四种碱基，但序列极长且高度重复，既没有天然的词边界，也没有类似自然语言那样的语义分段规则，因此主流做法要么用固定长度的 k-mer 切分，要么用 BPE 这类基于统计频率的合并策略。这两类方法有两个根本毛病：一是无法注入领域先验（比如启动子、增强子这类功能元件的结构规律），二是它们只是预处理步骤，和下游任务完全脱钩，没法被训练信号引导去捕捉对下游有用的语义模式。此前 VQDNA 尝试用残差量化来学可学习的 token，但对 VQVAE 该用什么语料训练、序列如何下采样、多头码本在 gLM 预训练中怎么用这些关键细节都缺乏系统考察，导致基于向量量化的 gLM 到底有多大潜力并不清楚。论文正是要把这条路线讲透，并给出一个完整可用的框架。

方法上的核心是两件东西：BQVAE 和 BQDNA。BQVAE 是一个上下文感知的量化自编码器，它先把 DNA 序列编码成 256 维特征，再投影到 48 维量化空间，切成 4 个头、每头 12 比特，也就是每头 4096 个码字。关键洞察在于抛弃了传统 VQVAE 的最近邻码本查找，改用二值球面量化（BSQ）：码字不需要显式维护和优化，而是由比特直接定义，这既避免了码本坍塌，又让每个头拥有独立的 4096 类预测词表，4 个头组合起来能表达 4096 的四次方种码元组，极大扩展了离散表示空间。为了让码本利用均衡，训练时除了重建损失还加了基于熵的辅助损失，一项约束单样本内的码分布熵，一项约束批级别的多样性。另一个重要设计是训练语料的选择：作者没有拿整部参考基因组（充满重复序列）去训 tokenizer，而是从多物种基因分类数据集中挑选功能元件相关的序列，理由是重建质量收敛很快，真正决定下游效用的是语料的功能相关性。BQDNA 则是第二阶段的自回归 gLM，BQVAE 冻结后充当分词器，把预训练语料离散成多头码本索引，语言模型直接做因果建模。为了在原始碱基分辨率上以线性复杂度处理长序列，骨干网络交替使用 1k 窗口的滑动窗口注意力和 Mamba2 线性注意力模块；又因为在多头量化中各头信息彼此独立，作者在预测头之前加了一个通道级注意力层，让 4 个头之间做特征交互，从而并行预测各头的码本索引，而不是逐头串行预测。

实验覆盖 50 多个下游数据集，结论相当有说服力。在 GUE 基准上，混合架构的 BQDNA 平均 MCC 达到 71.96，而同样骨干下用基础单碱基分词只有 64.13、用朴素 VQVAE 是 64.53，通道注意力本身也贡献了从 70.75 到 71.96 的提升；它同时超过了最强的外部基线 NTv2-500M 的 68.89，而预训练只用了 1 个 epoch 的 hg38、约 2% 的训练 token 预算。在表观遗传标记预测这种跨物种任务上优势尤其明显，MCC 从基础分词的 50.11 拉到 68.93。NT 基准上同样保持竞争力，平均 MCC 从 62.15 提升到 65.46。冻结嵌入加 XGBoost 的探针实验也显示其表征判别力领先，多物种启动子检测达到 63.74，超过 Caduceus-Ps 的 60.77。消融进一步说明两点：BQVAE 的训练语料分布对跨物种迁移至关重要，多物种语料明显优于纯 hg38；码本并非越大越好，多头配置比单纯增大码本带来更高的利用率和更强的功能元件区分度。局限方面，作者自己也承认 BQVAE 对训练语料分布敏感、需要精心策划，8 倍下采样变体在不同基准上的性能下降幅度不一致，说明分词分辨率对任务有依赖性，另外部分数据集因显存限制被排除。总体来看，这篇工作把“可学习向量量化作为 DNA 分词器”这条路线的关键工程细节补齐了，并用极低的预训练预算证明了它相对手工分词和朴素 VQVAE 的实质优势，对这个方向有较强的推动意义。

### [GaLF-ST: Gaussian Latent Fields for Spatial Transcriptomics Reconstruction](https://arxiv.org/abs/2611.27143)
`评分3 · 10 pages, 3 figures, 2 tables. We will release the appendix `

空间转录组学要在已知的组织位置上测量基因表达，但采样点天然稀疏，大量位置没有观测，因此需要从有限观测推断未测量位置的多基因表达，得到更致密的组织表达图谱。此前的主流做法是用坐标网络把表达建模成空间坐标的连续函数，比如 STAGE 把表达隐变量与坐标对齐、STINR 直接用隐式神经表示回归表达，但这些方法把局部空间关系隐式地编码在共享网络权重里，没有显式的局部位置、尺度和方向参数，组织区域和边界只能被间接表示，高频细节和边界锐变容易丢失。另一类思路是先拟合中间嵌入再训练预测器，例如 SUICA 先用图自编码器构造稠密嵌入、再训练坐标网络去预测它，然后冻结网络微调解码器；CPS 则用教师模型提取邻域表达状态，学生训练时冻结共享解码器以保持教师隐空间。问题在于，为表达重建学到的隐表示未必能从空间坐标轻易推断出来，两个训练阶段对隐表示的要求不一致，而且一旦冻结，坐标网络或解码器就无法再响应后一阶段的预测误差。再加上各研究在组织类型、平台、基因面板、掩码方式和聚合规则上各不相同，跨研究比较也很困难，这构成了提出新方法与统一基准的双重动机。

GaLF-ST 的核心洞察是把空间表达场显式参数化为可学习的高斯基元，而不是让网络权重隐式地记住空间结构。具体来说，它在组织坐标空间中放置 K 个高斯基元，每个基元拥有一个中心、一个各向异性协方差（用 Cholesky 分解参数化，保证正定，对角尺度限定在初始值的 1/r 到 r 倍之间、剪切参数归一化到 -1 到 1，从而稳定几何）以及一个低维隐系数向量。对任意坐标，先计算每个基元的高斯对数响应，再对所有基元做 softmax 归一化得到混合权重，这些权重对隐系数做加权平均，得到一个位于系数凸包内的低维隐状态；随后一个共享的非线性解码器（单隐层 GELU 加 softplus 保证非负，并按基因标准差还原尺度）把这个隐状态映射为全部基因的表达。低维隐状态在这里承担三重作用：捕捉基因间共享的依赖结构、压缩表达以缓解空间转录组零膨胀带来的噪声、以及把可学习表达参数从 K×G 降到 K×q 从而大幅节省参数量。关键在于训练方式：观测表达误差通过标准化损失（按基因标准差归一化）反向传播，同时更新高斯几何（中心位移、尺度、剪切）、隐系数和解码器参数，从初始化开始就是端到端联合优化，而不是分阶段拟合并冻结。这正好解决了前文提到的两阶段矛盾——空间表示和表达预测在同一个表达目标下共同学习，坐标网络不会因为冻结而无法响应预测误差。训练时用内部验证集做早停并记录最优 epoch，然后在全部观测上重新计算统计量并按该 epoch 数重拟合，查询时只需在查询坐标上重复同样的混合与解码操作即可生成表达图谱。

实验在七组数据集、三种留出比例（20%、50%、80%）共 21 个设置上，与 STAGE、SUICA、CPS、STINR 四种代表性方法在相同位置、划分、基因面板和评分规则下比较，覆盖全胚胎、近细胞分辨率脑区、人皮层和三维器官堆叠等组织。结果显示 GaLF-ST 在跨组织和不同观测密度下取得领先的整体重建性能，能恢复空间基因表达模式并在有限观测下保持组织域结构，同时显著降低运行时间和 GPU 显存占用。局限方面，论文摘要和正文尚未给出具体的误差下降数字，精确的量化提升需要等附录和代码发布后确认；高斯基元的数量 K 和隐维度 q 属于需要选择的超参数，基元初始化的尺度范围 r 也引入了先验约束，对极度不规则采样或表达极度稀疏的区域，固定数量的基元是否足够覆盖仍是开放问题；此外方法目前按数据集独立拟合，跨切片共享几何信息的三维扩展虽有 MOB 实验但机制上仍以独立拟合为主。总体而言，这项工作把计算机视觉中显式高斯基元表示的思想迁移到空间转录组重建，用可学习的各向异性空间基函数替代隐式坐标网络，并配套建立了公平可比的统一基准，为这一方向提供了一个兼顾表达精度、结构保持与计算效率的新基线。

### [Hierarchical Hybrid-Coordinate Flow Matching for Accurate and Physically Plausible Apo-to-Holo Protein Generation](https://arxiv.org/abs/2611.27162)
`评分3 · 36 pages, 11 figures, 25 tables`

这篇论文要解决的是基于结构的药物设计中一个很实际的瓶颈：拿到的是未结合配体的apo结构，但筛选化合物需要的是结合配体后的holo构象，尤其对于那些只有在结合过程中才暴露出来的隐蔽口袋，静态apo结构根本看不到口袋在哪。现有方法大多在笛卡尔空间做apo到holo的预测，用对齐后的Cα RMSD来评估，全局精度看起来不错，但RMSD高不代表局部骨架几何合理——相邻残基距离、伪角、非局部接触都可能被扭曲，等把Cα trace回填成全原子结构时这些误差就会放大。另一条路线是用内坐标表示，天然对局部几何有控制，但整条链回归式生成会遭遇杠杆臂效应：一个微小的角度误差经过逐残基累积，会把下游很远的残基推偏。所以核心矛盾是笛卡尔表示擅长全局运动但不管局部几何，内坐标擅长局部有效性但全局误差会累积，两边各缺一半。

CrypticFlow的做法是把这两种表示按层级拆开、各管一段。顶层用一个ESM-3条件化的E(3)等变图网络在笛卡尔空间生成稀疏的Cα锚点，步长取4，即每隔三个残基选一个锚点，同时处理D3PM数据中因残基匹配而产生的链断裂，不允许精化区间跨过断点。锚点生成后，用一个条件中点Transformer递归地在局部内坐标中填补空隙：每一层把所有未解析区间的中点同时生成，然后合并进部分trace成为下一层的父锚点，一个步长4的区间经过两层中点就补完了。关键设计在于中点的参数化方式——它不是直接预测一个无约束的笛卡尔位移，而是用相对于左右两个已生成父锚点的两个距离加上绕父轴的一个角度来表示，这个角度需要一个参考方向，作者把apo结构中对应中点残基的位置向量平移到当前圆的圆心再投影到圆平面上来定义零角方向，如果投影退化就换一个确定性选取的备用轴。更细的一层约束是相邻距离复制：如果中点与某一侧父锚点在序列上相邻，就把该侧的半径直接固定为apo的Cα-Cα距离（经过sanitize，只保留2.5到5.0埃之间的有限值，其余替换为3.80埃），这样中点根据两侧是否相邻分别有3、2或1个可学习的几何自由度。这个设计的直觉是相邻Cα距离由骨架连接性紧紧约束，apo到holo变化极小（作者在全部1591对D3PM数据上统计，99.82%的相邻Cα对变化小于0.2埃），所以直接抄过来既提供了强归纳偏置又不损失精度。训练上两个网络都采用clean-endpoint参数化的条件流匹配，锚点流从apo锚点坐标出发指向holo锚点，中点流从高斯噪声出发指向归一化的holo局部坐标状态，推理时按层级顺序生成、层内并行。消融实验表明相邻距离复制只是小幅精化，真正提供强偏置的是局部内坐标状态表示本身；而浅层级的递归设计限制了但并未完全消除杠杆臂放大。

在固定的150对D3PM测试集上，CrypticFlow在已发表基线容量下取得了最低的中位和平均Cα RMSD，五个独立训练的模型给出中位直接RMSD 1.333±0.056埃、平均2.766±0.041埃。局部几何的改善更明显：相邻距离保真度达到99.58±0.02%、伪角保真度95.87±0.25%（分别在0.2埃和20度容差内相对于holo参考）。把预测的Cα trace用cg2all回填成全原子结构后，MolProbity得分为3.034±0.054，优于所评估的基线。局限方面，作者自己指出浅层级的层次结构只是限制而非消除杠杆臂误差放大，这意味着更长的未解析区间或更深的递归可能仍有累积风险；此外方法依赖apo和holo的残基匹配以及D3PM描述符，对没有配对数据的场景泛化性未验证，相邻距离复制也建立在apo-holo相邻距离变化极小的经验统计上，对大幅骨架重排的极端案例是否成立还需检验。不过从方向上看，这篇工作给出了一个清晰的论证：混合坐标加层级生成可以在不牺牲全局精度的前提下把局部几何保真度拉上来，而且用回填后的全原子质量来评估比单看Cα RMSD更有实际意义，这对隐蔽口袋预测和基于结构的药物筛选是有直接价值的推进。

### [Structural Agreement Indicates Prediction Accuracy For Protein-Ligand Co-Folding](https://arxiv.org/abs/2611.27058)
`评分3 · 30 pages, 9 figures, 20 supplementary figures, 3 supplementa · 有代码`

这篇论文要解决的是蛋白质-配体共折叠（co-folding）模型在实际使用中的一个核心痛点：模型虽然能同时预测蛋白和配体的结合结构，但不同靶点上的预测准确率参差不齐，用户拿到一堆预测结果后根本不知道该信哪个。按照惯例，这类模型会输出置信度分数（比如pLDDT评估局部结构精度、ipTM评估界面精度），用户理应靠这些分数来挑选最可能正确的预测。但作者系统性地检验了七个共折叠模型后发现，基于置信度的挑选相比随机选一个pose几乎没有实质提升——在同时包含正确和错误预测的ensemble里，按ipTM选top-1的平均成功率是60.4%，随机选是58.6%，只差了1.8个百分点。更关键的是，他们发现约四分之三的ensemble要么全部pose都正确、要么全部错误，这意味着在这些情况下无论怎么排序都改变不了结果，置信度排序根本没有发挥空间。而在那些混合结果的ensemble里，正确和错误预测的ipTM分布重叠严重，高置信度并不能可靠地区分对错。此前评估预测可靠性的另一条路是用训练集相似度（蛋白序列identity、配体指纹Tanimoto、以及Runs N' Poses提出的结合口袋+配体pose相似度），但Runs N' Poses指标需要实验测定的配体pose才能算，在真实前瞻性场景中根本拿不到。所以问题就变成了：能不能只用模型自己生成的东西，不依赖任何实验结构，就判断出哪些预测可信？

作者的关键洞察来自扩散模型的一个本质特性：共折叠模型是通过从学到的条件分布中采样来生成结构的，对同一个输入反复采样就能经验性地刻画这个分布——如果模型对某个复合物“心里有数”，它会把概率质量集中在一个结构解附近，多次采样出来的pose彼此高度一致；如果模型“拿不准”，采样结果就会分散在多个竞争性结构之间。但作者也清醒地指出，集中不等于正确——模型可能自信地收敛到一个错误答案。所以他们要检验的是：结构一致性到底在多大程度上指示正确性，以及它是否提供了置信度和训练集相似度之外的信息。他们先做了描述性分析，发现全部正确的ensemble平均pairwise配体RMSD只有0.30 Å，远低于混合或全错的ensemble（1.77 Å），而且ensemble内部更大更紧的簇确实含有更高比例的正确pose。基于这个观察，他们设计了CORE Score（Concentration of Repeated Ensembles Score）：对ensemble中每个pose，找离它最近的三个其他pose，计算配体RMSD，将每个距离截断在阈值T（设为2 Å，与正确性判定的RMSD阈值一致）并除以T得到归一化惩罚，然后对整个ensemble取平均惩罚再用1减去。这个设计的精妙之处在于它同时捕捉了两个维度——最近邻距离落在T以内的比例（ensemble support，即有多少pose得到了其他pose的“呼应”）以及这些距离本身有多小（cluster tightness，即呼应得有多紧），而且不需要做显式聚类。用三个最近邻而非一个，意味着一个pose要得高分，至少需要四个pose紧密抱团，孤立的一对匹配不够；整个ensemble要得高分，则需要大多数pose都属于这样的紧密群体。在实际评估时，他们还做了前瞻性的有效性过滤：先用PoseBusters剔除物理上不合理的pose，再在剩余有效pose中按ipTM选top-1，这样成功需要同时满足RMSD、lDDT-PLI和物理有效性三重标准。

在Runs N' Poses基准的2,600个高分辨率蛋白-配体系统上（最终保留约13,396个模型特异性ensemble，覆盖七個模型），CORE Score在top-1成功判别上的平均ROC AUC达到0.866，而ipTM只有0.757；在oracle成功（ensemble中是否存在至少一个正确pose）判别上，CORE Score为0.838，ipTM为0.759。更值得注意的是，CORE Score在所有七个模型上都优于蛋白序列identity、配体Tanimoto和Runs N' Poses相似度，而它完全不需要实验配体pose——这是一个决定性的实用优势，因为后三者中只有Runs N' Poses考虑了结合模式，但它恰恰无法在前瞻性场景中使用。论文的局限也很明确：CORE Score本质上是一个无监督的一致性度量，它假设“模型反复收敛到的结构更可能正确”，但当模型系统性地偏向某个错误解时（mode collapse到错误答案），高CORE Score反而可能误导；此外它需要为每个输入生成足够多的重复预测（这里用了25个pose），计算成本高于单次预测加置信度打分；论文也没有给出一个绝对的CORE Score阈值来二分类“可信/不可信”，只是提供了排序和判别能力。不过这项工作的重要意义在于，它用扎实的基准数据揭示了当前共折叠模型置信度分数的严重不足，同时提供了一个无需额外训练、无需实验结构、即插即用的可靠性基线——任何未来想要声称自己改进了不确定性估计的方法，都应该先超过这个基线。
