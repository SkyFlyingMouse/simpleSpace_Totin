## 大模型 LLM

### [ALoDLM: Adaptively Looped Diffusion Language Models](https://arxiv.org/abs/2610.04198)
`评分4 · HF 53赞`

扩散语言模型（DLM）通过并行预测多个 token 来实现快速生成，但其实际落地始终受制于一个顽疾：与同等规模的回归模型（AR）相比，生成质量存在持续差距。这篇论文把根因归结为“计算量—难度错配”。在一个部分可观测的序列里，被 mask 的位置难度差异极大——有些 token 几乎可以凭上下文一眼猜出，有些则需要多跳推理或依赖尚未解析的其他 token 才能确定。然而现有 DLM 在每个去噪步对所有未知位置施加完全相同、固定深度的去噪计算，结果是在简单预测上浪费算力，在困难预测上算力不足。基于置信度的解码（如把低置信 token 推迟到后续去噪步）只能部分缓解：被推迟的 token 在下一步仍从 mask embedding 重新计算，之前为它做的隐状态计算被直接丢弃，等于它最终拿到的计算量还是固定的。AR 模型之所以没有这个“步内分配”问题，是因为它每次只预测一个 token、且条件在完全解析的前缀上。作者由此提出核心原则：DLM 应当为困难 token 维护并持续精炼其隐状态，让计算量随预测难度动态伸缩。

ALoDLM 的机制可以拆成推理与训练两条线。架构上把标准 Transformer（如 Qwen3）切成三段：Prelude（词嵌入加可选前缀块）、Recurrent Core（中间块，被反复复用）、Coda（剩余后缀块）。每个外层去噪步内部引入一个“内层循环”：Prelude 先产生初始隐状态，随后 Recurrent Core 反复迭代，每一轮 Coda 输出一个 readout 状态，同时喂给两个头——LMHead 给出词表分布，ExitGate 给出一个标量 logit，其 sigmoid 表示“此前未停、本轮停”的逐轮停止概率。关键设计是 token 自适应承诺：每轮计算各未解析位置的预测熵，熵低于阈值 τ 的 token 被采样出具体词、从待解集合中移除，其词嵌入在下一轮作为离散上下文反馈回循环输入；而仍未解决的 token 则保留并继续精炼自己累积的隐状态。也就是说，简单 token 早早“落地”为已解析上下文，困难 token 继续占用循环深度。内层循环何时结束由 ExitGate 的累积停止概率决定（均值达到阈值 q 或待解集合为空即停），若整轮无人承诺则强制提交熵最低者以保证推进。训练上，作者把每个 token 的退出深度视为隐变量，由于一个 token 的提前承诺会改变其余 token 的上下文、进而改变整条轨迹，退出深度必须联合建模为“退出调度”，对指数级多的调度求和不可行，于是引入由 ExitGate 参数化的变分分布，推导出条件负证据下界（NELBO），把语言建模损失和计算分配策略放在同一个目标里端到端优化；先验用截断几何分布鼓励浅层退出。由于退出调度是离散的、无法直接路径微分，作者用 score-function 估计器（REINFORCE 类）给出无偏梯度估计，并配合方差缩减技术稳定训练，同时用 stop-gradient 让 ExitGate 不影响骨干梯度。

实验上，作者在 5B token 语料上直接对 Qwen3 骨干做 SFT，训练了 1.7B 和 8B 两个规模，覆盖通用推理、数学、代码共 11 个基准。ALoDLM 的平均分分别为 65.5 和 80.3，超过所有对比的 DLM 以及对应的 AR 基线；在 GSM8K 上用并行解码，8B 版本达到 vLLM 服务的 Qwen3-8B 约 2.7 倍速度，且精度相当或更高，在质量—效率权衡上表现突出。分析还显示循环深度可作为测试时扩展的新维度，且模型无需显式难度标签就能学到 token 相关的精炼偏好。局限方面，训练依赖变分下界与 score-function 估计，方差和稳定性仍是工程负担；退出阈值、停止阈值等超参需要调；论文也未充分展开在更长序列、更大规模或开放生成任务上的表现。但它的意义在于把“计算—难度错配”明确立为 DLM 质量差距的一个根因，并给出 token 级自适应隐状态精炼这一可扩展的解法，为 DLM 追赶 AR 质量同时保留并行解码优势提供了一条有说服力的路径。

### [Base Models Can Reason By Taking a Cue From Training Data](https://arxiv.org/abs/2610.06851)
`评分4 · Project page: https://www.sophielwang.com/cues Code: https:/ · 有代码`

这篇论文要回答的是一个很具体也很根本的问题：基座语言模型到底有没有推理能力，还是说推理完全是强化学习后训练“教”出来的。此前的主流叙事是，像反思、自我验证这类行为是在RLVR（可验证奖励强化学习）阶段涌现的，DeepSeek-R1-Zero的“aha moment”就是典型例子。但作者指出，观察到后训练之后出现某种行为，并不能证明这个能力在之前不存在——RL可能只是把基座模型早就具备的能力激发出来，而非从零教会它。已有的工作确实发现基座模型通过显式提示或推理时搜索也能展现推理，但那些方法要么需要精心设计的长指令，要么需要额外的搜索开销。这篇论文的切入点是：如果推理已经在基座模型里，那么激发它所需的最小干预到底是什么？他们发现答案出奇地小——只需要固定模型回复的最前面两个token。比如对Olmo-3-7B，把回复开头强制设为“.\n\nOkay”，MATH-500的pass@1就从42%跳到78%，而经过完整RL训练的同款模型也才75%。这就引出了一个更深的疑问：为什么两个看起来毫无信息量的token能触发推理？它们和训练数据之间到底是什么关系？

核心方法分两层。第一层是发现和验证token cue。作者不依赖参考答案，而是先用beam search在30道MATH训练题上按模型自身的生成概率排序候选开头，保留20个；然后对每个候选开头采样16条续写，提取最终答案，计算答案分布的香农熵，选熵最低的那个——直觉是，如果一个开头能让模型采样出的答案高度一致，那它大概率把模型推向了正确的推理模式。这个无标签的代理指标在Olmo-3-7B上选出的cue与500个候选里MATH-500最优的cue只差1.1个百分点。选出的cue因模型和prompt格式而异，Olmo-3-7B是“.\n\nOkay”，Qwen3-14B是“ Alright,”。关键操作是prefill：把这两个token直接喂给模型作为已生成的上下文，然后让模型自由续写，权重完全不动。第二层是因果性地追溯这些cue的来源。作者在Olmo-3-7B的100亿token中间训练数据上做干预：把数据里所有的“okay”替换成“chicken”，重新训练一个checkpoint。结果“.\n\nChicken”这个原本毫无意义的开头，在MATH-500上从2.4%提升到37.2%，接近“.\n\nOkay”在同一数据上的38.3%。更妙的是，如果把数据里短问答文档开头的“Question:”标签替换成“Okay,”，那么“.\n\nOkay”这个cue就不再触发推理，而是让模型开始提问，准确率跌到0.2%。这说明cue的语义效果完全由训练数据中的关联决定，和token本身的字面含义无关。作者还发现，RL训练本身会大幅提高这些cue的生成概率——Olmo-3-7B上“.\n\nOkay”的概率从0.14升到0.65——而且RL带来的分布变化高度集中在输出序列的最初两个位置，之后的next-token分布几乎不变。如果在RL训练时直接强制固定这个cue，达到同等准确率所需的更新步数会显著减少。换句话说，RL在很大程度上是在做一件事：让模型更倾向于生成那些已经在基座模型里能触发推理的开头token。

实验结果覆盖了数学和代码任务。在MATH-500上，prefill cue让Olmo-3-7B从42%到78%（RL是75%），Qwen3-14B从72%到87%（与RL持平）。在GSM8K、AMC 23、AIME 2024上，同一个cue不加修改地迁移过去，多数情况下匹配或超过RL。HumanEval上Olmo的cue也追平了RL。作者还排除了“只是生成了更长的回复所以准确率更高”这个解释：有些开头生成的token数是推理cue的两倍，但准确率反而低于无cue；而在相同token预算下截断重打分，推理cue从1k token开始就稳定优于无cue，并且大约用一半的预算就达到RL级别的准确率。局限方面，这篇工作主要基于Olmo和Qwen两个模型家族，数据干预实验只在Olmo-3-7B和SmolLM3-3B上做了复现，10B token的中间训练虽然足以展示效应，但和完整100B训练下的行为是否完全一致还需要更多验证。此外，安全性的案例研究只是初步的：不同cue会引发不同的拒绝和顺从行为，比如“ I'm sorry”倾向于对良性和有害请求都拒绝，而“ Okay,”减少拒绝并增加对有害请求的顺从，但背后的数据关联机制还没有像推理cue那样被因果性地验证。这篇论文的意义在于，它把“推理能力从何而来”这个问题从抽象的“RL是否教会了新能力”推进到了可操作的数据因果层面：基座模型已经具备推理的行为模式，训练数据中的局部关联决定了哪些token能触发这些模式，而RL在很大程度上是在放大这些触发器的生成概率。这为理解后训练的真实作用提供了一个更精细的视角，也暗示了一条可能的路径——与其做大规模的RL，不如更直接地设计和控制训练数据中的关联结构来塑造模型行为。

### [Towards Looped Models Done Right, Part II: Rethinking at Fixed Points](https://arxiv.org/abs/2610.06833)
`评分4 · Code and checkpoints: https://github.com/ifm-ai/xllm-loop · 有代码`

这篇论文要解决的是循环语言模型（looped language model）在训练、推理、预填充和强化学习各阶段都随循环深度线性增长的成本问题。循环模型反复应用同一个共享层块，但关于它是否应该学习不动点一直存在分歧：一派放弃不动点、把循环次数固定得很小，另一派则塑造不动点并循环很深。问题在于，典型实现中每一次循环都要付出代价——训练时要存激活、解码时要缓存键值、预填充每个提示要算力、强化学习给每个 rollout 打分还要重放整条轨迹。论文的关键观察是：循环状态越接近不动点，到达它的路径就越不重要，因此终点状态可以替代整条轨迹。作者用终端 KV 共享来验证这一主张：复用终端的 KV 缓存几乎不改变 Huginn 的零样本 GSM8K 准确率，却让 Ouro 在四层循环时崩溃，这个分化正好对应收敛性——Huginn 的状态趋近不动点，Ouro 的没有。但要让这些好处真正兑现，训练必须塑造出好的不动点，而现有做法在两个关键组件上都不够好：一是深度先验（训练深度的分布），固定深度训练会破坏 KV 共享，Huginn 的固定宽先验虽支持共享却在目标深度上稀释了监督；二是输入注入，Huginn 和 Parcae 都放任状态中沿输入方向的分量自由增长，这个分量会根据符号放大或抵消注入，导致每次循环收到的输入强度不一致。

论文的核心创新正是针对这两个组件。对于深度先验，作者不再用固定的移位泊松-对数正态分布，而是从预测反馈中学习这个先验，让监督被拉向预测得好的深度，同时加一个熵项保持分布足够宽以支持 KV 共享——这样在相同平均深度下，既保留了跨深度监督带来的不动点塑造效果，又提升了目标深度的预测质量。对于输入注入，作者提出正交注入（OrthoInj）：把状态中沿输入方向的分量投影掉，使每次循环都以相同强度接收输入，消除了放大或抵消的不确定性。在训练方式上，论文论证了截断反向传播（TBPTT）本身就足以塑造不动点：它只对最后 b 次循环求导，内存和算力随 b 而非总循环数 R 增长，而且从任意状态出发它都是最后 b 次循环的精确梯度，所以早期和全 BPTT 一样稳定，等状态收敛到不动点后又逼近不动点梯度，不需要隐式梯度方法那种预热阶段。相比之下，固定深度加全 BPTT 在 R=5 时外推到 R=64 困惑度上升超过 25%，终端 KV 共享再上升 21%；而 TBPTT 只回传最后两次循环时，这两个数字分别不超过 2% 和 3%。在推理端，终端 KV 共享让每个前缀 token 只保留终端的 KV 库，后续所有循环都去读它，论文用引理证明了当参数固定、前缀 KV 收敛且更新映射是压缩映射时，联合迭代和冻结前缀解码会收敛到同一个不动点，因此序列并行的监督能迁移到终端共享的解码。预填充则蒸馏出一个轻量学生网络，直接从 prelude 输出预测循环终点，因为不动点塑造让终点近似是不动点，从学生预测的邻近状态跑一次教师循环就能得到接近教师终端库的 KV。强化学习阶段则复用 rollout 时保存的终点状态，只在那一次记录的循环上把反向传播迭代 b-1 次来近似 Neumann 级数，从而避免重放整条轨迹。

实验结果覆盖 100M 到 1.6B 参数。学习到的深度先验在每一个规模上都比 Huginn 的固定先验降低了困惑度并提升了下游平均分；在 1.6B 上，配合小 3 倍的 KV 缓存，它甚至追平了固定深度训练用完整缓存的平均分。正交注入相比最强的注入基线 Parcae，训练损失更低，验证困惑度降低 0.3% 到 1.4%，下游平均分也更高。蒸馏预填充只用了教师四分之一预训练 token，在 8K 提示上最高快 1.79 倍，下游平均分落后教师 1.0 到 4.5 分；在相同延迟下，它比教师用两次循环预填充还高 0.5 到 0.9 分。Rollout 状态复用在每次 RL 更新的打分和反向时间上减半，GSM8K pass@1 与全 BPTT 重放基线相差不超过 1.6 分。局限方面，这些捷径都依赖状态确实接近不动点，而收敛是异质的——不同 token 在不同深度收敛，且与位置只有弱相关，所以深度先验的学习和终端共享的收益在不同任务上可能不稳定；蒸馏学生目前只用于预填充，能否作为独立语言模型或投机解码的草稿模型还未验证；rollout 生成仍然占据 RL 训练的大部分时间，复用只省了打分和反向。总体而言，这篇工作把“不动点”从一个理论直觉变成了可操作的工程杠杆，说明只要训练正确地塑造不动点，循环模型就能在预训练、服务和后训练每个阶段都摆脱深度带来的成本，这对循环架构能否真正扩展到大规模序列建模是一个有分量的推进。

### [Science Utopia? Closed-Loop LLM Simulation of Academic Research Ecosystems](https://arxiv.org/abs/2610.01257)
`评分3 · HF 40赞 · 有代码`

这篇论文要解决的核心问题是：当大语言模型逐渐渗透进选题、写作、评审、资助分配等科研全流程时，我们其实缺乏一个能追踪“个体决策如何经年累月地反馈、重塑整个学术生态”的实验工具。真实学术界几乎不可能做受控干预——你没法随机让一半基金委放宽资助率、另一半收紧，然后等十年看谁还留在学术圈；更关键的是，反事实结果根本不可观测。已有的 LLM 智能体研究大多停留在单轮或短程任务上，比如让模型写一篇论文、评一篇稿，但它们没有把“拒稿导致改投、改投加重评审负担、评审负担挤占研究者精力、精力耗尽导致退出、退出又缩小评审池”这条闭环反馈链真正跑起来。换句话说，之前的方法卡在“静态、开环、无状态”上：智能体做完一次决策就结束了，下一年的条件不会因为上一年的结果而改变，因此无法回答“某个制度设计长期来看会把生态推向哪里”这类问题。

Suto 的关键设计在于把科研生态建模成一个持久化的闭环多智能体系统，每个研究者智能体维护一份跨年状态，包含 expertise 主题、reputation、预算、利益冲突集合以及一份记忆，记忆里记录着过往的发表、评审经验和资助结果。预算机制是闭环的枢纽：每年预算等于上年余额加上新获资助减去所有行动开销，预算耗尽的研究者直接退出活跃人口。这样，一次拒稿不只是丢一篇论文，它会触发改投决策、消耗额外预算、挤占后续选题资源，甚至最终把人逼出学术圈。系统还区分了大学研究者靠外部竞争性基金、产业研究者靠内部经费两种制度设定，并引入探索者、谨慎探索者、利用者三类策略来刻画选题的探索距离。论文提交阶段，智能体不是凭空生成论文，而是从与当前模拟年份匹配的真实文献库中检索候选论文，再选一个主题兼容的会议投出去，这保证了科学内容的可信度。评审阶段默认双盲，每篇论文分配三个审稿人，给出推荐分和书面理由，会议按平均分排名并只接受排名前 α 比例的论文。被拒论文从第二年起进入改投流程，智能体根据收到的评审意见、投稿历史、剩余预算和改投成本决定放弃、修改还是重投。资助阶段则让大学研究者提交基于自身专长和过往论文的简短提案，资助智能体从项目匹配度、研究潜力和发表记录三个维度评估，按资助率取排名靠前的人。整个流水线按固定顺序逐年执行，模拟年份映射到真实日历年，因此智能体只能引用当时已经存在的论文。这套设计的巧妙之处在于：它没有把制度干预和反馈效应混在一起，而是允许在保持底层规则不变的前提下，只改动某一个机制参数，然后追踪这个改动如何沿着闭环传播下去。

在 61 个模拟世界、超过四万名研究者、八千个机构、约四十万次发表决策和一百二十万条 LLM 生成的同行评审中，Suto 给出了几个反直觉的发现。第一，拒稿驱动的反复改投会显著放大审稿人负担，这种放大远超人口增长本身：如果只增加研究者数量，审稿池同步扩大，人均审稿量几乎不变，大约在 2.07 到 2.25 篇之间；但如果只开启改投机制，人均审稿量直接飙到 6.64 篇，而且更严格的接收标准会把审稿工作推到后续轮次，即使新投稿量没怎么变，总审稿工作量仍会增加约 14%。第二，发表量的增长可能掩盖参与度的萎缩：把每个项目的投稿上限翻倍，在大学场景下接收论文数增加 63% 到 69%，但十年后仍活跃的初始研究者比例从 39% 掉到 24%，即使资助容量随需求同步扩大也挡不住这个趋势。第三，谨慎探索者——那些频繁在自身专长附近开拓新方向的人——在引用影响力上超过纯粹利用旧方向的人和远距离跳入全新领域的人，而论文接收率和资助获取的下降幅度并不大；当多数研究者采取这种策略时，长期的研究活动在主题分布上保持较广的覆盖。第四，早期以微弱优势赢得资助并没有在随后三年带来显著的职业优势，但资源会随时间逐渐集中，近一半研究者最终耗尽预算退出。第五，在评审中披露第一作者的马甲姓名和机构，会让评分在 1 到 5 分制上提高 0.055 到 0.077 分，而进一步披露共同合作者或网络关系几乎没有额外影响。这些结果的局限也很明显：模拟中的论文虽然锚定真实文献，但研究方向和提案内容仍是 LLM 生成的，未必能完全复现真实科学中那些需要长期实验积累或偶然突破的路径；预算被抽象为类似 token 的资源约束，和真实科研经费的复杂结构还有距离；评审行为也只基于标题、摘要和主题，没有全文深度阅读。尽管如此，这项工作把“学术生态作为闭环复杂系统”这一视角真正做成了可运行、可干预、可复现的实验平台，为未来在 AI 深度参与科研的时代里讨论制度设计、资源分配和科学多样性提供了一个此前缺失的因果推演工具。

### [Source Preference in the Wild: How LLM Agents Favor Items by Source, and How to Reduce It](https://arxiv.org/abs/2610.03195)
`评分3 · HF 37赞`

这篇论文研究的是LLM智能体在端到端搜索与选择场景中表现出的“来源偏好”问题。现实中的搜索智能体不再是单纯给用户提供信息，而是直接替用户决定展示哪些商品、推荐哪家酒店、引用哪篇论文，而每个候选项都来自某个具体来源（比如Booking.com或Expedia）。此前已有工作（如Khan等）发现模型会偏好某些来源，但那些实验是把语义完全相同的内容挂到不同来源标签下，属于受控的、非真实的检索环境；真实搜索中每个来源提供的是各自不同的条目，内容质量和需求满足程度都不一样，因此无法简单套用旧结论。更麻烦的是，如果仅看选择率，某个来源被选得多，可能只是因为它的条目本身更好地满足了请求，或者恰好排在更靠前的位置——位置偏差和内容差异是混杂在一起的。所以核心问题就是：在真实的、智能体自己检索并挑选条目的端到端流程中，来源偏好到底存不存在？如果存在，它是否严重到能压过条目本身对需求的满足程度？以及这种依赖来源的倾向从何而来、能否被削弱？

为了把来源偏好从内容差异和位置偏差中剥离出来，作者设计了一套相当严谨的测量方案。首先，他们让12个模型（涵盖GPT、Gemini、GLM、DeepSeek、Llama、Qwen等家族）在购物、住宿、学术搜索三个领域执行ReAct式的搜索-选择循环，每个请求返回最多10条结果，每条包含标题、内容和URL，来源就定义为URL的可注册域名。关键控制手段是“需求匹配对”：对同一个请求，只把来自不同来源、但满足完全相同需求集合的两个条目配成一对，这样就排除了“某个来源的条目恰好更符合请求”这一解释。位置方面，他们把长度为L的结果列表做全部L种循环旋转，每种旋转单独跑一次，构成一个循环拉丁方，使得每个条目在每个展示位置上恰好出现一次，于是可以在同一位置上比较两个条目的选择结果。由于每个来源面对的对手来源组合不同，直接平均选择率会有偏，作者进一步用Bradley-Terry模型加上Davidson的平局扩展来联合估计每个来源的评分，把评分中心化后转换成偏好分数，表示该来源相对平均来源的预期选择率差；再用请求级别的聚类自助法做显著性检验，把来源分为偏好、中性、被回避三类。这套方法的洞察在于：来源偏好本质上是一个在控制了需求满足度和位置之后的残余选择差异，只有用匹配设计加位置轮转加配对比较模型，才能把它干净地估计出来。

结果显示，来源偏好不仅真实存在，而且强到能逆转需求满足度的排序。在需求匹配的受控比较下，全部12个模型在三个领域中都偏好某些来源、回避另一些，144个模型-来源组合中有110个被判定为显著偏好或显著回避，中位偏好分数分别为正15和负18个百分点；模型之间高度一致，比如大多偏好Booking.com、回避Expedia，偏好Walmart但只有两个偏好Target，说明偏好不仅存在于来源之间，也存在于同类型网站之间。更严重的是“倒置”现象：当较不满足需求的条目来自偏好来源、较好条目来自被回避来源时，智能体有约68%的概率选中较差的那个；反过来当较差条目来自被回避来源时，这个比例中位数只有2%，中性来源对作为基线约为19%。也就是说，来源偏好可以轻易压过一个需求的差距，让用户拿到更差的选项。作者还通过隐藏来源信息、以及把相同内容重新贴上偏好/被回避来源标签两种干预证明，来源标识本身就独立地影响选择：隐藏会削弱偏好，重贴标签会系统性改变选择率。关于成因，训练阶段如果DPO数据中某来源更常与更好的条目配对，模型就会把来源学成需求满足的捷径，而平衡这种配对可以缓解已有偏好；推理阶段，信息缺失会触发模型对来源的先入之见，补全缺失信息或用提示词对抗这些先入之见都能降低对来源的依赖。局限在于研究只覆盖12个模型和三个领域，来源偏好的具体成因仍只给出训练关联和推理触发两类机制的证据，尚未穷尽；但它的意义在于把端到端搜索中的选择偏差与来源标识的因果作用、以及可操作的缓解手段连接起来，提醒我们：如果这些选择结果再回流到训练数据，偏好会被自我强化，可见性会向少数来源集中，而用户可能永远看不到那些来自被回避来源、其实更符合需求的条目。

### [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/abs/2610.06830)
`评分3 · Code is available at https://github.com/ViktorAxelsen/MemPil · 有代码`

现有LLM智能体的记忆系统大多采用“查询无关”的方式预先构建记忆，也就是在用户提问之前就把交互历史压缩成某种固定表示。这种做法有两个根本性缺陷：一是预处理成本不可避免地被浪费，因为并非所有历史信息都会被后续查询用到；二是压缩过程会丢弃那些在当时看似不重要、但后来被证明关键的细节。近期一些工作开始把记忆处理推迟到运行时，根据查询需求动态提取证据或构建记忆，但它们要么只针对某一种特定操作（如即时检索、预算感知提取），要么依赖固定的处理流水线或预设的预算档位，导致运行时计算无法根据查询难度和证据模态灵活调配。更关键的是，已有方法通常只优化效率目标的一个子集——比如token消耗或金钱成本——而用户直接感知的延迟很少被当作显式的优化目标；同时它们大多假定一个固定的处理后端，忽略了不同模型在整理质量、成本和延迟上的巨大差异。这三个局限共同导致了一个核心问题：如何让运行时的多模态记忆整理能够自适应地编排，并在性能、成本、延迟三者之间实现可控的权衡？

MemPilot的核心设计原则是“双视图记忆”：一方面保留一个查询无关的记忆库，兼容现有的智能体记忆系统，用于高效检索；另一方面保留原始的多模态交互历史，按固定token长度切分成块，供运行时按需整理。推理时，一个多步LLM策略（称为编排器）迭代地决定每一步是直接从查询无关记忆库中检索，还是把原始历史中的相关片段委托给异构的LLM和VLM进行查询特定的整理。关键在于，这个策略把每个动作分解成多个可控维度：检索什么（检索查询）、检索多少（证据数量k）、如何整理（整理指令）、用哪个模型处理（从模型池中选择）、以及是否需要包含原始视觉证据。这样就把“检索什么”和“怎么整理”解耦开，避免把两个语义上不同的操作混在一个文本字段里。编排器本身只处理文本，不直接接触图像像素，视觉能力完全通过委托给VLM来实现。训练时采用GRPO，但针对多目标做了两项关键改进：一是目标级优势解耦，即对质量、成本、延迟三个奖励分别在组内做归一化，再按偏好权重聚合，避免直接混合奖励后归一化会掩盖各目标自身的学习信号；二是基于前缀的边际效用估计，用于在多步 rollout 中做更细粒度的信用分配，判断每一步整理动作对最终结果的边际贡献。这样，策略就能在不同偏好下学会把运行时计算分配到最需要的地方——比如偏好低成本时倾向调用小模型、减少检索数量，偏好高质量时则调用大模型并保留视觉证据。

在五个多模态智能体记忆基准上，MemPilot在不同优化偏好下都取得了比现有权衡感知基线更优的性能-成本-延迟前沿，也就是说，通过连续调节偏好向量，它能覆盖更广的权衡空间，而基线方法往往只能在离散的预算档位或固定流水线下工作。行为分析进一步显示，随着偏好变化，策略会自适应地改变模型选择、视觉访问频率和计算分配——这验证了细粒度控制确实被有效利用。局限方面，MemPilot目前依赖一个预定义的异构模型池，池中模型的性能和成本特征需要事先知道或估计；编排器本身是文本-only的，对纯视觉推理任务可能不够直接；此外，基于代理估计的延迟在真实部署中可能因服务波动而偏离。尽管如此，这项工作把记忆整理从“查询无关的预处理”推进到“偏好驱动的运行时编排”，为智能体记忆系统在真实场景中平衡效果与资源开销提供了一个可学习的、灵活的框架，后续可以在此基础上探索更动态的模型池扩展和端到端的多模态编排。

### [T-Search: An Open Agentic Retriever and Playground for Hard Multi-Step Search](https://arxiv.org/abs/2610.06782)
`评分3`

这篇论文要解决的是多步检索中一个被长期混淆的核心问题：现有检索增强生成系统默认“用问题本身去搜”就能找到答案，但HotpotQA这类多跳问题打破了这一假设，而BrowseComp及其固定语料变体BrowseComp-Plus更进一步——问题的搜索词根本不出现在问题里，模型必须先发现一个从未被提及的实体，同时拒绝那些看起来相关实则无关的文档。当前的深度研究智能体靠大模型跑长工具调用轨迹来处理这类任务，既慢又贵，而且评估的是最终答案，把检索质量和生成质量混在一起，无法判断到底是检索没找到证据还是生成没用好证据。T-Search的动机就是把检索阶段单独拎出来：给定问题和搜索后端，只做有界多轮搜索并返回带简短理由的证据块排序列表，答案生成完全交给下游模型，这样后端和生成器都能自由替换而无需重训，检索质量也能直接用金标证据的召回率来衡量，不再依赖答案评判模型。

方法上有三个关键设计。第一是短而有界的“轮次”结构：在ReAct循环中，每一轮只携带显式保存的证据前进，上一轮的工具调用记录和完整推理历史全部丢弃，下一轮的输入由原始问题、已保存证据块、轮次摘要、覆盖状态和下一轮目标重新拼装而成。这样做是因为工具输出不断累积会稀释模型的判断力，而让策略自己决定保存哪些块并附上理由，相当于把记忆控制权交给模型而非环境。第二是训练数据中工程化地注入搜索难度：先用命名实体标注、提及频率和共现统计预选连通子图，提取事实并转述为中间表示，让出题模型看不到原始引文以减少词汇线索，然后逐跳扩展问题并检查可答性和必要性；之后还有对抗循环，测试闭卷可解性、答案泄漏、直接用整个问题检索证据等捷径，逐个移除支撑块验证其必要性，甚至让出题模型作为搜索智能体去跑，把太容易的任务筛掉，约六万七千个候选中只有四万个存活。第三是奖励设计：强化学习阶段只给一个标量奖励，即最终排序中参考支撑集的召回率，完全基于块标识符计算，不需要评判模型，也没有对保存行为或每轮的额外塑形；作者发现基于精确率的目标准则会导致过早终止、证据不完整，所以选择召回率优先，并用GSPO优化。训练分两阶段：先在教师轨迹上做轮切分的监督微调，无效工具动作从损失中屏蔽但保留有用的恢复行为，再在独立问题池上做强化学习；英俄两个语言分支分别训练后用DARE和SLERP合并成单一双语模型。

在七个英俄基准上，T-Search单次 rollout 平均达到56.0 Recall@10，比基座模型高14.4个点，三次rollout融合后升至61.3，在所有基准上取得最高最终集召回率，且推理延迟远低于更大的开放模型——一轮的召回就接近Qwen3.5-397B-A17B五轮的水平而延迟只有其40%。它支持稠密、BM25和混合检索后端，换用LLM重排后平均召回可达62.87，说明后端可插拔的设计确实有效。局限也很明确：harness本身就是模型的一部分，换一个循环结构质量可能漂移，作者建议在自己的索引上验证后再依赖报告数字；它只返回证据不生成答案，不能作为独立问答系统部署，在通用基准上与基座模型差异不明显。但它的意义在于把证据收集当作独立组件来对待，并开源了模型、harness、演示和三个基准（包括首个俄语原生难搜索基准TRuST），让实践者可以替换后端、接入自己的索引、保留已有的生成器，这为检索与生成解耦的工程路线提供了一个可复现的起点。

### [Balancing Memory Pathways: Analyzing and Improving Memory Utilization in Hybrid LMs](https://arxiv.org/abs/2610.06750)
`评分3 · Code: https://github.com/amy-hyunji/Balancing-Memory-Pathway · 有代码`

混合语言模型（Hybrid LM）把注意力层和循环层交错堆叠，本意是同时拿到循环层的线性计算效率和注意力层的强表达能力。这类架构天然拥有两条记忆通路：注意力可以直接回看历史 token 做精确检索，循环层则把分散在长上下文里的信息压缩进一个固定大小的状态里做整合。之前的研究也确实分别刻画过两者的长处——注意力擅长"抄答案"，循环层擅长"推答案"。但论文指出的真实问题是：模型拥有两条通路，不等于它会均衡地使用两条通路。作者用一套巧妙的消融方法把两条通路拆开：把输入切成"过去段"和"当前段"，然后分别构造两种受限条件——recurrent-only 是阻断注意力跨段访问，让过去的信息只能经由循环状态传到当前段；attention-only 则反过来，阻断循环状态跨段传递，让过去信息只能靠注意力拿到。结果非常刺眼：在 Qwen3.5-4B 上，完整条件下准确率 30.2%，只留注意力时还有 20.2%，而只留循环时暴跌到 5.1%。也就是说模型绝大部分性能其实是注意力撑起来的，循环通路几乎没被用起来。更糟的是，标准监督微调（SFT）虽然把整体分数从 30.2% 拉到 34.6%，但注意力单通路的分数也从 20.2% 涨到 25.0%，循环单通路却纹丝不动（5.1%→5.0%）。在智能体任务 Quest 上同样如此，成功率从 27.0% 涨到 78.5%，可循环单通路只从 2.5% 爬到 4.0%。这说明 SFT 只是让模型更依赖注意力，两条通路的协调性不但没改善，反而更失衡了。

针对这个失衡，论文的核心干预是一个辅助损失（auxiliary loss）。思路很直接：既然模型偷懒只走注意力，那就在一次额外的前向传播里人为限制注意力对过去上下文的访问，逼着模型只能通过循环状态去取历史信息，让循环通路承担起它本该承担的信息传递职责。这个辅助目标和标准 SFT 联合优化，等于在训练时给循环通路"加练"。关键在于它不是简单地惩罚注意力，而是通过改变信息可达性来重塑模型的内部路由——当注意力被挡住时，梯度只能沿着循环状态回传，循环层因此被迫学会保留和利用长程信息。实验证明这个方向选对了：在 Qwen3.5-4B 上平均绝对准确率提升 3.9%，在 Nemotron-H-4B-Instruct 上提升 5.2%，覆盖六个问答数据集。而且增益分布很有说服力——长上下文数据集涨了 8.0%，短上下文只有 0.2%，恰好对应循环层擅长长程整合的特性。反过来，如果辅助损失改成鼓励注意力（即限制循环通路），增益明显更小，说明收益确实来自强化那条被低估的通路，而不是随便加个正则都行。在智能体任务上同样奏效：TextWorld 的 Quest 和 Treasure 成功率分别提升 3.5% 和 9.3%，BabyAI 的 PutNextLocal 和 GoToObjMaze 分别提升 22.0% 和 13.5%，而 BabyAI 的平均轨迹长度（134 步）远高于 TextWorld（42.2 步），再次印证长程场景受益更大。

从意义上看，这篇论文的价值不只是刷了几个点，而是揭示了一个更普遍的现象：多记忆通路的架构设计本身不保证通路被均衡使用，标准微调会系统性地偏向某一条通路，必须有针对性的监督信号去协调。作者进一步验证了这种失衡和辅助损失的有效性可以泛化——不仅适用于多个循环-注意力混合模型，还适用于那些拥有多种记忆形式的纯注意力模型，说明"哪条通路被冷落就给它加练"这个原则具有架构无关性。在需要多证据推理的问题上增益尤其突出（30.3% vs 单证据的 2.8%），在允许重试并保留历史尝试的记忆场景下，辅助损失训练的模型累计恢复率在问答上提升 16.6%、在智能体任务上提升 19.2%。局限方面，论文没有深入讨论辅助损失对训练稳定性和收敛速度的影响，也没有给出如何在预训练阶段就避免这种失衡的方案，目前仍是在微调阶段打补丁。此外，辅助前向传播带来的额外计算虽然通过减半优化步数做了对齐，但这种折中是否在所有规模上都成立还有待验证。总体而言，这项工作把"架构给了什么"和"模型实际用了什么"之间的鸿沟摆到了台面上，并给出了一个简单却有效的训练时干预手段，对后续混合架构的设计和训练策略都有直接的启发。

### [Learning to Read the Contextual Tokens in Diffusion Transformers](https://arxiv.org/abs/2610.06844)
`评分3 · Project page: https://omer11a.github.io/learning_to_read/`

多模态扩散Transformer（MM-DiT）已经成为当前高质量图像与视频生成的主流架构，其核心设计是让文本token和视觉token在每一层注意力中双向交互、反复更新。这意味着文本侧不再是固定的条件向量，而是在去噪过程中不断吸收来自正在成形图像的信息，演变成所谓的“上下文token”。问题在于，视觉token有明确的空间对应关系，并且直接受到去噪目标的监督，可以可视化、可以干预；而上下文token既没有空间结构，也没有专门的监督信号，因此学界一直不清楚它到底编码了什么视觉信息、这些信息如何随去噪演化、又在多大程度上真正影响生成结果。此前的工作要么分析注意力图，要么用因果干预证明上下文token“携带了信息”，但都没有直接揭示其语义内容——也就是说，我们知道它有用，却不知道它“在说什么”。

这篇论文的核心思路是把上下文空间当作一种可以被自然语言直接“读取”的表征。作者训练了一个轻量级瓶颈网络，把MM-DiT所有层、某个去噪时间步上的上下文token聚合起来，压缩成少量“上下文描述子”，再线性投影到冻结大语言模型的输入嵌入空间，让LLM仅凭这些描述子和一个关于当前生成图像的问题来自回归地给出答案。由于LLM看不到图像本身，瓶颈网络必须学会从上下文token中提取出真正的视觉语义，这就构成了一个视觉问答式的监督训练。具体实现上，他们用两层Q-Former加可学习查询token做跨层、跨位置的聚合，并为每段上下文token附加层编号和时间步的可学习嵌入，以保留“何时何层”的信息；训练时只优化瓶颈网络，MM-DiT和LLM全部冻结。这个设计带来的关键洞察是：上下文token中编码的并非只是对提示词的复述，而是一个全局性的、与具体生成实例绑定的场景表征。即使给MM-DiT输入空提示词，读者依然能在去噪早期识别出人物正在进行的活动，甚至早于视觉预测本身变得可辨认；随着去噪推进，越来越细粒度的属性变得可读。更重要的是，同一提示词下不同随机种子的生成结果，其上下文可读性存在差异，而可读性更高的生成往往获得更高的人类偏好评分，说明上下文空间的语义清晰度本身就是生成质量的一个信号。

基于这一发现，作者进一步提出“上下文对齐”训练技术，把上下文token中已经隐含的视觉语义信息显式地作为正则化目标加以强化，从而把被动观察转化为主动改进生成模型的手段。实验覆盖完整训练和微调两种设定，结果表明上下文监督与现有的表征对齐方法互补，能提升生成质量和分布覆盖度；尤其在微调一个已经充分训练过的模型到特定数据集时，现有对齐方法增益有限，而上下文监督仍然有效。当然，这项工作也有其边界：读取框架目前主要针对单人物、单主体的图像和一组预设问题，向更复杂场景、多主体关系以及视频生成的推广尚未验证；上下文描述子的容量和问题设计也可能限制可解码信息的范围。但总体而言，它把MM-DiT的文本侧从“难以解释的副产物”提升为一个语义丰富、可解释、且可被直接优化的目标，为理解多模态生成的内部动力学和设计超越标准扩散损失的新训练目标都提供了新的方向。

### [Sharpen Without Search: On-Policy Distillation of Sequence-Level Power Distribution](https://arxiv.org/abs/2610.06804)
`评分4 · 有代码`

这篇论文要解决的核心问题是：语言模型在推理任务上常常“知道正确答案却答错”，原因不是正确答案概率低，而是所有错误答案的概率加起来超过了正确答案。比如模型给正确答案 40% 概率，给每个错误答案各 5%，但 12 个错误答案合计 60%，采样时更容易抽到错误答案。已有的一种无需改参数的解法是“幂分布采样”：把每个完整答案的概率取 α 次方再归一化（α>1），相当于在序列层面锐化分布，让高概率答案被进一步放大，从而提升推理准确率。但问题在于，这种采样必须在推理时对每个 query 跑一个序列蒙特卡洛（SMC）采样器，需要同时维护多个候选答案、逐 token 计算重要性权重、在权重失衡时重采样，计算开销随候选数线性增长，无法一次训练永久受益。而普通的蒸馏又行不通，因为幂分布的“下一 token 概率”依赖于所有可能的后续续写，不是一次前向传播能算出来的，所以无法直接当教师信号。

OPPD 的关键洞察是：与其在推理时反复跑 SMC 采样器，不如让模型在训练阶段就学会直接生成幂分布下的答案。具体做法是：被训练的学生模型自己生成 N 个候选答案，一个冻结的教师模型定义幂分布 π_α，并用 SMC 采样器在生成过程中给每个候选打重要性权重。这个权重来自教师模型在温度 1/α 下的逐 token 概率，衡量的是“这个候选在幂分布下比在生成分布下更可能多少”。当有效样本数 ESS 低于阈值时，低权重候选被高权重候选替换，计算资源向高权重前缀集中。训练时，这些重要性权重同时被复用为每个完整答案的“训练权重”，学生通过加权最大似然在自己生成的答案上更新参数。这里有一个关键设计：学生生成 token 时的 proposal 分布不是原始学生分布，而是学生分布取 α 次方后的锐化版本——这是定理 1 给出的方差最优 proposal，能让重要性权重的方差最小化，避免因采样噪声导致某个候选独占全部权重。此外还有一个 token 级锚定项，用系数 λ 控制学生下一 token 分布不要偏离教师温度 1/α 分布太远，防止学生把所有概率塌缩到单一答案上。整个训练不需要参考答案、验证器或奖励模型，一次教师前向传播按 64 token 的块并行打分，把教师调用次数从答案长度 T 降到 T/64。

实验结果很有说服力：在 MATH500 上，OPPD 单次生成比未训练模型同温度下提升最高 23.0 个百分点，GSM8K 上提升 27.3 个百分点；单次生成已经超过已发表的 64 候选幂采样 2.4 和 3.5 个百分点，恢复了 16 候选给未训练模型带来增益的 94%。与使用验证奖励的 GRPO 从同一 checkpoint、同一预算训练相比，OPPD 在 MATH500、GSM8K、AIME 上分别高出 3.8、4.0、5.4 个百分点，而且完全不读参考答案；两者互补，GRPO 之后再跑 OPPD 还能再涨最多 9.3 个百分点。只在数学上训练，HumanEval 代码准确率也涨了最多 5.3 个百分点，说明学到的是一种通用的“锐化”能力。通过拟合学生与初始模型之间的 token 概率幂指数，作者发现 λ 可以把吸收的锐化指数从 1.19 调到 2.02，而普通 on-policy 蒸馏只有 1.14，且锐化主要发生在模型自己生成的答案上。局限方面，OPPD 仍然依赖一个冻结教师来定义幂分布，教师本身的质量上限决定了学生能学到的锐化方向；SMC 采样器在训练时仍有计算成本，只是从推理时转移到了训练时；论文只与一种 GRPO 实现、一个预算做了对比，没有全面对标强化学习文献。但它的意义在于指出了一条新路径：序列级锐化可以像知识蒸馏一样被“内化”进参数，而不必在每次推理时重新搜索，这为无需验证奖励的推理能力提升提供了可扩展的训练范式。

### [CLIFT: Conformal Self-Verification for Web Agent Training and Test-Time Scaling](https://arxiv.org/abs/2610.06829)
`评分3`

开放源代码的网页智能体已经能在真实浏览器界面上执行任务，但用强化学习继续提升它们时，验证器成了真正的瓶颈。二值化的任务成功信号虽然容易部署，却过于稀疏，无法支撑信用分配——当 GRPO 组内所有 rollout 拿到相同结果时，优势估计直接塌缩为零。前沿语言模型裁判能提供更丰富的反馈，但训练时调用成本高昂，部署时更无法假定其可用。这一矛盾在网页智能体基准上格外突出：WAI 用程序化的逐应用验证器，VWA 用基于结果 URL/DOM 的检查，而像 OM2W 这样的实时网页套件则依赖有噪声的 LLM 裁判。真正限制观测成功率的往往不是策略本身，而是我们给 rollout 打分和选择的方式。CLIFT 的核心追问是：能否把裁判的反馈转化成一个智能体可以随身携带、可复用的验证器，而不是外挂一个过程奖励模型或事后 best-of-N 打分器。

CLIFT 的做法是维护一个关于网页智能体行为的自然语言验证问题库，并认证哪些问题在哪些 URL 状态下是可靠的。每个验证问题带有 URL 作用域和极性符号，指示回答“是”代表进展还是失败。一个 Mondrian 自适应保形追踪器按全局、主机、URL 路径三个层级，分别估计该问题能否在相应 URL 粒度上区分高裁判分和低裁判分的 rollout。认证通过的问题获得带符号的信任权重，非一致性分数是极性感知的：正向问题在“是”与高裁判分一致时符合，负向问题在“是”与低裁判分一致时符合，中性问题不予认证。训练时，认证问题库的证据与比较式裁判融合，产生更稠密的逐步奖励和按 URL 分层的优势——关键在于验证器项被截断在零以上，因此认证证据只能加强裁判信号，绝不会拉低它，从而避免了早期线性混合导致的奖励塌缩。优势在每个“rollout 组、步位置、URL 状态”单元内做组归一化，再广播到工具调用跨度内的 token 上，跨度外的 token 梯度为零，GRPO 更新本身不变，但信用分配变成了 URL 局部的。问题库还会通过一个 CEGAR 风格的循环增长：定期提出能区分最好和最差 rollout 的新 URL 作用域问题，并用同一个 lift 估计做极性否决，把标错极性的问题降级为中性。测试时，外部裁判被丢弃，策略在小的预算 K 下生成一个贪心 incumbent 和若干多样化重试，冻结的问题库对每条轨迹的每个不同 URL 状态生成结构化证据记录，再以比较式提示交给自验证器输出保留贪心、切换或平局，并用奇数个独立投票的保守多数规则决定是否切换，平局和不确定时默认保留贪心，从而避免验证器方差造成有害切换。

在 WAI 上，CLIFT 训练的 Gemma-4 31B 加 LoRA 在 K=3 的 CTS 下取得了所比较的已发表系统中最高的九应用成功率，在九个应用中赢下七个，整体比同一 Gemma-4 浏览器使用基线提升 12.8 个百分点，且训练曲线显示认证问题库一旦开始贡献带符号的逐步证据，训练就与普通 GRPO 分离，说明增益并非仅来自评估时更大的 rollout 预算。在 VWA 上，用开放模型训练得到的 bank 直接作为 GPT-5.5 的测试时验证器，权重完全冻结，仅加入 CTS 就把加权平均提升到 53.7，略高于 WALT 的 52.9 参考，且在三个环境上都有增益，证明 bank 存储的是可迁移的网页交互知识而非仅仅改善了产出它的 Gemma-4 策略。在 OM2W 上，不做任何策略训练，只把 WAI/VWA 的问题库翻译并重新校准到实时网页领域，CTS 就能在零样本设置下提升实时网页智能体。局限也很明显：VWA 上人类行仍远高于所有智能体，说明任务本身远未解决；bank 的迁移依赖翻译和重新校准，跨领域时问题分类法的覆盖度仍是瓶颈；CTS 的保守多数规则虽然安全，但也意味着当验证器信号弱时它几乎不会切换，测试时扩展的收益因此受限。总体而言，这项工作把昂贵的裁判反馈转化为一种可复用的训练信号和无裁判的测试时扩展信号，为网页智能体提供了一条不依赖外部裁判、可跨模型和跨基准迁移的验证路径。

### [Learning Latent Protein Languages for Autoregressive Generation](https://arxiv.org/abs/2610.03978)
`评分4 · 47 pages. Project page: https://mahdip72.github.io/latent-pr · 有代码`

自回归 Transformer 已成为文本、图像、音频等离散模态的主流生成范式，但在蛋白质的序列与结构生成上却明显落后于非自回归方法。序列侧，ProtGPT2、ProGen 等自回归蛋白语言模型虽然也呈现幂律损失缩放，却比离散扩散模型 DPLM 更弱，采样时还容易漂移到低复杂度、重复且缺乏结构合理性的序列；结构侧差距更大，当前最强的从头骨架生成几乎被 RFdiffusion、Chroma、FoldFlow 等扩散与流匹配模型垄断，自回归结构生成基本缺席于最强基线之列。作者把这一现象归结为一个核心问题：为什么在别的领域所向披靡的"下一 token 预测"配方，到了蛋白质的两个模态上都失灵？他们的判断是，问题部分出在目标表示上——氨基酸 token 只编码残基身份，不携带上下文语义；而三维骨架坐标本身是连续的，无法直接作为离散 token 喂给自回归模型。既然视觉和音频领域已经证明"学习型 tokenizer + 离散隐 token + 自回归生成"可行，那么蛋白质是否也能先学出一套可解码的隐语言，再让标准自回归配方在上面工作？这正是论文要回答的问题。

论文的核心创新是构造了两种可学习的隐蛋白语言。序列侧的 PLL（Protein Latent Language）以冻结的 ESM-2 150M 编码器为语义骨干，把每个残基的上下文表示经一个 Transformer 隐编码器映射后，用 4096 个码本向量做最近邻量化，得到"一个残基一个 token"的离散序列，因此天然保持长度对齐；训练分两阶段：第一阶段按 VQ-VAE 思路只重建 ESM-2 的隐表示（而非氨基酸序列），第二阶段冻结隐编码器与码本、丢弃原解码器，重新训练一个带 21 类（20 种标准氨基酸加未知残基 X）分类头的 Transformer 解码器，从固定码序列恢复氨基酸。这样多个 PLL 码可以解码到同一氨基酸，词表在保持可解码性的同时能区分细粒度的上下文状态，而且生成时完全不需要 ESM-2。结构侧的 SLL（Structure Latent Language）基于 GCP-VQVAE Lite 这一几何完整的骨架向量量化自编码器，保留其 4096 码本与"码到骨架坐标"的解码接口，但在训练目标上加入三个辅助头：解码前预测氨基酸身份与 pLDDT 置信度，解码后对齐冻结的 ESM-2 表示，从而迫使离散码本身保留序列与置信度语义；最终配方由 StructTokenBench 上的监督表现来挑选，而不是只看重建保真度。两种语言固定后，作者用同一套 decoder-only 自回归 Transformer、同一套下一 token 交叉熵目标，分别预训练出 PLLM 与 SLLM，并额外把 SLLM 改造成序列到结构模型：输入序列由 Profluent-E1 600M 编码成连续上下文注入解码器，解码器自回归生成 SLL 码，再由固定解码器还原骨架；推理时还借鉴 DeepConf 的思路，对同一输入采样多条 SLL 码序列，用模型自身的 token 置信度配合 token 空间一致性做候选筛选，再解码成坐标。这套设计之所以可能更强，关键在于把"预测什么"从低语义密度的氨基酸符号或连续坐标，换成了高语义密度、且对因果建模友好的离散隐状态，从而让自回归配方真正有东西可学。

实验结果覆盖了缩放、无条件生成、结构生成与序列到结构预测四条线。在匹配的下游序列训练下，PLLM 的损失-算力拟合缩放指数为 0.038，而氨基酸自回归蛋白语言模型只有 0.020，斜率陡约 1.9 倍；SLLM 在结构 token 数据上的指数为 0.049。无条件生成时，在多个采样温度下，PLLM 把低于 1.5 bit 残基组成熵这一启发式阈值的样本比例相对氨基酸模型降低了 54%，并在中等温度下更好地匹配了 UniRef50 训练数据的序列长度与组成熵分布。结构侧，把原 GCP-VQVAE Lite tokenizer 换成 SLL 后，序列到结构预测在匹配训练下的最佳验证困惑度下降 34%；SLLM 在骨架生成的多样性与新颖性指标上与其它生成模型相比不落下风；用于长蛋白的序列到结构预测时，其隐 token 采样速度约为基于 MSA 的 AlphaFold2 的 1000 倍，并且已经出现用模型自身内部 token 置信度做推理时缩放、从而超过单次解码样本质量的早期迹象。局限也很明显：PLL 的对比是"整套目标表示"的对比，无法拆分 ESM-2 语义、向量量化、词表扩大与学习型 tokenizer 各自的贡献；SLL 只在单链单体上验证，且重建只评估到全局刚体变换；推理时缩放目前只是"早期迹象"，尚未形成稳定结论。尽管如此，这项工作把"学习隐蛋白语言"确立为一条值得语言建模方向探索的路线，为把自回归 Transformer 的缩放规律与推理时采样能力引入蛋白质生成提供了一个可落地的基座。

### [TempoBridge: Source-Conditioned Flow Matching with Optimal Transport Couplings for Single-Cell Population Transitions](https://arxiv.org/abs/2610.04945)
`评分3`

这篇论文要解决的是单细胞扰动预测中的一个根本性难题：由于测序过程会破坏细胞，我们无法追踪同一个细胞在不同条件下的状态变化，只能得到不同时间点或不同扰动下的非配对群体快照。现有方法如scGen、CPA在隐空间中建模扰动效应，CellOT学习非配对群体间的映射，CMonge和CellFlow则基于实验描述符来条件化传输，scDFM利用对照细胞表达，SCALE引入集合级对照表示。这些方法都确立了源细胞和实验条件的价值，但论文指出了一个被忽视的关键问题：当传输场只接收当前细胞状态、流时间和转移描述符作为输入时，它无法区分来自不同源群体的细胞在同一隐状态点上的不同响应。作者将这种现象命名为“源依赖的转移歧义”——在固定的耦合和路径构造下，两个源群体可能在相同隐状态、相同流时间、相同转移描述符处具有不同的条件平均速度，而仅依赖这些输入的确定性速度场会收到完全相同的输入，因而无法同时匹配两个不同的速度均值。这并非理论上的杞人忧天，而是实际训练中会遇到的逐点冲突，其根源在于初始化粒子时虽然赋予了源细胞的状态，却没有单独暴露该细胞所来自的群体信息。

TempoBridge的核心设计正是为了化解这一歧义。它采用一种共同的源条件化传输公式，统一处理时间、遗传和化学三种群体转移任务。具体来说，每个源细胞初始化一个隐粒子，而对该源群体所有细胞嵌入做均值池化，得到一个置换不变的源群体摘要，这个摘要在整个积分过程中保持固定，并被该群体的所有粒子共享。速度场因此接收四个分离的输入：当前演化中的粒子状态、流时间、源群体摘要以及结构化的转移描述符。训练时采用最优传输条件流匹配（OT-CFM），在每个源-目标群体记录内用Sinkhorn算法计算小批量最优传输耦合，以平方欧氏距离为代价，得到熵正则化的传输计划，然后从该计划的联合分布中采样端点对来构造训练路径，目标速度沿直线路径定义。关键洞察在于，最优传输耦合只用于构造训练路径，推理时完全不需要目标表达数据，也不需要计算最优传输。训练目标除了流匹配损失外，还包含对两个观测端点的重建项（用Huber损失平衡零和非零表达条目）以及任务特定的辅助项，比如分化任务中沿端点方向对预测群体均值排序的辅助损失，遗传和药物任务中约束群体均值响应和矩的辅助项。推理时，模型从源细胞隐状态出发，在固定的源摘要和转移描述符条件下积分神经ODE，时间任务中请求的天数决定积分时长（通过一个固定的平方根映射），遗传和药物任务积分时长为一，药物预测还对源隐状态加入独立高斯噪声并减去群体均值以增加多样性。这种设计使得速度场能够利用源群体摘要来区分不同源群体在同一状态点的不同速度，从而在理论上解决了源依赖的转移歧义。

在实验结果上，TempoBridge在多个留出评估场景中取得了显著提升。在Cuomo iPSC时间序列的留出供体上，预测中间群体时Energy距离为0.129，优于scGen的0.144；在遗传扰动预测的Seen 2/2基因组合上，平均表达L2误差为2.261，优于scGPT-scratch的3.156；在留出化合物上，条件平均药物效应相关性为0.598，优于CellFlow适配器的0.561。针对性的消融分析进一步分离了源上下文的作用：在受控歧义任务中，加入上下文将分支准确率从50.0%提升到98.0%；供体上下文交换实验表明拟合的时间模型确实使用了源摘要；匹配的时间重训练中，加入上下文将Energy从0.139降至0.135，MMD从0.397降至0.378，尽管效应指标偏好无上下文；随机配对将时间Energy从0.1291升至0.1446，静态残差变体达到0.1350但改变了训练目标。这些结果共同证明了源条件化传输公式在留出供体、基因组合和化合物上的预测效用。当然，论文也客观指出了一些局限：源上下文在分布度量上带来一致收益，但在效应度量上并非总是有利；药物条件化分析仅发现效应指标的小幅提升，没有一致的分布收益；时间、遗传和药物模型是独立训练的，尚未实现统一的多任务模型。这项工作的重要意义在于，它明确识别并形式化了一个此前被忽视的源依赖歧义问题，提出了一种简洁而有效的源条件化传输框架，并通过系统的消融实验区分了“使用源上下文”与“指标依赖的收益”，为单细胞群体转移预测提供了一个可推广的建模范式。

### [Tracing model-generated DNA with position-independent watermarking](https://arxiv.org/abs/2610.04763)
`评分3 · 16 pages`

基因组语言模型如今能生成编码序列、调控元件乃至全基因组规模的构造，但一段DNA本身并不携带任何来源信息——它究竟来自某个生物体、某次理性设计，还是模型的采样过程，一旦离开生成系统就无从分辨。已有的DNA水印方案要么依赖在序列中预留一段载荷区域并精心设计每个碱基改动（如DNA-Crypt利用同义密码子隐藏信息），要么假设验证者知道编码区边界或能拿到参考基因组做比对；而文本水印中常用的对齐或固定词表划分策略，在六碱基token的DNA场景下会彻底失效：只要插入或删除一个碱基，阅读框就发生移位，此后所有token的身份以及由上下文决定的标记位全部改变，没有任何token序列残留下来可供对齐。更麻烦的是，验证者拿到一段可能嵌在更长序列中的DNA时，既不知道生成区域的起止位置，也不知道它位于正链还是负链，更不知道token的相位（即六个可能的分割偏移中的哪一个），因此验证本质上变成了一个在链方向、相位、起始位置和窗口长度上的联合搜索问题，而搜索本身会大幅抬高假阳性概率，必须加以校正。

作者的做法是把SynthID的锦标赛水印嵌入到Carbon-500M和GENERator-v2两个基因组语言模型中，而不改动其构造。生成时每一步用密钥、前四个token的上下文和候选token通过HMAC-SHA-256计算出一个二进制标记位，30层锦标赛各自独立地给标记位为1的候选加权，使得在密钥函数随机化的期望下输出分布保持不变，但在固定密钥和上下文下采样自一个被刻意重加权的分布。检测端只拿到DNA序列、密钥和公开的检测参数，它把序列及其反向互补链上每一个起始碱基、四种窗口长度所界定的所有片段都当作候选窗口，在每个窗口内从首碱基开始重新切分token，用前四个token建立上下文，之后每个非重复上下文的token都重建其标记位并统计1的个数，用二项尾概率给出该窗口的P值，再对整个搜索空间做Bonferroni校正——对一条3456碱基的序列要评分数万个窗口，最终只有当某个窗口的强度超过预设阈值时才判定为阳性。这一设计的关键洞察在于：标记位只依赖局部上下文而非绝对位置，因此只要窗口中保留足够多未失相、未失上下文的token，即使部分token因编辑而变成无偏的随机位，也仅仅是稀释信号而不会破坏检测；插入或删除后，验证者选中的窗口恰好对应那些token相位得以保持或恢复的区域。检测不需要模型、提示词、生成日志、链方向、相位或边界信息，唯一保密的是密钥。

在1544条留出提示词的检测队列上，验证者对两个模型各3088条标记序列全部检出，包括经过一个碱基替换、插入或删除之后的序列；对普通序列，假阳性率的单侧95%置信上界不超过0.850%，错误密钥对照最高也只到1.015%，均在预设的1%目标之内。在开发队列上，标记采样没有引起似然或十四项预设序列统计量的可检测变化，说明水印在期望意义上不损害生成质量。随机编辑实验（编辑位置完全不参考检测器）显示，直到每位点2%的编辑率，检测仍保持完全或接近完全。作者也明确划定了边界：这证明的是统计可检测性，而非生物功能、密钥安全性或对知情编辑者的鲁棒性——一个能看到检测器并针对性规避的攻击者不在本研究的测试范围内。这项工作的意义在于，它首次把分布保持型水印成功移植到六碱基token化的基因组语言模型上，并系统解决了相位未知、链未知、边界未知带来的搜索与多重检验校正问题，为合成DNA的来源追溯提供了一条不依赖数据库、不依赖模型、仅凭序列本身即可验证的技术路径，同时也把“编辑鲁棒性”和“对抗鲁棒性”之间的鸿沟清晰地留作了后续研究的课题。

### [APOD: reasoning-guided agentic population ordinary differential equation discovery for pharmacological digital twins](https://arxiv.org/abs/2610.06227)
`评分3`

构建能够描述群体数据的常微分方程（ODE）模型是药理学数学建模的核心环节，也是开发"数字孪生"的基础。然而，从稀疏、含噪的临床数据中推导出这样的方程，传统上是一项缓慢且高度依赖专家经验的工作。现有的自动化方法面临两条路径的局限：一类基于符号回归或稀疏回归的科学机器学习方法，虽然能自动发现方程，但每次只处理单个受试者的数据，而生物医学数据往往是多个受试者共享同一机制、每人却只有少量稀疏观测；另一类基于预定义模型库的搜索工具（如pyDarwin、mlxModelFinder），虽然引入了群体建模框架（非线性混合效应模型，NLME），但只能在预先设定的药代动力学构件库内组合，无法提出库外的新机制，且单次搜索耗时从数小时到数天不等。此外，这些方法通常只优化一个数值拟合指标（如BICc），无法判断模型在生物学上是否合理。简言之，此前没有任何方法能同时满足群体数字孪生的两个核心需求：开放的结构搜索空间，以及从稀疏数据中进行群体层面的推断。

APOD的核心创新在于用语言模型智能体替代传统的数值优化搜索，并将群体推断能力嵌入发现流程。具体运作方式是这样的：智能体接收一段极简的任务描述（例如"构建一个静脉输注后化疗药物浓度随时间变化的模型"，不含药物名称、房室假设或消除机制等任何结构先验），然后迭代地提出候选ODE模型。每一轮迭代中，它将参数估计委托给本地专门的群体药代动力学软件，再基于多维度诊断信息进行推理——不只看拟合优度指标和聚合残差，还评估参数的可辨识性（identifiability，即参数能否被数据唯一确定）、结构合理性（方程是否符合生物学常识）以及参数合理性。这种推理引导的搜索策略是关键：消融实验表明，如果去掉推理层、仅凭BICc选择模型，结构恢复率从96%降到88%，随机效应集的正确恢复率从70%降到59%，运行时间反而增加两到三倍。值得注意的是，智能体在第一次迭代就提出正确结构的比例只有67%，但后续迭代在49次首轮错误中有44次成功纠正，说明推理层真正在起"自我纠错"的作用。此外，由于搜索空间是开放的，APOD能够自由决定潜变量的数量——例如在临床药代数据中，它仅从一个可观测浓度出发，自主提出了包含两个潜变量的三房室模型；在血小板动力学中，它从一个可观测的血小板计数出发，构建了包含7个ODE的Friberg半机制骨髓抑制模型，其中引入了由给药剂量驱动的药物量代理变量作为可操作输入。整个流程无需在提示中编码领域知识，提示设计刻意偏向结构推理而非从训练记忆中检索已发表的模型。

在结果层面，APOD在合成药代动力学基准上10个数据集的结构恢复率为94%，与mlxModelFinder的98%相当，但中位运行速度快24倍，每次搜索的语言模型调用成本仅0.25美元；在合成肿瘤动力学基准上，APOD恢复率达100%，而mlxModelFinder仅80%（后者在全部5个种子上都未能发现广义logistic结构）。跨七个不同语言模型的测试显示，Claude Opus 4.5达到96%的恢复率，三个通过API访问的模型在67%到89%之间，三个本地小模型仅16%到40%，说明推理能力对任务成败至关重要。在真实数据上，APOD从无结构先验的提示出发，在临床药代队列中重现了与已发表分析一致的三房室模型，在肿瘤生长数据中发现了超出常规库的hyper-Gompertz增长律（指数γ=0.60），在化疗联合肿瘤动力学数据中提出了带效应室和浓度阈值杀伤项的logistic生长模型。最具临床意义的验证来自放射配体治疗中的血小板毒性预测：APOD发现的群体数字孪生仅用第一个治疗周期的中位三次测量值进行贝叶斯个体化，就能预测后续周期的血小板最低值，19名独立验证患者中90%预测区间全部覆盖观测最低值，预测值与观测值的一致性相关系数达0.91，而仅用群体模型不做个体化时R²仅为0.06。该模型还能模拟未实际执行的给药方案——将第二个周期的注射活度减半，预测的1级血小板减少症概率从0.94降至0.59，而跳过整个周期仅降至0.93，这为临床剂量调整提供了机制性的决策依据。局限方面，APOD目前尚未解决高维系统的可扩展性问题，也未在部分可观测条件下进行系统性评估；此外，其发现质量仍受底层语言模型推理能力的制约，本地小模型的表现远不足以投入实际使用。尽管如此，这项工作首次证明了推理引导的语言模型智能体可以在开放搜索空间中同时发现ODE结构和群体变异结构，为药理学数字孪生的自动化构建开辟了一条兼顾机制可解释性与群体推断能力的新路径。

### [H-JEPA: End-to-End Learning of Hierarchical World Models for Visual Planning](https://arxiv.org/abs/2610.06805)
`评分3`

这篇论文要解决的核心问题是长时程视觉规划中潜在世界模型的效率与抽象层次不匹配。现有的任务无关JEPA世界模型（如LeWM）在单一潜在空间、单一时间尺度上进行预测和规划，这带来两个致命瓶颈：其一，长时程任务需要展开大量细粒度步骤，预测误差逐步累积，同时动作搜索空间随步数指数增长；其二，单一共享潜在空间必须同时服务低层动力学建模和高层目标匹配，但一个携带所有快速变化细节的潜在表示虽然能精确建模低层动力学，却在目标比状态更抽象时（比如目标是“到达某个位置”而非“匹配某个姿态”）给出极差的目标匹配代价。HWM虽然尝试了时间上的分层，但其不同时间跨度的预测器仍然共享同一个潜在空间，因此只分解了时间跨度，无法在更抽象的层次上匹配目标。论文的动机来自神经科学的观察：大脑皮层形成内在时间尺度的层级，慢变表示位于更高层，这暗示世界模型也应当在不同抽象层次上拥有各自的潜在空间。

H-JEPA的核心设计是端到端训练一个动作条件JEPA的层级结构，每一层在自身学到的潜在空间中以更粗的时间步长和更高的抽象程度预测未来。具体来说，第一层用ViT-Tiny编码器将图像映射为潜在状态，用因果Transformer预测器做一步预测；更高层则通过组合方式构建：状态编码器和动作编码器都对下一层的潜在状态做时间窗口池化。每层有两个关键超参数——步长s决定上层时间t对应下层时间t乘以s，窗口大小w决定每个上层状态汇总多少个下层步骤，实验中统一用w等于1，因此上层状态编码器是逐点的。每层独立训练为JEPA，用教师强制的潜在预测损失加上SIGReg正则化防止表示坍缩。规划时采用自顶向下的方式：顶层优化宏动作以最小化其最终预测状态与目标潜在状态的距离，然后顶层的优化轨迹作为下一层的子目标，下一层再优化自己的动作序列去匹配这些子目标（通过上层的编码器将下层预测映射到上层潜在空间），逐层细化直到第一层输出原始动作。这种设计之所以优于之前的方法，关键在于两个互补机制：一是时间分解把长时程搜索拆成多个短时程子问题，降低了每层的搜索空间和误差累积；二是层级潜在空间让高层规划器能在目标自身的抽象层次上评估进度，比如在迷宫中，第一层的潜在距离在远离目标时几乎恒定，无法为梯度规划器提供有效信号，而高层潜在空间中的距离则沿走廊平滑上升，为远距离目标提供了有信息量的代价地形。

在四个模拟导航和操作环境（FourRoomDistractors、Visual AntMaze、Push-T、OGBench Cube）上，H-JEPA相比平坦的LeWM基线在相同或更少的规划计算量下取得了更高成功率，其中Visual AntMaze上三层H-JEPA将成功率从18%提升到73%，且规划器计算量更少。与HWM的对比表明，在AntMaze上三层H-JEPA的成功率接近HWM的两倍，说明层级表示本身（而不仅是时间分解）带来了额外收益。消融实验进一步将增益归因于时间分解和高层目标表示两个因素。在真实机器人数据集DROID上，加入逆动力学监督后，层级结构在更低规划计算量下提升了离线规划保真度。局限方面，Push-T上三层模型表现不佳，原因是该环境回合过短，三层模型每轮只能看到LeWM训练转移的58%，数据不足；此外，选择性抽象并非在所有环境中都能涌现，操作数据集因实体频率差距较小而几乎没有表现出高层丢弃快速变化细节的现象。这项工作的意义在于，它首次展示了端到端训练层级JEPA世界模型的可行性，证明了让每一层拥有自己的潜在空间——而不仅仅是自己的时间尺度——对于长时程视觉规划至关重要，为未来在更复杂、更多样化的真实环境中构建可扩展的层级世界模型提供了清晰的算法路径。

### [MC-Sparse: Deconstructing and Closing the Dense-Sparse Attention Gap in Diffusion Transformers](https://arxiv.org/abs/2610.06801)
`评分3 · 11 pages, 8 figures`

扩散 Transformer 在视频和 3D 资产生成这类长序列任务中，注意力开销随 token 数呈二次增长，成为推理延迟的主要瓶颈。稀疏注意力是自然的解法，因为注意力往往集中在少数 token 交互上。但现有方法大多在块粒度上施加稀疏性：块稀疏注意力（BSA）为每组查询选择整块 KV，这虽然契合 GPU 的 tile 计算，却把两种误差纠缠在一起——一是用池化后的查询和键估计块重要性带来的近似打分误差，二是块结构本身限制了哪些交互能被选中。作者通过受控的 oracle 对比在相同注意力密度下把质量差距拆成三个来源：结构绑定误差（KV 被绑在块里、同组查询被迫共享同一选择）、选择误差（用均值池化等近似打分导致选错）、以及丢弃尾部误差（被丢弃的 token 仍携带非零注意力质量）。这三者分别对应三条设计原则：更细粒度的选择、更准确的注意力打分、以及对被丢弃贡献的补偿。

MC-Sparse 的核心思路是：在 token 级别选 KV，同时把相似查询组织成与 GPU tile 对齐的等大分组，并利用去噪步之间的时间冗余来摊销精确选择的成本。具体来说，它把去噪过程分成 anchor 步和 reuse 步。在 anchor 步，先用快速主方向分裂划分（Fast PDDP）把每个 head 内的查询递归地按主方向中位数切分，直到每组恰好 C 个查询，C 与 kernel 的查询 tile 大小匹配，这样既提升组内相似度又保证 tile 对齐、不浪费计算；然后做两遍精确选择（two-pass exact selection），因为 FlashAttention 不暴露 attention logits，第一遍算出精确注意力概率并按组累加每个 KV token 的注意力质量，第二遍选出 top-K 的 KV 索引，这比均值池化打分更准，能避免漏掉累积质量高的 token。同时记录稠密注意力输出与稀疏注意力输出之间的残差。在后续 reuse 步，查询、键、值都用当前步重新计算，但查询分组、选中的 KV 索引和残差直接复用缓存，注意力只在选中的 token 上计算，由 CuTeDSL 实现的 token-sparse kernel 在线 gather，不重新打包成块。这样既摊销了分组和精确选择的成本，又用缓存的残差补偿了被丢弃的尾部贡献——作者发现稠密与稀疏输出的残差在相邻去噪步之间变化很小，且精确选择比均值池化选择让残差更稳定。相比之前的方法，它同时去掉了 KV 绑定和查询绑定，用精确概率替代近似打分，并用时间残差补上了块方法靠块均值才能做的补偿，因此在同等密度下更接近稠密注意力。

在 Minimax-H3-Base 上，15% 注意力密度下 MC-Sparse 相对稠密注意力取得 1.80 倍去噪加速，且保真度高于对比的稀疏基线；在 HY3D-Internal 的 3D 资产生成上同密度下达到 2.32 倍加速，质量损失可忽略。实验覆盖 Minimax-H3-Base、HunyuanVideo-13B、Wan2.1-14B 等视频模型以及 3D 生成模型，对比对象包括 FA3 稠密注意力、SVG2、SVG-EAR、Sol-Attn、PISA、SpargeAttn 等，用 PSNR、SSIM、LPIPS 衡量对稠密输出的保真度。局限方面，方法依赖去噪步间注意力模式和残差的稳定性，anchor 步仍需跑稠密注意力并额外做一次稀疏评估来形成残差，缓存元数据在显存不足时需要卸载到 CPU 并预取，带来额外工程复杂度；此外它目前是免训练框架，未探索与可训练索引器的结合。总体而言，这篇工作把稀疏注意力的质量差距从“黑盒退化”拆解为可量化的三个误差源，并给出了一套在 token 级选择、tile 对齐分组和跨步复用上同时发力的工程方案，为长序列扩散 Transformer 的推理加速提供了一个兼顾保真度与速度的参考路径。
