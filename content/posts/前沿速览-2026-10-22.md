## 大模型 LLM

### [Socratic Skill Learning: Interleaving Teaching and Practice for Transferable Agent Skills](https://arxiv.org/abs/2610.17860)
`评分3 · HF 30赞`

这篇论文要解决的是LLM智能体技能学习中一个被忽视但关键的问题：如何让智能体从一次成功任务中提炼出可迁移的技能，而不是只记住这次任务的具体做法。现有方法大致分两类，一类是把执行轨迹蒸馏成技能包（如Trace2Skill），另一类是在失败后由教师给出反馈来指导修订（如SkillLearnBench的Teacher Feedback、SKILL-KD的对比蒸馏）。它们的共同缺陷在于：技能的形成依赖于“事后”证据——要么只看到成功轨迹，要么只在失败发生后才介入。但一个成功的任务尝试往往留下大量未经检验的假设：智能体可能碰巧用对了某个步骤，却不知道这个步骤在什么条件下成立、什么时候需要调整。事后蒸馏无法区分“这次管用的操作”和“这类任务普遍管用的操作”，而失败后的反馈又来得太晚，那些未被检验的假设早已被写进技能包、固化成可复用的规则。论文的核心追问因此是：外部专家知识应该在学习者仍在收集证据的过程中介入，而不是等证据收集完再评判。

SSL的核心设计是把“专家教学”和“学生实践”交错进行，但严格保持学生是唯一的环境操作者和技能作者。具体来说，系统里有一个Educator和一个Student：Educator对学生的近期工作记录和当前技能包只有只读权限，它可以解释、质疑、诊断、建议检查点，或者选择沉默；Student则负责实际探索环境、测试候选流程、决定收集什么证据、以及最终撰写技能包（SKILL.md加可选脚本和资源）。关键洞察在于，学生始终保有“质疑、测试、采纳或拒绝建议”的主动权——教育者的建议不是直接写进技能包的补丁，而是变成学生要去验证的假设。每一轮结束后，用一个全新的求解器会话在重置的锚点任务上测试当前技能包，检验它是否能脱离作者本人的会话上下文而独立生效，这个“新鲜求解器”的反馈再进入下一轮。论文给出两个实例化：Fixed-Window SSL每隔固定数量的工具调用就触发一次教育者审阅，节奏固定但指导内容随学生进展而变；Issue-Guided SSL则维护一棵持久化的“学习问题树”，每个教育者课程附带一个学习焦点和可观测的验收标准，问题可以打开、关闭、重新打开，已解决的枝干保留记录，只有当未解决问题出现、变化或重新打开时才触发审阅，从而把专家 token 花在真正未决的问题上。这套机制之所以优于事后蒸馏和事后教学，是因为它让建议在调查尚未闭合时到达，学生可以立刻用环境实验去检验建议、用检验结果去改写技能包，而那些被检验过的证据才真正进入可迁移的规则。

在SkillTransferBench上——35个任务族、408个可执行案例、覆盖六个领域，每个族有一个公开的变体规格说明哪些是不变量、哪些允许变化，锚点任务用于学习，留出的族内案例在全新会话中测试冻结的技能包——主队列22族155例上，Fixed-Window SSL达到0.801的效用，无技能基线是0.723，适配后的Trace2Skill是0.761，适配后的SKILL-KD是0.751，提升幅度约4到5个百分点，且配对bootstrap置信区间不跨零；完整通过率从32.50%提升到49.49%（Fixed-Window）和50.82%（Issue-Guided）。在三个模型对上，交错式指导一致优于专家直接撰写和事后教学，说明“学生 authorship 加过程中指导”的组合才是关键，而不是单纯保留学生作者身份。Issue-Guided SSL在主队列上达到0.805效用，同时教育者token减少61.7%、总获取token减少16.9%，说明按未决问题选择性审阅可以在不牺牲迁移效果的前提下大幅降低监督成本。局限方面，论文的评估集中在有明确变体规格的任务族上，规格本身由人工构建，向更开放、规格难以形式化的领域推广尚未验证；三个模型对的规模也有限，且Issue-Guided的收益依赖于学习问题能被清晰表述和追踪，在问题边界模糊的任务上可能退化。但这项工作把技能学习的关注点从“如何更好地蒸馏轨迹”转向“如何在证据收集过程中组织专家介入”，并用可执行的迁移基准把这一区分量化出来，对智能体技能获取这一方向的方法设计有直接的参照意义。

### [Environment Duels: A Microcosm of LLM Co-Evolution](https://arxiv.org/abs/2610.30116)
`评分3 · 有代码`

这篇论文要解决的是一个在当下模型训练生态中越来越真实、却缺乏受控测量手段的问题：前沿大模型之间实际上已经形成了某种“互为师生”的关系——一个模型生成的合成任务、环境或数据会被下一个模型拿去训练，而这些合成数据又通过公开仓库和基准在实验室之间流动，于是每个模型的训练分布都被其他模型“选择写什么”所塑造。当实验室有意闭环、让自己的模型为下一代写课程时，这就成了工程意义上的递归自我改进。问题在于，这种生态里最关键的能力不是解题而是“出题”：随着模型在既有基准上逼近或超过人类水平，人工策划足够难的题目成本越来越高，连千禧年猜想这类开放问题都被拿来当训练素材，说明可用的“未解难题存量”也是有限的，瓶颈会转移到“能否提出值得解决的新问题、并把难度校准到能推动当前方法边界”上。之前的方法卡在两点：静态基准一旦被掌握就饱和，无法随模型变强而自动变难；而单纯看解题分数又完全测不出“写题”和“写提示”这两种塑造下一代学习内容的能力，因此需要一个动态的、由被测模型自己出题的 agentic 基准来把这种共演化关系放到受控条件下观察。

方法上的核心设计是让每个被测模型同时扮演作者和解题者，构成一个“对决”微宇宙。作者在五个固定领域（符号推理、规划与优化、因果诊断、对抗策略、动态控制）之一内写一个可执行环境——它是一个带隐藏状态、文本观测、动作空间、奖励和 24 步动作预算的 Python 类，只暴露 reset(seed) 和 step(action)，必须确定性可复现；同时作者要给出一条“特权提示”，目标是让有能力的解题者在没有提示时失败、有提示时通过。构造分四阶段：先做规划，产出设计规格、给解题者的确切提示以及一份私有的可行性分析（含带提示的策略与回合/资源核算，且对解题者完全不可见），把设计难度和实现难度分离；再实现，第二个调用只负责把锁定的计划翻译成正确代码，且环境观测不得泄露提示；然后做程序化沙箱执行检查（无文件系统/网络、固定时空限制、两个种子加探针动作验证观测奖励终止格式）和作者在新会话中对匿名化环境-提示对的自审（可达性、指令一致性、信息充分性、提示正确性），失败则回到规划并最多两次修复；最后对决运行后还对“所有模型在任一提示条件下都无人成功”的环境-种子实例做白盒 LLM 审计加人工复核，双重判定无效才剔除。对决本身是每个模型在相同种子上、分别在无提示和有提示两种条件下玩每个环境（包括自己写的），两种条件只差提示是否在上下文中，因此每个种子给出配对结果，进而得到两张环境×解题者的成功矩阵；评分分三轴：解题率、难度（无提示下的失败程度）、提示提升（hint lift，按配对拆成“提示修好的局”减“提示弄坏的局”，所以提示什么都不改或修好和弄坏一样多都得零分），另外单独报告解题者“被救回”和“被弄坏”的概率。最关键的共演化机制是“反制一步”：作者最初是盲写，等所有对局返回后，它能看到匿名化的结果统计以及三对匹配轨迹（同一解题者同一种子在有/无提示下的完整尝试），从而发现解题者找到的捷径、被忽略或误读的提示，然后只能改环境或提示、但必须保持任务、接口、奖励契约、动作预算和种子到实例的映射不变，改完再走一遍构造流程并被所有模型重玩，最终分数用这一版。仅这一轮反制就把无提示通过率从 84.9% 降到 78.5%、提示提升从 6.3% 升到 13.4%，说明作者能把别人的反馈转化为更难、校准更好的环境——这正是它比静态基准强的地方：天花板由最强作者决定，加一个新模型就加一批更难的环境，成本只是 token 而非人工标注。

结果上，九个前沿模型各写十个环境（每领域两个）共 90 个环境，每个解题者在四个种子上分有无提示各玩一遍、反制前后各一轮，共 12960 局。第一个发现是出题能力和解题能力是两种不同的技能：解题排名与公开能力指数基本一致（Claude-Opus-5 和 GPT-5.6-Sol 领先），但难度和提示提升这两条作者轴上，前三名是 DeepSeek-V4.1-Flash、Gemini-3.8-Flash 和 Qwen3.8-27B 这三个紧凑模型（解题排名分别第三、第七、第四），而两个最强解题者难度不高于第四、提示提升只排第七；Claude-Opus-5 至少失败一次的那十个环境里有九个出自这三个模型，作者能力可能更依赖后训练而非规模——DeepSeek 官方就称其后期收益来自让 agent 合成任务、构造环境并校准难度的自动化流水线，等于说它被训练的就是这个对决所测的能力。第二个发现是强模型写的提示是给“像自己一样的学生”写的：Qwen3.8-27B 这个中游解题者写出最有用的提示（修好近四分之一的对局、几乎不弄坏），而三个最强解题者的提示把正确尝试弄坏的数量约为其他作者的三倍；这种弄坏是错配而非错误——顶级提示把底层解题者 17.7% 的正确尝试弄坏，其他提示至多 7.7%，但没有哪一层的提示能弄坏顶级解题者超过 3.1%；弱作者会点明陷阱和走法，最强作者只陈述机制、把推导留给解题者，弱解题者拿到这种提示会过早行动、中位 13 步就失败，而没提示时他们靠慢慢探索 20 步能成功。第三个发现是最强解题者对反馈响应最少：反制一轮后多数环境变难，但 GPT-5.6-Sol 几乎不改，Claude-Opus-5 的改动低于平均，而 Qwen3.8-27B 和 GLM-5.3 把通过率分别压低 13.1 和 10.8 个百分点；一种解读是强模型信任自己的原始设计，且它们收到的反馈只来自更弱的解题者、可学的东西也少。更有意义的是，论文还用 Qwen3.8-27B 做了强化学习实验，发现学习者在某作者环境上的提示提升，能预测用这些环境训练后它在留出推理与 agentic 基准上的提升幅度，无论环境是自己写的还是别人写的——这把对决内部的信号和外部的训练收益连了起来。局限也很清楚：只有九个模型、九十个环境、一轮反制，样本规模有限；提示提升的配对度量对“修好等于弄坏”的情形会给零分，掩盖了提示的异质作用；最强模型反馈少究竟是因为自信还是因为反馈源太弱，论文自己也没有定论；白盒审计和人工复核虽能剔除无效实例，但作者自审和 LLM 审计本身仍可能带偏。尽管如此，它的意义在于把“模型如何教、挑战并互相学习”这件事放进了可控实验台：头对头结果具有传递性因而能给出稳定排名，独立作者会收敛到相似设计，提示提升能预测训练收益，这些模式在真实生态里都有对应物，而环境由被测模型自己写、随最强作者水涨船高，使它成为一个能自我刷新的基准和 RL 环境来源。

### [Looped Uniform Diffusion Language Models](https://arxiv.org/abs/2610.30066)
`评分3 · 27 pages`

这篇论文要解决的是均匀扩散语言模型（UDLM）训练成本过高的问题。UDLM 的加噪方式是把序列中的部分 token 随机替换成词表里的普通 token，而不是像掩码扩散模型（MDLM）那样替换成专门的 mask 符号。这个区别看似细微，却从根本上改变了去噪任务的难度：MDLM 的去噪器始终能明确知道哪些位置被破坏了，只需在干净上下文上做预测；而 UDLM 的输入里每个位置都是普通 token，没有任何标记提示哪个被替换过。去噪器必须同时完成两件事——判断当前 token 是保留的还是被替换的，以及在认定被替换时预测出原始 token。更麻烦的是，这两个判断彼此耦合：一个 token 与上下文不协调，既可能是它自己被换了，也可能是它的邻居被换了，模型得从整条序列的相互一致性中反推。论文给出了一个精确的贝叶斯分解来刻画这一点：干净 token 的后验实际上是"观测 token 上的点质量"与"上下文预测分布"的混合，混合权重就是该位置的保留概率，而这个保留概率在 UDLM 中无法从输入直接读出，只能靠 token 与上下文的契合程度来推断。正是这种"上下文本身不可靠"的训练目标，使得 UDLM 比 MDLM 更耗 FLOP，但换来了更强的下游推理表现。此前 Lee 等人已在 MDLM 上证明，在每个去噪步内选择性地循环复用少量早期 Transformer 层，可以在等 FLOP 预算下提升训练效率；但 MDLM 中未解析的位置是显式可见的，循环是否对"连哪些位置坏了都不知道"的 UDLM 同样有效，此前是开放问题。

论文的做法是在完全不改动训练目标和采样器的前提下，把循环机制嵌入 UDLM 的去噪器。具体来说，Duo++ 的去噪器是一个时间条件化的 DiT，作者将其切成三段：头部若干块、中间一段被反复复用的块、以及带输出投影的尾部。输入只嵌入一次，穿过头部后进入中间切片循环 S 次，再经尾部输出干净 token 的预测；中间切片每次复用同一组权重，因此循环只增加计算深度、不增加参数量，S=1 即退化为原始网络。训练时每个优化器步随机采样一个循环次数 S，把中间切片展开 S 次并让梯度穿过所有迭代回传，从而得到一个能在推理时用不同循环次数运行的单模型。关键设计在于循环次数的分布 p(S)：除了沿用 LoopMDM 的均匀采样（S_max=12），论文提出两种新分布。其一是 FLOP 比例采样，让每个循环次数的采样概率反比于它的计算代价，使各循环次数分摊到的训练 FLOP 大致相等——由于单步代价随 S 线性增长，均匀采样会把大部分算力堆到大循环次数上，而推理收益在中等循环次数就已饱和，FLOP 比例采样则把期望代价从算术平均压到调和平均，在不引入额外超参的情况下省下算力。其二是噪声比例采样，用对偶时间采样把微批次按噪声水平排序分成若干带，噪声越大的带分配越大的循环次数，以检验"越脏的输入越需要多迭代精炼"这一假设，同时保持循环次数的边缘分布仍为均匀，从而与均匀采样在期望 FLOP 上可比、只隔离噪声与循环次数的耦合效应。推理阶段则考虑固定循环（每个去噪步用相同次数）和自适应循环（当相邻两次迭代隐状态相对变化低于阈值即提前停止）。论文还从机制上解释了循环为何有效：Duo++ 去噪器的输出经贝叶斯公式可转成估计的保留概率，而额外循环只改变上下文预测这一项，因此增益应主要来自对被替换位置的干净 token 预测的改善，而非对"哪些 token 该保留"的判断——后续实验证实了这一点。

在 170M 参数的 Duo++ small DiT 上，于 OpenWebText 和 FineWeb-Edu 两个数据集训练后，循环 UDLM 达到非循环基线约 0.5 万亿 token 训练的验证 NLL 时，分别节省最多 2.8 倍和 3.3 倍的训练 FLOP。推理端在相同去噪步数下，循环模型取得最多低 9.8% 的生成困惑度，大部分收益在中等循环次数即已获得；在七个域外数据集上，推理时循环平均降低 11.5% 的零样本困惑度。机制分析确认额外循环主要精炼被替换位置的预测，且在中等噪声水平增益最大。自适应循环在十个零样本多选题上匹配固定 12 次循环的准确率，同时分别少跑 26.0%（均匀采样）和 34.8%（FLOP 比例采样）的循环次数；而训练时更频繁采样小循环次数的策略，在下游任务上比均匀循环采样少用 12% 的循环而不掉精度。局限方面，实验规模限于 170M 参数和两个中等规模语料，循环切片的位置与 S_max 的选择虽给了消融但仍是人工设定，更大模型和更长序列上循环收益是否保持、以及与 MDLM 循环方案的直接对比都未展开；此外噪声比例采样只验证了耦合假设本身，并未带来独立的效率增益。尽管如此，这项工作把"循环提效"从有显式破坏标记的 MDLM 推广到了标记不可见的 UDLM，说明在上下文不可靠的场景下，用无参数的深度复用替代参数扩张是一条可行的算力节省路径，也为 UDLM 这类在推理任务上表现更强但训练昂贵的模型降低了扩展门槛。

### [Loopholing All the Way: Language Modeling with pure Self-Conditioning](https://arxiv.org/abs/2610.30068)
`评分3 · 有代码`

这篇论文要解决的核心问题是：扩散语言模型在生成质量上始终追不上自回归模型，而作者认为瓶颈出在采样过程中信息被反复丢弃。具体来说，离散扩散模型（如MDLM、Duo）为了计算可行，每一步都对每个位置独立采样，然后把去噪器预测的分布整个扔掉，只保留采样出的离散token进入下一步——这带来两个后果：一是并行独立采样在少步生成时质量很差，二是预测中蕴含的不确定性信息被彻底丢弃（作者称为information collapse）。连续扩散模型试图用ODE/SDE积分绕开因子化采样，但在推理任务上最多只能追平离散扩散，比如FLM和S-FLM在Sudoku、Maze上跟MDLM、Duo差不多，S-FLM只有在贪心生成时才能匹配MDLM的GSM8K成绩。与此同时，Self-Conditioning（自条件化，也叫Loopholing）作为一种把上一步预测或隐表示回灌给去噪器的技巧，在LDDM等工作里已经展现出很强的实证效果——比如LDDM-U在困难Sudoku上解出91.0%，远超Duo的58.4%——但它始终只是作为辅助启发式存在。于是作者提出一个尖锐的问题：能不能构造一个完全建立在Self-Conditioning之上的生成模型？

LAW的关键洞察是：既然SC状态可以跨步携带连续信息，那就干脆不让离散token参与步间传递，整个采样轨迹只传播SC状态，最后一步才解码成token。具体做法是：初始化时从均匀先验采样token并嵌入，得到初始状态；之后每一步把当前SC状态单独送入去噪骨干（不再拼接token嵌入），得到隐表示后，用去噪器预测的logits在词表上做softmax，再对嵌入矩阵加权求和，得到“期望嵌入”（Expected Embedding），作为下一步的SC状态。这个设计的关键在于：SC状态现在是去噪器的唯一输入，所以它必须长得像去噪器训练时见过的token嵌入，而期望嵌入正好是token嵌入的凸组合，天然满足这个要求。作者通过消融实验指出，这个选择是纯SC能work的核心——用期望嵌入在GSM8K上能到35.8%，而用LDDM那种LayerNorm后的末层隐表示则不到1.5%。第二个关键设计是温度正则化：采样时温度T≠1会让logits变尖或变平，从而让SC状态偏离训练分布；为了不让模型在这种状态下崩溃，训练时随机抽一个温度τ去扰动SC状态（但损失仍用未扰动的预测算），并且让τ的分布关于1对称（用因子ρ≥1控制两侧范围），否则LM head可以通过缩放权重把温度吸收掉，正则化就失效了。训练上沿用LDDM的多趟策略：以概率p=0.9展开M=2次前向，第一次吃token嵌入、后续吃SC状态，只对最后一趟反传，损失用NELBO或交叉熵；这样避免了沿整条轨迹反传的高昂成本，同时让模型见到自己产生的SC状态，缓解训练-测试不匹配。整个架构就是标准UDM的DiT，可以从头训也可以从预训练Duo微调，OpenWebText上还加了一个可学习的mode embedding来区分输入是噪声token嵌入还是SC状态。

实验结果覆盖四个任务。Sudoku上，LAW在180 NFE下三种难度都最准，困难难度解出96.5%，超过LDDM-U的91.0%；Maze上，LAW在2到64 NFE区间内是最准的模型，仅4 NFE就解出90.9%，而LDDM-U在89%以下就饱和、连续基线不到82%，直到512 NFE以上LDDM-M才略微反超；GSM8K上，从TinyGSM训练、温度1、1024 NFE采样，LAW解出42.2%，对比LDDM-U的34.5%，更惊人的是用LAW微调预训练Duo能把准确率从17.2%拉到48.1%，说明这套纯SC目标可以作为一个有效的后训练适配层；OpenWebText上，LAW在相同熵下用64 NFE就把生成困惑度推近自回归模型，1024 NFE时甚至低于AR基线，但熵最多只到5.1–5.2，说明它在多样性上还有天花板。局限也很明显：LAW需要较多NFE才能发挥优势（少步虽好但并非全面碾压），OpenWebText上的熵受限意味着模式覆盖不如AR，多趟训练和温度正则引入了额外超参（p、M、ρ），而且论文主要在中小规模设定下验证，能否在更大模型和真实大规模语料上保持优势仍是开放问题。不过它的意义在于把Self-Conditioning从辅助技巧提升为生成模型的第一性原则，证明了连续状态传播加末端单次解码这条路线在推理和约束满足任务上可以超越离散扩散甚至逼近自回归，为扩散语言模型的设计空间打开了一个新方向。

## 强化学习 RL

### [LongZero: Enhancing Long-Context Reasoning in LLMs from Zero Data](https://arxiv.org/abs/2610.30132)
`评分4 · Code and data are available at https://github.com/zhennan1/L · 有代码`

这篇论文要解决的是长上下文推理强化学习中的一个根本性数据瓶颈。要让大模型通过 RLVR 真正提升长上下文推理能力，训练数据必须同时满足四个条件：足够长、需要跨文档检索并整合证据、难度适中能产生学习信号、答案可自动验证。现实中同时满足这四点的数据极难获得——人工标注长上下文问题成本高昂，自然存在的长上下文问答数据远不足以支撑 RL 训练。现有做法都依赖外部资源：要么用干扰文档扩展现有短多跳问答数据集，要么让模型基于真实文档出题，要么用知识图谱加搜索轨迹构造任务，要么直接依赖更强的教师模型生成数据。这些路线不仅随着被训练模型变强而越来越难获取外部依赖，还引入了一个隐蔽的混淆因素：真实世界事实可能让模型直接凭参数知识作答而非真正依赖给定上下文，公开文本也可能与评测数据重叠造成污染。与此同时，"零数据 RL"在短上下文领域（数学、代码、游戏、工具智能体）已经取得很好效果，模型自己出题自己解，完全不需要外部数据。但长上下文任务没法简单套用这个思路：一个任务由长输入加针对它的问题构成，如果让模型先写长文档再针对文档出题，那么一个尚不能可靠推理长上下文的模型，同样不可能可靠地写出或验证关于自己刚写的长文本的问题——这恰恰是要解决的那个弱点被提前继承了。

LongZero 的核心洞察是颠倒生成顺序。不让模型先写长文再出题，而是先让模型以紧凑的结构化形式写出问题、支撑证据和答案，此时答案在任何长文本存在之前就已经被固定下来，唯一剩下的出错风险只在"把证据扩展成长文档"这一步。具体来说，模型先用严格 JSON 写一个"世界规格"：包含命名实体（至少两人同姓、至少两个机构名称高度相似以制造混淆）、原子事实集合、每个问题对应的多跳推理链（链与链之间部分共享桥接实体）、每条链配若干干扰事实（涉及同一桥接实体但在角色、时间或属性上不同），以及每个问题的答案和支撑事实。问题用描述性指代中间实体（如"该杂志母出版社的创始人"），迫使模型逐跳解析，而答案必须是事实中逐字出现的具体名称、地点、产品、标题或数字。规格写好后，模型把每条事实分配到多篇不同体裁的文档中，刻意把同一问题的支撑事实分散到不同文档、把干扰事实放到远离其所模仿事实的位置，然后逐篇独立写作，每篇只陈述分配给自己的事实且每事实只出现一次。最后程序打乱文档顺序拼成上下文，并做一道"忠实性闸门"：只有答案或其别名在扩展后的文本中逐字出现的问题才被保留，从而剔除扩展过程中丢失或篡改答案事实的样本。检索数据则模仿 MRCR 格式：模型针对"写一首关于老虎的诗"这类请求生成大量同类型回复作为"针"，程序随机选取某个请求的第 k 个回复作为目标、在前面加随机前缀，把多个近似重复的针插入到其他请求的回复之间直到达到目标长度，参考答案由程序构造保证正确，但解题必须区分模型自己生成的近重复回复并在长上下文中追踪顺序。两类数据混合后，模型对每个问题用小批量采样自测难度，只保留"有时对有时错"的不稳定区间问题——因为 GRPO 在组内归一化奖励，全对或全错的问题梯度为零，而检查中还发现持续失败的问题往往是规格本身有缺陷（如两篇文档对同一属性给了冲突值）。这个自过滤机制让保留问题的难度自动适配即将被训练的模型。训练用 GRPO，采用 DAPO 的 token 级策略梯度损失和 verl 实现的 k3 KL 估计；推理数据奖励用 difflib 的 SequenceMatcher 比率给部分分，推理数据奖励要求答案作为整词匹配且不能比参考答案长出太多以防止列举多个候选。

实验在两个基座模型（Qwen3-4B-Thinking-2507 和 Qwen3-8B）和五个长上下文推理基准上进行，与基于外部语料合成数据的 RL 基线对比。结果显示 LongZero 能从自生成任务泛化到真实任务，并同时超越两个基线，证明无外部数据提升长上下文推理是可行且有前景的路径。一个有意思的细节是 Qwen3-8B 保留自己问题的比例（13.1%）低于 Qwen3-4B（17.7%），意味着更强的模型需要更多合成轮次才能凑够同等数据量。局限方面，方法完全建立在模型自生成数据的忠实性闸门之上，闸门只能验证答案逐字出现，无法保证扩展后的文档在语义上真正支持该答案、也无法排除扩展引入的微妙不一致；虚构世界虽然规避了参数知识混淆，但与真实世界推理的分布差距是否影响迁移仍需进一步检验；检索任务依赖公开 MRCR 的格式和名词集合，严格说并非完全"零外部信息"。不过其核心思路——把长上下文数据的答案在长文本生成之前就固定下来，再用程序化扩展和自过滤保证可验证性与难度匹配——为长上下文 RL 的数据构造提供了一个不依赖外部语料或更强教师模型的范式，且与更好的奖励设计和 RL 算法正交，可以叠加使用。

### [Asymmetric On-Policy Distillation Learns In-Context Exploration](https://arxiv.org/abs/2610.30105)
`评分3`

这篇论文要解决的是部分可观测环境下的序贯决策问题：智能体只能拿到带噪的局部观测，必须先主动探索、把隐藏的任务相关信息（比如目标物体到底在哪个房间）搞清楚，才能有效行动。这类问题在机器人、具身智能里非常普遍。之前的做法各有各的死穴。从头用在线强化学习训练带记忆的策略样本效率极低，因为智能体得同时学会"怎么找信息"和"怎么用信息"。另一条路是利用训练期可以访问的特权专家——专家能看到隐藏状态，所以它根本不需要探索，直接给出最优动作。但问题在于，如果只是朴素地行为克隆专家轨迹，学生会学到在所有可能隐藏状态上平均后的动作分布：比如三扇门任务里，初始观测对三个目标完全一样，学生只能学到"随机选一扇门"这种独立同分布的瞎猜，而学不会"搜了A没找到就去搜B、再没找到就锁定C"这种基于历史的序贯排除。DPT（Decision-Pretrained Transformer）虽然证明了在覆盖假设下离线上下文学习可以收敛到后验采样，但它要求数据集覆盖所有可能的交互历史，这个组合空间随horizon指数爆炸，在高维观测和稀疏反馈下根本不可行，所以这类方法一直难以扩展到真实机器人任务。

ASTEROID的核心洞察非常干脆：训练数据不需要覆盖整个历史空间，只需要覆盖学生策略自己实际会走出来的那些历史。具体做法是把标准的师生蒸馏改成在策略的迭代式蒸馏——先让当前的学生在部分可观测环境下自己跑rollout，产生一串观测、动作、奖励构成的历史，然后拿着学生到达的那个真实状态去问特权专家"你会怎么做"，用专家的动作作为标签来监督学生。关键在于，专家本身从不探索，它只是给学生走过的历史打标签；但学生的失败和试探恰恰变成了有用的上下文：一段历史代表了对隐藏状态的不确定性集合，专家在不同隐藏状态假设下给出的不同标签，就教学生学会了"在剩余可能一致的假设之间采样"。还是三扇门的例子：学生在A没找到，历史排除了A，专家在目标为B时标"搜B"、目标为C时标"搜C"，学生于是学会在B和C之间采样而不是重试A；再失败一次，历史只剩C，标签就唯一了。这实际上是在逼近贝叶斯后验采样——一种理论上可证明高效的探索策略——但不需要显式维护后验分布，也不需要无限离线数据。论文还加了一个rollout horizon上的课程学习来提升样本效率、支持更长上下文的适应。整个方法只是在标准在线蒸馏上做了很小的改动，因此能直接套用现代Transformer架构和现有的sim-to-real框架。

实验覆盖11个环境，包括离散探索基准、机器人操作、导航和Procgen。在固定探索预算下，ASTEROID的回报约为基线的2倍，交互次数比RL基线少最多约100倍，探索表现甚至超过前沿模型；在视觉受限的真实机器人操作任务上，从仿真迁移的策略相比标准蒸馏成功率提升40%。理论部分（附录H）论证了在覆盖的历史支撑集上，该方法能以随上下文长度线性而非二次增长的误差恢复后验采样行为。局限也很明显：它仍然依赖训练期能访问特权专家，专家的质量直接决定上限；理论保证建立在学生策略支撑集被数据覆盖这一条件上，实际训练中策略漂移可能破坏该假设；真实世界实验目前只在视觉受限的操作场景验证，更复杂的高维感知任务还有待检验。但总体而言，这篇工作指出了一个被忽视的方向——探索行为未必需要靠RL硬试出来，用正确的在策略上下文加上特权监督，监督学习本身就能教会智能体"不确定时搜索、确定后利用"，这对sim-to-real的机器人学习和离线上下文决策都有直接的推动作用。

### [Differentially Private Sparse Reward Estimation with Preference Feedback](https://arxiv.org/abs/2610.30099)
`评分3 · 36 pages`

这篇论文要解决的是RLHF隐私保护中的一个结构性错配问题。现有的人类反馈强化学习流程需要先用成对偏好数据训练奖励模型，而偏好数据本身包含用户观点、偏好倾向等敏感信息，因此需要差分隐私保证来防止泄露。但此前所有私有对齐方法都把奖励参数当作稠密向量处理，在差分隐私机制下，噪声注入量正比于环境维度d，估计误差也随d多项式增长。现实情况是，高质量偏好标注极其昂贵，n往往很小，而语言模型的特征空间维度d极大，于是d远大于n时噪声完全淹没信号，对齐效果崩溃。论文的关键观察来自近期实证研究：LLM对齐中的奖励函数和特征表示存在显著的内在稀疏性，偏好信号实际上只由少量显著特征或token决定，即真实奖励参数只有s*个非零坐标且s*远小于d。差分隐私稀疏学习在线性回归等任务上已有结果表明可以绕开对d的多项式依赖，但那些结果无法直接搬到RLHF场景，因为这里涉及非线性的Bradley-Terry-Luce比较模型和成对数据的依赖性。于是论文提出并系统研究了"私有稀疏RLHF"问题：在高维BTL模型下，假设奖励由s*个相关特征控制，能否设计出估计误差不随d多项式增长的私有估计算法。

方法上，论文针对两种隐私邻接关系分别设计了算法。对于Sample-DP（保护整个交互元组，即上下文、两个候选回复和偏好标签），核心做法是把迭代硬阈值算法私有化：每轮用不相交的数据子集做梯度更新（样本分裂），然后把确定性的硬阈值操作替换为差分隐私的"剥皮机制"——该机制在每轮迭代中私下选出幅度最大的s个坐标索引并只保留这些坐标、其余置零，从而在梯度估计被噪声污染的情况下仍能正确识别稀疏支撑集。这里的关键技术洞察是：剥皮机制通过指数机制式的私下top-s选择，使得支撑集恢复的错误概率可控，而样本分裂保证了各轮迭代之间的隐私预算可以独立分配、避免隐私损失随迭代次数线性累积。对于Label-DP（只保护偏好标签、特征固定），论文采用随机化响应加去偏梯度估计的思路：对每个标签以一定概率翻转，再构造无偏的梯度估计量，与IHT结合。理论结果方面，在平方ℓ2参数估计误差下，Sample-DP达到Õ(s*/n + s*²/(n²ε²))的上界，Label-DP达到Õ(s*/n + s*/(nε²))的上界，其中n是训练样本量。下界方面，论文证明Sample-DP的速率在忽略对数因子意义下接近最优，Label-DP在随机化响应框架内的保证无法进一步改进，并给出了Label-DP问题的一般下界Ω̃(s*/n + s*/(n²ε²))。这些结果的意义在于：估计误差现在只依赖于稀疏度s*而非环境维度d，彻底消除了稠密方法中d/n量级的噪声开销，使得在d远大于n的高维小样本场景下私有估计仍然可行。

实验在情感生成和安全对齐两个基准上验证了框架的有效性，与稠密基线（DP-SGD和随机化响应）相比，稀疏方法在高隐私区间显著缓解了噪声开销，奖励分数和对齐率都有明显提升，展现出更优的隐私-效用权衡。局限方面，论文的理论保证依赖于几个较强的假设：特征需满足ℓ∞有界且协方差矩阵的特征值有常数上下界，初始点需落在真实参数的一个受限邻域内，样本量需足够大以满足样本分裂和隐私噪声的要求；此外Label-DP的分析限定在随机化响应范式内，虽然给出了该范式外的通用下界，但尚未提供能达到该下界的算法。对方向的影响上，这篇工作首次把稀疏性引入私有RLHF的理论分析，打通了差分隐私稀疏学习与基于偏好的奖励估计之间的鸿沟，为高维小样本下的隐私对齐提供了可证明的算法框架，也提示后续研究可以探索更一般的稀疏结构（如组稀疏）、更弱的假设条件以及在实际LLM规模上的可扩展实现。

### [AtomicRL: Atomic Reinforcement Learning for Long-Horizon Robotic Manipulation](https://arxiv.org/abs/2610.30097)
`评分3`

这篇论文针对的是长程机器人操作任务中VLA模型强化学习后训练的两个核心痛点。第一是信用污染问题：现有VLA-RL方法大多只用轨迹终点的稀疏成功奖励，当一条轨迹完成了前k个子任务却在第k+1个失败时，由于没有终点奖励，GAE会把与失败相关的TD残差一路反向传播回轨迹起点，导致前面正确执行的动作优势被系统性压低——而且horizon越长，这种污染越严重。之前的工作试图用阶段级偏好优化或子任务级中间奖励来缓解奖励稀疏，但它们只是改变了奖励密度，并没有解决信用污染本身，失败信号依然会跨子任务边界回溯、污染已完成前缀的信用估计。第二是子任务掌握不均衡：训练后期失败往往集中在少数瓶颈子任务上，而均匀的任务采样和固定的探索强度会把交互预算浪费在已经饱和的子任务上，对真正的瓶颈却探索不足。

AtomicRL的核心洞察是把语义子任务结构同时作为信用传播和探索资源分配的统一依据。方法上由三个组件耦合而成。首先是SAPO（语义感知策略优化）：它不改动一步TD残差，也不改动值自举，而是只在GAE的递归迹上做文章——在子任务内部保持标准的γλ衰减，在语义边界处引入一个基于结果感知的软门控κ：如果后一个子任务成功，κ=1，正常传播；如果失败，则0<κ<1，对跨边界的残差传播进行衰减。这样失败段内部的残差仍在该段内正常传播，但进入已完成前缀时被额外削弱，而已完成前缀内部的残差保留标准迹权重，从而在抑制下游失败对上游成功行为干扰的同时，保住了子任务内部的信用分配和成功子任务之间的依赖关系。边界信号由PCC（进度-完成评论家）提供：这是一个轻量模块，基于最近若干帧观测-动作对，以当前原子任务为条件，输出序数进度logits和完成logit，用累积序数损失加类别平衡的完成损失离线训练，当进度和完成同时超过阈值并持续若干步时判定子任务完成、推进任务索引。其次是BATE（瓶颈自适应目标探索）：它用完成率的指数移动平均估计每个子任务的掌握度，掌握度越低，该子任务所在完整任务的采样权重越高（同时保留基线权重以监控遗忘），并且在该子任务激活时施加强度更大的熵正则，把探索资源动态导向尚未掌握的瓶颈。PCC的进度估计还可以选择性地构造基于进度的塑形奖励，与稀疏环境奖励叠加。最后是Real2Sim2Real流水线：仅凭一条真实世界多模态演示和少量辅助信息，自动重建可交互仿真环境、统一观测-动作接口、生成可复现的随机初始布局，把昂贵的真机试错转移到可并行、可重置的仿真中训练，再部署回真机。

实验结果上，在LIBERO-LONG上，AtomicRL配合π0.5达到99.0%成功率、配合OpenVLA-OFT达到98.8%，相对PPO分别提升3.6%和4.0%绝对值；在CALVIN ABC-D上，平均完成序列长度从3.56提升到4.56，完整五子任务链的成功率相对PPO提升9.5%；结合Real2Sim2Real流水线后，真机长程任务平均再提升21.3%。这些数字说明语义边界门控加瓶颈自适应探索确实能提升长程VLA强化学习的学习效率和最终操作性能。局限方面，方法依赖对长程指令的原子子任务分解，分解质量直接影响SAPO的边界门控和BATE的掌握度统计；PCC是离线训练的，其进度与完成判定在分布外场景下的可靠性没有充分讨论；软门控κ的取值策略、以及Real2Sim2Real中仿真与真实的动力学对齐误差，都是影响真机迁移上限的潜在因素。总体而言，这篇工作把“语义子任务结构”从一种被动的任务分解方式，变成了主动调控信用传播和探索预算的杠杆，为长程VLA的RL后训练提供了一个不靠堆奖励密度、而是靠修正信号传播路径的新思路，对后续长程操作强化学习的设计有较强的借鉴意义。
