## 大模型 LLM

### [Continual Learning Mechanisms Compose for Long-Horizon Memorization](https://arxiv.org/abs/2609.06986)
`评分3 · HF 287赞`

这篇论文关注的是一个在语言模型持续学习中长期被忽视但非常现实的问题：模型需要像记忆一样，随着时间推移不断吸收新信息，并且在经历大量后续更新后仍然记得早期学到的内容。作者把这一设定称为“长时程记忆”，具体做法是让模型在领域增量式的持续监督微调中依次学习100个查询-答案任务，训练时不能保留早期任务的原始样本，推理时也不提供任务标识。这和传统持续学习评测很不一样——以往工作要么关注异构下游任务之间的迁移，要么研究模型编辑中的定向修正，而这里要求模型把每个任务里的具体关联真正“记进参数里”。问题在于，顺序更新会引发灾难性遗忘：新任务的梯度会覆盖旧任务学到的知识。作者系统评估后发现，没有任何单一持续学习机制能在这个100任务的长时程下保持较强保留率，比如朴素顺序微调最终平均保留率只有1.2%，最好的单机制也仅8.1%。这促使他们提出核心假设：既然遗忘来自不同来源，那么针对互补遗忘来源的机制组合起来，应该比任何单一机制都更有效。

为了验证这个假设，作者把组合空间拆成两个设计维度：锚点和低秩分配规则。锚点回答“每次更新应该保留什么旧信息”，分为数据锚、函数锚和权重锚。数据锚用前一个模型的冻结副本，从一个与任务无关的重放标记生成完整伪序列，每个新任务前生成300条并丢弃空输出，训练时当前任务的小批量与一个重放小批量配对，从而在数据层面 rehearse 旧任务；函数锚则只在当前任务输入上做自蒸馏，让当前模型对当前任务输入的预测分布靠近前一个模型，相当于在函数层面约束输出行为；权重锚则根据参数对旧行为的重要性来限制更新，作者采用了基于重要性的正则化，并用对角Fisher信息或路径贡献来估计重要性。低秩分配规则回答“更新存在哪里、怎么跨任务保留”，主要比较共享LoRA和合并LoRA。共享LoRA在所有任务上持续优化同一对低秩矩阵，而合并LoRA在每个任务结束后把当前任务的低秩更新折进稠密权重，再为下一个任务初始化新的低秩矩阵和优化器，这实际上是把ReLoRA的合并-重初始化模式搬到持续学习中。合并LoRA的关键好处是：每个任务的更新被写进稠密权重后，后续任务的新LoRA不会直接覆盖它，同时保留状态大小不随任务数增长。作者还用任务级逐次减半来高效搜索组合空间，先用较短任务 horizon 筛掉差配置，再逐步加长，最后用因子实验测量各机制的主效应和交互效应。

实验在三个100任务数据集上进行：Symbol-QA是随机键值关联，LLM-QA是大模型生成的虚构事实，Real-QA是从十个公开问答数据集中过滤出的自然问答。评价指标包括最终保留率、即时获取率和遗忘程度。结果显示，最佳方法把三种锚点与合并LoRA组合起来，在三个数据集上都稳定进入前三，平均最终保留率从朴素顺序微调的1.2%提升到34.9%，相对提升28倍。因子分析进一步指出，数据锚和合并LoRA是平均增益最大的两个因素，并且它们在三个数据集上都表现出超加性交互——也就是说，二者一起用的效果大于各自效果之和。这支持了“互补机制组合”的核心论点。当然，论文也有局限：34.9%的绝对保留率仍然不高，说明长时程记忆远未解决；实验主要基于LoRA和特定锚点实现，其他参数隔离或记忆架构是否也能同样组合尚不清楚；任务规模是100个，真实应用中可能更长。但这项工作的意义在于，它把长时程记忆形式化为一个独立的持续学习问题，给出了锚点加低秩分配的设计空间，并证明机制组合可以显著超越单机制，为后续研究提供了可复用的评测管线、数据集和组合分析框架。

### [How Lossless Is Lossless Speculative Decoding? The Role of Numerical Precision in Orthrus](https://arxiv.org/abs/2609.15504)
`评分3 · HF 15赞`

这篇论文针对的是推测解码（speculative decoding）中一个被广泛接受却很少被严格检验的宣称——无损性（losslessness）。Orthrus 是一种混合架构，它保留一个冻结的自回归（AR）骨干模型，同时附加一个轻量级的扩散视图来并行预测多个未来 token，再通过模型内部的共识机制用 AR 视图验证这些候选 token，从而在理论上保证输出序列与原始 AR 模型完全一致。作者的核心动机是：这种“无损”宣称在真实有限精度硬件上是否成立？此前的方法要么直接替换 AR 模型、要么大幅修改其分布，Orthrus 的吸引力恰恰在于它声称不改变原模型行为却能加速，因此如果这个宣称站不住脚，整个方法的定位就需要重新审视。论文独立复现了 Orthrus，并系统性地在 BF16 和 FP32 两种数值精度下对比其生成轨迹与参考 AR 模型（Qwen3-1.7B）的轨迹，发现 BF16 下只有 45%（作者发布的 checkpoint）和 43%（独立训练的模型）的 prompt 能完全匹配轨迹，而 FP32 下 1190 个 prompt 全部精确匹配。

方法上的关键洞察在于：Orthrus 的共识机制在理想算术模型下确实能保证精确等价，但有限精度浮点运算会引入微小数值差异，而自回归生成是离散决策过程——每一步的 argmax 只要因为数值误差偏了一点，选出的 token 就会不同，之后整个轨迹就分叉了。作者为此专门构建了一个可控的训练框架来独立复现 Orthrus，并发现训练数据分布对并行解码效率至关重要：由于扩散组件是在 teacher forcing 下训练的，用普通人写的文本续写并不能复现冻结 AR 模型自己生成时遇到的状态分布，所以他们改用 teacher-generated 的蒸馏语料——直接让冻结的 AR 模型对 prompt 做贪心解码，把生成的续写作为训练目标，这样数据就沿着模型自身的预测轨迹走。独立训练的模型在 12 个领域中的 10 个上取得了比官方 checkpoint 更高的 Tokens Per Forward（TPF），说明这套训练流程是有效的。更关键的是，作者用逻辑回归量化了轨迹匹配概率与参考模型响应条件困惑度（response-conditional perplexity）之间的关系：困惑度越高，精确匹配的概率越低，系数在官方模型上是 -8.10、独立模型上是 -10.92，置信区间都远离零，说明分叉不是随机发生的，而是系统性地集中在参考模型本身就不太确定的样本上。

结果层面，BF16 下轨迹分叉并没有导致下游 benchmark 的系统性退化——在 GSM8K、HumanEval 和 IFEval 上，独立训练的 Orthrus 甚至在三项上都略高于 Qwen3 基线，当然作者也谨慎指出这些差异在统计上不显著。这恰恰说明了一个重要问题：benchmark 分数相等或略高，并不能证明两个系统产生了相同的 token 序列；反过来，微小的数值扰动偶尔也可能把生成推向 benchmark 更偏好的答案。论文的局限在于它只定位了“有限精度导致分叉”这一现象，并没有进一步定位是哪些具体层或算子贡献了这些数值偏差，这留作未来工作。但它的意义已经很清楚：任何宣称“无损加速”的神经解码系统，都必须同时说明在什么数值精度下、用什么操作标准来衡量等价性，否则“无损”这个词在工程实践中就是模糊甚至误导的。

### [LLaDA-UI: Bringing Block-wise Diffusion to Vision-Language GUI Agents](https://arxiv.org/abs/2609.13287)
`评分3 · HF 15赞`

这篇论文要解决的核心问题是：扩散大语言模型（dLLM）虽然在文本生成上展现出块并行、任意顺序解码的效率优势，但能否把它真正扩展成一个能用的多模态 GUI 智能体，同时保住并行解码的速度红利，此前完全没人验证过。GUI 智能体是个天然合适的试炼场，因为它必须反复感知屏幕状态、实时输出结构化的、带空间定位的动作，对延迟极其敏感。但之前的工作存在明显断层：自回归（AR）范式的多模态大模型虽然成功，可生成本质上是串行的，推理延迟高，而且严格的因果结构对需要双向上下文或全局语义精修的任务并不友好；已有的扩散视觉语言模型如 LLaDA-V、SDAR-VL 只证明了扩散解码可以作为多模态生成的替代方案，近期也有工作把扩散模型用于静态 GUI 定位和单步坐标预测，但没有人把 dLLM 当作需要反复感知变化屏幕、产生可执行动作、完成长程任务的视觉语言 GUI 智能体来探索。换句话说，扩散模型在 GUI 智能体这个方向上是空白，而 GUI 智能体恰恰是最能体现扩散并行解码价值的场景。

LLaDA-UI 的核心设计是一个 16.7B 总参数的 MoE 架构、块级扩散的视觉语言 GUI 智能体，它怎么运作的关键在于两阶段训练管线和几个针对扩散特性的工程细节。第一阶段是多模态预训练，把原生动态分辨率的 ViT 和 LLaDA2.0-mini-base 这个扩散语言骨干对齐。视觉编码器用预训练 SigLIP 初始化，支持原生分辨率输入并采用二维 RoPE 来捕捉二维空间关系；视觉语言投影器借鉴 Qwen2.5-VL 的设计，先把每四个相邻图像特征在空间维度上分组拼接，再用两层 MLP 投影到语言模型嵌入空间，这样大幅压缩了图像特征序列长度、降低计算开销。预训练本身走三阶段课程：S0 做视觉语言对齐，只用高质量图文对和视觉知识数据，先让 ViT 学会提取能被文本有效整合的表示；S1 解冻全部组件做全参数端到端训练，引入交错图文、OCR、计数和定位等细粒度数据，同时混入纯文本数据保住语言能力；S2 加入更难的推理密集型数据如多任务学习、VQA、多模态数学和智能体任务。训练目标用的是块扩散语言模型损失，在给定前序干净块的条件下，对当前块内被掩码的 token 做交叉熵重建，时间权重由扩散过程导出。MoE 部分采用无辅助损失的负载均衡机制，对路由门输出做 2.5 倍缩放以稳定 RMS 幅度，偏置更新时对专家负载不均衡项做 RMSNorm 式归一化来平滑更新。针对多模态样本目标长度差异大的问题，用基于活跃掩码目标数的逆平方根权重来平衡长样本和短样本对梯度的贡献；还用了互补掩码，对每个干净目标构造两个掩码互为逻辑反的损坏视图，让每个 token 在一对中被观察一次、预测一次，提高信息利用率并减少 token 级采样偏差。第二阶段是 GUI 智能体监督微调，数据覆盖移动端（100 多个中文应用、70 多个英文应用）、桌面、网页和定位四大域，最终混合超过 600 万样本，导航目标用 think 和 action 标签的结构化响应，定位则直接返回目标点。微调保留块扩散目标和 MoE 均衡机制，从多模态基础模型初始化，全模型微调三个 epoch，峰值学习率 1e-5，余弦衰减加 3% 预热，最大序列长度 16K，用 32 到 64 张 H100。它凭什么比之前好？关键在于块级扩散让当前块内多个 token 可以并行精修，而不是像自回归那样一个接一个生成，这在 GUI 场景下意味着更低的非缓存推理延迟；同时双向上下文建模让模型在生成动作时能同时利用屏幕的全局信息，而不是只依赖左侧已生成的历史。

实验结果上，预训练基础模型只用了 145B token 训练，远少于 Qwen2.5-VL 的 4.1T 和 Qwen3-VL 的 2.2T，却在扩散多模态基线中建立了新的最优，尤其在推理和文本密集任务上优势明显：相比 SDAR-VL-8B，在 MathVista、MathVision、MathVerse 上分别领先 12.8%、13.6%、31.1%，在 ChartQA、CharXiv-DQ、OCRBench 上分别超出 2.5%、8.6%、17.8%。GUI 智能体评测覆盖 ScreenSpot-V2 和 ScreenSpot-Pro 的静态定位、AndroidWorld 和 MobileWorld 的动态移动导航、OSWorld-Verified 的桌面导航、WebVoyager 的网页导航，LLaDA-UI 大幅超越 Qwen2.5-VL-7B，并在六个报告的 GUI 基准中的四个上超过同量级的自回归 Qwen3-VL-8B。在受控的配对 API 评测中，LLaDA-UI 在网页、桌面和移动输入上都表现出比 Qwen3-VL-8B 更低的非缓存推理延迟，说明在双方都没有精确重放缓存命中时，扩散解码有实际的推理优势。局限方面，论文自己也做了失败场景分析，说明并非所有场景都占优，扩散智能体的推理行为还有待更深入理解，而且目前只在 16.7B 这个量级验证，更大规模是否依然成立、块大小和扩散步数如何影响长程任务成功率，都是开放问题。但它的意义在于，作为第一个让扩散语言模型有效充当视觉语言 GUI 智能体的工作，LLaDA-UI 把块级扩散确立为多模态 GUI 智能体的一种实用生成范式，为未来视觉语言智能体开辟了一条区别于自回归的新路径。

### [When Should LLMs Abstain? Chain-of-Self-Questioning for Selective Risk Control](https://arxiv.org/abs/2609.17516)
`评分3`

这篇论文要解决的是大语言模型在事实依据薄弱时仍然给出流畅答案的问题，也就是我们常说的幻觉。作者指出，现有的问答评测体系隐含地奖励“必须作答”：模型即使对某个问题没有可靠依据，只要猜一个答案，也可能在总体准确率上拿到不错的分数，因为它无法区分自己“能答”和“不能答”的问题。思维链提示虽然能提升推理表现，但它本身并不产生“作答还是弃答”的决策——模型完全可以沿着一条连贯的推理路径得出一个错误的事实答案。检索增强生成和后验验证虽然能提升可靠性，但要么需要额外的基础设施，要么是在候选答案已经生成之后才介入，属于事后补救。这篇论文关注的是一个更窄但更互补的问题：模型在生成答案之前，是否应该承诺作答。作者用医疗场景做类比：医生在证据不足时把病例转诊给专科医生，并不是失职，而是一种负责任的决策，CoSQ 想把同样的操作原则搬到语言模型的回答上。

方法的核心是 Chain-of-Self-Questioning，一个纯提示词、模型无关的三阶段框架。第一阶段，模型先识别出回答该问题所需的信息单元，也就是把“要答对这个问题，必须知道哪些事实”显式拆出来。第二阶段，模型对每个信息单元给出一个置信度分数，然后通过一个门控规则决定是否允许承诺作答。第三阶段，如果通过门控，模型只用那些被接受的信息单元来生成最终答案，否则就弃答。论文设计了三个变体：Grounded-CoSQ 取所有信息单元置信度的平均值作为门控分数，只有均值超过阈值 τ 才作答，且最终答案只基于通过门控的信息单元生成，这样能降低最终答案建立在已被明确拒绝的前提上的风险；Critical-CoSQ 要求模型把每个信息单元标注为“关键”或“辅助”，只有关键单元的置信度参与门控，这样做是为了消除辅助细节数量对平均分的机械影响，检验把决策聚焦在“没有它就不可能答对”的信息上是否能改善选择性作答；Adaptive-CoSQ 则同时施加三个检查——整体平均置信度、关键单元平均置信度、以及关键单元中的最低置信度，并且根据整体置信度高低切换“自信模式”和“谨慎模式”来生成答案，最后还做一次矛盾检测，检测到矛盾就弃答。关键洞察在于，它把置信度从“解释性文本”变成了一个可操作的、决定是否承诺的开关，而且这个阈值不被当作校准概率，只是一个经验性的操作参数，用来在风险-覆盖率曲线上选一个工作点。相比之前需要额外训练、多模型或任务特定资源的方法，CoSQ 刻意保持纯提示词，适用于黑盒或托管模型。

在 TruthfulQA 多选题验证集（817 题、选项位置经过确定性平衡）上，用 11 个开放权重和托管模型家族、17 种条件做了评测。在 τ=0.90 的主工作点上，Grounded-CoSQ 把平均无条件错误承诺率从思维链提示的 13.1% 降到 8.9%，相对降低 32.1%，同时把已作答准确率从 86.9% 提升到 89.7%，并且仍然回答了 87.6% 的问题；这两个改进在全部 11 个模型和每一个评测阈值上都成立。Critical-CoSQ 和 Adaptive-CoSQ 提供了相邻的工作点，覆盖率分别为 88.6% 和 86.5%，可靠性也都优于基线。作者还用 Natural Questions 短答案做了二次验证，得到收敛的开放形式证据。局限方面，CoSQ 因为要先做信息提取和置信度评估再生成答案，增加了模型调用次数和推理开销，这是用额外算力换取更低错误承诺率的 deliberate exchange；此外托管模型的端点标签不一定对应不可变的权重版本，这是一个可复现性限制；模型数量较少且端点之间并非独立训练样本，所以推断结果需要结合每个模型的具体数值和完整阈值曲线来解读。这项工作的意义在于，它把选择性预测的风险-覆盖率框架真正落地到了 LLM 提示层面，证明了模型的自评估信号即使不是校准概率，也能支撑显式、可调的“作答或弃答”决策，在错误承诺比转诊或人工复核代价更高的场景下有直接的应用价值。

### [Large Language Models Develop Belief State Geometry In-Context](https://arxiv.org/abs/2609.17376)
`评分3 · 87 pages`

这篇论文关心的核心问题是：大语言模型在上下文学习（ICL）时，内部到底有没有形成对生成过程的“信念状态”。所谓信念状态，就是在给定已观察到的 token 序列后，对隐藏马尔可夫模型（HMM）中隐藏状态的后验分布。换句话说，模型如果真在按贝叶斯方式做上下文推断，它就不只是记住表面 token 共现，而是应该在残差流激活里编码出“当前最可能处于哪个隐藏状态、各状态概率多大”这类信息。此前关于 ICL 机制的研究，很多停留在注意力模式、归纳头或任务向量层面，能说明模型会利用上下文，却难以证明它是否逼近了最优贝叶斯预测；而信念状态几何此前主要在显式用 HMM 数据训练的小型玩具网络上被观察到，能否推广到生产级 LLM 并不清楚。论文的动机正是要补上这一环：把 LLM 放在受控的 HMM 提示环境中，直接探测其激活是否线性包含真实信念状态，并用干预实验检验这个表示是否真的参与下游预测，而不是仅仅相关。

方法上的关键洞察是，把 HMM 的信念状态当作一个可计算、可监督的目标，然后看 LLM 残差流激活能否线性解码出它。作者选了 40 个具有非平凡信念结构的 HMM，向六个开源 LLM 输入由这些 HMM 生成的 token 序列，再在每一层残差流上训练线性探针去回归真实信念状态。结果发现，信念状态确实可以从激活中线性读出，峰值探针的 R² 在不同 HMM 与 LLM 组合中达到 0.83 到 0.99，而且出现位置从较早层到较晚层都有，说明这种表示不是某一层偶然的副产品。更关键的是，他们没有停在“能解码”这一步，而是进一步做因果干预：通过 patching 和 steering 直接改动探针识别出的子空间，也就是把激活中对应信念状态的方向替换或偏移，再看模型下一 token 预测会不会跟着变。如果这个子空间只是相关噪声，干预应该破坏不大；但实验显示，干预后的下游预测质量仍能接近未篡改模型，而对照干预则显著退化。这就把“线性可解码”提升为“功能相关”：模型确实在用这个子空间做近似贝叶斯预测，而不是旁边另有一套完全不同的机制在干活。

在结果与意义上，论文覆盖了 40 个 HMM 和六个开源 LLM，探针 R² 峰值从 0.83 到 0.99，说明信念状态几何在 production-scale LLM 中普遍存在，并且可以被线性读出。干预实验进一步表明，直接操纵这个子空间能保持接近原始模型的预测质量，而控制干预会大幅降低性能，这为“ICL 近似最优贝叶斯预测”提供了表示层面的证据。局限也很明显：研究集中在 HMM 这种离散、有限状态、生成过程明确的受控环境，真实语言任务的隐藏状态远更复杂、非马尔可夫、层级和语义因素交织，信念状态未必有唯一或可计算的定义；此外，线性探针能读出并不等于模型内部完全以线性方式使用该信息，干预保持性能也只说明该子空间足够关键，不能排除其他冗余通路。尽管如此，这项工作把输入分布结构与激活几何之间的联系，从显式训练在 HMM 数据上的玩具网络推进到了生产级 LLM，提示 ICL 的底层机制可能比“模式匹配”更接近对上下文生成模型的贝叶斯推断，也为后续研究真实语言中的信念表示、干预和可解释性提供了可复用的实验范式。

### [Where Should a Document Live: Context, Representations, or Parameters?](https://arxiv.org/abs/2609.17346)
`评分3`

这篇论文要回答的是一个非常实际的问题：当大模型需要回答预训练数据之外的问题时，新知识到底应该以什么形式注入模型？目前有三条主流路线——把文档放进上下文窗口（ICL/RAG）、把文档编码成隐表示（KV cache 前缀）、或者把文档写进模型参数（微调）。这三条路线各有各的效率、成本和效果权衡，但此前的工作并没有给出公平、可控的横向对比。已有的比较研究存在两个关键缺陷：一是大多在维基百科段落上评测，而这些内容很可能已经在预训练阶段被模型见过，所以测的其实是"回忆"而不是"注入新知识"；二是往往只覆盖单一文档场景，或者只比较少数几种方法。Eyuboglu 等人虽然尝试做了表示法与参数法的对比，但方法覆盖有限，多文档场景的结果也很少。这篇论文的动机就是填补这个空白：在真正未污染的知识密集型任务上，把上下文、表示、参数三条路线的代表性方法放在同一套训练数据、同一个目标函数、同样的存储预算下做头对头比较，同时量化每种方法对模型通用能力的破坏程度。

方法上的核心设计可以拆成几个层面来理解。作者选了五种适配方法加两个基线：无上下文基线（只给问题，量化预训练知识能答多少）、ICL（文档直接进上下文）、Cartridges（训练一个小的 KV cache 前缀，推理时拼在问题前面）、Compaction（把文档压缩成一组紧凑的 key-value 对，通过匹配模型对完整文档的注意力分布来训练）、LoRA（在每层前馈投影上加低秩更新）、MLP 适配器（在每层注意力块后插入小 MLP）、以及全量微调作为容量上界。训练数据不是直接用原始文档，而是用 LLM 生成的合成 Self-Study 数据：一个 GPT-OSS 120B 作为问题生成器，看到文档片段和种子提示后生成问题；目标模型自己作为答案生成器，在能看到文档的条件下给出答案的 token 及其对数概率分布。目标函数用的是蒸馏损失，即最小化"教师"（同一模型但文档在上下文中）和"学生"（被适配的模型）之间的 KL 散度，而不是传统的下一 token 预测。这个选择很关键，因为之前的工作已经证明蒸馏目标在知识注入上优于下一 token 预测。在单文档 oracle 设置下，每个文档训练一个独立的适配器，推理时只给问题和系统指令，不提供文档原文。在多文档检索设置下，对每个问题检索 top-k 个 chunk，表示法把 k 个 KV cache 拼接起来，参数法则把 k 个权重平均合并成一个。作者还做了存储匹配的实验：把 LoRA 的秩和 MLP 的瓶颈维度调整到与 KV cache 方法在相同压缩率下的每文档内存占用一致，压缩率从 2 倍到 100 倍变化，这样才能公平比较不同方法在相同存储预算下的表现。

结果层面，在单文档 oracle 设置下，无上下文基线只有 24.9 分，说明知识确实是注入进去的而不是回忆出来的。表示法整体占优：Compaction 平均 73.4 分，几乎追平 ICL 的 73.6 分上限；Cartridges 70.6 分；参数法中 LoRA 最好，64.5 分，MLP 适配器 62.2 分，全量微调反而只有 59.8 分。但压缩率一拉高，两种表示法的行为就分道扬镳了：Compaction 在低压缩率下最强，但衰减极快，比如 FinQA 从 2 倍的 66.4 掉到 20 倍的 19.3，LongHealth 从 87.7 掉到 100 倍的 46.5；Cartridges 则几乎持平，LongHealth 从 81.1 到 77.3，QuALITY 从 78.6 到 76.4，TechQA 甚至从 75.8 微升到 76.9，在所有数据集上都压过存储匹配的参数法。在多文档检索场景下，Cartridges 是唯一能追平 ICL 的方法，领先参数法 29 分，领先 Compaction 15 分。但代价也很明显：Cartridges 和全量微调、大 MLP 适配器一样，会出现灾难性遗忘，在控制基准上平均掉 6 分，代码任务上掉 13 分。Compaction 在高压缩率下虽然避免了遗忘，但精度损失太大。论文的结论是没有单一最优方法：如果存储极度受限且能接受一定精度损失，Compaction 在低压缩率下可用；如果需要多文档组合且追求精度，Cartridges 是首选，但要接受遗忘风险；如果最看重通用能力的保持，LoRA 类参数法更安全，但注入新知识的效果会打折扣。这个工作对领域的意义在于，它把"知识注入"从单一维度的精度比较扩展到了存储、压缩率、多文档组合、灾难性遗忘的多维权衡，并且用未污染的数据和统一的蒸馏目标保证了比较的公平性，为后续研究提供了一个更可靠的基准框架。

### [Coupled Calibration and Learning: Mitigating Teacher Bias in LLM Distillation without Target-Domain Reward Feedback](https://arxiv.org/abs/2609.17474)
`评分3`

这篇论文要解决的是大模型蒸馏中的一个真实痛点：当教师模型本身带有系统性偏差时，直接让学生模型去模仿教师的输出，会把教师的错误一并学过来。这个问题在协变量偏移（covariate shift）场景下尤其严重，也就是源域问题（有可靠奖励反馈）和目标域问题（学生真正要回答的问题）分布不一致时。教师可能在源域问题上表现很好，但这并不能保证它在目标域问题上同样可靠，而目标域恰恰又没有奖励反馈可用。已有的理论工作，比如Yamamoto和Wainwright关于偏差传播的研究，虽然提出了让教师去拟合学生残差的方法，但仍然依赖目标域的反馈信号；而实际中为目标域构建奖励模型或验证器成本极高，比如数学推理需要大量人工步骤标注，代码评估需要任务特定的测试环境。所以核心问题是：在只有源域奖励反馈、目标域仅有问题本身的情况下，能否从一个有偏教师中蒸馏出一个接近最优的学生？

CCL的核心思路是把教师校准和学生更新耦合在一个迭代过程中，而不是先校准再蒸馏这种单向流程。具体来说，每一轮迭代先用源域上的奖励反馈来校准教师——这里的校准不是简单地微调教师参数，而是在token级别进行分支（token-level branching），利用源域反馈来修正教师在生成每个token时的偏差倾向。校准后的教师随后被用来在目标域问题上训练学生，而更新后的学生又会反过来影响下一轮的教师校准，形成一个闭环。这个设计的关键洞察在于：学生本身携带了关于目标域的有用信息（因为它在目标域问题上被训练），这些信息可以帮助教师校准过程更好地聚焦于目标域相关的偏差，而不是仅仅在源域上做修正。理论分析上，作者在自回归策略框架下证明了学生到oracle学生（即在学生策略类内最大化真实目标奖励并带KL正则化的那个策略）的期望平均KL散度以多项式速率收敛到零。证明的核心思路是控制学生梯度在oracle附近的进展，同时在远离最优区域时保持足够的探索，并分别控制校准误差和有限rollout带来的误差。更重要的是，作者建立了一个分离结果：即使教师达到了比学生策略类中任何策略都更高的正则化目标奖励，正则化直接匹配（即直接让学生模仿教师）相对于oracle学生的KL散度仍然可能保持在一个严格大于零的常数上。这意味着直接蒸馏存在一个不可消除的持续误差，而CCL能够消除它。

在结果层面，这篇论文的贡献主要体现在理论保证而非实验数字上：它证明了CCL能够以多项式速率收敛到学生类内的最优策略，并且严格优于正则化直接匹配。这个分离结果的意义在于，它从理论上说明了即使教师在某些指标上看起来比学生更强，直接模仿也可能导致学生永远无法达到自己能力范围内的最优表现——因为教师的偏差会成为一个持续的下界。论文的局限也很明显：分析建立在学生类内存在oracle这个假设上，也就是说学生策略类必须足够表达才能包含最优解，如果学生类本身表达能力不足，收敛目标本身就不是全局最优；此外，理论假设源域和目标域共享策略可实现性以及联合源域可识别性，这些条件在实际LLM场景中是否成立需要进一步验证。但总体而言，这篇工作为无目标域奖励反馈下的蒸馏提供了一个有理论保障的路径，也提示了一个更广泛的方向：教师校准和学生学习的耦合可能比传统的单向蒸馏范式更适合处理分布偏移下的知识迁移问题。

### [Agentic Societies Need a Social Harness](https://arxiv.org/abs/2609.17527)
`评分3`

这篇论文关注的是一个正在浮现但尚未被充分研究的真实问题：当多个AI智能体分别代表不同的人类或组织（即“委托人”），在缺乏人类实时监督的情况下自主协调任务时，即便所有智能体都是诚实且能力足够的，它们也常常无法达成令各方满意的结果。作者以“会议调度”作为实验场景——让代表教授和学生的智能体自主协商会议时间，每个智能体只能访问自己委托人的日历，且各委托人的目标只是部分一致（都想开会，但对具体时间偏好不同）。实验发现，随着参与智能体数量增加，或单个智能体同时处理的任务增多，成功率显著下降。例如在教授协调多名助教的场景中，当智能体使用隔离的会话上下文（每个对等方一个独立LLM对话）时，某模型配置在7个参与者下成功率为零；即便只有一名学生和一名教授，智能体之间也可能交换上百条消息，陷入无意义的“确认循环”，互相转发内部推理过程，浪费大量资源。更关键的是，现有基础设施（如A2A、AGNTCY等协议）只解决智能体之间的连通性，不保证协作结果的质量；而共享维基式架构虽然能降低协调复杂度，却要求智能体放弃对私有上下文的保护，在跨信任边界的场景中不可行。作者还指出，恶意或故障智能体可以利用通信（即“言语”）来拖延进程、操纵结果甚至实施跟踪等有害行为，而当前模型被训练得“乐于助人”，面对不合理请求时容易顺从，进一步加剧了风险。

论文的核心洞察在于：智能体社会需要的不仅是每个智能体管理自身私有上下文和与委托人通信的“个人挽具”，还需要一个专门管理智能体之间交互的“社会挽具”。作者提出将社会挽具组织为五层架构，自下而上依次提供身份标识、可靠有序通信、不当行为防护、任务特定通信规范以及执行与治理服务。其中通信规范层尤为关键，它强制约束智能体在特定语境下的言语行为，例如在调度场景中，一旦有人提出时间提案，后续消息必须是接受或反提案，而不能是无关的闲聊或重复确认。这种分层设计借鉴了传统网络协议栈的思路：底层提供基础服务，上层在此基础上配置和扩展，从而将“什么消息在什么条件下是合法的”这一判断从单个智能体的推理能力中剥离出来，变成基础设施层面的保障。作者还强调，社会挽具需要同时具备三种能力：在消息生成或发送前就阻止无效消息、在运行时检测到无效消息以支持智能体自我保护、以及在事后调查恶意或故障行为并施加后果。实验表明，共享会话上下文可以将分布式协调问题转化为“收集后集中推理”，从而提高成功率，但会带来隐私泄露风险，且当中心化协调者不可信时不可用；组播消息虽能大幅降低消息复杂度（某些配置下减少3到25倍），但无法消除竞态条件，因为网络只能保证消息投递顺序，不能保证智能体生成回复的顺序，导致“互相抢话”和通道争用。

在结果层面，论文通过系统实验给出了具体数字：在教授协调7名助教的场景中，从隔离会话切换到共享会话，某模型配置的成功率从0%提升到90%；组播消息将消息复杂度降低了3到25倍。然而，即便在诚实智能体之间，调度成功率仍随参与者数量增加而下降，且共享会话会引发隐私问题。引入故障智能体后，即使只有一个，也会显著降低会议预订能力；恶意智能体通过社会压力（如威胁向院系举报歧视）和欺骗（如谎称对方已有安排被取消）成功影响了结果，甚至利用多个学生智能体分头探测教授日历，通过侧信道聚合出教授的完整日程。值得注意的是，这些攻击成功绕过了模型的安全护栏：模型会拒绝直接要求撒谎的指令，但恶意委托人可以将虚假信息作为“事实”提供，智能体便会如实转述。论文的局限在于，五层架构目前只是概念性提案，尚未实现完整系统并验证其端到端效果；通信规范的制定需要跨模型、跨挽具的共识，而不同委托人独立配置的智能体可能遵循不同规范，协调成本高。尽管如此，这篇论文的意义在于将智能体社会的协作失败从“模型能力不足”重新定位为“基础设施缺失”，并借鉴人类协作和网络协议栈的经验，为构建跨信任边界的智能体交互机制指明了方向。如果这一方向得到社区跟进，未来智能体之间的通信可能像互联网一样，在底层协议保障下实现可靠、安全且可追责的自主协作。

### [Agent as Policy for Robotic Manipulation](https://arxiv.org/abs/2609.12541)
`评分3 · HF 12赞`

这篇论文要解决的是机器人操作领域一个根本性的矛盾：通用智能体（基于多模态大语言模型）在数字任务上已经展现出强大的推理和编程能力，但把这些能力迁移到物理世界时，现有方法都卡在了“策略边界”的划分上。目前主流的两种做法各有致命缺陷。第一种是让智能体在任务执行前生成可执行程序（代码或计算图），机器人按程序运行——但程序只能用显式规则表达运行时决策，面对不确定的观测和意外结果时，很难预先写清楚“如果插入失败且偏移方向是斜的，应该先侧移再重新对准”这类需要现场判断的逻辑。第二种是让智能体充当“调度器”，从已有的学习策略库中选择和排序策略——但动作生成的质量被所选策略的能力上限锁死，智能体只能决定“用哪个策略”，不能决定“动作本身该怎么微调”。真实物理任务恰恰需要同时灵活地解释证据和生成动作：一次失败的插入可能需要更近的视角、修正的对齐估计、或者完全不同的接近方向，而选择并执行这些响应需要联合推理当前场景、已尝试的运动及其结果。这正是AGP的出发点——把智能体本身当作策略，让它在运行时完全自主地决定观察什么、如何解释证据、请求什么运动，并随时编写和修改局部程序。

AGP的核心设计可以拆成三个层面来理解。第一是“智能体即策略”的定位：给定任务规格和机器人接口文档，一个通用编码智能体在本地工作区中维护脚本、笔记和观测数据，通过工具调用与机器人交互。关键之处在于模型参数全程冻结，适应完全发生在会话内部——通过更新测量值、程序和决策来实现，而不是微调权重。第二是“智能体-机器人桥”的设计：这个桥暴露了校准后的观测、几何查询和运动命令三类能力。机器人向智能体提供两类信息——相机（腕部RealSense D405提供对齐的RGB-D，顶部Logitech BRIO提供矫正后的RGB）和本体状态（关节位置及通过正运动学算出的末端位姿）；智能体向机器人发送观测请求和动作请求，动作请求可以指定关节角或末端位姿加夹爪开合，机器人用Mink做逆运动学求解，生成受工作空间和运动限制约束的关节轨迹，并用电机反馈跟踪。特别值得注意的是，运动执行和监控独立于智能体推理运行——机器人执行已提交的运动时，智能体可以在工具调用之间继续推理，这避免了“思考时机器人静止”的时间浪费。第三是运行时编程与反馈适应：智能体在执行过程中写Python程序来处理保存的图像和深度数据，估计物体位置、计算目标夹爪位姿、提交机器人命令；执行后根据运动反馈和新观测修正估计和后续动作。它自己决定抓取位姿、动作序列、观测时机和恢复策略，直到报告完成或耗尽预算。这套机制之所以比之前的方法更好，是因为它把感知、运动生成和恢复的控制权都放在了“新物理证据变得可用的那一刻”——而不是预先写死在程序里，也不是委托给一个能力固定的底层策略。

在真实机器人上的实验覆盖了从人类视频装配、目标图像积木构建、掷骰子、定向投掷到双臂叠毛巾五类任务，跨越长程推理、动作多样性和物体多样性。主评估中每次试验都从全新会话开始，模型权重固定，无先验任务执行经验或仿真排练。结果相当有说服力：装配任务10次成功8次，三种积木构建配置合计30次成功29次，掷骰子10次全成功，八个任务配置中七个成功率至少80%，五个达到100%。效率方面，通过让智能体把程序、测量和修正记录到文件中供后续复用，重复试验的执行时间明显缩短；更强智能体的记录迁移给较弱智能体后，后者的成功率和平均执行时间都有改善。但局限也很明显：执行时间和推理成本仍然是实际部署的硬障碍——比如投掷任务平均22.8分钟，其中约40%花在投掷后的轨迹分析和验证上，而非投掷本身。这说明当前AGP的“慢思考”模式在需要快速闭环的任务上还不实用。不过这项工作的意义在于开辟了一条新路径：通用基础MLLM可以直接作为机器人策略，通过运行时推理、编程和交互来扩展自主性到物理操作，而不需要任务特定或环境特定的训练。它把机器人策略的边界从“训练一个动作生成器”转移到了“设计一个能让通用智能体有效感知、推理和行动的接口”，这对后续研究如何利用基础模型的强大能力来构建更高效、更通用的机器人系统提供了明确的启示。

### [HyCoSeq: Contextual Hyperbolic Representation Learning for Genomic Sequences](https://arxiv.org/abs/2609.16925)
`评分3`

基因组序列分类长期在欧氏空间里做表征学习，但序列之间因共同祖先与分化关系而隐含层次结构，这种树状或分支结构在欧氏空间里需要极高维度才能低失真嵌入。双曲空间因负曲率带来体积指数级增长，天然适合表示层次结构，已有工作如 HGE 把全双曲卷积网络引入基因组建模，用洛伦兹卷积提取局部模体特征，并在多个任务上验证了双曲几何的有效性。然而 HGE 存在两个卡点：一是残差聚合方式沿用了全双曲 CNN 的设计，先聚合类空分量再反推类时分量以满足洛伦兹流形约束，导致完整的洛伦兹表示并未直接参与残差聚合，且这种残差形式在双曲几何下缺乏清晰的几何解释；二是洛伦兹卷积块的感受野有限，只能编码局部模式，而许多调控任务的预测信号不仅取决于单个模体，还取决于模体之间的空间排布、间距和侧翼上下文，纯局部卷积无法建模序列级的长程依赖。这两个缺陷一个在几何层面、一个在序列建模层面，共同限制了双曲基因组表示的表达能力。

HyCoSeq 的核心设计正是针对这两点分别下手。在局部编码阶段，它保留多曲率洛伦兹卷积架构——每个卷积块关联一个可学习的负曲率，逐块把表示从一个洛伦兹流形映射到另一个曲率不同的流形，从而让不同层在各自合适的曲率下编码特征。关键改动在残差连接：HyCoSeq 采用 LResNet 的加权洛伦兹残差聚合，把残差块输入和卷积变换后的输出这两个完整洛伦兹表示先做加权线性组合，再用一个共享的归一化因子把组合结果重新投影回洛伦兹流形。由于两个分支共享同一归一化因子，残差输出只依赖于两分支系数的比值，因此固定输入分支系数为 1、把变换分支系数参数化为 softplus 加小常数，每个残差块就能学到一个独立的、控制变换输出相对权重的比例，既保证了流形约束，又让完整洛伦兹表示直接参与聚合，几何上更自洽。在序列级建模阶段，HyCoSeq 把最后一层卷积输出的洛伦兹表示取出其类空坐标，因为给定曲率后类空坐标唯一决定流形上的点，所以在这一坐标表示上跑一个单层双向 LSTM，每个方向隐层大小为 16，前向和后向隐状态拼接后经线性变换映射回与类空分量相同的维度，再逐位置投影回目标洛伦兹流形，最后经洛伦兹展平、全连接变换、激活和洛伦兹多项逻辑回归完成分类。这样 BiLSTM 从两个方向整合序列位置间的上下文依赖，把局部双曲卷积编码扩展为序列级上下文表示，而投影回流形则保证分类头仍在双曲几何下运作。整个模型端到端用交叉熵训练，用 RiemannianAdam 优化，所有可学习曲率初始化为负一。

实验在 TEB、GUE 和 Genomic Benchmarks 三个基准上展开，统一用马修斯相关系数评估。消融实验显示，单独加入加权洛伦兹残差聚合或单独加入双向上下文建模，都能在 TEB 全部七个任务上超过 HGE 基线，两者结合后的 HyCoSeq 在每个任务上都取得最高平均 MCC，整体平均 MCC 比 HGE 提升 5.53 个百分点，说明两个设计互补：前者改善卷积块内的几何聚合，后者补足局部编码缺失的序列上下文。在 17 个代表性 GUE 数据集上，HyCoSeq 只有约 460 万可训练参数，比 HCNN-M 多 0.16%，而对比的预训练 DNA 语言模型参数量从 770 万到 25 亿不等，HyCoSeq 不做大规模基因组预训练、每个下游任务端到端训练，却取得平均排名 3.18，仅次于平均排名 3.06 的 DNABERT-2-PT，而后者参数量约为 HyCoSeq 的 25.4 倍，并且在绝大多数数据集上超过双曲 HGE 基线。任务类别层面的结果也显示，HyCoSeq 在表观标记预测、转录因子结合、剪接位点、启动子、增强子、调控元件和开放染色质等所有报告任务组上都取得最高平均 MCC。这些结果表明性能提升并非来自模型容量膨胀，而是来自几何一致的残差聚合与序列级上下文建模的结合。局限方面，BiLSTM 的序列建模能力相比 Transformer 仍受限于单向递归结构和隐层规模，且模型未利用大规模预训练，在部分任务上仍落后于最大的预训练模型；此外多曲率设计和流形映射增加了实现复杂度。但这项工作证明了紧凑的双曲架构配合恰当的残差与上下文设计，可以在不依赖海量预训练的情况下与远大于自己的模型竞争，为双曲几何在基因组表示学习中的进一步应用提供了有说服力的方向。

### [GPCR Ligand Bioactivity Prediction with Physics-Informed Dual-State Query Learning](https://arxiv.org/abs/2609.16468)
`评分3 · Accepted by APBC2026 · 有代码`

这篇论文要解决的是GPCR（G蛋白偶联受体）配体生物活性预测中一个长期被忽视却至关重要的问题：现有深度学习方法大多只预测结合亲和力，却无法区分配体的功能效应——到底是激动剂还是拮抗剂。这件事之所以难，根源在于GPCR的功能效应本质上由受体在活性态与非活性态之间的构象平衡决定，而配体的作用恰恰是打破这个平衡。传统基于结构的方法依赖高分辨率晶体结构，但活性态GPCR结构因本身不稳定而极其稀缺；即便有结构，活性态与非活性态在跨膜区的几何差异也非常细微，标准几何深度学习模型很难分辨。另一条路线——基于配体的QSAR模型——又完全丢弃了受体的结构语境，导致在受体不重叠或孤儿GPCR上泛化能力很差。换句话说，之前的方法要么缺结构、要么缺物理、要么缺对构象平衡的显式建模，始终没能在"结合强度"和"功能效应"之间建立起有物理依据的桥梁。

DSQ的核心创新是把Monod-Wyman-Changeux（MWC）别构模型真正嵌入到神经网络里，而不是当作事后解释。具体做法是：用ESM-2提取蛋白质残基嵌入、用MolFormer提取配体嵌入，然后引入两组可学习的正交查询向量，分别对应活性态和非活性态，通过交叉注意力从蛋白质嵌入中"探测"出两个解耦的潜在结构视图。这一步绕开了对显式3D结构的依赖，用潜在空间模拟构象选择。接着，配体特征分别与这两个状态视图做交叉注意力，得到状态特异的亲和力预测——活性态亲和力和非活性态亲和力。关键模块是神经MWC门控：它把受体激活概率建模为sigmoid函数作用于两个状态亲和力之差减去受体固有构象能垒，再除以一个可学习的温度参数τ。这个公式直接来自玻尔兹曼分布和MWC理论，意味着模型要预测激动剂，就必须学会让活性态亲和力显著高于非活性态并克服能垒；拮抗剂则相反。最终生物活性是两态亲和力的加权期望。训练时用了四个损失：回归损失、门控监督（用激动/拮抗标签做二元交叉熵）、正交约束（让两个状态视图余弦相似度最小化）、以及对比排序损失（强制激动剂满足活性态亲和力大于非活性态，拮抗剂反之）。这套设计让预测不是黑箱拟合，而是被热力学关系约束在物理一致的流形上。消融实验也验证了这一点：把MWC门控换成普通MLP，RMSE从0.999升到1.051，门控准确率从0.840降到0.747；冻结温度参数τ（训练中它从1.0自动降到0.2627，说明模型学会了锐化激活门），整体R²从0.517掉到0.427。这说明提升不是来自增加容量，而是来自MWC参数化带来的归纳偏置。

在结果上，DSQ在从GLASS和GPCRdb构建的大规模人类GPCR基准上，与DeepDTAGen、DrugBAN、GraphDTA对比，整体指标全面领先：RMSE从1.071降到0.999（降低6.7%），MAE从0.816降到0.746（降低8.6%），R²从0.446升到0.517（提升15.9%），PCC、SCC、C-Index也都有4%到7%的提升。但最关键的发现是提升集中在激动剂子集：基线模型在激动剂上R²为负（DeepDTAGen -0.084，GraphDTA -0.282），意味着比均值预测还差，而DSQ达到0.269，说明显式建模双态确实能恢复被单标量回归淹没的激动剂信号。不过论文也坦诚了局限：在拮抗剂子集上DSQ并非全面占优，DeepDTAGen和GraphDTA在部分拮抗剂指标上更好；更重要的是同源性分层评估显示，当测试受体与训练受体序列一致性低于60%时，所有模型R²都退化到接近零或负值，说明基于序列的公式在跨越大进化距离时泛化能力仍然有限。这项工作的意义在于，它提供了一种可操作的思路——把生物物理模型作为可微分模块嵌入深度学习，用热力学约束引导表示学习，而不是简单堆叠注意力或增大模型。它同时也划出了一条清晰的边界：物理归纳偏置能显著改善激动剂预测和整体精度，但低同源性泛化仍是这个方向尚未解决的核心挑战。

### [MIRAGE: Measuring Interpolation and Redundancy in Affinity GEneralization](https://arxiv.org/abs/2609.14491)
`评分3`

这篇论文要解决的核心问题是：当前结构导向药物设计中，深度学习模型（尤其是共折叠模型如AlphaFold3、Boltz-1/2、Chai-1、Nesso-1等）在预测蛋白-配体结合亲和力或姿态时，标准评估只用单一留出相关系数或汇总的姿态成功率，无法区分模型是真正学到了可迁移的结合物理原理，还是仅仅因为测试靶点所属的蛋白家族在公开结构数据库（如PDBbind）中已被大量见过而“记住”了答案。这种区分至关重要，因为实际药物研发项目面对的是全新靶点，而全新靶点恰恰在公开数据中代表性最低。此前的工作已经表明，基于配体的基准和对接基准会奖励记忆，亲和力网络依赖训练-测试相似性而非物理，去泄漏后的语料会降低表面准确率。但缺失的是一个模型无关的、系统性的分析框架，去量化深度学习在亲和力和姿态预测上的准确率究竟如何依赖于蛋白家族支持度。Runs N’ Poses研究了姿态恢复与训练相似性的关系，NTAB按配体新颖性分层，Leak-Proof PDBBind构建了保护性划分并重新训练打分函数，但它们都没有审计冻结的前沿模型在整个家族支持度曲线上的表现，也没有加入外部时间评估。Nesso-1的报告明确缺少靶点序列或结构相似性分析，而MIRAGE正好填补了这一空白。

MIRAGE的核心设计是将“历史公开家族支持度”作为一个显式的实验变量。对于某个家族f中的靶点，其公开家族支持度S_f定义为PDBbind中与该靶点在同一MMseqs2 30%序列一致性聚类中的结构数量（包含评估复合物本身），因此单例家族S_f=1，排除查询后的支持度为S_f-1。S_f只统计截至2019年的历史公开支持度，所有评估复合物都是1982至2019年的PDBbind沉积。MIRAGE将S_f分箱为{1, 2–5, 6–20, 21–80, 81–300, 301+}，在每个箱内计算匹配pK窗口[4.5, 8.0]上的Pearson相关系数r，然后定义“家族泛化差距”G_m为最高支持度箱（S_f≥301）与单例箱（S_f=1）的r之差，通过家族-配体两级自助法估计。为了控制直接家族识别，MIRAGE使用家族不相交模型作为阴性对照：一个随机森林QSAR模型（ECFP4加氨基酸组成）和一个配体kNN基线，均在5折家族不相交交叉验证下训练，此外还有家族均值、分子量和clogp等平凡基线。冗余集包含18,759个PDBbind衍生复合物，带有精确Kd/Ki/IC50标签，标注了S_f和配体最近邻Tanimoto相似度，并按支持度×配体相似度分层，从而将两种记忆通道分离。时间集包含649个化合物针对一个低支持度靶点的新发布配体和亲和力系列。Boltz-2和Nesso-1使用公开权重默认设置运行，smina和gnina提供经典经验打分和学习型对接分数，Chai-1和ESMFold2的ipTM作为标记代理进入分析。关键洞察在于：如果模型真正学到了可迁移的结合原理，那么其准确率不应随测试靶点的历史公开家族支持度而剧烈变化；而如果模型主要依赖对已见家族的识别，则准确率会随支持度上升而显著提高。MIRAGE通过匹配分层、家族不相交控制、配体-only基线和时间评估，将这种依赖量化出来，并证明它不能被配体化学、精确靶点重复、测定类型或协变量所解释。

在结果上，MIRAGE揭示了“冗余驱动的膨胀”现象：在Nesso-1的2,147个匹配复合物上，家族泛化差距为+0.446，而随机森林QSAR为-0.082，配体kNN为-0.035，gnina为+0.067，smina为+0.130；与随机森林QSAR的配对差异为+0.528，置信区间[+0.26, +0.75]排除零。在Boltz-2的373个匹配复合物上模式相同但更大，不过其家族平衡端点区间跨零，这是其583复合物覆盖度不足所致而非方向反转。Nesso-1的差距在家族平衡、测定限制和20–50%一致性聚类下仍显著。在协变量调整中，控制配体相似度、蛋白长度、发表年份、家族内亲和力方差、测定类型和亲和力区间后，家族支持度系数对Nesso-1为-0.130（t=-5.1），对Boltz-2为-0.152（t=-3.4），标准误按蛋白家族聚类。在全新家族（S_f≤5）上排名反转：家族不相交随机森林领先两个共折叠模型，对Nesso-1为0.411对0.324，差异+0.087，置信区间[+0.007, +0.167]排除零。在一个外部低支持度靶点上，分子量 alone 的Spearman相关系数达到0.469，Nesso-1为0.486（其自身报告称不具统计说服力），Boltz-2为0.395，gnina、smina、AEV-PLIG和AQ-Affinity均低于分子量基线。在姿态预测中，smina自身显示+0.23的姿态差距（全新靶点62%成功率对冗余靶点86%），作为红对接难度参考；SigmaDock仅增加约0.05的额外差距，DiffDock-L增加+0.13且在全新家族上崩溃到18%成功率，单序列共折叠模型最极端，Boltz-2达到+0.64（全新2%对冗余66%）。一个关键干预是：对Boltz-2提供ColabFold MSA后，全新家族成功率从2%升至46%，而冗余家族成功率恰好保持在66%，姿态G_m从+0.64降至+0.20，效应是单向的，翻转了22/50个全新复合物成功且无一反向。局限方面，家族密度仍是训练暴露的代理而非直接证据，设计无法完全分离记忆与其他家族相关难度；外部时间集只有一个靶点，属于佐证而非群体级证据；smina作为经验打分函数并非自由能计算，两个打分函数不足以建立定律。但MIRAGE的意义在于将基准数字转化为决策规则：在信任学习型打分器或对接器之前，先计算靶点的家族支持度，对于所评估的模型，低支持度下约0.1–0.3的数值比其汇总相关系数更相关于新靶点；选择汇总准确率就是在选择对已解决家族的熟悉度。它建议在开发过程中就使用家族不相交划分进行验证，而不是只在最后；沿着观察到的支持度曲线，增益集中在已经密集的家族而非新颖端，而提供缺失的进化上下文是唯一直接测试的干预。报告学习型方法相对于家族不敏感经验参考的超出量，成本为零且比汇总相关系数说得更多：一个在熟悉家族上击败经验基线但在不熟悉家族上仅匹配它的模型，尚未赢得前瞻性角色；一个在单例家族上击败它的模型，才真正做到了。
