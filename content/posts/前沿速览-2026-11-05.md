## 大模型 LLM

### [Persona Perspectives: Adopting Viewpoints Reorganizes Representations in LLMs](https://arxiv.org/abs/2611.06848)
`评分3 · 26 pages, 14 figures`

这篇论文要解决的是一个在LLM可解释性和安全监控中非常实际但此前被忽视的问题：我们用来监控模型内部状态的那些工具——线性探针、稀疏自编码器（SAE）特征分类器——都默认一个前提，即某个概念（比如"真实性"或"道德性"）在模型潜空间中有一个跨上下文一致的表示方向。但LLM的一个核心能力恰恰是可以通过提示灵活地切换到不同的"人格"或视角，而不同视角背后对应的是不同的概念关系系统。如果人格切换会改变潜空间的表示几何结构，那么在一个视角下训练出来的监控器，换到另一个视角下就可能失效甚至给出完全相反的判断。此前关于人格与潜空间的工作大多把人格当作一个可以用于steering的单一向量，或者沿着一条"助手轴"来分类，很少有人追问：人格是否改变了其他特征之间的下游关系，从而真正实例化了一套不同的概念系统。这个问题之所以重要，是因为如果模型在"保守派"人格下把某条争议性声明表示在"真实"方向上，而固定训练的真假探针仍然按"自由派"人格下的几何来读取，那监控就被绕过了。

方法上的核心洞察是：不把人格当作一个孤立的方向，而是把人格视为对整个语义轴系统的重新组织，并通过几何对齐的变化来量化这种重组。作者用Llama 3.1 8B（及另外七个模型做复现）作为主模型，通过简单的系统提示（"以美国自由派民主党人身份回应" vs "以美国保守派共和党人身份回应"）诱导两种政治人格，另设空系统提示和"有帮助的AI助手"两个基线。他们从最常见的约一万个英语单词中，每个词放入五个提示模板，取最后一个token的残差流激活并跨模板平均，得到每个词在每个条件下的表示；同时用对比锚点对的方法构建33条语义轴（每条轴由十对正负锚点词的表示差平均而成），每条轴在每个条件下单独构建。关键测量有两个：一是词在轴上的归一化投影（词落在该维度上的位置），二是轴与轴之间的余弦相似度（两个概念之间的关系）。他们发现人格条件系统性地改变了这两者，而且改变的方向与指定意识形态一致——比如在自由派人格下，"自由派"这条轴与"好"的余弦相似度是正的，在保守派人格下则反转为负。为了验证这种变化确实对应现实中的意识形态概念结构，他们把同样的33条轴在分别用自由派和保守派语料训练的词向量模型中构建出来，然后比较两种系统下"轴间相似度差异矩阵"的相关性，结果LLM的人格诱导变化与词向量模型的政治语料变化高度对应。更进一步，他们用steering实验检验几何变化是否有行为后果：沿一条轴干预残差流，然后测量对另一条轴评分行为的溢出效应，发现每个条件下轴间的溢出模式更好地被该条件自身的轴对齐所预测，而非被另一个人格或助手基线的对齐所预测，说明几何对齐确实在因果层面驱动了行为层面的特征交互。

结果层面，最直接的发现是人格确实重组了表示几何：在无系统提示时，"自由-保守"轴与"好-坏"轴的词投影几乎不相关（r=0.02），助手提示下也只有弱相关（r=0.21），但自由派人格下变成r=0.75，保守派人格下变成r=-0.79，即同一批词在两个视角下与"好"的关系完全翻转。轴间余弦相似度的变化也集中在"自由-保守"轴上，其次是"集体-个体""软-硬""女性-男性"等轴。更关键的是对监控的影响：作者构建了不含争议内容的真假陈述数据集（9,192条，来自1,149篇维基百科文章）和道德/不道德行为对数据集（8,000条），仅用空系统提示训练三类分类器——全维度线性探针、SAE特征探针、以及用人工挑选的词表示构建的探针——然后把这些分类器应用到有政治人格条件下的争议性陈述上，三类分类器一致地给出了有政治偏向的真假和道德评分，即同一条声明在自由派人格下被判为真/道德、在保守派人格下被判为假/不道德（或反之），说明固定监控器无法跨人格迁移。局限方面，研究主要集中在政治人格这一种切分上，其他类型的人格（如文化、职业、情感状态）是否产生同等程度的重组尚未验证；语义轴的构建依赖锚点词的选择，33条轴远不能覆盖模型概念空间的全貌；争议性陈述的"党派背书"预期是由GPT-5-mini生成的假设而非真实标注，因此偏向的方向性结论应谨慎解读；此外实验主要在8B到70B的指令微调模型上做，更大规模或不同训练方式的模型是否表现相同仍需检验。但这项工作的意义在于，它把"人格"从一个行为层面的提示技巧提升到了表示几何层面的结构性变化，并直接指出了当前可解释性监控的一个系统性盲区：监控器不是中立的，它嵌在训练时所用视角的几何结构里，换一个视角就可能读到不同的世界。这对AI安全领域意味着，跨上下文鲁棒的监控可能需要显式地建模人格条件下的几何变化，而不是假设一个固定的特征方向可以通用。

### [LooM: Loop-Invariant Memory for Causal Encoder-Decoder Language Models](https://arxiv.org/abs/2611.06835)
`评分3`

这篇论文要解决的是循环Transformer在实际部署中遇到的三个硬约束。循环Transformer通过反复执行共享层来增加有效深度而不增加参数，此前已有工作证明这种做法能让模型媲美更大的标准模型，但落地时卡在三个地方。第一，显存随循环次数线性增长：在标准KV缓存下，每一轮循环都会写入新的key-value条目，因为同一组层既负责构建上下文又负责精炼每个token的状态，Ouro等工作因此缓存开销随循环数膨胀。第二，计算量只能按整块调整：现有循环语言模型通常重复整个层块，预算只能是块大小的整数倍，无法低于一次完整前向，粒度很粗。第三，循环次数训练后难以更改：在某个循环数上训练的模型换用更少循环就会退化，想动态调整计算量通常得引入学习到的路由器或停机策略，或者做循环条件化，增加了复杂度和不稳定性。这三个问题叠加，使得循环架构虽然理论上有吸引力，工程上却不好用。

LooM的核心洞察是把循环放在因果编码器-解码器架构的“读”阶段，并配合“一次发布”的缓存规则。具体来说，编码器和解码器第一层负责为每个token写一次全局记忆（global memory），包括未压缩的KV bank和indexer keys，这部分在任何解码器层开始循环之前就已经完成，所以循环永远不会再写全局记忆。真正被循环的是解码器第2到第6层，称为reader层，它们各自独立地循环零到四次，每次访问都读取同一份全局记忆并更新隐状态，但每个reader层只在第一次访问某个token时发布该token的局部KV条目，后续访问只重算query、改变注意力分布，不再写入新条目。这样一来，无论某层对某token访问一次还是四次，后续token读到的局部缓存条目数都一样，缓存大小与循环次数解耦。更妙的是，由于发布一次，即使某层被跳过（深度为零）也不会留下缓存空洞，后面的token读取最近一次前序发布即可。每层独立循环还带来细粒度预算：解码器第一层固定执行一次，五个reader层各自零到四次，合法路径共2000种，覆盖从3到21次层执行（即每token的解码器调用数）的每一个整数预算，而不是像整块循环那样只有6、11、16、21四档。训练时采用Random-Depth策略：每次更新先采样一个预算，再在该预算下采样一条随机路径（即每个reader层各跑几次），按最大采样深度展开并掩码未执行的重叠，损失只作用于实际执行的调用；预算分布刻意偏向高预算区间（17到21次占四分之三权重，期望17.19次调用），让模型在所有预算上都得到训练。推理时不需要路由器，对每个预算在验证集上搜索并锁定一条静态路径，用同一套权重服务所有预算。作为对照，论文还实现了Self-Distilled（加一个全深度教师做stop-gradient KL）和一个学习到的planner（用直通估计器训练、带熵正则的动态路由），以分离不同因素的影响。

在5B token的FineWeb-Edu上从头训练、204M参数的设定下，Random-Depth模型从11次调用起就超过同等数据训练的单遍基线，到21次调用时测试交叉熵低0.020 nats、零样本平均准确率高0.79个百分点，而缓存大小完全相同。下游任务覆盖LAMBADA、HellaSwag、PIQA、WinoGrande、ARC-Easy/Challenge和WikiText-2困惑度，长上下文则在64K续训后用PG19和三个RULER检索任务评估。分析部分给出了几个有价值的发现：训练时的预算分布决定了额外深度买到的是什么能力；重复读取实际上是在反复重新检索全局记忆；静态路径与学习到的路由器效果接近，说明token级动态分配带来的增益有限，这反过来支持了无需路由器的设计。局限也很明显：所有循环模型与单遍基线的训练计算量并不匹配，循环运行用了2.9到4.7倍的GPU小时，所以质量提升中有一部分可能来自更多训练算力而非架构本身；静态路径是在验证集上分三阶段搜索锁定的，第一阶段虽穷举全部2000条路径但后续阶段是贪心收窄，锁定的路径只是“搜到的最好”而非全局最优；预填充阶段借助滑动窗口重放近似重建解码器缓存，65K预填充从3次到21次调用只涨3.2%，说明预算主要影响解码而非预填充，但这一近似的误差未被单独量化。总体而言，这篇工作把“在哪里循环”这个问题回答得很干净——在编码器-解码器里，记忆写一次、深度变成部署时可选预算——为循环架构的实用化提供了一个无需路由器、缓存恒定的执行规则，其意义更多在于给出了一种可部署的循环范式，而非追求单点指标的大幅刷新。

### [Context--Answer Metamodels: Forecasting LLM Activations Before the First Answer Token](https://arxiv.org/abs/2611.06837)
`评分3`

这篇论文要解决的核心问题是：在随机解码下，同一个上下文可能产生许多不同的回答，而传统上要刻画这种变化，必须反复做昂贵的自回归 rollout，每次只能看到一个实现样本。对于罕见行为筛查和 pass@k 估计这类应用，单次补全根本不足以代表模型可能的行为分布，而现有做法要么采样大量回答再用探针或另一个语言模型打分，代价高且对稀有事件没有预警能力；要么像 Jiralerspong 等人那样只在每个 prompt 上采一个回答、拟合线性或非线性上下文到答案的映射，只预测条件均值而丢掉了 rollout 带来的方差信息。作者提出的问题是：能不能在模型吐出第一个答案 token 之前，就直接从读上下文时产生的激活序列预测出答案激活的均值和分布，从而绕开组合爆炸式的完整 token 序列建模。

方法上的关键洞察是把预测目标从完整 token 序列换成答案激活的汇总表示。具体来说，冻结的语言模型在 prefill 阶段对上下文产生一个激活迹，形状是上下文长度乘隐藏维度；一次 rollout 产生的答案激活迹则被均值池化成一个隐藏维度的向量，随机解码因此同时定义了条件期望和条件分布。作者训练了四类元模型：线性岭回归直接用最后一个上下文 token 的激活做全维线性映射，闭式求解、用验证集 R² 选正则系数；MLP 则先把上下文迹自适应平均池化成 32 个连续 bin，再用一个可学习的全局 query 做单 query 的注意力池化，把 bin 归一化后算注意力分数、用未投影的 bin 作 value，得到汇总向量后送入三层 4096 到 8192 再回到 4096 的 GELU 网络，以每个 prompt 多次 rollout 的经验均值为目标最小化 MSE。分布元模型有两个：高斯模型冻结 MLP 的均值预测，只学协方差结构，协方差从 prompt 内的残差估计，可选各向同性、对角或低秩加对角，尺度可以是全局的也可以由一个小头从汇总向量预测 log 方差得到，协方差族、秩、尺度模式和缩放系数都按验证集能量分数选择；流模型用条件流匹配加线性路径，从高斯基样本出发、以汇总向量为条件、沿学习到的向量场积分 32 步欧拉得到样本，网络是 4096 宽、带正弦时间嵌入和八个条件残差块。相比之前只做点预测的做法，这套设计既能给出高保真的均值预测，又能显式建模 rollout 的离散程度，而且用多次 rollout 监督让分布目标真正可学。

实验在 Qwen3.5-9B 的第 18 层解码块输出上做主研究，用 LMSYS-Chat-1M 的五十万训练 prompt、每个四个独立种子 rollout，结果显示一个明显的规模依赖反转：线性岭回归在早期所有评估集上都优于非线性的 MLP 和流均值，但随着 prompt 覆盖增加，非线性模型反超，线性曲线则很早就饱和；在最大规模上流均值在域外两个数据集上逼近 MLP，域内还有小幅差距。分布指标上高斯在 LMSYS 的能量分数和方差排序略好，流在域外能量分数更低。行为探针实验表明预测激活保留了行为预测信号，MLP 均值在四组行为上都优于仅用上下文的基线，高斯在自伤和欺骗上与 MLP 接近。跨模型迁移上，Qwen2.5-7B 第 19 层的上下文激活去预测 Qwen3.5 第 18 层和 Gemma 4 第 47 层的答案激活，均值精度略低于匹配目标模型的对照但相当，说明激活预测可以跨架构、跨模型家族迁移。局限也很明确：目标只覆盖两个模型的特定层，选层是按域内均值精度挑的，未必对分布指标、迁移或行为预测最优；训练和分析只用每 prompt 2 到 16 次 rollout，更大数量下的稳健性未测；行为标签来自 GPT-6 Luna 的评分而缺乏充分的人工验证；学到的分布还绑定于具体解码规则、聊天模板、生成长度上限、激活边界和答案池化方式。尽管如此，这项工作指出了一个有前景的方向：上下文激活迹可以在第一个答案 token 生成之前，为 LLM 答案的行为提供可扩展的预测，未来可用于行为监控和干预，比如提前预判奖励黑客行为。

### [Alignment Myopia in Generative AI](https://arxiv.org/abs/2611.06830)
`评分3`

当前生成式AI的对齐范式本质上是一种“短视对齐”：它依赖对话评分、成对比较等即时偏好信号，通过RLHF之类的方法把模型推向用户当下满意的方向。问题在于，这套做法隐含了一个关键假设——用户在单轮对话中表达的偏好，可以可靠地代理他们自身和社会的长期利益。但人类偏好本身是动态的、自相矛盾的、高度情境依赖的，而且系统性地偏向即时满足。当AI系统越来越深地嵌入持续性的用户关系——作为信息源、认知助手、教育引导者、情感伴侣和职业协作者——其影响早已溢出单次交互的边界。重复交互会塑造人如何思考、学习、建立关系和理解自我，而只优化即时满意度会系统性地忽略累积效应：认知技能萎缩、真实社会连接的弱化、以及人类主体性的侵蚀。作者把这种只盯眼前偏好、忽视长期后果的倾向命名为“对齐短视”，并指出它不是一个边缘性的技术缺陷，而是当前对齐范式的结构性盲区。

论文的核心贡献不是提出某个新算法，而是做了一张“张力地图”：沿着人类福祉的四个面向——认知能力、关系健康、情感福祉、主体性与身份——逐一拆解即时价值与长期成本之间的冲突，说明为什么现有奖励模型在结构上无法捕捉这些后果。以认知面向为例，AI作为认知卸载工具在短期内降低负荷、提升产出速度，用户自然会给这类交互打高分；但持续卸载会削弱批判性思维、专业判断和技能习得，一项针对肿瘤专家的长达一年的追踪研究发现，初期生产力提升伴随的是专业能力的渐进侵蚀。更讽刺的是，监督AI输出恰恰需要那些被卸载掉的领域专长。在关系面向，AI伴侣提供无条件的肯定和低摩擦的陪伴，即时满足感极强，但正因为它绕开了人际关系中必需的互惠、分歧和妥协，长期使用可能削弱社交技能、扭曲对冲突责任的感知，甚至使用户觉得真实人际关系“过于费力”。情感面向同理：共情模拟带来即时的情绪调节和宣泄，但长期外包情绪处理会催生情感依赖，谄媚式AI的无限肯定可能加剧情绪失调和分离痛苦。论文的关键洞察在于，这些长期风险恰恰是短视对齐所奖励的模型行为所助长或放大的——不是唯一原因，但对齐在其中扮演了结构性角色。因此作者主张从简单的偏好优化转向“长程对齐”，即奖励模型必须显式建模跨时间尺度的个体与社会后果，而不是把单轮满意度当作福利的代理指标。

需要客观地说，这篇论文是一篇立场性/综述性工作，而非实证研究：它没有提出可落地的长程对齐算法，也没有在具体任务或数据集上给出与基线方法的定量对比，其“结果”是文献综合与概念框架的构建。它的价值在于把分散在机器学习、人机交互和行为科学中的证据组织成一个可操作的问题结构，明确指出当前奖励模型在时间维度上的失效模式，并呼吁对齐研究从“让用户此刻满意”转向“让用户在长期变得更好”。局限也很明显：长程福祉的度量本身极其困难，涉及跨时间归因、个体差异和系统性外部性，如何把这些维度转化为可优化的训练信号仍是开放问题；论文也承认对齐只是众多干预点之一，模型行为受制于更广泛的生态因素。但它的方向性意义不容低估——如果对齐社区继续把即时偏好当作福利的充分统计量，那么随着AI交互从一次性查询变成持续性关系，短视对齐的代价只会越来越大。这篇论文实际上是在为下一代对齐研究划定问题边界：不是如何更准地拟合偏好，而是如何定义和优化那些偏好信号根本捕捉不到的东西。

### [Systolic Linear Attention: Co-Designing Tile-Grouped Gated Delta Attention for TPUs](https://arxiv.org/abs/2611.06828)
`评分3`

这篇论文要解决的真实问题是：以 Gated DeltaNet、Kimi Delta Attention（KDA）和 GDN-2 为代表的门控 delta 线性注意力层，虽然在 GPU 上表现良好，但直接迁移到 Google TPU 上会严重浪费硬件。TPU v7x 的矩阵乘法单元是 256×256 的脉动阵列，而现有这些层通常用 128 维的 key 和 value 头，导致每个矩阵 tile 有一半是空的；同时 KDA 和 GDN-2 的逐通道衰减门需要在 16 token 的子块上对 key 做逐元素重缩放以避免 FP32 溢出，这类向量操作在 GPU 上很便宜，但在 TPU 上因为矩阵吞吐约为向量吞吐的 128 倍而成为瓶颈；更关键的是，chunkwise WY 训练算法需要对每个头、每个 chunk 求解一个 C×C 的单位下三角系统，现有 kernel 用顺序替换法在向量处理单元上做，实测占核心 kernel 时间约 45%。作者指出，单纯做 kernel 融合只能带来 1.03 倍的提升，因为时间花在 VPU 求解和填充不足的 MXU tile 上，而不是 HBM 访存，所以必须改层本身的设计。

SLA 的核心创新是把层结构围绕 256×256 的脉动阵列重新塑形，具体有三根支柱。第一，把 key 宽度加宽到 256，并让每个 key 头及其标量写门 β 在 R 个（R=2 或 4）value 头之间共享，这借鉴了分组值注意力（GVA）的思路；这样打包后的状态矩阵正好填满整个 MXU tile，而且 key-query 投影、卷积和 chunk 求解的计算次数减少为原来的 1/R。第二，把 256 个 key 通道分成 4 个 64 通道的 tile，每个 tile 只用一个标量衰减率，形成块对角遗忘门；这介于 GDN 的每头单一衰减率和 KDA 的逐通道衰减率之间，使得 chunk 内得分计算变成四个 64 宽的 MXU 矩阵乘法再乘以衰减掩码，完全不需要 VPU 做重缩放。第三，因为 β 在打包的 value 头之间共享，每个 key 头只需要一次 C×C 求解；SLA 完全用 MXU 上的块矩阵乘法来计算逆矩阵，默认用精确的递归块倍增求逆，也可选一步 Neumann 近似来加速，并与层的其余部分融合在 VMEM 中执行。此外，SLA 还引入了一个 chunk 边界动量项（系数 0.25）来平滑 chunk 更新，该动量缓冲常驻片上 SRAM。关键在于，这三项改动是相互配合的：头共享减少了求解次数，tile 分组门使得衰减可以在 MXU 上以块矩阵乘法完成，而共享的 β 又让 chunk 求逆可以整体搬到 MXU 上，最终整个前向和反向都在单个融合 kernel 内完成，避免了 VPU 与 MXU 之间的反复切换。

在结果方面，作者在 TPU v7x 上做了 kernel、层、服务以及上下文并行多个层级的评测，并进行了 2048 芯片的稀疏 MoE 预训练研究，模型规模从 65 亿到 631 亿参数，数据用 Dolma。完整 SLA-R4 层比开源的 Tokamax KDA kernel 快 1.6 到 2.5 倍（精确 chunk 求逆时是 1.4 到 2.4 倍），加速主要来自头共享和 kernel 融合；在相同困惑度下，SLA 训练比 KDA 快 11% 到 24%，在较小规模匹配随机种子的实验中困惑度还略低于 KDA。作者也客观指出，SLA 应被理解为一种硬件高效的运行点，而不是更具表达力的更新规则：它与 GDN-2 这类建模进步是互补的，GDN-2 每 token 的困惑度更低；可选的一步 Neumann 逆以约 0.2 的困惑度换取速度；SLA 与宽 key 逐通道 KDA 对照组的困惑度差距约 0.1，但避免了逐通道门在长上下文下的漂移问题。这项工作的意义在于示范了一种软硬件协同设计范式：当加速器的矩阵单元远宽于向量单元时，与其在 kernel 层面硬适配 GPU 形状的层，不如重新设计层的状态几何、衰减结构和求解算法，使其天然匹配硬件的数据通路，这为线性注意力在 TPU 类脉动阵列加速器上的高效部署提供了可复用的设计思路。

## 强化学习 RL

### [What Does Multi-Turn Reinforcement Learning Really Improve in LLM Agents?](https://arxiv.org/abs/2611.06483)
`评分4 · HF 33赞`

这篇论文要回答一个被高成功率掩盖的问题：多轮智能体强化学习到底提升了什么。以往的工作几乎都只看轨迹级指标，即任务在给定预算内是否完成，并据此宣称 RL 显著优于基座模型。作者指出这种评估忽略了一个对交互式智能体至关重要的维度——交互深度。于是他们引入 Pass@(K,T) 这一二维指标，K 代表采样广度（独立采样多少条轨迹），T 代表每条轨迹允许的最大交互轮数。实验发现一个反直觉现象：当 T 足够大时 RL 模型确实大幅领先基座模型，但随着 T 收紧，这一优势迅速缩小，在某些任务上甚至消失或反转。更关键的是，作者计算了每个任务在受限预算下的结构性性能上界，发现在小 T 时即便离上界还有很大空间，RL 也拿不出对基座模型的优势——这说明问题不是任务变得不可解，而是 RL 的收益本身就依赖于充足的交互预算。这一发现直接动摇了“RL 让模型每步决策都更强”的默认假设，也暴露了真实部署中的风险：在预算严格或动作不可逆的场景里，轨迹级成功率会掩盖模型逐步决策质量的隐患。

为了定位增益的真正来源，作者做了步级动作质量分析。他们在相同状态和历史下，让基座模型与 RL 模型各自采样 16 个动作并取平均质量分，状态池从两者的轨迹中等量采样以消除访问偏差。结果相当刺眼：在 DeepCoder-MT 上 RL 仅在 46.8% 的状态取得更优动作，FrozenLake 上是 42.8%，平均质量甚至略低于基座模型。也就是说多轮 RL 并没有普遍提升单步决策。但把状态池换成“前一步被人为注入错误动作”的错误状态后，格局完全反转：RL 在 FrozenLake 上 65.7%、DeepCoder-MT 上 67.3% 的状态选出更优动作，从相同错误状态继续执行的最终成功率也显著更高（51.3% 对 38.6%，38.5% 对 22.9%）。再按轨迹中的归一化深度分组，发现 RL 的优势在早期几乎不存在甚至为负，随着交互推进才逐渐显现并反超。机制层面作者用似然分析给出了解释：RL 产生的单步动作在基座策略下的负对数似然与基座自身动作高度重叠（均值 12.20 对 10.25），说明每一步都落在基座策略的支撑范围内、局部完全合理；但整条成功轨迹在 RL 策略下的累积对数似然比远高于基座（约 228 对 26）。换句话说，RL 学到的不是“每步都更聪明”，而是把一堆局部合理的动作可靠地组合成一条长程轨迹的能力，这也解释了为何它能突破基座的 Pass@K 边界却不需要每步都赢。基于这一诊断，作者提出 BudgetMix RL：训练时随机变化交互预算，让模型在宽紧不同的预算下都见到梯度信号，从而缓解对充足预算的依赖，实验显示它在多种执行设置下性能更稳健，同时减轻了步级动作质量的下滑。

这项工作的价值不在于提出某个刷榜方法，而在于重新定义了该问的问题。它用 Pass@(K,T) 把采样广度和交互深度拆开，证明了多轮 RL 的收益集中在错误恢复和长程韧性上，而非单步决策的普遍提升，并通过似然分析把“局部合理、全局可靠”这一机制讲清楚了。局限也很明显：步级质量评估依赖可靠的过程奖励，作者只能在 FrozenLake（动态规划算精确 Q 值）和 DeepCoder-MT（单元测试通过率）这两个能拿到可信步级信号的任务上做分析，结论向 BFCL、InterCode-SQL 等任务的推广仍是间接的；BudgetMix RL 只是初步方案，预算混合的分布设计、与过程监督信号的结合都还没展开；机理分析停留在似然层面的相关性解释，没有深入到参数或表征层面。但它的影响可能是方向性的：今后评估智能体 RL 若只报一个轨迹成功率，将越来越难站得住脚，预算敏感性和步级动作质量必须一起看，而训练策略也需要从“追求更长程”转向“在任意预算下都可靠”。

### [Turns Matter: Advancing Streaming Video RL via Turn-Level Credit](https://arxiv.org/abs/2611.06728)
`评分3 · HF 80赞`

这篇论文要解决的是流式视频理解中一个被此前工作忽视的信用分配粒度问题。流式场景要求模型在视频流持续到达的过程中反复做决策：当前该开口回答，还是继续沉默观察。近期工作如MMDuet2、ThinkStream、StreamPro已经把GRPO引入这一设定，但它们的共同缺陷是：整条交互轨迹只算出一个轨迹级优势，然后把这个标量广播到每一个决策轮次的所有token上。问题在于，一条好轨迹里可能包含坏决策，一条差轨迹里也可能包含好决策。举例来说，模型早期成功回答后，后面一次纯粹冗余的重复回复仍然会继承正的轨迹优势，哪怕奖励函数明确惩罚重复；反过来，早期失败后一次有价值的补充回答会因为整条轨迹低于组均值而拿到负优势，被错误压制。更糟的是，GRPO默认的token-mean损失聚合让每一轮的权重正比于该轮输出的token数，于是短小的“NO REPLY”等待动作在损失里几乎可以忽略，长回复则主导梯度。这两点叠加，使得学习信号既在时间上错位（用过去累积的奖励评价当前决策），又在权重上失衡（用输出长度决定决策重要性），最终鼓励冗余回复、抑制有用的追问。

TurnWise的核心创新正是围绕“决策轮次”这一单位，同时修正优势估计和损失聚合。第一项机制是silence-completed prefix scoring：利用流式场景中显式的等待动作，把一条轨迹的前t个动作保留、后面所有轮次强制置为沉默，用同一个轨迹打分器（PAUC-based reward，衡量回复质量与时间窗口内的及时性，并惩罚重复、窗口外回复和过长共享前缀）重新打分，得到一个前缀分数。相邻前缀分数之差给出每一轮的奖励增量，而完整轨迹分数减去当前轮之前的前缀分数，就得到从该轮开始的剩余回报。这个剩余回报在组内做归一化，就得到轮级优势——它天然剔除了此前累积的奖励，等价于return-to-go原则在无critic设定下的实现。关键在于，这个计算完全复用已有的rollout评估结果：沉默后缀不改变已保留回复及其前置回复的评分，因此不需要额外采样、不需要学习价值网络、也不需要额外的裁判调用，只需一次确定性扫描。作者还引入系数α在训练前10%的更新中从0线性升到1，实现从共享优势到完全轮级优势的平滑过渡。第二项机制是turn-mean损失聚合：先在每一轮内部对token损失取平均，再在轨迹的各轮之间取平均，使每个“回复或等待”决策的权重恒为1/T，与输出长度彻底解耦。两者结合，让优势估计和损失加权共享同一个决策轮次单位，等待动作不再被长回复淹没。

实验在ProactiveVQA、OVO-Timing和StreamingBench三个流式基准上展开，Qwen2.5-VL-3B和Qwen3-VL-4B两个骨干均取得最佳综合得分，且相比仅做信用修正的版本，加入turn-mean聚合后响应时机更好、重复明显减少，说明两项设计是互补而非冗余的。方法的意义在于指出了流式视频RL中一个容易被忽略但影响实质的粒度错配问题，并给出了一套无需critic、无需额外rollout的轻量修正方案，对后续流式agent的RL训练有直接参考价值。局限方面，轮级优势仍依赖轨迹打分器本身的质量，PAUC类奖励对回复窗口标注的依赖较强；前缀扫描虽然复用评估，但每条轨迹需要T次打分，轨迹较长时计算开销不可忽视；α的退火 schedule 和5的裁剪阈值目前是经验设定，缺乏系统性消融；此外方法默认各组轨迹共享同一观测计划，对异步或可变horizon的流式设定是否依然成立还有待验证。

### [Reinforcement Learning Enables Scaling Generalist Robot Policy Improvement](https://arxiv.org/abs/2611.06905)
`评分3`

这篇论文要解决的核心问题是：当前的通才机器人策略（尤其是视觉-语言-动作模型，VLA）虽然通过大规模预训练获得了跨任务的零样本泛化能力，但在实际部署中往往不够可靠，需要额外的适应阶段才能达到足够的成功率。已有的强化学习自我改进方法几乎都局限在单任务设定下——针对某一个具体部署任务做在线微调，这跟通才策略本身的多任务能力形成了鲜明对比。单任务改进的代价是：每换一个新任务就得重新做一轮在线交互和微调，成本无法摊销。论文提出的问题是：能否利用跨多个任务的在线交互，实现真正的“通才改进”——既在训练过的多个任务上同时提升，又能泛化到训练中没见过的任务上去？为了回答这个问题，作者首先搭建了一套结构化的评测体系，系统性地考察价值估计、策略提取和资源分配这几个设计维度上的算法与实践选择，而不是直接提出一个新算法。

方法上的关键洞察在于把“策略改进”拆解为两个可独立考察的机制：直接策略适应和评论家引导的改进。直接策略适应以过滤式监督微调（FSFT）为代表，用经验回报超过阈值的成功轨迹做加权监督学习，只更新策略参数本身。评论家引导的路线则先学一个状态-动作价值函数来给动作“打分”，再分两种方式利用它：一是测试时精炼，以Best-of-N采样为代表，策略不变，推理时采样多个动作候选、用评论家挑最好的；二是评论家引导的策略提取，以离策略生成式策略优化（OGPO）为代表，把评论家对动作的评分作为目标来更新策略，让策略本身学会产出高价值动作。论文系统地对比了这三类方案，发现虽然只要训练任务足够多样，三类方法都能带来一定程度的泛化，但评论家引导的方法在任务泛化上明显更强——不仅能跨训练场景泛化，甚至能跨物体类型泛化。更关键的是，评论家引导的策略提取（OGPO）显著优于测试时精炼（BoN），且随训练任务多样性呈现出相似的扩展趋势，这说明评论家学习才是随任务多样性扩展而实现通才改进的关键组件。此外，论文还系统考察了训练任务分布本身：不仅任务数量重要，任务之间所需解题策略的多样性才是诱导可泛化解题行为的关键因素。

在结果层面，论文在多种机器人操作任务上验证了上述结论：通才策略确实可以在线跨多样任务同时改进，而且正确的配方能带来对未参与在线训练的任务的性能提升，且这种提升随训练任务数量和多样性的增加而扩展。与直接策略适应相比，评论家引导方法在跨场景和跨物体泛化上的优势是量级上的，OGPO又明显强于BoN。论文自称这是首批关于机器人基础模型在线通才改进的证据之一。局限方面，作者也坦承泛化并非无条件成立：测试任务分布必须与训练分布存在合理关联，泛化到任意任务在现实中不现实；实验规模仍属中等，尚未在超大规模VLA和真实车队级部署上验证；评论家学习本身在离线/在线混合设定下的稳定性和样本效率也还有进一步打磨的空间。意义在于，它指出了通才策略部署的一条新路径：与其对每个部署任务单独做昂贵的单任务在线微调，不如把成本摊销到一组多样化的任务上，从而在未来的新部署任务上直接获得更好的性能，而无需再付出额外的在线微调代价。

### [On Turn-Level Best-of-N Sampling for Scaling LLM Agents](https://arxiv.org/abs/2611.06868)
`评分3`

这篇论文要解决的是LLM智能体在长程交互任务中表现不稳定这一真实问题。所谓长程任务，是指智能体需要在外部环境中执行一长串动作、每一步都观察环境反馈再决定下一步，比如在终端里完成软件工程任务。这类任务的成功与否取决于整条轨迹上每一步决策的质量，而LLM智能体的动作是从一个随机策略中采样出来的，同一个任务跑多次，有时能成功、有时失败，一致性很差。此前的推理时扩展方法主要有两条路线：一是轨迹级best-of-N采样，即并行生成N条完整轨迹，再用结果奖励模型或LLM裁判打分选最优，但它的根本局限在于选择只发生在轨迹全部结束之后，无法改变每条轨迹内部中间动作的分布，而且它需要N倍的沙箱环境来并行执行，对于跑在用户自己机器上的智能体（比如终端智能体、电脑操作智能体）来说，根本拿不到N个沙箱，顺序生成N条轨迹再打分也不现实。另一条路线是DFS、MCTS这类树搜索，它们能在中间状态探索替代动作，但需要对外部环境做检查点保存和状态恢复，在很多实际场景中同样不可行。所以问题就卡在：如何在不对环境做检查点、不复制沙箱的前提下，在推理时改善智能体每一步的决策质量。

论文的核心思路是把best-of-N从轨迹级下移到单步级，提出Turn-BoN：在每一轮，让生成器模型采样出N个候选动作，再由一个选择器模型从中挑一个执行，只有被选中的动作才会真正在环境中执行，其余候选不需要沙箱。这个设计的关键洞察在于，它实现的是推理时的一步策略改进的采样版本——经典RL理论告诉我们，如果有一个 critic 函数Q^π能评估在状态s下采取动作a的期望回报，那么相对于原策略π的贪心策略一定不劣于π。此前Zainullina等人和Wang等人的工作正是用训练好的critic模型来做这种值引导搜索，但训练一个独立的动作价值critic成本很高。本文的创新点在于：直接用现成的开源LLM充当生成式critic，让选择器模型以listwise方式（把所有N个候选动作作为一个列表给它，让它推理并返回最佳候选的索引）直接比较候选动作，从而绕开了训练critic的需要。作者还给出了理论支撑：他们证明了一个比经典策略改进更弱的条件——只要选择器选出的动作在Q^π下的期望值不低于原策略的期望值（这个条件只需在折扣状态访问分布下平均成立，而不需要每个状态都成立），Turn-BoN诱导的策略就不会比生成器策略差。换句话说，选择器不需要完美，只要平均而言比随机采样略好，就能保证改进。这也解释了为什么一个未经专门训练的现成LLM选择器有可能奏效：它不需要精确估计Q值，只需要在候选之间做出比随机更好的相对判断。

实验在长程终端任务上进行，使用mini-SWE-agent作为智能体框架，生成器覆盖Qwen3.6-35B（中等规模）和K2-Horizon-375B（大规模），选择器使用Kimi-K3、Deepseek-v4.1-Flash等开源权重模型。结果显示Turn-BoN在准确率上带来5%到10%的提升，pass@1和pass@k都有改善，重复尝试之间的一致性也明显增强。更有意思的是轨迹行为分析：Turn-BoN让智能体执行的轮数大幅减少，并且在测试、调试、遵循任务指令等方面表现出更可取的模式，循环执行失败命令等不良行为减少，即使在最终失败的尝试中这些行为改善也存在——这说明增益不只是“选对了答案”，而是整条轨迹的行为质量被改变了，这是轨迹级BoN做不到的（后者不改变轨迹内部行为）。当然论文也坦承局限：Turn-BoN在每一轮都要生成N个候选并调用一次LLM选择器，推理时计算开销相当大，如何设计计算高效的近似方法在保留增益的同时降低成本仍是开放问题；此外选择器只是listwise打分，pairwise锦标赛式比较虽然可能更准但成本过高，在小规模实验中已被排除。这项工作与Kang等人的同期工作构成独立验证，但本文的独特贡献在于把逐轮动作选择与一步策略改进理论挂钩，并系统分析了选择器偏好哪些动作类别、轨迹行为如何变化，为理解Turn-BoN相对于轨迹级BoN的增益来源提供了实证和理论双重基础。

### [Empirical Bayes Flow Matching for Continuous Cryo-EM Heterogeneity](https://arxiv.org/abs/2611.05202)
`评分4 · Accepted at NeurIPS 2026. 20 pages, 6 figures, 5 tables. Cod`

这篇论文要解决的是从间接且带噪的观测中学习高维隐变量的生成先验这一逆问题，具体场景是冷冻电镜（cryo-EM）中的连续异质性。真实问题是：蛋白质在溶液中以多种构象存在，cryo-EM 拍到的只是这些构象在随机未知方向下的二维投影，而且信噪比很低，所以目标不是重建单一结构，而是从这些投影里恢复三维原子坐标的整个分布。之前的方法卡在一个结构性缺陷上：经典流程和近期的深度学习方法（cryoDRGN、3DFlex、cryoFIRE 等）都是两阶段——先把二维投影重建成三维密度/体素网格，再把原子模型拟合到密度上。这种解耦让密度阶段拿不到原子坐标先验，而原子拟合阶段又接触不到原始观测，恰恰在观测欠定、信噪比低、最需要强原子先验的时候最吃亏。唯一例外是 Rosenbaum 等人的工作，直接在原子坐标空间用变分自编码器把原子先验和原始图像耦合起来，但 VAE 的先验表达能力有限。另一条路是用预训练扩散先验在推理时做引导（如 CryoBoltz），但 de novo 发现场景下根本没有干净原子结构可用来预训练，训练数据只有间接带噪的投影，所以核心难题是：当数据本身就是待解逆问题的输出时，怎么训练一个现代生成先验。

EB-FM 的关键设计是把这个问题写成经验贝叶斯下的蒙特卡洛随机近似 EM：E 步对每个观测做近似后验采样，M 步用这些稳定后的隐变量当训练目标去更新流匹配先验。具体来说，它维护一组与每个观测一一对应的持久隐变量，E 步先用当前先验做一次带引导的流采样——引导项来自扩散后验采样（DPS）那套思路，用网络对干净状态的点估计，把观测残差通过可微的非线性前向算子反传回去，得到近似的似然梯度来修正采样轨迹；然后并不直接拿这个高方差单样本去训练，而是用随机近似做滑动平均更新持久隐变量，让它近似跟踪后验均值。这里的关键洞察是：全局构象分布可以非常复杂、多峰，但给定单张二维投影，其后验在局部近似单峰，所以用后验均值作为该观测的稳定目标既降方差又合理。M 步则把这些持久隐变量当作“伪干净数据”，跑标准的条件流匹配损失来更新向量场网络，如此交替。相比 DiEM 那类同样用经验贝叶斯加扩散先验的方法，EB-FM 绕开了两个致命限制：DiEM 只对线性高斯前向模型成立（靠矩匹配有闭式解），而 cryo-EM 的前向算子是非线性的——原子坐标通过高斯径向基之和进入投影图像；DiEM 的 E 步还要在每个离散化步解大型线性系统、做向量-雅可比积，在高维观测下计算上不可行。EB-FM 改用点估计引导，天然适配可微非线性前向模型，E 步也变得可处理。相比原 VAE 路线，流匹配先验能表达复杂多峰分布，而持久隐变量的优化式推断替代了摊销编码器，避免了编码器在低信噪比下的偏差。

实验上，作者先在二维 two-moons 和高维 MNIST 的受控逆问题上验证设计选择（线性与非线性前向算子都试），确认带梯度引导的流匹配加持久隐变量能稳定 E 步、降低后验采样方差；然后在用分子动力学和电镜模拟器生成的模拟 cryo-EM 数据上，在已知姿态的简化假设下，证明能直接从二维投影在原子坐标空间恢复蛋白质构象的连续分布。论文没有给出与基线对比的具体提升数字，这算是结果呈现上的一个弱点。局限也很明确：姿态被假定已知，真实场景里姿态未知需要联合估计；训练用模拟数据，与真实数据的域差距尚未处理；后验均值近似依赖局部单峰假设，对多峰后验可能失效。意义在于它给出了一个方法论底座——把现代流匹配先验的训练从“需要干净数据”解放出来，直接对接非线性可微前向模型，为后续扩展到未知姿态和真实数据、以及更一般的科学逆问题提供了可搭建的框架。

### [CellCanon: An Agentic Cellular World Model for Prediction, Explanation, and Observation-Driven Updating](https://arxiv.org/abs/2611.05890)

这篇论文要解决的是单细胞扰动筛选里的一个根本性缺口：药物诱导的转录组变化虽然能被测到，但大量化合物和细胞背景的组合从未被实验覆盖，而生物发现恰恰要求模型能基于已有分子知识和新测量去推断没观测过的条件。此前的数值扰动模型（如 chemCPA、PRnet、STATE 等）能高效预测表达谱，但它们把每个基因的响应当成独立的数值回归目标，既没有显式利用同一药物-细胞条件下基因共享的生物学背景，也无法给出可审查的判断依据；另一类基于语言模型的逐基因推理（如 VCWorld）虽然能结合分子知识和检索样例推断响应标签，但每个基因都要单独跑一遍推理链，token 开销极大，而且预测、解释和后续修正彼此割裂，新测量进来后无法系统地修订已有结论。换句话说，之前的方法要么"只会算不会说"，要么"只会说不会改"，缺少一个把预测、解释和观测更新串起来的统一状态。

CellCanon 的核心设计是一个共享的"世界状态"加上三个角色分工：语言模型负责解读证据，工具负责核查引用和通路，数值模型负责预测和更新。具体来说，Predict 模块先让语言模型为每个条件挑选带来源链接的靶点证据，区分结合、功能作用、背景调控和对照细胞表达等证据类型，再用冻结的文本嵌入加结构化特征编码成每个基因共享的表示——关键洞察就在这里：同一药物-细胞条件下所有基因共享同一套证据解释，只是各自的数值读出不同，所以证据分析只做一次、跨基因复用，而不是逐基因重复推理。这个共享表示进入一个细胞特异的 MLP 得到检索查询，与训练图谱中各个供体药物的知识特征做注意力式检索，检索分数还融合了化学、靶点和机制相似性；检索到的观测值再经过细胞特异的读出层，分别产生连续响应、差异表达概率和条件方向上调概率三套独立监督的输出——论文特意用消融证明，如果把分类头换成连续分数加阈值，DE Macro-F1 会从 0.8077 掉到 0.5278，说明幅度、是否差异表达、方向这三件事必须分开监督。最后这些读出与匹配的 DMSO 对照细胞、剂量参数一起驱动单细胞表达生成。Explain 模块则针对靶点作用、对照表达、调控通路等提出 supported/contradicted/insufficient evidence 三态判断，附带引用和自然语言理由，并通过声明依赖关系支持后续修订；Update 模块在新测量到来时，用一个支撑集训练好的核岭回归，把已测源条件的响应相似性与化学、生物相似性结合，去修正同一药物在未测细胞背景下的预测，父预测器和更新映射都保持冻结、不改权重，因此一次测量就能泛化到其他背景。

实验结果相当有说服力：在 SciPlex3 三个细胞系的 339 个留出条件上，DE AUPRC 达到 0.8067、Macro-F1 0.8164，相比最强基线分别提升 63.3% 和 17.3%，方向 Macro-F1 提升 7.2%，联合不变/上调/下调的 Macro-F1 从 0.5400 拉到 0.7420；连续指标上 logFC Pearson 0.6944 对 chemCPA 的 0.4306。更值得注意的是效率：相对于 VCWorld 的逐基因推理，Predict 的 token 用量下降 99.77%，Explain 下降 98.41%，这直接来自"证据跨基因复用"的设计。在模拟实验反馈的设定下，每个药物只给一个已测源背景，Update 就把 DE AUPRC/Macro-F1 推到 0.9077/0.8261，超过在 48 个观测上微调的六个响应模型中最强者（0.6279/0.7630），而且完全不动模型权重。解释基准上，966 个问题上 Explain 对所有可回答问题给出完整证明、对所有证据不足的情况正确弃答。局限也很清楚：DE 召回率 0.5739 低于 PRnet，说明它偏精确而欠敏感；方向增益集中在强响应条件，最强响应层的 DE 置信区间跨零；更新依赖已有源测量，无源测量时只能退回初始预测；解释的正确性由分子源记录定义参考答案，本质上受知识库覆盖度约束。但整体而言，它把"预测—解释—修正"做成了一个可累积、可修订的闭环，为细胞世界模型提供了一个有别于纯数值回归和纯语言推理的第三条路线。

### [HistoTx: Early fusion of H&E images and spatial transcriptomics at varying spatial transcriptomics resolution with self-supervised learning](https://arxiv.org/abs/2611.02681)
`评分3 · Presented at 3rd Workshop on Multi-modal Foundation Models a`

这篇论文要解决的是计算病理学中一个很实际的问题：H&E染色全切片图像是癌症诊断的黄金标准，病理基础模型在检测、分型等任务上已经很强，但它们对需要分子层面知识的任务力不从心。空间转录组技术能在组织切片上直接测基因表达，理论上和图像互补，但现有方法大多把转录组当作训练时的监督信号而非真正的输入模态——无论是用对比学习把图像和转录组嵌入对齐到共享隐空间，还是直接用图像特征回归基因表达，推理时本质上仍是图像驱动的，转录组信息在推理阶段被丢掉了。即便有些方法做多模态融合，也只是在特征层面做后期拼接或平均，没有在模型架构内部做深度交互。此外，空间转录组数据格式异构：Xenium给出单个转录本的坐标和基因身份但基因面板固定，Visium则是全转录组但以55微米直径的规则网格spot聚合表达，大多数模型只能处理其中一种，据作者所知只有MINT能同时编码两种模态，但它只支持一个可学习的转录组token，表达能力严重受限。

HistoTx的核心设计是一个早融合的多模态视觉Transformer：把转录组数据构造成token，和图像patch token拼进同一个序列，一起过共享的Transformer堆栈做深度跨模态交互。关键创新在转录组token的构造方式——对Xenium数据，在非重叠的T×T像素区域内按基因计数转录本检测，每个区域产出一个计数向量作为一个token，改变T就能改变token数量和覆盖的物理尺度（比如在0.5微米每像素下T=14对应7×7微米，在2.0微米每像素下T=56对应112×112微米），从而在亚细胞到组织级别多个尺度上捕捉生物结构；对Visium数据，以每个spot为中心取224×224像素图像得到一个转录组token，在更粗分辨率下一张图覆盖多个spot就贡献多个token。转录组计数向量先经预训练的基因基础模型Geneformer（冻结不训练）编码，再经线性层投影到图像token的维度并对齐范数，位置编码通过动态空间重采样适配转录组token的空间网格，然后与图像token和CLS token拼接送入ViT。训练策略上，作者从纯图像的病理基础模型（ViT-B/14，初始化自Midnight检查点）出发，用DINOv2做继续自监督预训练，把“图像视图”扩展为“图像-转录组对”：对Xenium数据，随机裁剪和缩放同时作用于两种模态，只保留落在裁剪区域内的转录本检测，图像再做标准光度增强；关键的自监督信号设计是转录组只出现在全局视图中，局部视图保持纯图像，这样全局CLS token是多模态的、局部CLS token是纯图像的，DINO原有的局部裁剪损失就迫使两者一致，从而把转录组知识蒸馏进视觉编码器。这个设计的巧妙之处在于：推理时即使没有转录组数据，图像编码器已经通过自监督被“灌注”了分子层面的信息；而有转录组数据时，早融合架构让两种模态在每一层Transformer中交互，远超后期拼接的信息利用效率。训练数据用了HEST-1k（含Visium和Xenium配对数据）加TCGA（纯图像，用于保持基础图像能力），单一骨干网络因灵活的token化策略能同时消化两种平台的数据。

结果方面，作者对比了纯图像基线（起始的病理基础模型）和SEAL-CONCH（用CLIP式对比学习微调CONCH骨干的强基线）。在基因表达预测任务上提升最明显：HEST-Bench上从H&E预测50个高变基因，Pearson相关系数从0.31提升到0.38，且优于SEAL-CONCH；HEST-Expr上预测380个固定面板基因从0.26提升到0.36；BEAT上从ETOP BEAT-meso数据的H&E预测100个Xenium附加基因从0.53提升到0.66。推理时若额外提供非目标基因表达作为输入，性能还能进一步受益，说明模型确实在用多模态输入而非仅仅依赖图像。在回归和分割任务上普遍有0.01到0.08的提升。但局限也很明显：多类分类任务上，乳腺癌基准（BACH、BRACS、BreakHis）出现性能下降，前列腺任务结果参差（PANDA-Radboud提升但Gleason TMA下降），作者推测继续多模态预训练可能把编码器拉向基因表达对齐的特征，削弱了区分视觉相似亚型所需的细微形态细节，这是否是组织特异性还是任务特异性尚无定论。另外，有监督的BEAT专用基线（用类似token化但任务特定监督训练）仍然优于HistoTx，说明通用自监督预训练在特定任务上未必能完全替代任务定制化训练。这项工作的意义在于证明了早融合加继续自监督预训练是一条可行路径：既保留了图像单独使用时的竞争力，又在需要分子知识的任务上打开了对转录组信息的利用通道，同时用灵活的token化策略统一了两种主流空间转录组平台，为后续在多模态病理基础模型上做更精细的跨尺度融合提供了架构和训练范式上的参考。

### [Ablating Design Choices for Protein Ensemble Generators Across Structural Regimes](https://arxiv.org/abs/2611.05055)
`评分3 · 13 pages, 2 figures`

这篇论文要解决的核心问题是：蛋白质构象集合生成模型的设计选择，在有序蛋白和无序蛋白这两种截然不同的结构区域中是否同样有效。过去的方法存在一个根本性偏差——生成模型的大量架构设计继承自折叠蛋白的结构预测任务，比如配对表示、结构模块、蛋白质语言模型的条件化方式等，但有序蛋白和无序蛋白在物理上属于不同的聚合物标度区域：有序蛋白的Flory指数接近1/3到2/5，表现为塌缩的球状体；无序蛋白则在θ区域到自回避行走极限之间，指数从1/2到约0.59，由净电荷、电荷分布模式和疏水性等序列物理化学性质决定。多结构域蛋白则是这两种区域的组合。问题在于，支撑折叠蛋白结构预测的实验手段——晶体学和冷冻电镜——对无序蛋白几乎不适用，PDB中有序蛋白严重过代表，无序蛋白只能靠SAXS和NMR化学位移这类集合平均观测量来约束，而这些观测量只能间接约束构象集合。因此现有方法要么依赖全原子分子动力学（精度高但计算代价巨大），要么用粗粒化模拟如CALVADOS（全局链尺寸标定得好但牺牲局部骨架几何），要么用片段组装（局部几何准确但采样群体不服从玻尔兹曼分布）。近年来的生成模型如idpGAN、idpSAM、STARLING、AlphaFlow、ESMFlow、BioEmu、PepTron、IDPFold2等各有侧重，但没有人系统检验过：哪些设计选择在哪个结构区域真正起作用。这篇论文的动机就是做这样一个消融研究，把“架构 vs 训练数据”这个根本问题拆开来看。

方法上的核心思路是建立一个极简的Cα流匹配基线模型（3570万参数），然后逐一消融各类设计选择，看每个变体在按结构区域分层的评测中表现如何。基线模型用冻结的ESM2-650M嵌入做序列条件，坐标加噪后与嵌入一起送入带RoPE位置编码和AdaLN-zero时间条件化的Transformer主干，预测逐残基速度场，训练损失是逐残基MSE加随机SO(3)旋转增强，刻意不做任何对齐。Cα分辨率的选择是为了匹配粗粒化训练集合的分辨率，原子细节后续用cg2all回映射恢复。训练数据均匀混合三个来源：高置信度AFDB结构（pLDDT≥90）作为有序单构象、IDRome-CALVADOS模拟的无序链集合、以及AF-CALVADOS模拟的多结构域蛋白（整链用CALVADOS模拟但折叠域被约束向AlphaFold2结构）。消融的变体包括：把ESM2-650M换成ESM2-8M来测试序列模型容量需求；加入静态配对表示（ESM2嵌入的外和加相对序列位置和加噪坐标的分箱距离，投影为每层注意力偏置，辅以distogram损失）；加一个冻结的逐残基无序探针预测pLDDT衍生的无序分数作为额外条件信号；用五专家top-2路由加共享专家的混合专家FFN替换前馈层；在损失端加入Kabsch叠加以处理旋转不变性；把无序训练数据从CALVADOS模拟换成片段组装的IDRome-o，以及两者各半的混合；还有两个故意削弱模型的对照——去掉RoPE和缩小到1100万参数。评测用PeptoneBench，对439个SAXS数据和659个化学位移数据计算集合平均观测量的归一化RMSE，再用LOWESS-AUC沿连续无序度量（平均G-score）积分汇总，并按G-score把蛋白分成有序、无序、多结构域和过渡四个格子分别报告，同时计算每个格子内的Flory标度指数作为不依赖前向模型和实验数据的自洽性检验。关键洞察在于：这个实验设计能区分“某个设计选择在所有区域都有用”“只在特定区域有用”和“根本没用”三种情况，而之前的论文从未做过这种分层归因。

结果非常清晰且有些反直觉。首先，所有添加的架构组件——无序探针、混合专家（参数量翻了三倍多）、静态配对表示（增加了二次复杂度的配对轨道）——在数据能分辨的范围内都没有可检测的效果，变化都在正负5%以内。把ESM2-650M换成ESM2-8M只在有序和多结构域蛋白上变差（有序蛋白SAXS恶化24%、化学位移恶化12%，多结构域SAXS恶化26%），无序蛋白上完全检测不到变化，这符合无序区域不依赖共进化空间接触而依赖体相物理化学性质的论点。损失端Kabsch对齐则在所有格子都恶化了SAXS（有序蛋白+26%到无序蛋白+99%），化学位移不受影响，而且连它理论上最该帮助的有序蛋白也变差了；无序蛋白上效应最大，与“伸展的瞬态尾部作为杠杆臂主导叠加、导致链其余部分错位并向梯度注入旋转噪声”的机制一致，且重加权后退化依然存在，说明集合中与测量兼容的构象太少；无序格子的Flory指数从基线的0.54升到0.58，接近自回避行走值，表明过度伸展。唯一能改善任一观测量的设计选择是训练数据来源：用片段组装替代CALVADOS模拟，在有序格子之外改善化学位移11%到16%，把化学位移AUC拉到与IDPFold2持平，但无序蛋白SAXS恶化62%、Flory指数升到0.61；两者各半的混合保留了大部分化学位移增益（AUC从-11%到-9%）而SAXS代价小得多。甚至故意削弱模型也变化不大——三分之一大小的模型无可检测效果，去掉RoPE只损失几个百分点（AUC+8%）。基线模型本身在SAXS上与三个已发表生成器竞争（主要靠无序蛋白），但在化学位移上每个格子都落后于IDPFold2，在有序蛋白上落后于所有三个基线，不过参数量对比并不对等（BioEmu约3100万但需MSA上的Evoformer表示，IDPFold2约3.3亿总参数、每token约1.9亿活跃，PepTron约6.9亿）。论文的结论是：在这个尺度上，模型受限于训练数据而非架构；真正起作用的选择只作用于特定区域或特定观测量，只有按区域分层的评测才能揭示这一点；无序训练数据的来源在局部和全局精度之间存在权衡，等量混合可以缓和这一权衡；未来进展需要同时在局部和全局尺度、跨结构区域都准确的训练数据源。局限也很明确：训练数据全部来自粗粒化模拟、片段组装和预测结构，CALVADOS的标定数据可能与评测用的SAXS数据库重叠；Cα模型只在与实验比较时才回映射且未量化回映射误差；有序数据限于高置信度预测结构，部分有序区域代表不足；架构结论只在单一尺度和固定等比例数据混合下得出；评测只依赖两个观测量，SAXS对有序蛋白测的是紧凑性而非折叠正确性，且每个变体只有三个训练种子，小的非有序SAXS格子（34到42个蛋白）使若干比较无法分辨。尽管如此，这篇工作的方法论贡献——按结构区域分层消融、用Flory指数做自洽性检验、把架构效应和训练数据效应分离——对蛋白质集合生成这个方向有直接的指导意义：继续堆架构组件的边际收益在这个尺度上已经很低，真正的瓶颈在数据。

### [The DynaCell Evaluation Suite for Dynamic 3D Virtual Staining of Live Cells](https://arxiv.org/abs/2611.02324)
`评分3 · 64 pages: 10-page main text with 4 figures and 1 table, plus`

这篇论文要解决的是活细胞动态三维虚拟染色的评估缺失问题。虚拟染色的核心思路是用无标记的透射光或相差图像去预测对应的荧光图像，从而避免反复荧光激发带来的光毒性和光漂白，让同一批细胞能够在数小时甚至数十小时内被连续观测。然而作者指出，尽管虚拟染色模型层出不穷，但它们在体成像加时间序列这一最贴近真实生物学场景的数据上的表现几乎没人系统刻画过。原因有三层：其一，公开的配对数据绝大多数是静态二维快照，缺乏深度信息来解析三维细胞器结构，也缺乏时间轴来反映扰动响应；其二，少数配对三维数据集要么没有时间维度，要么规模、细胞器覆盖和扰动条件都不足以做系统评测；其三，评估协议本身过于单一，绝大多数工作只报告 PSNR、SSIM、PCC 这类像素级重建指标，而这些指标衡量的是"像不像目标图"，并不能回答"预测出的虚拟染色能否替代真实荧光去做细胞器定位、分割、追踪或表型分析"。更麻烦的是，荧光目标本身是有噪声的测量，长时间活细胞成像中荧光会逐渐漂白、信噪比下降，标准 PCC 会惩罚模型没有复现这些非生物学的伪影，导致指标失真。正是这些数据与协议上的双重缺口，使得虚拟染色在真实生物研究中的可用性无法被判断，也阻碍了方法本身的迭代。

作者的做法是构建一套围绕数据、基线模型和三层指标联动的评估套件。数据侧，他们贡献了一个新的 A549 三维延时数据集，用 Mantis 显微镜同时采集无标记明场与光片荧光，体素间距接近各向同性，连续成像 20 小时，覆盖核、质膜、内质网和线粒体四种细胞器，并分别在 Mock、寨卡病毒和登革病毒感染三种状态下采集，因为这两种病毒感染会随时间重塑这些细胞器；原始数据经过定量相位重建、荧光去斜、双模态配准、裁剪、统一到两小时时间网格以及人工质检，最终得到 262 个视野序列，测试集每个细胞器与条件组合各 12 个视野、约一万七千个细胞，且训练与测试来自不同孔位。此外他们还重新处理了 Allen Institute 的 WTC-11 hiPSC 数据集作为跨细胞类型、跨显微镜的分布内评测，以及少量同显微镜下的 HEK293T 数据用于分离细胞类型与成像设备的影响。基线方面，他们统一训练协议，覆盖从经典 3D U-Net 到带掩码自编码器预训练的现代卷积模型这类回归基线，还实现了 pix2pix 的三维扩展和基于 CELL-Diff 的三维流匹配生成模型，形成回归与生成的对照。指标是这套工作的关键洞察所在：第一层是像素保真度，除常规 PSNR、SSIM、NRMSE 及其尺度不变版本外，还引入傅里叶壳相关、MicroSSIM，以及作者提出的 Spectral PCC——它在频域计算相关系数，剔除最低频段以避开自荧光和照明不均，并按目标信号高于高频尾部估计的噪声底来加权，从而不让模型因没复现噪声和漂白而被误罚；第二层是分割效用，对核与质膜取焦平面附近三层的最大强度投影，用 Cellpose v4 分别对预测和真实荧光做实例分割，计算 Dice 和不同 IoU 阈值下的平均精度，直接检验虚拟染色能否支撑下游任务；第三层是单细胞表型相似度，用 CellProfiler 或学习到的编码器把每个细胞表示为特征向量，再在特征空间中比较预测与实验的分布。这套设计的巧妙之处在于，三层指标各自捕捉不同侧面，能暴露单一指标掩盖的结构保真与表型保真之间的权衡。

实验结果给出了几个有信息量的结论。在覆盖 3 种细胞类型、2 台显微镜、4 种细胞器和 3 种扰动状态的评测中，回归基线在预测目标细胞器的空间定位上更好，也就是像素和分割层面更准，而生成基线在捕捉细胞间表型分布上更强，能更好地复现群体层面的异质性；这说明两类模型各有擅场，单看重建指标会得出片面甚至误导性的结论。作者据此论证，虚拟染色模型应当按下游任务来选型和训练——做定位和分割就偏向回归，做表型 profiling 就偏向生成。局限也很明显：数据集虽然已是目前少有的配对三维延时资源，但细胞类型和扰动面板仍然有限，病毒感染的生物学复杂度也未必能代表全部扰动类型；Spectral PCC 的噪声底估计依赖高频尾部假设，在信噪比极低时可能不稳；分割指标只覆盖核与质膜，内质网和线粒体的实例分割本身就更困难，评估尚不完整；生成模型只做了三维流匹配一种，扩散与自回归在三维延时上的表现仍待探索。尽管如此，这套套件把数据、检查点和评估代码一并以 DynaCell 框架发布，为虚拟染色从"能生成好看的图"走向"能支撑可复现的活细胞测量"提供了一个可比较的基准，也指明了指标选择应当与下游生物学问题对齐这一方向性判断。

### [From Pixels to Actions - Towards Native Vision-Language-Action Policies](https://arxiv.org/abs/2611.06918)
`评分3 · HF 56赞`

这篇论文针对的是视觉-语言-动作模型（VLA）中一个被长期默认却很少被审视的设计选择：感知必须先经过一个独立的预训练视觉编码器（如CLIP、SigLIP、DINOv2）压缩成固定特征，然后语言骨干和动作头才在此基础上做推理。作者指出，这种“先编码、后推理”的接口把视觉计算的全部层级结构隐藏掉了，只暴露编码器的最终输出，而机器人操作恰恰高度依赖那些最容易在抽象过程中丢失的信号——局部几何、边界、深度、细微的状态变化。已有证据支持这一担忧：视觉模块被识别为VLA的主要瓶颈，视觉组件对剪枝异常敏感，动作微调还会反过来破坏预训练的视觉表征。于是论文提出一个根本性问题：动作策略应该继承一个固定的视觉终点，还是应该直接访问不断演化的视觉计算过程？NEO-VLA的回答是后者——它构建了一个结构上无编码器的VLA框架，图像由轻量卷积patch嵌入器直接映射进语言骨干的token空间，视觉token与指令词在整个40层、2B参数的骨干中共同演化，一个flow-matching动作专家则从骨干不同深度的层中读取缓存的key/value来预测连续动作块。这样一来，“从哪一层读视觉特征”就从一个被编码器锁死的隐式事实，变成了一个可以显式设计和系统研究的架构变量。

方法上的关键洞察在于把“动作读出的深度”当作一等公民来对待。作者定义了层映射（layer map）的概念：动作专家的第j层去attend骨干的第m_j层，由此构造了几种参数量匹配的对照设置——first-28只读前28层（偏早期、细粒度特征），end-28只读第12到39层（偏晚期、语义化特征），skip-28在全部40层中近似均匀采样28层，以及容量更大的full-40读全部层。视觉接口本身沿用NEO的无编码器方案：两阶段卷积嵌入器以总步长32把每个32×32图像区域压成一个视觉token，配合原生旋转位置编码把位置分解为时间、高、宽三个坐标，并采用模态感知注意力——文本token走因果注意力，视觉token在视觉块内双向交互，从而在保持密集空间建模的同时让视觉与语言表征逐层共同演化。多模态前缀把多视角图像（每视角带相机身份token和由轻量MLP编码的内参、旋转几何）、结构化语言提示（控制频率、本体、夹爪配置、动作坐标系、任务指令）以及机器人本体感受（6个状态token加有效性掩码）统一进一个token序列，缺失的部件直接掩码，因此同一接口能适配不同机器人构型。动作侧用flow-matching专家预测速度场，目标包含双臂各30步×26维（7个关节、3个平移增量、3个旋转向量增量、1个夹爪、12个手部关节）和共享身体的30步×8维，训练时对四个动作组按2:1:1:1加权，推理时用10步欧拉法从噪声积分到动作块，不做classifier-free guidance。这套设计真正的价值在于它让“早期视觉层对控制是否重要”成为一个可做受控实验的问题——而实验结果给出了明确答案：冻结骨干时，包含早期层的读出稳定优于只用晚期表征；全量微调后，早晚期特征组合最好；更直接的干预实验显示，在不同观测之间交换早期层激活所引发的预测误差远大于扰动晚期层，说明对动作至关重要的信息在最终表征之前就已经出现，此时细粒度的空间与几何线索仍然可直接访问。

在结果层面，作者在LIBERO、LIBERO-plus和RoboTwin 2.0上评估，覆盖标准操作以及视觉外观、语言、环境三类分布偏移。与Qwen3-VL-2B和Gemma-3-4B这两个理解能力相近的编码器式骨干在相同动作专家和相同机器人训练语料下对比，NEO-VLA在冻结骨干和全量微调两种设置下都取得更高的LIBERO成功率，且冻结骨干时的优势尤其明显——这正是因为策略必须直接依赖预训练视觉表征，无编码器架构保留的中间层访问权就变成了实打实的增益。在分布偏移下，NEO-VLA的鲁棒性提升在相机扰动和图像噪声下最为突出，这与逐层探针的结论互相印证：保留对中间视觉计算的访问不仅在受控消融中有用，也转化为实际场景中的稳定控制。作者也坦承局限：不同骨干在预训练数据和模型容量上的差异使得增益无法完全归因于“去掉编码器”这一项，因此结论应理解为“原生骨干是动作学习的一个强且可迁移的基础”，而非严格的因果分离。此外full-40需要更深的动作专家、参数量更大，与28层设置并非严格等容量比较。但这项工作的意义在于它把VLA设计中的一个隐含前提翻了出来：有效控制不只取决于骨干表征了什么，还取决于视觉计算的哪些阶段对动作保持可访问——这为具身智能的架构选择提供了一个可检验的新维度。

### [DreamX: Video Diffusion Model is a Universal Latent Action Learner](https://arxiv.org/abs/2611.05377)
`评分3 · HF 54赞`

DreamX 要解决的是跨具身动作表征学习中的核心矛盾：如何从视频中提取一种既对同一动作的不同执行方式保持一致、又对具身形态和外观变化保持不变的通用动作表示。此前的潜在动作模型（LAM）走的是"逆动力学—前向动力学"瓶颈路线，即用专门的编码器把相邻帧之间的视觉变化压缩成潜在动作，再用解码器仅凭当前帧和潜在动作重建未来帧。问题在于，重建精度本身并不保证潜在动作真正隔离出了"动作"——只要有助于降低重建误差，编码器完全可以把视角、场景外观、具身特定的视觉线索一并塞进潜在动作里。更根本的是，这类方法的监督信号通常只来自单帧对或极短的局部转移，编码器看不到运动在一步之外如何持续演化，因此学到的表征天然与训练时的具身绑定，跨具身迁移能力受限。人类视频没有机器人动作标签，不同机器人的控制空间又各不相同，同一个行为对应截然不同的底层动作，动作标签无法直接共享——这正是需要一个共同动作接口的现实动机。

DreamX 的关键洞察是：预训练视频扩散模型本身就同时具备两样东西——大规模视频预训练得来的丰富时空表征（涵盖运动、对应、几何与语义结构），以及一个生成先验（给定初始帧和额外条件就能合成合理的未来帧）。方法上，它把可学习的查询 token 追加到视频 token 序列后面，让它们与视频 token 一起经过骨干网络的时空注意力，从而在单次前向中"读取"出潜在动作。具体地，每个 VAE 潜在帧分配一组查询 token，查询到视频的注意力是帧因果的（第 g 组查询只能看到第 0 到 g 帧），而查询之间的注意力不受限，这样查询就能编码有时序依据的运动信息。最终 1200 个帧 token 被压缩成仅 4 个潜在动作 token，实现 300 倍的 token 缩减。监督方式是生成式的：用同一套预训练骨干作为解码器，以初始帧提供场景外观、以潜在动作替代原本的文本条件来重建未来帧。这个设计巧妙之处在于，外观信息已经由初始帧和生成先验负责了，重建目标就会"逼着"潜在动作只去编码解释未来所必需的运动，而不是重复那些解码器已经知道的视觉线索。此外，当有动作标签时，解码器还会以本体感受状态为条件、把潜在动作解码成动作块作为辅助任务，进一步把动作相关线索注入表征。迁移时无需配对数据：从源视频提取的潜在动作，配上目标初始帧就能生成目标域视频（视频迁移），配上目标机器人状态就能解码成可执行的低层动作（动作迁移）。

实验上，DreamX 以 Cosmos-Predict2.5 2B 为骨干，在 MolmoAct2-BimanualYAM、Bridge、DROID、AgiBot 等机器人演示和 EgoDex、EgoVerse 人类视频上预训练，编码器和解码器各用 rank-16 LoRA 适配。在 LARYBench 上它取得了潜在动作模型中的 state-of-the-art，并展示了无需配对训练数据的任意到任意视频迁移和人类到机器人的动作迁移。下游应用中，它把潜在动作经变分瓶颈压缩成低维码作为策略的预测目标，策略执行时不需要生成未来视频，从而降低了基于视频扩散的策略的计算开销，同时人类视频可以只监督潜在码预测、机器人演示再额外监督低层动作。局限方面，方法仍依赖大规模视频扩散骨干，推理和训练成本不低；跨具身迁移虽被证明可行，但论文并未给出在更多样具身上的系统性量化；辅助动作分支也意味着有标签数据仍能带来额外收益，纯无标签场景下的上限尚待厘清。尽管如此，它把"视频扩散模型本身就是通用潜在动作学习器"这一思路坐实，为利用无动作标签的人类视频和异构机器人数据提供了一条统一接口，对通用机器人策略预训练方向有明确的推动作用。
