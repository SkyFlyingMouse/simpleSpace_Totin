## 大模型 LLM

### [The Trinity:Capability-Driven Recursive Self-Improvement for Multimodal Agents](https://arxiv.org/abs/2610.36077)
`评分3 · HF 311赞`

这篇论文要解决的是多模态智能体训练中的一个结构性瓶颈：如何让智能体在异构任务上持续自我改进。当前的多模态基础模型虽然在感知、推理和生成上进步很快，但智能体的实际能力越来越受限于它外层的 Harness——也就是协调冻结模型完成任务的整套控制流协议，包括感知、记忆、推理、规划、编排和循环控制等模块。问题在于，构建大规模、异构且可验证的训练环境成本极高，而人工迭代 Harness 的速度又跟不上任务多样性和复杂度的增长。已有的 Harness 递归自我改进工作基本集中在纯文本任务（如编程和数学），采用任务特定的进化策略，这在任务能力需求相似时有效，但一旦跨到异构的多模态任务就会导致 Harness 过拟合、泛化差；反过来，用一个全局 Harness 硬扛所有任务，又会因为任务间需求冲突（比如具身任务里性能与效率的权衡）而顾此失彼。论文的关键洞察是：表面模态和形式不同的任务，底层可能共享相同的能力需求——比如 ARC-AGI-3 和 Micromouse 结构迥异，但都依赖准确的感知和状态跟踪。因此作者主张把任务组织方式从“按表面类别”转向“按共享能力需求”，让能力成为学习和优化的共同目标。

具体实现上，The Trinity 框架通过 Creator、Explorer、Evolver 三个角色把环境生成和 Harness 进化耦合起来。Evolver 先利用已验证的执行轨迹，从任务目标、允许的观测、动作规则和完成标准中推导出能力需求，把原始任务树重组成一棵分层的能力树——同一节点下的异构任务共享学习目标。沿着这棵树，作者提出 Capability-Driven Real2Sim2Real：Creator 把同一节点下异构任务的共同需求抽象成简化、可验证的模拟世界用于能力学习，再回到原始任务上评估迁移效果，这样既降低了环境构建成本，又保证了学到的能力是真能迁移的。Explorer 则在能力树上做选择性继承——子节点继承父节点已验证的模块注册表，但只有在相同验证任务、相同试验次数和预算下严格优于旧版本时才保留父节点更新，否则维持原状，本地模块则通过 Evolver 对比成功与失败轨迹来提炼可复用模块，更新要经过宿主对证据、接口、血缘和可执行契约的校验。这样迭代下来形成一棵拓扑固定的 Harness 树，不同分支专精不同能力。由于 Harness 已经特化，推理时需要按任务选配置，于是有了 Capability-Aware Harness Router：它利用公开任务信息和已验证的执行经验，从树中选出兼容的模块配置。Creator 一侧则在每轮迭代结束时把验证过的更新做合并去重， consolidation 成新的 Base Harness，与 Explorer 共享同一棵树结构但扮演不同角色。

实验上，进化出的 Harness 在 28 个训练基准上平均提升 34 分，在 18 个未见基准上提升 26 分，还包括两个真实世界的具身任务，说明能力驱动的组织方式确实带来了跨任务、跨基准乃至跨到真实具身场景的迁移。论文还通过实证关联和受控干预分析了任务级能力需求与可复用模块配置之间的对应关系，为 Harness 设计提供了能力-模块先验。局限方面，整套流程依赖宿主执行的验证器和预设的能力类别体系，能力树的构建质量受限于需求推导和评审的可靠性；选择性继承要求严格性能提升才保留父节点更新，可能在某些节点上偏保守；Router 的选择依赖公开任务信息，面对分布外任务时的鲁棒性还有待检验。但总体而言，这篇工作把递归自我改进的组织原则从任务驱动转向能力驱动，给出了一个可操作的框架，对这个方向的影响在于：它指出了跨异构任务泛化的关键不在于堆更多任务特定优化，而在于识别和复用共享的能力需求，这为多模态智能体的持续进化提供了一条更可扩展的路径。

### [Work Agents: Systems, Capabilities, and Optimization](https://arxiv.org/abs/2610.35845)
`评分3 · HF 117赞`

这篇论文要解决的是基础模型从“生成信息”走向“执行数字工作”时缺乏统一理论框架的问题。当前 agent 研究大多零散地聚焦于某个环节——有的只谈模型能力（规划、工具调用），有的只谈工程脚手架（记忆管理、错误重试），有的只谈 benchmark 设计，但没有人把 agent 当作一个完整的“工作系统”来刻画：它由基础模型和运行时 harness 共同组成，在有状态的工作空间里执行任务并交付可验证的结果。这种碎片化导致两个实际困境：一是研究者无法说清一个 agent 在什么工作条件下可靠、在什么条件下会崩，因为缺少描述“工作条件”的维度；二是优化时容易顾此失彼，比如只提升模型推理能力却忽略了 harness 对长程状态的管理，或者只堆工程手段却不清楚模型侧该补什么。论文的动机就是把“agent 替人完成被委托的工作”这件事当作一等公民，建立一个能同时覆盖系统结构、能力需求、优化路径和评估方式的统一视角，而不是再提一个孤立的框架或技巧。

核心创新在于提出了一套刻画“工作”本身的分析坐标系，并据此反推系统设计。论文引入两个互补维度：工作持久性（work persistence）和工作开放性（work openness）。持久性衡量任务在时间上需要维持多少状态、跨越多少步骤和会话，开放性衡量任务在环境、工具、目标上的不确定程度和自由裁量空间。这两个维度组合出一个工作条件的二维空间，再按任务范围和组织方式把数字工作分成五类形态，从而让“什么样的工作适合什么样的 agent 架构”变成可讨论的问题。在这个框架下，论文识别出可靠执行所需的五类核心能力，并把优化拆成三条线：模型优化（提升基础模型自身的规划、工具使用、长上下文推理等）、harness 优化（运行时对状态、记忆、错误恢复、工具编排的管理），以及二者的联合优化——这是关键洞察，因为模型能力和 harness 能力存在互补与替代关系，单独优化任一侧都会遇到瓶颈，比如模型再强也无法在无状态 harness 下维持跨会话的工作连续性，而 harness 再精巧也弥补不了模型在开放环境中的决策失误。论文还从“工作产出”而非“对话质量”的角度重新审视评估方法与指标，强调可验证结果是衡量 work agent 的最终标准。

在结果与意义层面，这篇论文是立场与框架型工作，其“结果”主要体现在分析框架的覆盖力和对现有评估的重新组织上，而非单一任务上的数字提升；它把此前分散在模型侧和工程侧的优化手段放进同一个坐标系里比较，指出哪些组合在何种工作条件下更有效，并据此给出未来方向：持续性的工作委托（长程、跨会话的责任承接）、对开放环境的适应、以及工作执行与能力提升之间的相互作用（agent 在干活中自我改进）。客观地说，它的局限也很明显：框架目前偏概念化，两个维度和五类工作形态的边界划分还缺少大规模实证校准，联合优化的具体算法和量化规律没有被充分展开，评估部分也更多是视角梳理而非提出新的可复现 benchmark。但它的影响可能在于给这个领域一个共同语言——让后续工作能明确说出自己的 agent 在持久性和开放性上处于什么位置、优化的是模型侧还是 harness 侧、用什么工作产出指标来衡量，从而避免各说各话，推动系统向可靠、可验证、有实际价值的工作交付演进。

### [Memory Tax: Dissecting the Net Value of Agent Memory](https://arxiv.org/abs/2610.34073)
`评分3 · HF 99赞`

这篇论文要追问的是一个在实际部署中长期被含糊处理的问题：为长程智能体构建专门的记忆系统，相对于直接从原始交互历史里做朴素检索（naive RAG），到底有没有净收益。作者的出发点很直接——近两年记忆系统的设计越来越复杂，从扁平存储、层级/生命周期管理、图结构组织到训练出来的记忆策略，各类表示和管理机制层出不穷，但这些工作大多只跟其他记忆系统互相比拼，很少把朴素 RAG 当作正式基线；即便列了 RAG，检索配置（分块方式、top-k、上下文预算）也常常语焉不详，导致"构建记忆带来的价值"和"直接检索证据带来的价值"纠缠在一起，记忆的边际贡献无法被单独识别。作者在 LongMemEval-s、PersonaMem-v2、MINT-Eval 三个个人助手对话记忆基准上，用 Qwen3.5-4B、Qwen3.6-27B、GPT-5.6-luna 三个骨干模型，对 A-Mem、SimpleMem、MemOS、MemoryOS、LightMem、OpenViking、HippoRAG2、PlugMem、MAGMA、Mem-T、Memory-R2 等代表性系统做了大规模评测，并用 Retrieval Scope（检索暴露给模型的 token 数占系统可检索存储总 token 数的比例）来对齐各系统的检索预算，避免固定 top-k 在不同记忆粒度下造成的比较失真。结果相当反直觉：朴素 RAG 是一个极强的基线，很多专用记忆系统在大量设置下打不过它，也就是说净价值为负。但逐查询对比又显示记忆并非全面更差——它能解决一些 RAG 漏掉的查询，同时也会弄丢一些 RAG 本来能答对的查询，作者由此把净价值拆成"记忆收益"和"记忆税"两部分。

核心洞察在于：任何非平凡的记忆过程都必然让信息偏离原始历史，这种偏离是双刃的。记忆系统在摄入阶段把历史重组成摘要、抽取事实、结构化记录或情景条目，本意是让信息更好保存和使用（比如把散落的事实聚合起来、蒸馏出用户偏好），这部分预期收益就是记忆收益；但同样的重组、压缩和改写也可能删除或遮蔽证据，造成记忆税。作者从三个内部维度解剖记忆税的来源。其一是忠实性：他们做宏观的"金标回放"——只用带证据的原始对话轮次、以及只用对应的金标记忆单元分别重放问答，后者排除了检索失败，剩下的性能落差就反映构建阶段的损失；微观上则采样原子事实逐条追踪到记忆单元并标注信息丢失程度，发现不少系统在构建时确实存在不同程度的信息丢失，而即便换成 oracle 记忆后税仍不能完全消除，说明退化不止发生在构建环节。其二是可访问性：他们对已构建的记忆做多轮迭代检索回放，统计找回全部金标单元需要几轮，发现记忆系统首轮能恢复的查询数普遍少于 RAG，说明证据被埋得更深；微观案例分析归纳出三种典型模式——证据被碎片化到多个记忆单元、被无关信息稀释、被改写措辞，都会削弱查询与证据之间的对齐，作者还用查询-金标原始轮次相似度与查询-金标记忆单元相似度的逐点变化和整体漂移来量化这种偏移。其三是鲁棒性：用三个骨干分别独立构建记忆、再交叉用不同骨干做问答，发现固定问答骨干时换构建模型会带来明显分数波动（这在意料之中，因为许多中间操作依赖模型），但更有意思的是固定构建、只换问答骨干时，很多记忆系统的性能波动比朴素 RAG 更大，说明记忆机制在原始历史检索之外引入了额外的脆弱性。此外，作者指出评测侧也存在放大效应：在一些广泛使用的基准上，极简的 IDF 关键词匹配就能拿到 50% 以上的绝对分，RAG-Hybrid 能到约 70%，说明这些任务本身对检索友好、留给重型记忆的提升空间（benchmark headroom）很有限，此时记忆税在总分上就格外显眼；这也解释了为何一些轻量甚至几乎不做显式记忆构建的系统反而又强又省——它们继承了朴素检索的大部分性能，却几乎不交税。

这项工作的意义主要在于视角转换而非某个新模型：它把评价重心从"记忆系统的单独表现"移到"相对直接检索的净价值"，并给出收益/税这一可操作的拆解框架，还把这套视角推广到经验记忆和世界模型记忆等更广场景，从中提炼出一些不引入新架构、可直接套用到现有记忆系统上的设计启示。关键数字方面，论文的核心结论是多数记忆系统在多个基准和骨干上未能超过朴素 RAG，而简化基线在部分基准上可达 50% 以上、RAG-Hybrid 约 70%，凸显当前评测的检索友好性与有限提升空间。局限也很明显：收益与税都是相对朴素 RAG 定义的、依赖参照系，换基线结论会变；评测受成本约束只采样了 PersonaMem-v2 的 20% 和 MINT-Eval 的 10%；跨系统比较相似度绝对值只有指示意义；鲁棒性分析覆盖的骨干数量有限；而且论文主要是诊断性分析，给出的设计建议偏原则性，尚未提供一套能系统性压低记忆税、同时保住收益的完整方法。对方向的影响在于，它提示后续记忆研究应把朴素 RAG 作为必报基线并公开检索配置，把评测重心放到净价值和税的来源上，同时推动基准补充更难、检索不友好的任务，以免记忆系统的真实贡献被检索友好型评测掩盖。

### [Can Discrete Tokens Serve as Semantically Lossless Representations of Visual Signals?](https://arxiv.org/abs/2610.37662)
`评分3 · HF 81赞 · 有代码`

这篇论文要解决的是多模态统一建模中一个被广泛接受却未经严格检验的假设：把连续视觉特征量化成离散token时，量化误差必然导致语义损失，因此离散表示在语义保真度上天然劣于连续表示，连续特征构成了不可逾越的上界。这个假设直接动摇了"用离散token统一视觉与语言"这一路线的根基——如果离散化注定丢语义，那原生多模态基础模型就只能退回连续特征加投影层的旧范式。作者用多模态理解任务作为语义保真度的代理指标，做了一个很干净的对照实验：拿单码本VQ和八组RVQ比较，构造两个"部分表示"，一个保留奇数残差组、一个保留偶数残差组。结果非常反直觉——奇数组的重建误差大得多（因为它丢掉了第0组捕获的粗粒度成分），但下游理解性能反而明显超过VQ，和偶数组相当；偶数组重建误差和VQ差不多，理解性能却强得多。这说明重建MSE和语义保真度之间根本没有可靠的对应关系，量化误差不是决定语义容量的因素。那真正的决定因素是什么？作者回到第一性原理：原始RGB图像本身就是有限比特的离散信号，连续特征和离散表示都只是不同比特预算下的编码，而视觉信号冗余度极高，理论上用少得多的比特就能承载其语义内容。于是他们提出真正的关键变量是"有效比特预算"——对离散表示而言，比特预算随码本数量线性增长、随码本大小仅对数增长，所以多码本扩展是更高效的路径。实验确实显示，随着比特预算增大，下游理解性能稳步提升，OCR这类对高频细节敏感的任务也逐步恢复。但问题来了：现有的多码本量化器在预算增大时会饱和。RVQ后面的码本只能拟合越来越小的残差，PQ则把特征切成越来越窄的通道组，两者新增码本携带的语义信息都在递减，名义比特预算涨了、有效语义容量却没跟上，8个码本扩到16个只带来边际收益。这就是论文要突破的瓶颈。

针对这个饱和问题，作者提出Factorized Vector Quantization（FVQ），核心思路是让每个新增码本都拿到一份"信息量不衰减"的输入视图。具体做法分三步。第一步是互补紧框架投影：对每个patch的特征向量，用一组稠密投影矩阵把它映射成L个固定维度的视图，每个投影矩阵都在全部输入通道上稠密，因此每个码本看到的都是完整特征的一个全局视图，而不是像PQ那样只看到被切窄的一部分通道；关键约束是这些投影堆叠成的分析算子满足紧框架条件，即其转置与自身的乘积正比于单位矩阵，这保证了变换是各向同性的——每个特征方向被等比例缩放，没有任何非零方向会被所有视图同时丢弃，因此这L个视图在量化之前集体地保留了原始特征的几何结构。投影矩阵由固定高斯矩阵做QR分解得到并全程冻结，给码本提供稳定的输入空间。第二步是对称并行量化：每个视图独立地在各自码本里做最近邻查找，所有码本大小相同、地位对称，一个patch表示为L个离散ID的元组，比特预算就是L乘以码本大小的对数。这里没有RVQ的残差层级，所以新增码本不会拿到更弱的输入。第三步是紧框架合成：训练tokenizer时用合成算子把选中的码字组合回去重建特征，由于紧框架条件，分析-合成这一对变换在量化前能精确还原原始特征，因子分解本身零重建误差，所有失真只来自最近邻替换。这三步合起来的效果是：名义比特预算随L线性增长的同时，每个码本可用的信息在结构上不会衰减，从而绕开了RVQ和PQ的饱和。实验上FVQ在RVQ和PQ饱和之后仍随预算继续提升，最终在多模态理解上追平连续表示。

在结果层面，作者用Qwen3-8B搭配基于Qwen3 ViT、16码本FVQ构建的任意分辨率tokenizer，在工业级多模态数据上训练。在九项指标的平均值上，相对UniAR提升22.8%、相对Emu3-Chat提升59.2%，在离散表示模型中达到SOTA；据作者所知，这是首个在包括细粒度OCR任务上与Qwen3-VL这类强连续表示旗舰模型具有竞争力的离散表示模型。这个结果的意义不只是刷点，而是用实证支持了"离散视觉表示足以支撑大规模原生多模态基础模型"这一主张，并且作者进一步提炼了实现这种竞争力的关键原则和实用配方，给后续工作提供了可复现的设计指引。客观地说，局限也明显：FVQ只是缓解饱和的"一种"方案，紧框架投影在Ld大于等于D时才能用QR构造，投影维度和码本数量的搭配仍有约束；工业级训练成本高，探索性实验依赖LLaVA-OneVision数据，结论的普适性还需更多验证；此外论文以多模态理解为语义保真度的代理，对生成、空间推理等任务的语义完整性尚未系统检验。但无论如何，它把"量化误差等于语义损失"这个长期默认的前提拆掉了，把讨论重心转移到有效比特预算和码本信息分配上，这对离散token路线的发展方向有实质性的纠偏作用。

### [Can Test-Time Memory Evolution Outperform Test-Time Training for Scientific Discovery?](https://arxiv.org/abs/2610.32046)
`评分3 · HF 49赞`

这篇论文要解决的是科学发现任务中测试时训练（TTT）带来的计算开销问题。近期以TTT-Discover和ThetaEvolve为代表的框架，把迭代搜索与测试时强化学习结合起来：LLM生成候选程序，执行后由任务验证器给出有效性和分数反馈，这些反馈被当作训练数据在线更新模型权重，从而把搜索经验“内化”进参数里。这种做法的效果确实亮眼——小规模开源权重模型借此在困难科学发现任务上超过了AlphaEvolve这类依赖前沿闭源模型的推理系统。但代价也很直接：整个发现过程都要在线做权重更新，FLOPs和时间开销都很大，模型越大越难扩展，这促使作者追问一个更本质的问题：在同一个发现框架下，是否存在比权重更新更高效的测试时自适应方式，且性能不降甚至更好？作者的假设是：当前LLM本身已具备足够的基础知识、推理和编码能力，只要把搜索过程中积累的经验持续蒸馏、组织进外部记忆并在上下文里供给，就足以指导下一次尝试，不必把经验写进权重。

方法上的核心是TTME，一个即插即用的自演化记忆系统，只替换框架中的TTT部分，父代选择、存档更新和验证器全部保留。关键洞察是把搜索经验拆成两类互补的东西，对应两个记忆模块。其一是Guideline Memory，负责“怎么把候选实现对”：每隔K步，把这段时间内各父代产生的执行与评估结果汇总（有效结果、分数、失败情况），用同一个基座模型蒸馏成一条条准则，每条准则包含适用条件、相关失败或改进的解释、以及具体建议动作；更新时对新提出的准则与已有条目做匹配，命中则增加复现计数并刷新最近确认步，未命中则新增，同时按复现计数优先、近期性打破平局的方式淘汰陈旧条目并限制容量，这些准则作为后续生成的共享上下文。其二是Strategy Memory，负责“什么算法想法能提分”：只挑出修改后程序有效且分数高于父代的案例，让基座模型对比原程序、修改后程序及差异和评估结果，抽取“经验笔记”，每条记录一个算法想法、它是如何被应用的、以及来源案例；由于同一想法可能有不同实现，系统把共享同一底层想法的笔记聚合成策略族，为每族维护一个持久条目，描述共享想法、适用条件、多种实现方式及来源引用，新笔记到来时由模型判断归入已有族并合并更新，或建立新族。生成阶段的关键设计是Strategy-Guided Search：由于策略来自特定修改、直接套到别的父代上未必合适，系统先用一个selector按“对当前父代的改进潜力”从策略记忆中顺序挑选至多N个不同策略（同类合理时优先选本步尚未分配给前面父代的策略，以促进多样性），再由adaptor读取策略全文和父代完整代码，产出针对该父代的具体修改指令；若没选到合适策略，adaptor就基于父代和策略记忆提出新想法并写成指令。候选生成分两支：一半预算走Direct Generation，只用父代上下文和Guideline Memory；另一半预算平均分给N条策略指令走Strategy-Guided Generation。这样既能把某个提分修改中的想法与当前父代已有思路组合起来，又保留了无指令探索的空间。它之所以可能优于TTT，在于把“学习”从昂贵的梯度更新转移到了上下文层面的经验检索与适配，而经验的组织（准则去重计数、策略族合并）保证了记忆不会随搜索无限膨胀、也不会退化成零散日志。

实验在五个数学构造任务（Erdős最小重叠问题、第一与第二自相关不等式等）上，跨TTT-Discover和ThetaEvolve两个框架、Qwen3-8B、gpt-oss-120b和Distill-Qwen3-8B三个模型，严格保持各框架原配置、只替换自适应机制，与各自论文报告的TTT结果对比。结果是TTME在全部五个任务上都超过了TTT，同时FLOPs降低82.8%到84.6%，运行时间降低47.7%到58.4%。行为分析还显示，两种方法相对无自适应的基线都提升了实现有效率，但TTME更高，且TTME更频繁地在先前探索过的、能提分的想法组合之上继续构建，说明收益不只是“省算力”，搜索行为本身也更好。局限方面，评估集中在带可执行程序和确定性验证器的数学构造任务，这类任务反馈干净、经验容易文本化，向反馈更嘈杂、验证更昂贵的领域（如实验科学）外推仍需验证；记忆的蒸馏、匹配与合并全部依赖同一个基座模型，记忆质量受其能力上限约束，且K、N、α等超参的影响论文未充分展开；此外对比基线取自原论文报告数字而非同环境重跑，虽已尽量控制变量，仍存在框架实现差异的潜在干扰。尽管如此，这项工作给出了一个清晰的方向性结论：在科学发现这类迭代搜索场景中，精心设计的外部记忆演化可以替代在线权重更新，且更便宜、效果更好，这对想把测试时自适应扩展到更大模型和更长搜索预算的研究者有直接的参考价值。

### [Heads of Security: Learned Attention Gates Improve Prompt Injection Robustness](https://arxiv.org/abs/2610.37657)
`评分3`

间接提示注入的本质是模型把外部内容里夹带的指令误当成合法命令来执行，随着 LLM 接入越来越多外部数据和工具，这个攻击面变得愈发关键。尽管前沿闭源模型在红队测试下已明显更难攻破，但提示注入整体仍未解决——自适应攻击对经过充分评估的系统依然有效，开源权重模型的情况更糟，同等红队强度下 Claude 和 GPT 的鲁棒性显著高于主流开源模型。作者聚焦于“指令—数据分离”这一互补防线：它建立一个硬信任边界，授权指令可以驱动模型行为，而外部数据只能被读取和分析、不能被当作指令执行，适用于网页摘要、文档抽取这类外部内容本就该当数据用的场景。此前的方法分两类：以 SecAlign++ 为代表的微调路线用 DPO 教模型忽略数据段里的注入，Meta-SecAlign-70B 曾被视为最抗攻击的开源权重模型之一；以 ASIDE 为代表的架构路线则通过对不可信 token 的嵌入施加固定旋转来编码输入角色。但两者都有明显短板：微调会波及模型原有能力，在少样本和多轮场景下退化严重；ASIDE 的固定旋转不区分头、不区分上下文，在需要工具调用的智能体任务上几乎瘫痪，效用只剩 10%。更根本的问题是，这些方法都没有针对“注意力该往哪里流”做精细控制，面对 RL-Hammer 这类黑盒强化学习攻击和 Claudini 这类白盒优化攻击时仍然脆弱。

HoS 的核心洞察有两条：一是可解释性研究已表明注意力头存在功能分化，有的负责上下文复制、有的负责复制抑制、有的负责指令跟随，因此每个头应当学习属于自己的、与其角色匹配的信任重分配方式，压制不可信指令而不干扰无关能力；二是信任边界由外部给定（比如网页结果默认不可信），模型不需要自己推断谁可信，也不需要习得新能力，这本质上是一个注意力路由问题。具体做法是给每个 token 打上 trusted、untrusted、template 三种通道标签之一（系统与用户提示及模型自身生成为可信，工具输出为不可信，聊天模板 token 包括常充当注意力汇点的 BOS 为模板），然后为每一层每一个头维护一张通道到通道的门控 logit 表，把门控值经 sigmoid 后取对数加到 softmax 之前的注意力 logit 上。由于 softmax 先指数化再归一化，加上 log σ(g) 等价于把该键的未归一化权重乘以 σ(g)，这与因果掩码加负无穷是同一机制；当所有键共享同一门控时 softmax 会抵消公共平移，所以初始 logit 的绝对尺度无关紧要，全同通道的输入与基座模型完全一致。这样一来，一个负责指令跟随的头可以对不可信通道关门、把注意力质量几乎全部压到用户指令上，而其他头仍可自由读取不可信内容以完成推理。GPT-OSS 因为有显式注意力汇点，需要把汇点当作额外的仅键通道，门控表相应扩一列。训练只更新门控参数：Llama-3.3-70B 上是 46080 个标量，GPT-OSS-20B 上是 18432 个，相比 SecAlign 的 3.49 亿/3800 万参数和全参数微调的 700 亿/210 亿，规模小了几个数量级；训练沿用 SecAlign++ 的 DPO 配方和清洗过的 Alpaca 数据，偏好对中优选回答遵循用户指令、拒绝回答跟随注入。

在结果上，HoS 在自适应攻击下的优势非常突出：黑盒 RL-Hammer 攻击对 GPT-OSS-20B 达到 97% 攻击成功率、对 SecAlign 85%，对 HoS 只有 10%；Llama-3.3-70B 上对应为 99%、82% 和 1%，甚至低于 GPT-5.6-Luna 被同类攻击攻破的 36%。白盒场景下，作者用 GPT-5.6-Sol 做了 50 轮 autoresearch 专门针对 HoS 迭代出 V38 攻击，即便如此，在 AgentDojo 和 InjecAgent 上要把成功率打到 50% 所需的算力仍是基座和 SecAlign 的约 2.6 到 3.6 倍。效用方面，HoS 基本贴合基座模型：5-shot MMLU-Pro 上 GPT-OSS-20B 得 67% 对基座 68%，Llama-3.3-70B 得 55% 对基座 56%，而 SecAlign 和 ASIDE 分别跌到 59%/52% 和 16%；在 AgentDojo、AgentDyn、LLMail-Inject、WASP 等智能体基准上，HoS 与 SecAlign 表现相当，大幅压低攻击成功率且多数评测几乎无效用损失，ASIDE 则持续无法产出可用工具调用。局限也很清楚：HoS 依赖外部给定信任标签，标签错误或边界模糊时防线失效；训练数据仍是单轮 Alpaca 格式，多轮和少样本虽比基线稳但并非无懈可击；针对 HoS 训练的攻击者因奖励稀疏只学到 3.2% 训练成功率，说明其攻击面确实被压缩，但也提示更聪明的自适应攻击仍可能找到缝隙。总体而言，这项工作把提示注入防御从“改权重”转向“改注意力路由”，用极小参数量换来了更强的对抗鲁棒性和更好的效用保持，为指令—数据分离提供了一条可解释、可干预的新路径。

### [GEPA-Curator: Curated Learning for Self Improving Agents](https://arxiv.org/abs/2610.37651)
`评分3`

这篇论文要解决的是反思式提示优化在真实智能体场景下的信号污染问题。GEPA 这类方法的核心思路是让智能体带着工具在环境里跑任务，然后由一个 Reflector 根据轨迹和评估结果诊断失败原因、改写提示词，形成自我改进的闭环。但这个闭环隐含一个强假设：失败轨迹里含有可归因于提示词的、能泛化到未来任务的学习信号。在智能体任务中这个假设经常不成立——执行要经过 harness 与外部环境交互，成功与否往往由 LLM-as-a-judge 判定，一次失败可能来自提示词缺陷，也可能来自工具不可用、harness 限制、执行或评估的随机噪声，甚至任务本身歧义或不可行。论文举了个很具体的例子：智能体在购物网站下单失败，如果是漏勾了必选项，那反思后修改提示词是有用的；但如果是网页购买按钮临时故障，把这次失败当成提示词问题就会让 Reflector 得出“要寻找替代下单方式”这类有害结论。已有的防护手段是留出验证集做门控，GEPA 还会在 minibatch 上重测变异后的提示词以防退化，但作者指出这不够：一是门控依赖聚合分数，执行和评估的随机性会让好变异被拒、坏变异被收；二是门控只发生在变异生成之后，无法提升反思本身的质量。这就引出了论文的动机——与其事后过滤，不如在源头控制喂给优化器的经验质量，并给 Reflector 补充额外的上下文证据。

GEPA-Curator 的设计正是围绕这两点展开，它作为一层 harness 套在现有提示优化器外面，不修改优化器本身，只通过输入元数据施加影响。它维护每个任务的历史，包括历次轨迹和评估结果，并承担两个角色。第一个是任务策展：普通优化器每步随机打乱抽取 minibatch，而 Curator 会主动挑选更可能提供干净信号的任务、跳过疑似噪声任务。冷启动阶段优先探索历史不足的任务以积累记录；随着历史增多，遇到反复稳定成功、反复因提示词之外的因素失败、或相似结果评估不一致的任务时，Curator 可以临时跳过。关键在于“临时”——每个 epoch 都会重新考虑，因为提示词更新可能让已解决任务回退（比如提示词压缩或新增规则冲突），也可能让当初太难的任务变得可解。第二个是历史成功轨迹检索：常规优化器只对着当前 minibatch 的失败轨迹反思，Reflector 只能靠猜来诊断；Curator 则从任务历史中挑出一条最可靠的成功轨迹作为对照，让 Reflector 对失败行为做对比学习，有了可信参照再改提示词。挑选时偏好评估证据一致的成功，回避成功本身存疑或与其他观察矛盾的轨迹；找不到合适成功样本时直接弃权、不提供该元数据，避免噪声正例误导优化。由于任务策展和成功检索在同一次 Curator 调用中联合完成，后者不额外增加 LLM 调用开销。这套机制之所以比之前的方法更好，是因为它同时改善了优化循环的输入端（minibatch 里噪声和冗余更少，每步信号密度更高）和反思端（Reflector 有具体可信的正例作锚，变异更有依据而非猜测），而验证集门控只能做事后否决、管不到这两处。

实验在 GoBrowse 的四个 WebArena 网站（GitLab、Shopping、Shopping Admin、Reddit）、ALFWorld、AppWorld 和 τ-bench 上进行，actor 用 gpt-oss-120b，优化器模型分别用 Gemini 3.1 Pro 和 Claude Opus 5，minibatch 为 16，结果取 5 次运行平均。WebArena 上以 Gemini 3.1 Pro 为优化器时，GEPA 相对种子提示词提升 6.3%，GEPA-Curator 提升 9.7%，四个网站全面胜出，单站增益 1.6% 到 7.4%，聚合高出 3.4%，相当于 GEPA 优化增益的 1.54 倍；换成 Claude Opus 5 时，GEPA 提升 6.4%，GEPA-Curator 提升 11.4%，单站增益 0.6% 到 7.4%，聚合高出 5.0%，达到 GEPA 增益的 1.78 倍。附加基准上以 Gemini 3.1 Pro 为优化器，GEPA-Curator 在四个测试集上均超过两个基线，平均比 GEPA 高 14.3%、比 ACE 高 5.0%，摘要中给出的最大增益为相对 GEPA 20.7%、相对 ACE 21.2%。值得注意的是，作者采用的是去掉 Pareto 候选选择的贪心版 GEPA（单一线系、每次变异即下一检查点、每 16 步在验证集评估），消融显示 Pareto 选择影响不大，这说明收益主要来自策展而非搜索策略。局限方面，论文没有给出 Curator 自身判断错误（比如误跳过一个其实含有效信号的任务、或检索到表面成功但不可复用的轨迹）的定量分析，跳过决策依赖历史证据的积累，在 rollout 预算紧张时冷启动成本可能偏高；评估也集中在若干特定基准和两种优化器模型上，跨更多环境与更弱优化器模型的泛化性仍待验证。但它的方向性意义比较清楚：把课程学习里“数据选择与排序决定优化质量”的思想迁移到了智能体的反思式提示优化中，指出自我改进的瓶颈不只在 Reflector 会不会反思，更在于喂给它的经验是否值得学，这对递归自我改进方向是一个成本低、可插拔且与具体优化器解耦的改进思路。

### [Can LLMs Uncover Hidden Physical Laws through Free Exploration?](https://arxiv.org/abs/2610.37649)
`评分3 · https://zhenyangcs.github.io/LongChang-website/`

这篇论文要解决的是一个相当根本的科学发现问题：大语言模型能不能在没有被明确告知“去研究什么”的情况下，自己注意到世界运行方式不对劲，主动提出研究问题，并通过实验把隐藏的物理规律找出来。之前的工作卡在几个关键点上。PhysGym、NewtonBench 这类基准虽然也做“规律发现”，但它们在一开始就把发现目标交代清楚了——告诉模型去恢复某个隐藏方程，或者给定数值查询接口，模型只需要在既定任务框架内做参数拟合或假设检验。DiscoverPhysics 研究粒子模拟中的规律发现，同样预设了发现目标。另一些协议要求模型先给出显式初始假设、规定最少实验次数，或者干脆把异常现象直接喂给模型让它解释。这些设定都绕过了科学发现中最难也最真实的一环：异常是自己撞见的，问题是自己提的，实验是自己设计的。LongChang 的动机正是把这一环补上——它构造了一批“物理法则被篡改”的模拟世界，比如让重的物体下落得更慢，但不告诉探索者哪里被改了、甚至不告诉它世界被改过，看模型能否在自由摆弄物体的过程中自己察觉异常并追查到底。

方法上的核心设计可以拆成三块。第一块是环境构造：一个 LLM 设计者定义场景中的物体、几何结构、物理程序以及被篡改的法则，框架把这些编译成 MuJoCo 刚体仿真。基础集包含一个正常对照场景和 14 个各篡改一条物理法则的场景，每条被改法则的目标物体、触发条件、可观测效应都被记录下来供评估用，但对探索者完全保密。第二块是自主探索：被评测的 LLM 作为探索者，初始提示只要求它自由探索，不给研究任务也不给任何关于篡改的暗示。它能推、扔、抓取、释放物体、等待、标记参考位置，观测以结构化形式返回位置、运动和仪器读数。关键创新在于探索者可以自己设计工具——当它觉得需要额外控制或测量手段时，可以指定装置的几何和机械连接（关节、弹簧等），由一个独立的 LLM 审查者检查设计是否物理上可行，被拒可以修改重交，通过后装置被装进当前场景，探索者可以把物体放上去、调关节、读取运动数据。每一轮它记录观察和行动理由，最终报告里的每条结论必须引用支持它的轮次，并且只能使用笔记里已经记录过的解释，从而保留当时声明的不确定性。第三块是评估与场景演化：一个 LLM 裁判对照被篡改的法则和完整探索记录来评判报告，要求同时满足“法则正确性”（识别出被改法则及其目标物体、条件、触发器和可辨识常数）和“证据支持”（记录中的实验能支撑所有主张）。更妙的是，探索记录里未解决的问题和被后续观察纠正的错误，会被反馈给场景设计者，设计者据此用生成、精化、组合三种操作造出新的更难场景，整个循环无人干预地跑下去。这套设计比之前的方法更狠的地方在于：它把“注意到异常—提出假设—设计判别性实验—修正解释”整条链路都压给了模型，而且工具构造与假设检验是绑定的，探索者必须自己想清楚要造什么工具来区分竞争解释。

结果方面，在 12 个 LLM 中只有 GPT-6-Astra 取得了 16.7% 的发现率，其余 11 个全部为 0%。但数字背后的结构更值得看：GPT-6-Astra 的证据支持率高达 97.6%，法则正确率却只有 19.0%，说明它经常能做出有实验支撑的观察和部分发现，却没能把被改法则的完整条件或适用范围确定下来——比如它验证了红球之间的吸引，却没弄清这种吸引对距离的依赖关系、也没确认是否适用于其他红球。Claude-Opus-5 呈现相反的模式：16.7% 的运行识别出了被改法则，但没有一份报告通过证据支持检查，也就是说猜对了但没证出来。探索统计揭示了具体障碍：Gemini-3.7-Flash 每次都提前停止，平均只用 10.9 轮；GLM 系列用约 90 轮、每次都能造出可用装置，却零发现，且超过 60% 的建造尝试失败、失败动作占 16.8% 到 20.2% 的轮次；Grok-4.7 最少提前停止但同样零发现，说明光有耐心和能用的装置并不足以带来发现。消融实验给出了两个有意思的结论：给 GPT-6-Astra 加上规律发现任务提示和场景线索后，发现率从 16.7% 升到 28.6% 而证据支持率不变，平均探索长度从 39.3 轮降到 30.9 轮，说明引导在证据能力已经很强时能帮助锁定法则；把预算从 100 轮加到 500 轮并没有提升发现率，因为模型大约 40 轮就自己停了，多给的轮次用不上；而关闭工具构造功能后，发现率从 16.7% 跌到 4.8%、法则正确率从 19.0% 跌到 4.8%，直接证明了“自己造测量工具”这件事对发现隐藏规律是实质性的贡献。正常对照场景还暴露了另一个问题：36.1% 的报告因为谎称存在被改法则或对普通物理做出无支撑解释而被拒，比如 DeepSeek-Flash 把球在灰色地砖上滚得更远归因于摩擦更小，但每次推之前球已经在动了，起始速度不同就足以解释距离差异。局限也很清楚：整体发现率仍然很低，多数模型连异常都注意不到或者注意到了不追；法则正确率与证据支持率之间的巨大落差说明模型在“把规律说完整、说精确”上还很弱；场景演化部分虽然展示了用纠正过的错误来指导新场景生成的机制，但论文没有给出演化后场景上的发现率提升数据，这条闭环的实际增益还有待验证。尽管如此，LongChang 把“自由探索中的自主科学发现”做成了一个可自动运行、可量化评估的闭环，并且用工具构造消融和引导消融把关键机制拆开验证，为后续研究提供了一个比“给定任务做规律拟合”更接近真实科学实践的测试床。

### [Multi-State Linear Attention with Generalized Second-Order Routing](https://arxiv.org/abs/2610.37645)
`评分3`

这篇论文要解决的是长序列建模中一个很具体但被忽视的瓶颈：多状态线性注意力（MSLA）里"聚合"这一步怎么做。背景是这样的——标准自注意力是二次复杂度，KV cache 随上下文线性增长，没法无限扩展；线性注意力（比如 DeltaNet、Gated DeltaNet）用固定大小的记忆状态替代 KV cache，做到线性时间和常数内存，但单个固定状态容量有限，长上下文压缩时必然丢信息，实际效果还是打不过 full attention。于是 MSLA 把上下文切成若干段，每段压进各自的记忆状态，查询时从多个段级输出里加权求和得到最终表示，这样在"单状态线性注意力（常数内存）"和"全注意力（线性内存、二次时间）"之间插值。MSLA 引入两个新问题：怎么切段（separation）和怎么合并段级输出（aggregation）。这篇论文盯的是后者，因为前者已被研究得较多而聚合相对空白。现有聚合方法要么纯靠位置（假设越近越相关），要么只用查询与某段所有 key 的均值对齐度（一阶矩）来定权重。问题在于：均值对齐度无法区分"段里有个别 key 和查询高度对齐"和"段里所有 key 都 weakly 对齐"这两种情况——它们的均值可能一样，但前者显然更该被重视。作者用 HELMET 的 TriviaQA 检索任务做了个诊断实验，发现同时用均值和方差算权重的聚合方式，能把最高权重准确给到包含 ground truth 的那一段，而位置法和纯均值法都做不到，这就把"方差（二阶矩）必须进权重"这个动机坐实了。

Merlin 的核心设计是给每个段额外维护 key 的一阶矩和二阶矩，让查询能同时恢复出它与该段对齐度的均值和方差。具体来说，对每个 token 额外投影出一组维度更小的 key 和 query（维度 dr 小于主维度 d，目的是让矩保持紧凑），每段的第一个矩是该段所有 key 的均值向量，捕获 key 的平均方向；第二个矩是该段 key 外积的平均，捕获 key 在空间里的散布情况。查询到来时，用 query 与一阶矩做矩阵向量积得到均值对齐分，用 query 与二阶矩做二次型运算得到方差对齐分——注意这两个分数都只是矩阵向量乘法，不随段内 token 数增长，所以额外开销可控。得到两个分数后，分别用可学习温度缩放、各自做 softmax 归一化，再用一个从隐状态投影出来的标量门控把两者混合成最终聚合权重。这里的关键洞察在论文 3.3 节：如果把 token 级 softmax 注意力的质量按段分组，并对段内证据做 cumulant 展开，会发现一个段获得的总注意力质量恰好由均值和方差两项主导——也就是说 Merlin 的均值项和方差项正是 full softmax 注意力在段级别上的前两阶近似。但 Merlin 没有照搬那个固定系数的单一 softmax，而是用门控混合两个独立归一化的 softmax，温度和门控都可学，因此比固定展开更灵活。它比之前方法强的地方就在于：位置法完全无视段内容，均值法只能看到平均对齐、分不清"尖锐对齐"和"均匀弱对齐"，而 Merlin 通过二阶矩把段内对齐的分布形状也编码进路由权重，实现了真正 content-aware 的段选择。

实验上，作者把 Gated DeltaNet-1.3B（在 FineWeb-edu 上预训练 50B token）和 Mamba-2-780M（官方 300B token checkpoint）通过 mid-training 转成多状态变体：固定每段 256 token 均匀切分，16K 训练上下文下要聚合多达 64 个段级输出，分两阶段 mid-train——第一阶段 2B token 的 LDC 加 10% RULER NIAH 式合成数据激活聚合机制，第二阶段 60M token 的 LDC 加 RULER HotpotQA/SQuADQA 合成数据强化推理场景下的聚合。在 RULER 的 NIAH 和长上下文 QA 上，Merlin 比最强基线在 Gated DeltaNet 上高 8.3%、Mamba-2 上高 7.0%；在 LongBench 的 11 个子任务上平均分别高 13.5% 和 12.0%，甚至超过了消耗 4 倍内存的基线。局限方面，论文的分离机制固定为均匀切分、段长 256 未做自适应，二阶矩的额外存储和计算虽小但并非零成本，评测上下文停在 16K、模型规模最大 1.3B，更长上下文和更大模型上的表现尚未验证，且 mid-training 依赖 RULER 式合成数据，对真实长文档分布的泛化性还需更多检验。意义在于它把"段级路由"从位置先验和一阶统计推进到二阶统计，并给出了与 softmax 注意力的理论联系，为 MSLA 这类介于线性与全注意力之间的架构提供了一个简单、通用、可插拔的聚合模块，说明在固定内存预算下把统计矩用对，可能比单纯堆内存更划算。

### [Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis](https://arxiv.org/abs/2610.37648)
`评分3`

这篇论文要解决的是工具使用智能体训练数据从哪来、怎么配比才真正有效的实际问题。当下让大模型在多步、有状态的环境中调用工具完成任务，瓶颈不在模型结构，而在高质量训练数据的稀缺：互联网文本里几乎不存在多步工具交互轨迹，而这类数据又同时要求真实的任务、多样的工具和丰富的环境状态。已有路线大致分两类，各有硬伤。一类是用大模型直接模拟整条轨迹、连工具返回结果也由模型编造，这种做法扩展性不错，但复杂工具输出和状态转移很难被可靠地模拟，一旦环境状态变复杂，模拟出来的监督信号就会失真。另一类是用代码实现可执行的工具环境，可靠性上去了，但这些工作几乎都把注意力放在堆数据量上，没有回答一个关键问题：生成数据里究竟是哪些属性在驱动下游泛化——是工具的种类、任务的数量，还是工具所操作的数据库状态？这个空白导致大家不知道在固定预算下该往哪个方向扩，只能盲目地增加任务条数。

SynthAPI 的核心创新是把环境合成做成可控的，从而把上述几个属性解耦开来单独研究。整个流水线分两阶段。第一阶段由构建用的大模型从零用 Python 写出一批"应用"，每个应用包含元数据、一个定义数据类型的数据库 schema 文件，以及一层操作该数据库的 API 函数；这些函数读写实例化的数据对象，对外暴露为智能体可调用的工具，天然形成工具间的依赖关系，贴近真实部署场景。第二阶段为这些应用合成任务，一个任务由指令、初始数据库状态、验证器和一条 oracle 求解程序组成：验证器是判断任务是否完成的 Python 函数，oracle 求解器则用智能体可见的同一套 API 走通任务，用来过滤掉不可行的样本，只保留初始状态未完成、执行后完成的那些。关键在于它暴露了四个显式控制旋钮：应用数量 A 控制工具多样性，每应用任务数 T 控制任务多样性，每任务指令下的初始数据库数量 S 让同一指令在不同初始状态下重复出现，以及每个初始状态里干扰数据的批数 D 控制复杂度。任务总量是 A×T×S，而 D 只改变难度不改变数量，于是研究者可以在固定数据预算下精确地把预算分配给"新工具""同工具下的新任务""同任务的新数据库状态"这三条轴。智能体侧的接口设计也值得一提：它不预先塞入所有工具定义，而是只给 list_apps、list_tools、get_tool_documentation 和 complete_task 这几个元工具，让智能体自己发现并加载相关工具，这既压缩了上下文长度，也迫使模型学会迁移到新工具集，这也是它能在下游未见过的基准上泛化的原因之一。

实验规模相当扎实：共生成 458,752 个任务、64 个应用、10,472 个 API，训练了四种尺寸共 849 个模型，并据此拟合出一个以环境组成为自变量的缩放律。结论很有信息量：随着数据预算增大，扩工具多样性和数据库多样性比单纯增加任务数更划算，重复同一任务但换初始数据库状态也比生成新任务更有价值，提高数据复杂度在高预算下收益更大。该缩放律在留出的最高 25% 训练算力区间上外推，包括达到拟合所用最大算力 16 倍的那些运行，归一化下游得分的平均绝对误差为 0.0285，而只按任务数量建模、忽略环境组成属性的基线误差高达 0.1706，差距说明组成信息确实是预测泛化的关键变量。按这套配方训练出的智能体在 AppWorld、BFCL 和 ASTRA-Bench 上平均比此前大规模工具智能体数据训练的模型高 30.5 个百分点，在 AppWorld Test-Challenge 上比各尺寸下最强的单基准合成基线高 7.6 到 11.6 个百分点，BFCL 上高 2.0 到 3.7 个百分点。局限也很明确：目前所有任务都限制在单个应用内，多应用协同任务留作未来工作，只是实验显示模型能泛化到下游的多应用评测；此外整个流水线依赖一个强构建模型来写代码和验证器，合成质量的上限受它约束，验证器覆盖不到的错误行为可能漏网。但无论如何，它把"该生成什么样的数据"从经验直觉变成了可预测、可外推的定量配方，这对工具智能体的数据规模化是一条有实际指导意义的路径。

### [MuonGS: Pretraining LLMs with Relaxed Weight-Norm Control](https://arxiv.org/abs/2610.37647)
`评分3 · 21 pages, 9 figures`

这篇论文要解决的是大语言模型预训练中权重范数控制“为什么有用、需要多少才够”这一悬而未决的问题。现有做法大致分两类：一类是AdamW和MuonW那样用解耦权重衰减做软性收缩，强度需要调参且最终权重尺度依赖优化动力学；另一类是MuonH、nGPT那样把权重范数硬性固定住，直接规定训练全程的权重尺度。这些方法确实有效，但缺少统一解释——到底范数控制的哪个量在起作用，硬约束是不是必要的。作者的切入点是“有效学习率”，即名义学习率除以当前权重矩阵的Frobenius范数，它衡量每一步相对权重尺度走了多远。权重范数一旦增长，即使名义学习率不变，相对步长也会被稀释。作者进一步把整个训练轨迹上的有效学习率累加起来，记为C_T，并证明在更新方向有界的前提下，任意区间[s,T]上的相对权重位移被M(C_T−C_s)所界定；对于尺度不变的损失函数，损失下降量同样需要足够的C_T增量。这就把“探索能力”量化成了一个必要条件：C_T增长不够，权重就动不了多远，损失也降不下去。在这个视角下，原生Muon在常数学习率下范数线性增长，C_T只能达到对数级Θ(log T)，后期几乎停止累积，这正好解释了它经验上进步偏慢的现象；而MuonW和固定范数的MuonH在相同条件下能保证至少线性累积Ω(T)。但作者同时指出，有界范数只是实现线性累积的充分条件而非必要条件——只要范数增长得足够慢，累积速度就能超过原生Muon的对数最坏情形，这就为更宽松的范数控制打开了设计空间。

MuonGS的核心设计正是顺着这个洞察走的：它不固定权重范数，而是用Gram–Schmidt投影把Muon更新中沿当前权重方向的分量（径向分量）去掉，使更新在Frobenius内积意义下与当前权重正交。这个正交性很关键——它消掉了权重范数的一阶增长项，范数只在步长的二阶意义上增长。在更新方向有界、名义学习率恒定的条件下，作者证明经过t步后权重范数最多按根号t增长，于是C_T达到Ω(根号T)，而且这个累积在后期训练窗口[2T, T]上仍保持Ω(根号T)的增量，也就是说探索能力不会像原生Muon那样在后期枯竭。相比MuonH把范数钉死在固定半径上、牺牲了权重尺度自由演化的空间，MuonGS只移除了会导致范数爆炸的那个方向分量，保留了切向的更新自由度，因此既拿到了比原生Muon更好的累积保证，又不像硬约束那样限制权重尺度的自然变化。对于光滑的尺度不变目标，作者还给出了O(T^{-1/2})的平稳性收敛保证，说明这种松弛并没有破坏收敛性。直观上，Muon的更新方向本身已经做了正交化处理、各奇异值被拉平，GS投影再剥掉径向分量后，每一步都在“转动”权重而不是“撑大”权重，相对步长得以在训练全程维持。

实验在FineWeb上用现代化GPT风格模型做预训练，规模为约160M和400M参数的稠密模型，另外还在Ultra-FineWeb上训了一个约135M激活、1B总参数的MoE模型。对比对象是MuonH。在较长训练周期下，MuonGS的验证困惑度低于MuonH；把MuonH的损失拟合为训练token预算的函数后，在匹配验证损失的点上估计出最高约15%的token等效加速。MoE模型上MuonGS同样取得更低的验证困惑度。这些结果支持了论文的核心主张：比有界范数更弱的范数控制不仅能维持训练后期的累积探索，还能在实际预训练中带来更好的效果。局限方面，理论保证依赖更新方向有界和常数名义学习率等条件，实际实现中Newton–Schulz迭代和形状相关缩放会引入常数因子，虽然可被吸收进界中，但严格常数并非直接对应；此外Proposition 3.1只是必要条件，累积大并不自动意味着损失更低，探索能力与实际泛化之间的定量关系仍未完全刻画。不过这篇工作把范数控制从“每步保护相对移动”的局部视角提升到了“整条轨迹上累积有效学习率”的全局视角，指出了硬约束可以被松弛而不损失甚至提升性能，这对Muon系优化器的设计空间是一个实质性的拓宽，也为后续按范数增长速率来分类和设计优化器提供了可分析的语言。

### [Gym-Anything-RT: Scaling Real-Time Environments for Vision-Language Agents](https://arxiv.org/abs/2610.37567)
`评分3`

这篇论文要解决的是当前 AI 智能体在需要实时交互的场景下表现不佳、却缺乏可控评测手段的问题。现有智能体在数学、软件工程、桌面操作等任务上进步显著，但这些场景的共同点是环境会“等”智能体思考——模型往往要花十秒以上才决定一个动作，而环境状态在此期间不变，所以慢不是问题。可一旦换成打电子游戏或操作物理设备，环境会在智能体推理时、甚至在模型做一次前向传播的过程中持续演化，等动作真正执行时可能已经失效，智能体也无法对期间发生的变化做出反应。现有评测对此几乎无能为力：计算机使用类基准在动作之间会等待智能体，因此从未真正测试“状态演化下行动”的能力；视频游戏类基准虽然实时运行，但前沿模型进展甚微，而且每个游戏把 3D 空间理解、时序推理、学习陌生操控等多种能力捆绑在一个固定任务里，导致无法判断失败究竟是因为模型太慢，还是因为缺少别的能力。要把“慢”和“其他能力不足”这两个原因分开，就必须在同一个任务上做受控对比，只改变智能体可用的响应时间——这正是此前工作缺失的关键一环。

作者的核心思路是构造“视觉小游戏”（visual minigames）：它们只保留实时交互所需的一组能力，而避开完整游戏的复杂度，同时把每个小游戏做成可执行程序，从而能精确控制它的时钟。具体来说，每个小游戏是一个可执行环境，程序定义了内部状态、操控方式和时钟；智能体每步看到一张截图、发出鼠标键盘动作，而环境在它决策期间持续演化。所谓“需要实时交互”，被严格定义为：智能体必须依据最近的视觉证据来选择动作，且从观察到执行之间的状态变化会降低该动作的价值——仅仅加个倒计时或装饰性动画不算数。关键设计在于每个小游戏都有十种配置（五档难度乘以简化/完整两种交互模式），并且能以三种时钟方式运行：原生速度实时运行、按 1/s 速率放慢、以及在观察后冻结画面直到动作执行。更重要的是，每个实时小游戏都有一个“非实时对应版本”，由创作者智能体对时序做最小改动得到，目标、操控、难度和可用信息全部保持不变，再经独立审计智能体在全部十种配置上核验两者只在时序上有差异——这样对比同一任务的实时版与非实时版，就能把实时性要求的影响从任务本身的难度中剥离出来。小游戏不是手工做的，而是用智能体流水线自动生成：先由调研智能体从先前工作、公开演示、视觉谜题中筛选候选任务，标准是能自成一体、需要视觉理解与定位、通过视觉界面操作、结果可客观验证；再由创作者智能体把任务实现为程序，并额外写一个“神谕求解器”（oracle solver），利用环境的特权内部状态走一遍合法解法，以此证明任务可解、动作路径与评分路径一致；然后由无法修改程序的独立审计智能体检查生成、可解性、渲染、动作处理、评分和失败恢复，还专门搜寻能绕开实时要求的捷径（比如让运动部件停下的“刹车”、或周期性运动使解可以预先算好），问题退回创作者修复，循环直到审计通过；最后由评审智能体标注每个小游戏所需的能力并校准难度。为了让弱模型也能被评测、并研究任务难在何处，创作者还在保留原配置的前提下构造四档更简单的难度（改变信息量、依赖数量、速度、精度、动态性或同时操控要求），并实现简化交互（暴露代理控件）与完整交互（要求直接的鼠标键盘操作）两种模式。在工程上，为了不让动作传输延迟污染实时性测量，作者还搭了直连协议：中央服务器仍并行管理大量沙箱，但每个智能体与自己的沙箱直接交换动作和截图、绕过服务器，使从发出动作到收到结果截图的中位时间低于 50 毫秒；放慢模式下会缩放小游戏的所有时钟（计时器、动画、服务端时钟），但动作投递与截图捕获仍按真实时间运行，因此只改变可用响应时间而不改变交互方式。

在结果上，作者用这套流水线构建了 100 个实时小游戏及其 100 个非实时对应版本，加上四档更简单难度和简化交互模式，共 2000 种配置，并在实时、放慢、暂停三种设置下评测了前沿与开源模型。结论相当刺眼：GPT-6 Astra（xHigh）在实时小游戏上的通过率只有 9.0%，而在仅改动时序的非实时对应版本上达到 66.0%；Claude Opus 5.5（xHigh）和 GPT-6 Luna（xHigh）的实时通过率分别只有 5.0% 和 1.0%，开源权重模型 Qwen3.8-27B 与 Qwen3.5-9B 更是只有 1.0% 和 0.0%。通过放慢时钟可以干净地定位瓶颈：把环境放慢 64 倍，Astra 的通过率从 9.0% 升到 57.0%，直接暂停则升到 75.0%，说明对前沿模型而言主要瓶颈就是速度；借助可控的难度与交互界面，作者还识别出时序推理和对陌生界面的探索是额外的难点来源。另一个有趣发现是，前沿智能体能部分地用强大的编码与推理能力弥补实时性的不足：当允许 Astra 写代码时，它会写出脚本代替自己在两次响应之间感知和行动，例如在“旋转屏幕键盘”任务中用图像模板匹配定位移动的按键并在 200 毫秒内点击，使实时通过率从 9.0% 提升到 31.0%——这既是能力，也是一种值得警惕的“绕过”行为。局限方面，这套基准仍局限于程序化的视觉小游戏，与真实游戏和物理设备的复杂度有距离；评测规模为 100 个任务，覆盖面有限；小游戏由智能体自动生成，即便有审计环节，仍可能存在偏差或漏网的捷径；而“写代码绕过实时感知与行动”这一现象也提示，单纯以通过率衡量实时交互能力可能被智能体的工程手段所混淆。尽管如此，这项工作把“实时性”从一个笼统的失败原因拆解为可测量、可控制的变量，提供了可公开复用的环境与生成流水线，对该方向的意义在于：它给出了一个清晰的诊断工具，让后续研究能区分模型是“想得慢”还是“不会做”，并为实时交互智能体的训练与评测树立了可对照的基线。

### [VideoLVR: Latent Visual Reasoning over Grounded Video Evidence](https://arxiv.org/abs/2610.37613)
`评分3 · 13 pages`

这篇论文要解决的是多模态大模型在视频推理中的一个根本性缺陷：基于语言的思维链虽然能提升推理能力，但推理轨迹本身是纯文本的，模型在逐步推理的过程中会逐渐"遗忘"视频中与任务相关的视觉证据，也就是所谓的视觉遗忘问题。现有的两条技术路线各有硬伤。第一条是用文本坐标（时间戳加边界框）来指代证据位置，这种方式虽然紧凑可追溯，但坐标编码的是"位置"而非"视觉内容本身"，模型拿到的只是一个符号化的地址，并没有真正重新看到那块画面。第二条是调用视觉工具把相关区域裁剪出来或额外抽帧再塞回多模态上下文，这样确实保留了视觉细节，但每次工具调用的返回结果都需要重新编码并插入上下文，随着推理步数增加上下文会急剧膨胀，而且工具集是预定义有限的，不够灵活。潜空间视觉推理（LVR）提供了一条新思路——用连续隐状态而非文本或额外视觉观测来表示中间视觉证据，但此前的工作主要集中在图像域，视频场景下有兩個特殊困难：一是单个推理步骤可能需要来自多个时间点的局部证据联合支撑，任何单一时刻的画面都不够用；二是相邻帧的视觉token高度相似，传统的MSE特征回归对每个预测目标独立对齐，无法把目标token与视频中其他长得差不多的token区分开，模型很容易学到"差不多就行"的捷径。

VideoLVR的核心设计围绕"分组潜空间视觉证据"展开。首先在数据层面，它从一个教师模型合成证据接地的推理轨迹，每条轨迹中穿插若干证据组，每个证据组把一个中间推理断言与一组带时间戳和边界框的局部区域绑定在一起，这些区域可以来自同一帧也可以跨多个时刻。合成过程用了拒绝采样保证答案正确且证据格式合法，再用证据引导的抛光步骤修正证据组的位置——因为拒绝采样出来的轨迹里证据组经常出现在相关推理语句之后甚至堆在末尾，直接转成潜空间块会导致证据与推理步骤错位。然后是关键的目标构造：把每个局部区域映射到编码后视频的时空token网格上，取出被边界框覆盖的视觉token嵌入序列，同一个证据组内的多个区域按时间戳排序后直接拼接成一个分组目标序列，不插入任何分隔符，用<bot>和<eot>标记每个潜空间块的起止位置，块内的潜空间位置数量等于该组所有区域视觉token数之和。训练时每个潜空间位置的前一个隐状态被监督去预测对应的目标视觉token。这里最关键的创新是视觉token预测（VTP）目标：它不直接做特征回归，而是把输入视频编码出的全部N个视觉token构成一个候选词表，用隐状态经一个两层MLP投影成视觉查询，然后以负的均方距离打分、经温度softmax得到整个词表上的分布，再对目标token做交叉熵。这样一来，同一个视频里那些视觉上相似的token就成了竞争项，迫使每个查询在整段视频的视觉内容中精准识别出自己接地的那个目标，而不是回归到一个模糊的平均特征。文本部分照常做下一token预测，两个损失加权联合优化。推理时，解码器隐状态经同一个投影头变成潜空间视觉状态直接反馈回模型，不需要插入任何额外的帧或裁剪区域，上下文几乎不增长。论文还把方法扩展到了强化学习，提出文本-视觉策略优化（TVPO），把从输入视频视觉词表中采样出的视觉token当作与文本token并列的动作，用最终答案的奖励联合优化文本和视觉两类的策略。

实验在多个视频理解和推理基准上验证了有效性，尤其在需要细粒度视觉证据的任务上提升明显，但摘要和引言没有给出具体的对比数字和提升幅度，需要看正文的实验表格才能确认量化结果。从意义上看，VideoLVR的价值在于它把"重新访问视觉证据"这件事从上下文膨胀的困境中解耦了出来——潜空间块提供了一种紧凑、可微分、与文本生成统一在同一token预测框架下的证据回访机制，而且VTP用输入视频自身的视觉词表做竞争性预测，比MSE回归更能抵抗视频帧间冗余带来的捷径学习。局限方面，方法依赖教师模型合成高质量的时空接地推理轨迹，数据构造管线较重且教师的质量上限会传导到学生模型；潜空间块的长度由接地区域的token数决定，推理时每个块的潜空间步数是固定预算，这种固定预算与证据复杂度之间的匹配是否最优尚不清楚；此外论文自己也引用了诊断性研究指出潜空间token可能被模型绕过或偏离目标，VTP的竞争机制能在多大程度上缓解这一问题还需要更细致的消融来支撑。总体而言，这条路线为视频推理中的证据回访提供了一个有别于"坐标指代"和"工具调用"的第三种范式，如果后续能在数据依赖和潜空间监督的鲁棒性上继续改进，对长视频多步推理方向会有实质推动。

### [Multiscale Policy Optimization for Long-Horizon LLM Agents](https://arxiv.org/abs/2610.35013)
`评分4 · HF 316赞`

这篇论文要解决的是长程LLM智能体强化学习中的信用分配尺度错配问题。LLM智能体与环境交互时，动作是以完整的助手回合为单位提交的（比如一次搜索查询、一次工具调用或最终回复），但策略本身是逐token自回归生成的。这意味着从终端任务奖励中学习时存在两个尺度：信用需要把最终结果连接到整条轨迹上的各次交互，同时还要区分每次交互内部各token的贡献；策略更新既要考虑完整输出概率的变化，又要保留token级的局部区分。现有两类主流RL方法恰好卡在这两个尺度之间：无critic的组相对方法（GRPO、DAPO、GSPO等）从组相对结果奖励中为每条生成序列导出一个共享优势，这个共享信用信号无法区分单条rollout内各个回合或各个token的贡献；有critic的token级方法（PPO、VC-PPO、VAPO、SAO等）用学到的价值函数沿token序列估计优势，把每个生成token当作动作，提供了更细的信用，却没有显式区分回合内生成与回合级环境交互。作者观察到一个关键的经验事实：在搜索智能体的2048条轨迹、16323个回合中，回合均值之间的差异占critic的token加权轨迹内价值方差的中位数达89.5%，93.8%的轨迹中回合间方差超过回合内方差。这说明critic价值主要在回合尺度上变化，因此需要一种既能在回合间传播长程信用、又能保留回合内token信息的优化方法。

MPO的核心设计由两部分组成，背后有明确的理论分析支撑。作者先把完整助手回合视为宏动作，建立了回合级的策略改进界，并证明在相同KL约束下，token级替代目标会因回合内分布偏移而引入额外的惩罚项——具体来说，宏替代目标在新策略前缀上对token优势求平均，而token替代目标用的是旧策略前缀，这个前缀分布的差异产生了额外代价；同时token级KL上限换算到宏尺度会多出与回合长度和最大token数相关的惩罚。基于这个分析，MPO的第一部分是Multiscale Advantage Estimation（MAE）：先用回合级GAE在宏时间轴上传播信用，做法是把一个回合内所有TD残差求和，内部价值预测全部抵消，只留下边界值，这样共享信用按交互次数而非token数衰减，且与回合长度和内部critic预测无关；然后通过一个中心化的局部修正来细化token信用，局部trace只在当前回合内计算、在边界处截断，最终分配被表述为一个严格凸的最小二乘投影问题——在保持回合均值等于回合级估计的前提下，让token权重尽可能接近缩放后的局部信号，其解等价于把局部信号中心化后加上回合估计，β=0时退化为回合广播。第二部分是回合级重要性修正：用完整回合的概率比ρ_t进行策略梯度加权，但对其他token的概率比做stop-gradient，只保留当前token的MAE优势，这样既在回合尺度上对齐了信用分配与策略更新，又避免了完整回合比率在未截断求和中把中心化局部修正抵消掉。相比之前的方法，MPO的关键改进在于让信用分配的粒度和重要性加权的粒度都锚定在回合尺度上，同时不丢失token级区分。

实验在搜索、工具使用和自动化三类任务上，用4B和30B-A3B两种模型与强RL基线对比，均取得了一致的性能提升。论文摘要和贡献部分给出了定性结论但没有在正文中列出具体提升数字，需要查阅实验部分才能获得精确数值。局限方面，理论分析假设固定的回合horizon且γ=1，实际任务中回合数可变、终止条件复杂，这个假设与真实场景存在差距；MAE的回合级信用传播依赖边界critic值的准确性，虽然附录用边界critic误差刻画了估计误差，但critic本身在长程任务中的学习质量仍是瓶颈；局部修正的缩放系数β需要调节，论文未充分讨论其敏感性。此外，stop-gradient构造虽然在理论上保住了token级信用，但它对梯度方差和训练稳定性的影响还需要更多消融来验证。从方向上看，这篇工作把智能体RL中"回合作为宏动作、token作为微观生成"的双尺度结构显式建模进策略优化框架，给出了回合级改进界和token替代目标的额外代价这两个可复用的理论工具，对后续长程智能体RL的信用分配和重要性采样设计有直接的参考价值。

### [Rollback: Experience Backtracking in World Models for Policy Improvement](https://arxiv.org/abs/2610.36068)
`评分3 · HF 50赞`

这篇论文要解决的是机器人策略学习中一个很实际的瓶颈：用真实世界交互来改进策略代价太高，每次试验都要占用机器人、还得人工重置环境，而基于动作条件世界模型的方法虽然提供了可扩展的替代方案，却普遍把世界模型当成"只能向前播放"的物理环境替身——生成一条前向 rollout，中间的上下文用完就扔。这相当于浪费了世界模型一个物理环境根本不具备的能力：回退到过去的决策点、从同一段历史分叉出反事实的未来。现有方法卡在三个地方。第一，探索效率低：一条轨迹里真正决定成败的关键决策只有少数几个，其余决策换个动作结果差不多，但独立 rollout 无法识别这些关键点，只能把算力均匀撒出去。第二，决策级监督太稀疏：轨迹级的成败标签说不清哪个中间动作起了作用，而单独学一个价值模型又引入额外假设和估计偏差。第三，世界模型预测有偏：从策略选出的上下文分叉，会把交互推到世界模型训练分布之外，预测误差累积甚至被优化过程利用，想象出来的收益未必能迁移到真机。这三个问题不解决，"回退重想"这个诱人的能力就没法真正落地。

Rollback 的核心设计正是围绕这三点展开。它把世界模型从被动模拟器变成"反事实引擎"：从真实成功或失败轨迹的中间决策点回退，缓存世界模型的时间上下文，从同一历史分叉出不同的动作块继续想象。具体由三块组成。其一是经验回退树搜索：以真实轨迹为参考路径，每个非终止节点都是分叉点，策略在此提出替代动作、世界模型模拟后果，并用蒙特卡洛树搜索自适应分配想象预算——用 PUCT 分数在"高经验成功率的分支继续深挖"和"访问不足的分支给探索奖励"之间平衡，把算力集中到那些替代动作会导致结果分化的关键决策上，而不是穷举所有分支。这里有个工程细节很关键：他们用的 GE-Sim 2.0 世界模型不仅预测三路相机的未来帧，还通过 pose-expert 头预测机器人本体状态（每条手臂七个关节加一个夹爪），这样策略在想象中收到的输入和真机上完全一致，否则光靠生成图像推断手臂构型，对于需要精确接触和释放时机的任务来说太粗糙了。其二是树结构价值估计：兄弟分支共享同一个决策上下文，对比它们的下游结果就能把单个动作的效应隔离出来，通过对子树级结果做聚合，得到细粒度的动作级优势监督，完全不需要额外学一个价值模型，也就避开了价值估计偏差。其三是世界模型与策略的共同演化：分布式世界模型搜索和异步真机执行统一在一个训练系统里，真机经验持续修正世界模型，更准的世界模型又反过来驱动策略改进。他们把这个循环中世界模型一侧的能力称为"测试时物理 grounding"——世界模型预训练后作为策略的训练环境，而策略自己采集的真实转移通过轻量 LoRA 管线去纠正世界模型在策略实际访问状态上的动力学预测。这一点很要害：现有世界模型大多是离线训练完就当固定模拟器用，做评估够用，但做策略学习不够，因为一个正在变强的策略恰恰会走进模拟器见得最少的状态。

实验在三个有挑战的真实机器人任务上验证：方块抽取、抛球和桌面冰壶。相比最强基线，成功率分别绝对提升 10.67%、11.11% 和 11.85%，而且在相同交互预算下训练过程更稳定、提升更快。更值得注意的是，尽管策略是从远低于人类水平的遥操作演示初始化的，在单台真实机器人上训练 8 小时内，抛球和桌面冰壶两个任务的平均成功率就超过了人类玩家的平均水平。局限方面，论文没有回避世界模型预测偏差这个根本问题——测试时物理 grounding 只是用策略实际访问状态上的真实转移去纠偏，如果策略探索到分布外很远的地方，LoRA 修正能否跟上仍是开放问题；此外方法依赖 MCTS 在连续动作空间里的采样效率，动作维度高或任务 horizon 长时搜索成本会上升，三个任务也都是相对短时程的操作。但这项工作指出的方向很有价值：世界模型的价值不只是"替代真实环境做前向模拟"，更在于它能被回退、被分叉、被用来做反事实归因，这把世界模型从评估工具推向了真正的策略改进引擎，而搜索与训练、真机执行三者并发互馈的系统设计，也为世界模型在真实机器人上的闭环学习提供了一个可复制的工程范式。

### [EnvSched: Environment-Aware Scheduling for Rollout-Efficient Agent Reinforcement Learning](https://arxiv.org/abs/2610.37609)
`评分3`

这篇论文要解决的是智能体强化学习里一个很实际的瓶颈：当可执行环境从几十个扩展到成千上万个时，生成和验证 rollout 的开销随之暴涨，工业界报告里动辄几十万 GPU 小时的训练成本让「怎么把有限的 rollout 预算花在刀刃上」成为核心问题。已有的在线任务选择方法（按任务难度、prompt 表示或历史奖励来估计训练价值）都只对 prompt 或任务本身建模，把可执行环境排除在选择模型之外，但环境恰恰决定了工具集合、初始状态、状态转移规则和验证器，也就决定了任务会怎样展开、能产生什么样的学习信号。换句话说，同样的任务描述放进不同环境，rollout 的信息量和失败模式可能完全不同，而旧方法对此一无所知，于是容易反复采样那些「看起来难但实际奖励方差很小」的任务，或者过度集中在少数环境上，导致策略见过的工具、状态和验证模式越来越窄。

EnvSched 的关键洞察来自 GRPO 这类组相对方法的更新机制：同一任务多次 rollout 之间的奖励差异决定了相对优势，奖励几乎相同的任务提供不了学习信号，所以调度器应该优先选择当前奖励分布最可能产生有信息差异的任务；但同时，只盯着高方差任务会让策略反复困在少数环境里，因此还必须显式保证环境与交互模式的覆盖。为同时支撑这两个判断，它把「环境–任务对」建成一张双关系图的节点：环境内边用六个 TF-IDF 视图（指令词与字符片段、验证器检查文本、验证器代码结构、初始上下文、完整操作描述）刻画任务语义与具体工具、状态、验证器特征的相似度；跨环境边则先由 LLM 抽取结构化操作描述，再把工具名、字段名、实体标识和目标值剥离，把操作与条件映射到查找、资格检查、关系替换、依赖状态校验等抽象类别，从而让「重新指派顾问」和「转移病床」这类业务术语不同但执行拓扑相似的任务互相迁移历史统计。每个训练步，节点沿两类边分别聚合历史 rollout 的奖励均值、组内奖励方差和均值校正离散度，经过向全局基准收缩、两路估计等权融合成图先验，再与节点自身历史按观测权重结合，校准出一个信息量百分位分数；调度时每批一半预算给覆盖（按当前批次环境覆盖、累计环境暴露、任务观测次数的字典序优先级圈定候选，再在其中按信息量排序），一半给利用（按信息量乘以随累计选择次数衰减的暴露因子排序），两阶段共享同一个贪心批次，并用环境配额、连续选择上限和基于完整任务表示的相似度惩罚抑制冗余，另外还有进度过滤器（暂时剔除估计进展非正的任务）和标识符过滤器（用固定动作重放确认可疑的产奖励动作并剔除相关任务）来修正候选资格。整个 rollout–更新–传播–选择的闭环不需要额外的试点 rollout，就能在策略演化过程中持续把预算导向既有奖励区分度、又覆盖不足的环境与任务。

在 EnvScaler 的 2550 个任务、51 个可执行环境上，用统一 GRPO 配置训练 Qwen3 系列模型，每批 64 个环境–任务对、每对 8 条 rollout，覆盖比例固定为一半。Qwen3-8B 训练 40 步后在 BFCL-v3、τ-Bench 和 ACEBench-Agent 上平均分达到 48.81，超过了随机任务选择训练 120 步才达到的最高分，也就是说 rollout 效率大约提升到三倍；同样预算下各模型尺寸的下游表现也都有提升。机制层面的统计验证很能说明问题：Qwen3-4B 上被选中任务的组内奖励方差均值从 0.03208 升到 0.04290，每批覆盖的环境数从 36.53 升到 45.96，消融实验进一步确认奖励区分度和环境覆盖两者互补、单独任何一项都不足以带来有效训练。局限方面，论文的评测集中在工具调用与多轮交互类基准，环境池规模（51 个环境）相对工业级数千环境的场景仍小，图相似度在训练中固定、依赖 LLM 预抽取的操作描述质量，跨环境迁移的抽象粒度是否在更异构的领域仍然成立也还没有验证；此外调度器引入的图维护与相似度计算开销、以及超参（邻居数、覆盖比例、暴露衰减）在不同环境池上的稳健性，论文没有充分展开。但它的意义在于把「环境级数据管理」正式提为一个可建模、可调度的问题，并给出了一套不增加额外 rollout 就能落地的方案，为以数据为中心扩展高效 Agentic RL 提供了一个明确的方向。

## AI + 生物

### [HELICS: Biobank-scale Conditional Synthetic Genome Generation via Latent Flow Matching](https://arxiv.org/abs/2610.36361)
`评分4 · NeurIPS 2026`

这篇论文要解决的是基因组合成数据生成中的一个真实瓶颈：个体级基因型数据是遗传发现、疾病风险建模和药物靶点研究的基石，但在代表性不足的祖先群体、罕见病或类别不平衡的疾病队列、以及访问受限的生物样本库等场景中，数据严重匮乏。条件式合成基因组本可用于隐私保护的基准测试、模拟和数据增强，但难点在于必须学习一个定义在几十万到上千万个相关SNP之上的超高维离散分布。以往的方法各有硬伤：经典的单倍型模拟器和参考面板方法（如HAPGEN2、HAPNEST）依赖已分型的参考队列，而单倍型分型（phasing）在生物样本库规模上计算代价极高，且很多方法只针对小区域或GWAS筛选后的变异集；基于GAN或扩散模型的学习式生成器虽然更灵活，却被限制在单个染色体、小基因组区域或预先选定的性状相关SNP子集上，无法覆盖全基因组范围内分布的微弱多基因信号。至于DNA碱基级的基础模型，它们面向的是调控和功能预测，建模对象是参考序列而非人群变异，与GWAS、多基因风险评分等以变异为坐标的分析范式并不对齐。因此，核心动机是：能否直接从无分型的生物样本库剂量数据出发，在全基因组尺度上学习一个既保真又可控的生成模型。

HELICS的关键设计是把"超高维离散序列生成"转化为"低维连续潜空间中的传输问题"，并刻意绕开单倍型分型。整个流程分两阶段。第一阶段为每条染色体训练一个卷积自编码器：输入是one-hot编码的SNP剂量序列，编码器通过带残差的下采样块（类似pixel-unshuffle的跨步卷积加长度到通道的短路连接）把每条染色体压缩成固定维度的连续潜令牌，全部22条染色体合计只有4096个令牌、每个256维，把超过60万个SNP压缩了两个数量级以上，同时把下游Transformer的注意力复杂度从原始位点数的平方降到令牌数的平方。解码器镜像地上采样回原始长度并输出三个剂量类别的logits。自编码器的损失不只是逐SNP交叉熵，还额外加了两个关键约束：一是惩罚解码后的期望剂量算出的次等位基因频率与经验MAF之间的平均绝对偏差，二是惩罚局部基因组窗口内解码剂量与真实剂量的相关矩阵差异，也就是局部LD结构的失真。这两个约束很要紧，因为只优化重建精度的话，模型可以几乎全预测主基因型而获得很高的准确率，却丢掉了低频变异和连锁不平衡——而等位基因频率差异正是祖先群体结构的来源，LD直接决定变异标记和多基因评分的行为。此外还有一个条件预测项，把潜令牌均值池化后用两层MLP预测祖先和遗传易感性摘要，迫使潜表示保留这些信息；潜空间稳定化正则只在训练最后25%启用。第二阶段冻结自编码器，在拼接后的全基因组潜表示上训练一个Transformer参数化的条件流匹配模型：从标准高斯先验采样起点，从自编码器潜分布采样终点，沿直线插值路径学习预测恒定速度场，条件版本则把祖先和遗传易感性摘要作为条件输入速度网络。生成时从先验积分流场得到潜令牌，再经各染色体解码器取argmax得到硬基因型调用。相比之前的方法，HELICS的优势在于：不需要phasing因而避开了生物样本库规模上最昂贵的预处理；在全基因组而非预选位点上建模，因而能保留预定义关联位点之外的微弱多基因结构；条件控制是学出来的而非依赖外部关联检验筛选的SNP集，因而适用于高多基因性状和发现型场景。

在UK Biobank数据上（质控后604,243个常染色体SNP、427,948个多祖先个体，另训练一个251,465名无亲缘关系White British个体的单祖先版本），HELICS在留出真实基因型上的保真度优于现有的单倍型和基因型模拟器，外部评估中等位基因频率一致性达到R²=0.992，并更好地保留了局部与长程SNP相关结构。条件生成方面，以祖先和遗传易感性摘要为条件可以跨遗传风险谱定向生成；在扰动分析中，提高条件化的疾病性状易感性会在生成基因组中诱导出SNP水平的剂量变化，而这些变化与已发表的关联权重高度相关，这为条件控制提供了一个可解释的外部校验。局限也需要客观看待：模型目前只覆盖常见变异（约60万SNP），稀有变异和结构变异未纳入；评估主要围绕 allele frequency、LD、祖先几何和下游遗传学基准，是否足以支撑隐私保护承诺（如成员推断攻击下的安全性）论文并未系统量化；条件控制依赖遗传易感性摘要这一汇总层级的输入，对具体因果位点的精细操控能力有限；此外自编码器压缩到4096个令牌是否在更大多祖先队列或更密变异集下仍然够用，也需要进一步验证。尽管如此，这项工作把全基因组SNP级合成从"依赖参考面板和phasing"推进到"直接在无分型生物样本库数据上学习潜空间生成模型"，为数据受限的遗传学研究提供了一条可扩展、可条件控制的技术路径，其"高压缩自编码器加潜空间流匹配"的组合对其它超高维离散生物数据的生成建模也有借鉴意义。

### [Accurate structural modelling of protein-glycan recognition with GlycoWeave](https://arxiv.org/abs/2610.37410)
`评分4`

蛋白质-糖识别是免疫识别、细胞黏附、信号转导和病原侵染等过程的核心分子事件，但要在原子层面准确预测蛋白-糖复合物结构却长期是个难点。问题的根源在于糖链本身的化学复杂性：单糖单元种类繁多、连接方式（ linkage）和立体化学的组合空间极大，糖链又高度柔性，同一序列可以采取多种低能构象，而实验解析的蛋白-糖复合物结构在 PDB 中数量稀少、覆盖不均，导致数据驱动的结构预测模型严重缺乏监督信号。此前的方法大致分两类：一类直接把蛋白结构预测的通用框架（如 AlphaFold 系列）套用到糖链上，但这些模型主要在蛋白质和核酸数据上训练，对糖的环构象、糖苷键扭转角和连接特异性缺乏建模能力，往往给出化学上不合法或构象失真的糖链；另一类基于分子动力学或对接的物理方法虽然能保证几何合理性，但采样成本高、难以覆盖大构象空间，且对蛋白-糖界面的识别精度有限。因此真正的问题是：如何在保证糖链化学有效性和构象合理性的前提下，高效地采样出接近天然结合模式的蛋白-糖复合物结构。

GlycoWeave 的核心思路是把扩散生成过程放到糖链的内部坐标空间里做，而不是直接在笛卡尔坐标下预测原子位置。内部坐标（键长、键角、二面角）天然保证了糖环的连通性和立体化学不被破坏，模型只需专注于探索糖苷键的扭转组合，这大幅压缩了有效搜索空间，也让采样效率显著提升——论文报告每个构象采样仅需 0.34 秒。在表示层面，它设计了一个异质等变网络，把原子级的相互作用几何（蛋白侧链与糖羟基之间的氢键、堆积等界面细节）与单糖级的结构上下文（糖单元类型、连接方式、邻接关系）耦合起来，使模型既能感知局部化学环境，又能把握糖链的整体拓扑。训练策略上采用多源多头学习：一方面用实验解析的复合物结构做监督，另一方面引入经经典力场和量子力学势能修正过的结构作为补充数据，从而在实验数据稀疏的情况下仍能学到物理上合理的构象分布。相比 AlphaFold 3 这类通用模型，GlycoWeave 的优势不在于更大的网络，而在于把糖的化学先验（内部坐标约束、连接特异性、立体化学）显式编码进生成过程，使采样从一开始就落在化学合法的流形上，而不是先自由生成再靠后处理修正。

在包含 698 个蛋白-糖复合物的基准测试上，GlycoWeave 的 Top-25 高质量成功率（即采样 25 个构象中至少有一个达到高质量标准）达到 71.9%，而 AlphaFold 3 仅为 19.2%，差距接近四倍，同时单构象采样时间只有 0.34 秒，兼顾了精度与效率。论文还报告模型能保持糖链结构合法性、恢复天然的蛋白-糖相互作用接触，并重现不同糖苷键连接方式特有的构象偏好，且在多种糖链架构和蛋白环境下维持较高准确率。客观来看，局限仍然存在：基准规模（698 个复合物）相对有限，对稀有单糖、高度分支或带电荷修饰的糖链泛化能力还需更大规模验证；Top-25 指标本身也说明单次采样成功率仍有提升空间，实际应用中往往需要生成多个候选再筛选。尽管如此，这项工作把“化学约束的生成式建模”这一思路扎实地落到了蛋白-糖识别问题上，为糖生物学中结构预测这一长期短板提供了一个可用的、开源的专用工具，也提示了通用结构预测模型在特定化学体系上需要领域定制化改造的方向。

### [A unified coarse-grained neural network potential for the dynamics of biomolecular complexes](https://arxiv.org/abs/2610.37606)
`评分3`

这篇论文要解决的核心问题是生物分子复合物（尤其是蛋白-配体体系）在长时间尺度上的动力学采样效率问题。原子级分子动力学虽然能描述结合过程中的瞬态接触、构象变化和中间态，但结合事件本身是稀有事件，要重建完整路径往往需要数十微秒的累计采样和大量重复轨迹，计算代价极高。经典分子力学靠预设函数形式和拟合参数描述相互作用，精度受限于函数形式；全原子神经网络势虽然能从数据中学习灵活的多体表示，但对大体系（尤其加显式溶剂）每次力评估的开销仍然太大。混合方案（配体用神经网络势、蛋白和溶剂用经典力场）又需要为不同组分分别建模并显式处理交叉相互作用，工程复杂。粗粒化是另一条路，比如 Martini 力场通过减少相互作用位点平滑能量面，已能在毫秒级累计时间上做无偏结合模拟，但映射方式决定了保留哪些信息，效率和细节之间要权衡；而机器学习粗粒化势多依赖力匹配，面临投影力噪声大、需要大量原子级训练数据的问题，且现有蛋白粗粒化神经网络势大多只面向蛋白，映射方式无法自然扩展到化学多样的小分子，也就难以统一处理蛋白-配体交叉相互作用。

AMARO v2.0 的关键设计是在 v1.0 的 noh 映射基础上做统一化：每个重原子保留为一个粗粒化位点并沿用其原子质量，把该重原子所连氢原子的数目编码进珠类型（bead type），这样氢原子不显式出现但其化学信息被保留。蛋白侧原有 12 种珠类型（CH0–CH3、NH0–NH3、OH0–OH1、SH0–SH1），论文将其扩展到 26 种、覆盖 18 种元素，加入了 B、F、Si、P、Cl、Br、I 以及 Na、K、Ca、Mg、Co、Cu、Zn 等，从而让同一套表示同时适用于蛋白和类药小分子；溶剂和反离子被隐式处理，不进入映射体系。网络主干用 TensorNet2，一种基于笛卡尔张量表示的等变神经网络，并插入神经电荷均衡（NQE）模块来做总电荷条件化：这些模块预测每个位点的标量特征和再分配权重，再用体系总电荷对每个特征通道在整张图上做归一化，归一化后的特征进入后续消息传递。关键在于这些量只是隐特征，通过力匹配目标学习，既没有部分电荷或偶极矩的监督，也不用来计算显式的库仑能量项——网络直接输出一个标量有效势，力取其负梯度。训练目标是力匹配，采用 Krämer 等人的基本力聚合方案：对第 i 个 noh 珠，把该重原子上的力与其所连氢原子上的力按聚合规则合并成粗粒化目标力，从而把原子级力数据转成映射空间的监督信号。训练是顺序进行的：先量子力学小分子数据，再蛋白构象，最后蛋白-配体复合物。总电荷的来源也做了区分：小分子从分子元数据取形式电荷，蛋白和复合物则按 pH 7.45 下的残基质子化状态用 HTMD 赋值。这个设计之所以比之前的方法更统一，是因为同一套重原子映射和同一套网络不再区分蛋白与配体，交叉相互作用天然被同一个势描述，不需要为不同组分单独建模；隐式溶剂和反离子则直接减少了每次力评估的原子数，而 NQE 让网络能区分几何相似但电荷状态不同的构型，同时避免引入显式库仑项带来的刚性和参数化负担。

结果方面，论文先在泛素上验证折叠态稳定性：602 个珠、净电荷为零，两条独立 500 纳秒模拟中 noh-RMSD 主要维持在 1.5 到 3.0 埃，没有渐进漂移。在 α3D 和 villin 两个快速折叠蛋白上，用与 v1.0 相同的 TICA 加马尔可夫状态模型流程、各 32 条从全原子参考自由能面均匀选取的构象出发，v2.0 相比 v1.0 减少了 α3D 中心区域的过度采样、更接近全原子分布，villin 上则在晶体结构附近给出更明显的低自由能区。小分子力预测用 AceFF v2.0 基准（650 个构象、Schrödinger 配体集，含比训练集更大的分子），以 ωB97M-V/def2-TZVPPD 参考力映射后比较：AceFF v1.0 和 v2.0 的中位 MAE 分别为 0.061 和 0.047 eV/Å，小分子检查点 AMARO v2.0 (SM) 为 0.134 eV/Å，约为 AceFF v2.0 的三倍；最终检查点为 0.659 eV/Å，约为 SM 检查点的五倍，说明后续蛋白和蛋白-配体训练阶段存在精度权衡。不过动力学上最终检查点完成了全部 27 条 5 纳秒模拟（含 4 飞秒步长）而无数值不稳定，局部几何上 SM 检查点更接近 AceFF。胰蛋白酶-苯甲脒案例中，质子化苯甲脒在三条 100 纳秒重复里配体 RMSD 大多低于 1.75 埃、与 Asp171 的接触占有率持续很高，中性形式则出现明显位移和接触丢失，说明模型能区分两种质子化态。从 100 个未结合构象出发、初始配体-口袋距离约 15 到 35 埃、每条 50 纳秒，AMARO v2.0 在 42% 的轨迹中恢复参考结合姿态，全原子仅 4%；在每轨迹约 4 GPU 小时的固定预算下（对应 AMARO 27.3 纳秒、全原子 98.7 纳秒），AMARO 有 30% 轨迹至少一次到达参考姿态，全原子为 9%，相差 3.3 倍。结合自由能估计上，胰蛋白酶体系全原子给出 −5.80±0.39 kcal/mol、实验 −6.20 kcal/mol，而 AMARO v2.0 给出 −11.59±0.74 kcal/mol，比实验值有利约 5.39 kcal/mol，即能量上偏得更多。论文也明确点出局限：262 个复合物、11 个靶点上多数配体姿态能保留，但 HIF2A 三元复合物出现四级结构重定向；TYK2 能恢复参考结合姿态并支持结合自由能估计但数值偏有利；SHP2 在结合姿态恢复上有困难，CDK8 在位点特异性上有问题。总体意义在于，它给出了一个共享的重原子粗粒化神经势，用同一套表示和同一个势覆盖蛋白、类药小分子及其复合物乃至三元体系，在固定 GPU 预算下显著提高结合姿态恢复效率，同时保留了质子化态敏感性这类化学细节；但其结合自由能系统性偏有利、部分靶点姿态恢复和位点特异性不足，说明它目前更适合作为复合物动力学的共享势和采样加速工具，而非可直接替代全原子热力学计算的定量方法。

### [Structure, Not Sequence: Tracking and Validating Folding Mechanisms in ESMFold's Trunk with Sparse Autoencoders](https://arxiv.org/abs/2610.36226)
`评分3`

这篇论文瞄准的是一个结构生物学与机制可解释性交叉处的真实空白：像ESMFold这样的深度结构预测器已经能把氨基酸序列在秒级时间内折叠成三维结构，但序列到结构的计算过程始终是黑箱。此前针对蛋白质模型的可解释性工作几乎都集中在序列语言模型ESM-2上，用稀疏自编码器（SAE）从掩码语言建模的稠密嵌入中提取可解释特征，但这些字典只能触及序列语义，无法覆盖折叠主干中真正负责几何计算的部分。作者通过预实验给出了三条关键证据说明为什么不能直接套用旧方法：其一，用线性CKA度量ESM-2层与主干块之间的表示相似度，跨模型配对平均只有0.14，而主干块彼此之间平均高达0.65、中间层甚至到0.96，说明主干自组织出了一套与序列模型截然不同的相似性结构；其二，成对残基距离这类几何信息在主干独有的pair表示中线性可解码，而在任何单残基状态中几乎不存在，序列字典根本读不到这个对象；其三，功能位点信号在ESM-2第36层达到峰值后随主干深度衰减，而埋藏度等几何信号随深度增长，说明残基语义是从序列模型继承来的，几何则是在主干内部现算的。这三点共同构成了动机：要理解折叠，必须直接解释主干，而且要同时解释single和pair两种表示。

方法上的核心设计是一套三段式协议。首先在主干48个block中均匀取五个深度（第0、12、24、36、47块），对single表示和pair表示分别训练TopK稀疏自编码器，字典宽度8192、每token激活16个特征，训练语料是50万条UniRef50序列折叠产生的约9500万个单残基激活，并刻意让序列基线字典与主干字典共享相同的数据预算和优化配置以保证比较公平。其次，用推理型大语言模型对每个特征自动命名并归入七类概念（二级结构、埋藏、接触、功能位点、二硫键、化学、位置），single特征的prompt沿用InterPLM的管线，输入是该特征激活最强的残基及其结构功能环境；pair特征则需要新设计的prompt，因为此前工作没有处理过成对对象，prompt描述特征所激活的残基对群体并给出两端残基的上下文，让模型开放式地回答这对残基编码了什么关系。第三步是电路追踪：用积分梯度在真实ESMFold前向传播中把下游特征归因到上游编码，源端拼接所选表示的字典、目标端用自身字典编码，沿从零编码基线到实际上游编码的直线路径计算梯度，从而得到四种边——single到single、pair到pair的同域信息流，以及single写pair、pair写single的跨表示耦合，把概念组合成一张有向折叠电路。这套设计之所以比先前方法更强，关键在于它把评估建立在“相对序列模型的增量”上：对每个目标先在ESM-2第36层（主干对ESM-2各层的学习混合权重为0.90）拟合探针，再在相同状态拼接主干编码后拟合同样探针，读留出AUROC的差值，且对关系型目标统一给所有表示相同的成对交互特征，链方向还在共同距离壳内评分以排除邻近性冒充拓扑，这样就能干净地把主干真正新增的计算从继承的语义中剥离出来。

结果层面，主干编码在残基关系任务上相比语言模型状态最多提升0.32 AUROC的接触和链方向检测，而残基级属性（如埋藏、注释位点）在语言模型上本就可恢复，这一不对称恰好印证了“single承载继承语义、pair计算几何”的分工假设；特征还能在折叠结构上定位催化残基和二硫键等功能位点，且概念激活能预测模型自身的折叠质量——用岭探针从某块编码回归pLDDT和lDDT，在未见蛋白上报告留出R²，单个概念按与准确率的Spearman相关排序。局限也值得客观看待：研究只覆盖五个深度、单一模型ESMFold和固定k=16的字典配置，自动命名依赖推理LLM的判断、虽有留出上下文验证但仍有标签噪声风险，积分梯度电路是在单次recycle上做的（作者称跨recycle变化极小），因果验证也仅限于边级别的扰动确认而非全电路级别的充分性证明。尽管如此，这项工作把折叠主干从黑箱变成了稀疏、可解释、可科学验证的电路，首次系统解释了序列模型字典触及不到的pair几何计算，并示范了如何用概念激活反读模型自身的置信度，对蛋白质机制可解释性和AI辅助结构生物学都有直接的推进意义。

### [ProtAgent: Post-Training Compact Protein Tool Agents with Interaction-Level Credit Assignment](https://arxiv.org/abs/2610.33746)
`评分3 · 20 pages, 2 figures`

这篇论文要解决的是蛋白质功能注释智能体在真实工具环境中的训练问题。蛋白质注释本质上是一个证据整合任务：给定一条蛋白序列和一个注释目标（比如酶类、结构域、信号肽、无序区或GO/InterPro条目），智能体需要决定调用哪些生物信息学工具、解读异构的工具输出、并在收集到足够证据后给出答案。此前最强的系统如PFUA依赖在线前沿大模型在推理时调用工具，而它训练的小模型仅用最终答案重叠奖励做后训练，效果很快饱和。核心痛点在于：监督微调能教会模型工具调用的语法和基本路由，但无法直接优化“该收集什么证据、什么时候停止”这类决策；而只用单一的终端奖励，会把同样的信用分配给有用的调用、冗余的调用和格式错误的调用，模型无法从交互过程中学到哪些步骤真正贡献了最终答案。论文因此提出一个问题：紧凑模型能否在与真实工具交互的过程中、通过逐步反馈学会证据收集与利用？

方法上的关键设计是两阶段后训练管线加交互级信用分配。第一阶段用SFT在经校验的工具轨迹上教模型工具调用语法、任务到工具的路由和答案格式，这些轨迹包含真实工具输出而非模型生成的伪文本。第二阶段用标准的无critic的REINFORCE做在线策略训练，核心创新不在估计器本身，而在奖励分配的位置：作者把每个助手响应边界（一次工具调用或最终答案）定义为一个交互步，中间工具调用获得局部动作奖励（首次成功使用新工具加0.25，重复动作扣0.30，无关工具扣0.10，格式错误扣0.20，截断扣1.50），最终答案获得终端奖励，该奖励由训练时的注释覆盖率、必需工具覆盖、推理标记、效率和结构化答案兼容性加权组成，并乘以长度因子。关键在于用蒙特卡洛回报把这些信号沿同一轨迹回传：步级回报把每个奖励分配给产生它的响应以及之前的所有动作，而回合级基线则把整个回合的回报统一分配给每个动作。此外还有一个“已完成工具守卫”项，当没有任何工具成功执行时，代数上抵消掉格式正确但未调用工具所获得的模式奖励，防止模型刷格式分而不真正用工具。作者在三个随机种子上做了2×2的对照实验，同时变化回报粒度和回报归一化方式，发现步级回报在两种归一化下都大幅优于回合级回报，这说明细粒度的信用分配确实让模型学到了哪些交互步骤有价值。

在固定的闭环协议下（4步交互预算、真实生物信息学工具、1000条平衡测试集），ProtAgent-8B的注释覆盖率成功率达到61.00%，而DeepSeek-V3.2-Thinking 671B只有41.60%，最强的前沿系统为60.80%，也就是说一个本地8B模型在同等协议下超过了参数量大两个数量级的基线并与最强前沿系统持平。三种子对照中，步级回报平均成功率61.40%，回合级仅42.70%（恒等归一化下），组相对归一化下分别为58.20%和36.50%，差距稳定且显著。作者也坦承局限：该指标衡量的是对参考注释的恢复程度，并不直接证明生物学正确性或证据完全落地；信号肽任务中标签生成用SignalP 5.0而运行时用6.0，版本差异可能影响结果但未做受控测试；MMseqs2审计只排除了训练集同源重叠，不能保证测试蛋白在运行时数据库中不可检索。此外论文的信用分配方案是固定环境奖励加标准蒙特卡洛回报，并非新的通用估计器，其贡献在于在蛋白质工具环境中做了受控验证。这项工作的意义在于证明了紧凑模型通过交互级后训练可以在专业工具环境中达到前沿系统的水平，同时保持本地可部署，为低成本、可复现的科学智能体训练提供了一条务实路径。

### [PDRVLA: A Vision-Language-Action Model with Physical Dynamics Representations](https://arxiv.org/abs/2610.37381)

这篇论文要解决的是当前视觉-语言-动作模型（VLA）对物理世界动态理解不足这个真实瓶颈。现有的VLA模型虽然能借助预训练视觉语言模型把观察和指令映射到机器人控制，但近期分析发现它们对物体物理属性（比如质量）的编码很弱，动作也难以随物体质量变化而可靠调整。对于操作任务来说，只识别当前场景远远不够——抓取、移动、放置都会改变物体的构型和空间关系，如果能预判场景在交互过程中如何演化，就能为动作选择提供有价值的上下文。另一条思路是借助预训练视频世界模型来学习物理动态，因为这类模型天然会预测场景随时间的变化；但问题在于，如果把未来视频生成放进控制回路里，会引入很高的延迟，实时性无法保证。近期一些工作改为只在训练阶段用视频预测来塑造紧凑表征、推理时不再在线生成视频，PDRVLA正是沿着这个方向推进的。

核心创新是一个轻量的物理动态模块（Physical Dynamics Module），它从VLM中间层特征中抽取一组固定数量的“物理token”，动作专家在生成动作时同时使用这些物理token和VLM最后一层特征。关键在于这个模块怎么训练：它有两个互补的监督目标。其一是直接监督，用未来的RGB特征、深度特征和光流特征作为预测目标，迫使物理token编码未来的外观、几何和运动信息——这相当于让token在潜空间里“预演”场景会怎么变，而不是真的生成视频帧。其二是辅助监督，用一个冻结的预训练视频世界模型，以物理token为条件去做时序预测，从而把世界模型学到的动态先验蒸馏进这些token里。在联合策略训练阶段，动作损失、视觉语言损失和持续的未来预测损失一起优化，但部署时只跑学习到的物理token，完全不调用视频生成器，因此没有额外延迟。这个设计之所以比之前的方法更好，是因为它把“预测未来”的能力压缩进了紧凑的表征里，既保留了世界模型对物理动态的理解，又避免了在线生成视频的代价；同时物理token来自中间层而非最后一层，相当于给动作生成补充了最后一层特征里缺失的动态信息。数据方面，训练语料完全来自公开数据集，涵盖真实机器人轨迹、手持UMI演示和仿真交互，再通过自我中心人类视频到机器人的合成（把EgoDex的手部关键点重定向到12种机械臂、用分割和视频修复替换人手并渲染机器人）、子任务标注和具身思维链（ECoT）标注来扩充，动作统一表示为当前位姿到目标位姿的平移与旋转增量，夹爪动作为归一化的绝对目标开度。

在结果上，PDRVLA在四个仿真基准上取得了LIBERO 99.3%、LIBERO-Plus 89.9%、RoboTwin 2.0 93.6%、SimplerEnv 81.5%的成功率，这些数字在同类方法中属于很有竞争力的水平。消融实验显示，加入世界模型辅助监督后未来预测质量确实提升，同时论文还系统考察了子任务条件、未来物体位姿监督和ECoT训练对动作成功率的影响，说明这些设计各自有贡献而非堆砌。客观来说，论文的验证集中在仿真环境，真实机器人上的泛化能力尚未充分展示；物理token是否真的编码了可解释的物理量（如质量、摩擦）也没有直接分析，更多是间接通过成功率体现；此外整个数据管线依赖大量公开数据集和合成流程，合成数据与真实数据之间的分布差距可能影响迁移。尽管如此，这项工作指出了一个有价值的方向：不必在控制回路里跑视频生成，而是用世界模型作为训练期的“老师”来塑造紧凑的物理动态表征，这为VLA模型补上物理理解这一课提供了一条低延迟、可扩展的路径，对后续把世界模型知识蒸馏进策略网络的研究有直接的启发意义。

### [ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning](https://arxiv.org/abs/2610.37666)
`评分3 · HF 47赞`

这篇论文要解决的是视觉-语言-动作模型（VLA）在机器人操作中泛化能力受限的真实问题。当前 VLA 主要依赖带动作标注的机器人演示数据来学习策略，这类数据需要真实平台、特定于本体的接口和大量人力，行为覆盖面和环境多样性都很有限。人类视频虽然提供了远为丰富的行为与环境经验，却缺少可直接执行的机器人动作，因此从人类视频中学习一直面临"可扩展数据"与"显式动作接地"之间的根本权衡。已有路线大致分两类：一类是潜在动作模型，从帧对或帧序列中推断转移变量用于表示或策略学习，虽然天然可扩展到无标注视频，但这些变量约束不足，容易捕捉到外观变化或相机运动而非可控行为；另一类是全监督方法，通过恢复手部姿态、物体交互或重定向轨迹来提供显式运动监督，物理接地更强，但依赖精确的姿态估计和人到机器人的对应关系。另一条思路是利用未来观测作为监督信号，因为任何视频都记录了行为之后的后果，预测式世界模型和基于前瞻的 VLA 通过预测未来像素、视觉特征或轨迹来利用这一信号，但它们关注的是"什么发生了变化"，而推断导致这些变化的中间动力学仍然困难，尤其在没有动作标注的大规模人类视频上。论文由此提出一个自然的问题：能否让中间动作表示直接以其在世界中引发的动力学为依据，从而为不同本体提供共享的动作接口。

ThinkWorld 的核心设计是把每个"动作思考"表示成链式动力学（Chain-of-Dynamics, CoD），即一串离散的运动 token，刻画从当前世界到未来状态之间的中间动力学，并作为人类与机器人共享的动作表示。具体做法是：把机器人轨迹的运动片段和标注过的人手轨迹都映射到归一化的末端执行器增量表示，再用 FAST 风格的运动分词器离散化成共享词表里的 CoD 序列，VLM 在指令、视觉历史和当前观测条件下自回归地生成 CoD。仅有运动接地还不够，因为 CoD 本身并不说明它会引起怎样的世界变化，于是模型在 CoD 之后拼接一组可学习的未来查询，让 VLM 在视觉上下文和教师强制给出的 CoD 条件下把这些查询上下文化，再由一个轻量 Transformer 解码器映射到物理时间跨度 Δ 之后的未来表示。关键洞察是：预测目标不是重建未来 RGB 像素，而是在冻结的 DINO 特征空间中预测，DINO 特征保留稠密的空间与物体结构却抽象掉外观细节，使想象未来与观测未来可以按结构变化比较，而无需逼真的图像生成；目标表示由冻结 DINO 编码器编码真实未来帧得到，该帧只用于构造目标、从不作为 VLM 输入。训练时联合优化 CoD 生成与未来预测两个目标，而连续控制由动作专家消费被这些目标塑造过的 VLM 表示，而不是直接解码 CoD token。更关键的是第二阶段：仅靠教师强制下的未来预测并不能教会 VLM 规划通往目标未来所需的中间动力学，因此论文用"世界想象"做强化学习——对同一视觉上下文采样多条候选 CoD，各自想象其未来表示，再与观测未来在潜空间中比较，用运动增强的特征相似度打分，对当前到未来变化更大的图像块赋予更高权重，同时保留全场景的均匀贡献以维持全局一致性并防止冗余背景主导奖励；由于打分只用观测帧，不需要任何动作标注。随后用 GRPO 配合归一化的世界想象奖励更新 VLM，并用监督回放保持 SFT 阶段学到的运动接地，RL 期间其他组件全部冻结，部署时既不需要生成 CoD 也不需要未来预测。这样，无动作标注的视频也能通过"观测到的状态转移"提供直接监督，人类与机器人经验得以精炼同一个推理空间。

实验在仿真基准和真实机器人上展开，采用 Qwen3-VL-2B 作为 VLM 主干、MolmoAct2 的动作专家、DINOv3 提取未来表示，训练数据混合了 EgoDex、EgoVerse 等人类自我中心视频与 DROID、BimanualYAM、Bridge/RT-1、BC-Z、RoboCOIN 等机器人演示，SFT 与 RL 分别使用 128 和 64 块 H100。结果上，论文报告了在 LIBERO 等仿真基准以及真实双臂机器人平台上，ThinkWorld 相比基线在未见任务与环境上的泛化提升，并展示了人到机器人的技能迁移能力：机器人只需在组成任务的原子技能上接受机器人监督，就能执行人类视频中演示的完整任务，这说明无标注人类视频的规模扩展确实能反哺动作推理。客观来看，论文的局限也较明显：CoD 依赖将人手与机器人动作统一到末端执行器增量表示，这一归一化假设在灵巧操作或强运动学差异的本体上是否成立仍需验证；奖励完全建立在冻结 DINO 特征的潜空间相似度上，若未来变化主要体现在 DINO 不敏感的属性上，监督信号会变弱；RL 阶段需要采样多条候选轨迹，训练成本不低，且论文尚未系统给出 RL 规模与收益之间的饱和曲线。尽管如此，这篇工作的意义在于把"未来预测"从控制输出或策略优化的想象 rollout，转变为训练时强化动作推理的奖励信号，从而把无标注视频中的世界变化直接转化为动作推理的监督，为跨本体共享动作表示与人类视频规模化利用提供了一条较为自洽的技术路径。
